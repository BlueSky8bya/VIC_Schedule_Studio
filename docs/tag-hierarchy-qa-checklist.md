# 2계층 태그 리팩토링 — 확인 체크리스트

작성: 2026-06-03 · 범위: PR1~PR6 전부 구현·배포 완료. 계획서: `docs/tag-hierarchy-plan.md`.
DB 마이그레이션 `0036_tag_parent.sql` 적용 완료. 일어나서 아래만 눈으로 확인하면 됩니다.

> 핵심 아이디어: **데이터(무제한 계층 태그)와 시각(소수 대분류 색)을 분리**.
> 색은 대분류에만(≤12색), 세부는 무제한(부모 색 상속). 카드 색은 대분류 ≤2 + 나머지는 점 줄.
> 필터는 전체 태그 집합으로 매칭 → "하루 6개 천장"이 사라짐.

---

## A. 태그 편집기 (태그 관리 모달) — 가장 먼저 여기서 세부 태그를 만들어야 나머지가 보입니다

- [ ] 대분류(기존 태그들)마다 아래에 **"세부 추가"** 점선 버튼이 있다.
- [ ] **세부 추가** → 들여쓰기된 세부 행(┗)이 생기고, 색 스와치 대신 **부모 색 칩**만 보인다(색 못 고름).
- [ ] 세부 이름 수정·삭제 가능. 대분류만 드래그로 순서 변경(세부는 드래그 없음).
- [ ] 대분류는 색 선택, **같은 색 두 대분류 금지**는 그대로(세부는 색 안 겹쳐도 됨).
- [ ] 휴뱅은 여전히 잠금(이름·색·순서·삭제 불가, 세부 추가 버튼 없음).
- [ ] "전체 저장" 후 새로고침해도 대분류-세부 구조가 유지된다.
- [ ] 태그 총 개수 상한이 120개로 늘었다(예전 20).
- [ ] 예시로 만들어 보기: **게임**(대분류) 아래 **롤·명조·실크송**(세부) 3개.

## B. 일정에 태그 달기 (이벤트 태그 피커)

- [ ] 일정 편집 카드의 태그 영역이 **검색창 + 대분류 행 + 세부 칩** 형태다.
- [ ] **검색**("롤") 치면 매칭되는 세부/대분류만 추려진다.
- [ ] 한 일정에 **최대 6개**까지 태그가 붙는다(예전 2개). 선택 칩에 **순번(1·2·3…)** 표시.
- [ ] 6개 다 차면 나머지 칩이 흐려지고 안 눌린다. 카운트 `N/6` 표시.
- [ ] 세부 칩은 부모 대분류 색을 따라 보인다(점선 테두리로 세부 구분).
- [ ] 데스크톱·모바일·매니저(상세/시트) 피커 **모두** 같은 방식.

## C. 캘린더 카드 색 (시각) — 핵심

- [ ] 한 일정에 **같은 대분류 세부 여러 개**(게임>롤+명조)를 달면 → 카드 색은 **게임 한 색**(안 쪼개짐).
- [ ] **서로 다른 대분류 2개**면 → 두 색 그라데이션(기존과 동일).
- [ ] **대분류 3개 이상**이면 → ≤2색 + 카드 아래 **작은 색 점 줄**로 나머지 대분류 표시.
- [ ] 웹 그리드·모바일 아젠다·**공개 포스터**(그리드/아젠다) 모두 점 줄이 보인다.
- [ ] 업 도움(🌱) 카드엔 점 줄 없음(정상).

## D. 색상 필터 (색상 안내)

- [ ] 색상 안내/필터에 **대분류만** 나온다(한 색 = 한 칩). 세부는 안 나옴.
- [ ] **대분류를 필터로 누르면** → 그 대분류의 **세부를 가진 일정까지** 강조된다(색 안 칠해진 세부도 포함).
      → 이게 "하루 6개 천장" 해결: 카드에 색으로 안 보여도 데이터로 필터됨.
- [ ] 스튜디오 좌측·모바일, 포스터 세로·아젠다 레전드 모두 동일.

## E. 인사이트 통계 (월별 인사이트)

- [ ] "이번 달 컨텐츠 순위"에서 **세부가 대분류로 합산**된다(롤 12 + 명조 10 → 게임 22).
- [ ] 트렌드의 "태그별 컨텐츠"·"하트 받은 태그"도 **대분류 단위**로 집계.
- [ ] 개발자 인사이트와 매니저/작업자/소유자 인사이트(member-insights) **둘 다** 그렇게 보인다.
- [ ] 휴뱅은 통계에서 계속 제외.

## F. 회귀 (기존 동작 유지)

- [ ] 세부 태그를 하나도 안 만든 상태(전부 대분류)면 **이전과 똑같이** 동작한다(색·필터·통계).
- [ ] 일정 생성/드래그 이동/순서/저장 정상. 비공개(엠바고/작업자) 점선·경계 정상.
- [ ] 포스터/내보내기에 점 줄만 추가될 뿐 admin UI 없음.
