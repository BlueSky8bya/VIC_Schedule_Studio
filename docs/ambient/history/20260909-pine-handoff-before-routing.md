````markdown
### 프롬프트 다시 뽑기

`.scratch-pw/`는 추적하지 않으므로 다른 기기엔 없다. 두 길 중 하나:

- **아트 보드**(권장): `/studio/ambient-art`(개발자) → 자리를 누르면 `/studio/ambient-art/tree-pine` →
  **「이 자리 프롬프트」** 또는 **「남은 N장만」**. 목록 상단의 **「남은 파일만」**은 보이는 자리 전부를 한 장으로 만든다.
- **스크립트**: 임시 테스트 파일을 만들어 `batchPrompt`를 호출한다(매니페스트가 정본이므로 표와 프롬프트는 어긋나지 않는다).

```ts
// tests/unit/zz-dump.test.ts (쓰고 나면 지운다)
import { describe, it } from "vitest";
import fs from "node:fs";
import { ART_SLOTS, batchPrompt } from "@/components/shared/ambient/art/manifest";
describe("dump", () => {
  it("d", () => {
    const ids = (process.env.ART_IDS || "rock").split(",");
    const files = (process.env.ART_FILES || "").split(",").filter(Boolean);
    const slots = ART_SLOTS.filter((s) => ids.includes(s.id));
    const note = process.env.ART_NOTE || undefined;
    fs.writeFileSync(".scratch-pw/out.md", batchPrompt(slots, process.env.ART_TITLE || "배치", { ...(files.length ? { files } : {}), ...(note ? { note } : {}) }), "utf8");
  });
});
```

ART_IDS=tree-pine,tree-pine-autumn,tree-pine-winter ART_TITLE="소나무 21장 재작업" npx vitest run tests/unit/zz-dump.test.ts
```

한 번에 재는 것(⚠가 붙으면 목표 미달, `← 기준`은 합격본 줄):

**판정은 절대 수치가 아니라 그 자리의 합격본 대비다.** 자리마다 도트 굵기·물체 모양이 달라 고정 임계값은 반드시 헛짚는다
(겨울 참나무의 앙상한 가지, 몸통 100칸짜리 바위, 길고 옅은 새털구름이 전부 "결함"으로 잡혔지만 셋 다 합격한 그림이다).
합격본이 없는 자리는 **큰 파탄만** 본다.

| 검사 | 합격본 대비 목표 | 왜 |
|---|---|---|
| 도트 결 | 가로 런 −15% 이내 · 변화 밀도 +25% 이내 | 스티플이면 합격본과 어법이 갈린다 |
| **고아 칸** | +5%p 이내 | 이웃에 같은 색이 없는 한 칸 = 화면의 먼지 |
| **갇힌 얼룩** | +8 이내(천 칸당) | 소유자가 "구멍이 뻥 뚫렸다"고 부르는 것 |
| **외곽선** | −8%p 이내 · 끊긴 곳 +6 이내 | "선이 중간에 끊겨 있다" |
| 다양성 | 어느 두 장도 실루엣 일치 < 80% | 한 화면에 열여섯 그루가 선다(PLAN-009 규칙) |
| 계절 짝 | `-n`끼리 ≥ 95% | 어긋나면 달을 넘길 때 나무가 바뀐다 |
| 눈(겨울)·잎 색상(가을) | 눈 −3%p 이내 · 노랑기 +10%p 이내 | 아래 반려 ②④ |

**구조 결함 셋은 도트 격자 위에서 잰다** — 블록 크기는 그림에서 추정한다(정렬된 b×b 칸이 단색인 비율 95% 이상인 가장 큰 b).
화소 단위로 재면 한 도트 안의 계단이 전부 결함으로 잡힌다. 눈 색 경계 칸은 외곽선 판정에서 뺀다 — 안 빼면 겨울판이
구조적으로 전부 걸린다(합격본 겨울 소나무가 71.7%였다가 제외 후 97.1%).
**모든 지표는 도트 칸 단위로 잰다** — px로 재면 소나무에 맞춘 기준이 새털구름을 잡는다(같은 그림이 px로는 12.9, 칸으로는 5.9다).
실측 대비(합격 → 반려): 고아 **5.5% → 16~21%** · 얼룩 **1.3 → 최대 31** · 외곽선 96.4% → 85~92% · 가로 런 **2.47칸 → 1.67~1.89칸**.
전수 검사에서 배달 완료본 43장 중 **오탐 0**, 진짜 발견 2건(구름 변형이 서로 너무 닮았다 — `cloud-low` 최대 83.5%, `cloud-mid` 80.7%).
프롬프트 쪽에도 같은 넷이 **「제출 전 자기 점검」**으로 들어가 있다(`ART_STYLE_GUIDE`) — 다만 **줄이는 장치이지 막는 장치가 아니다.**
막는 것은 이 검사다.

수치는 **폭 240으로 맞춘 뒤** 잰다 — 1024 원본과 정리본(240×432)을 그냥 비교하면 축소가 만든 잡음을 화풍 차이로 읽는다
(정리 전후로 재 보고 확인했다: 값이 같다).
색 수·반투명·채움비·떠 있는 가로줄은 `npm run art:normalize`가 이미 잰다. **대조표**(3계절 × 8을 한 장에)는 아직 없다 —
필요하면 알파 상자로 잘라 같은 높이로 세우면 실루엣 차이가 바로 보인다.
````
