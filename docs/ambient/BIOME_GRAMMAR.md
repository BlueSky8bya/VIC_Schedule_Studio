# 바이옴 문법(Biome Grammar) — 열한 화면의 시각 규칙(2026-09-05)

> 에이전트(검사)와 구현(장면 코드)이 **같이 참조하는 구체 규칙**. 추상어 대신 수치·자리·조건으로 적는다.
> 좌표는 `world/view.ts` 정규화 v(지평선 아래 0 → 화면 아래 1), 크기는 `world/scale.ts SIZE`(근경 1× px, 원경은 `depthScale .6→1`).
> 기준 화면 1400×860. 시간·날씨 공통 규칙은 [SEASON_TIME_WEATHER_GRAMMAR](SEASON_TIME_WEATHER_GRAMMAR.md), 산 전용은 [MOUNTAIN_DEPTH_RULES](MOUNTAIN_DEPTH_RULES.md), 판정은 [IMMERSION_BREAK_RULES](IMMERSION_BREAK_RULES.md).
> 지도: 계곡·민물·산 / 언덕·★초원·숲 / 갯벌·모래해안·암석해안 / 먼바다 / 깊은 바다(`world/biomes.ts`).

## 공통 규칙

### 공통 층 구성(3/4 카메라)

| 층 | v | 무엇 | 크기·값 |
|---|---|---|---|
| 하늘·지평선 띠 | y < hz(**.30h** — 2026-09-06 하늘 확대) ~ v .0 | 안개·먼 언덕 실루엣·수평선. **땅의 것은 없다** | `bakeHorizon` |
| 원경 | v 0 ~ .20 | 작은 것들이 **촘촘히**(비스듬한 시점은 먼 땅을 압축한다) · 나무 줄·먼 무리 | `depthScale .6~.68`, `depthFade .78`, 안개 α 최대 |
| 중경 | v .20 ~ .55 | 화면의 주제(빈터·물길·노두·물가) | `.68~.86` |
| 근경 | v .55 ~ 1.0 | 큰 소품·잘리는 나무·초점 바위. 화면 아래에서 **잘리는 것** 1~2개(가까움의 신호) | `.86~1.0`, 안개 0 |

- 지평선 높이는 **전 바이옴 동일**(.12) — 화면을 넘나들 때 카메라가 튀지 않게(라운드2 결정).
- y-sort: 서 있는 것은 발 위치 y로 매 프레임 정렬. 바탕에 구운 큰 소품과 매 프레임 그리는 나무·생물 사이도 순서가 맞아야 한다(구운 소품이 나무 앞에 있으면 나무 뒤로 못 들어간다 → 큰 소품은 바탕이 아니라 정렬 목록에).

### 공통 간격 규칙(visual spacing — 충돌이 아니라 실루엣 기준)

거리 = 발 위치 중심 간, 세로는 `/0.7`(눌린 바닥) 보정. R = 수관 반지름, W = 소품 폭(모두 `depthScale` 적용 후).

| 관계 | 최소 거리 | 예외(군집) | 위반 시 |
|---|---|---|---|
| 나무–나무 | ≥ 0.85·(R1+R2) (겹침 ≤ 15%) | 무리 안에서는 ≥ 0.6·(R1+R2), 무리 크기 ≤ 4, 무리 안 크기 편차 ≥ 1.25× | S-1 P1 |
| 나무–바위 | ≥ R_tree·0.9 + W_rock/2 | 줄기 바로 옆 "뿌리 바위" 1개 허용(≤ W_rock 0.5·R) | S-1 |
| 나무–관목 | ≥ 0.5·R + W/2 | — | S-1 P2 |
| 나무–그루터기/통나무 | ≥ 1.2·W | — | S-1 |
| 바위–바위 | ≥ 1.1·(W1+W2)/2 | **노두**: 맞닿음 허용, 단 큰 것 1 + 작은 것 ≤ 5, 크기비 ≥ 1.4, 결 방향 하나 | S-1 P1 |
| 관목–관목 | ≥ 0.9·(W1+W2)/2 | 울타리 띠(해안 사구 뒤)만 맞닿음 허용 | S-1 P2 |
| 버섯 | 군집 2~3 ≤ 24px, **나무·그루터기·통나무 90px 안**에만 | — | S-2 |
| 꽃·풀포기 | 겹침 허용(무리 1~7, 퍼짐 26~80px) | — | R-1로만 판정 |
| 물가 소품 | 물 폴리곤 안 금지(잠긴 규칙으로 그리는 것 제외) | — | S-2 P0 |
| 생물–생물 | boids 분리(같은 종 ≥ 몸 폭) | 무리 종(물고기·참새) 예외 | A-3 |

- 배치는 **`claimSpot` 경유가 기본**(`art/props.ts`). 지금 미경유: 숲 나무·언덕 풀·계곡 수변 풀(풀은 예외). 관계별 반경 표는 `world/spacing.ts`(신설 예정)에 코드로 둔다.
- **군집 형태**: 완전 무작위(벽지)도, 등간격(가로수)도 아니다. 무리 중심을 뽑고(포아송 반경 ≥ 무리 지름) 무리 안에서 각도·거리를 흩는다. 무리 수 × 무리 크기 = 목표 밀도.

### 공통 물가 규칙

- 물 폴리곤은 `claimSpot`에 **가장 먼저** 등록(ADR-0017 ⑱-20). 뒤에 놓이는 것은 물 위에 못 선다.
- 물가 40px 띠는 **비어 있지 않다**: 사초·갈대·젖은 바위·자갈 둔치 중 둘 이상. 잔디 마진(공원)은 금지.
- **잠긴 돌**(계곡·민물·암석해안 웅덩이): 2단 그리기 — 수면선 위 = 원래 소품, 수면선 아래 = 물색으로 물든 사본(α .55~.7, 위로 갈수록 투명) + 수면선에서 **젖은 띠**(2~3px, L −10) + 앞 반원 수면선(뒤 반원은 몸에 가려짐) + 잔물결 1~2줄(계곡은 상류 쪽 흰 물살 + 하류 후류). 잠긴 깊이는 y 오프셋으로 말한다(8k = 발치만 · 18k = 절반). **잘라내기만(clip) 금지**.
- 물과 뭍의 명도가 갈린다(겨울 얼음 vs 눈밭 ΔL ≥ 8).

### 공통 생물 규칙(스폰·표면·레이어)

| 항목 | 규칙 |
|---|---|
| 스폰 v | 땅 위 종: **v ∈ [.18, 1.0]**. 원경이 흐린 시간대(새벽·밤·안개)는 v ≥ .25. 물 위 종: 물 폴리곤 안. 물속 그림자: 물 폴리곤 안 + 기슭 24px 밖. 나는 종: 어디든, 단 그림자는 땅 위 v ≥ .12 |
| 출입 가장자리 | 땅 위 종: **좌·우·아래** 셋. 위(지평선)는 나는 종·그림자만. 물속: 물 폴리곤 가장자리 |
| 허용 표면 | 종 카드(`species.ts`)에 `surfaces: ("ground"\|"snow"\|"sand"\|"mud"\|"rock"\|"log"\|"ice"\|"water"\|"air")[]`(신설 예정). 지금은 장면 코드가 암묵적으로 정함 |
| 금지 구역 | 지평선 띠(v < .12)·하늘·능선(산 ②층)·물 폴리곤(비수생)·핫 존(달력) 안 스폰 |
| 지면 접촉 | 그림자는 발밑(오프셋 ≤ 4·6px×k), 점프·비행에서만 분리 |

| 퇴장 | 몸을 돌려 화면 밖으로. 페이드·소멸 금지 |
| 공중 보행 판정 | 걷는 종 y < `groundY(.12)` → **P0**(A-1). 스폰 `gy() − n` → P0 |
