# 몰입 파괴 판정 규칙(2026-09-05)

> 세 검사 에이전트와 통합 판단(triage)이 **같은 잣대**로 심각도를 매기게 하는 문서. "예쁜가"가 아니라 "이상한가"를 판정한다.
> 방향: [VISUAL_DIRECTION](VISUAL_DIRECTION.md). 절차: [VISUAL_QA_PROTOCOL](VISUAL_QA_PROTOCOL.md).

## 1. 심각도

| 등급 | 정의 | 예 | 처리 |
|---|---|---|---|
| **P0** | 명백한 버그 — 규칙·물리·레이어가 깨져 "잘못됐다"가 즉시 보인다 | 동물이 하늘/지평선 띠를 걷는다 · 렌더 오류 · 금지 날씨 조합 · 물 위에 선 바위/관목 · 순간이동·랩 점프 · 페이지 에러 | 다음 라운드 최우선. 수정 없이 넘기지 않는다 |
| **P1** | 몰입을 크게 깨는 품질 문제 — 첫눈에 "어색하다" | 갯골이 도형 이음 · 잘린/얹힌 돌 · 겹친 수관 · 산/능선 모호 · 날씨가 오버레이(3열 미만 반응) · 시간대가 틴트뿐 · 반투명 원경 겹침 | 라운드당 2~3건 안에서 우선 |
| **P2** | 눈에 띄는 개선 필요 — 보면 안다, 보지 않으면 모른다 | 반복 패턴 감지 · 밀도 리듬 밋밋 · 그림자 방향 불일치 · 안개가 세로 층 | 상황에 따라 |
| **P3** | 취향·폴리싱 | 색 미세 조정 · 소품 한 종 추가 · 애니 곡선 취향 | **소유자 요청 없이 손대지 않는다** |

**신뢰도(Confidence)**: 높음 = 코드 경로까지 확인 · 중간 = 캡처에서 반복 관찰 · 낮음 = 한 장에서만 봄/주관. 낮음은 P0로 올리지 않는다(재현 먼저).

## 4. 동물·소형 생물 판정 기준(상세)

- **스폰 위치**: 땅 위 종은 `v ∈ [0.18, 1.0]`에서만 태어난다(지평선 띠 .12 + 여유 .06). 가장자리 출입은 **좌·우·아래 셋**. 위(지평선)로는 **날거나 그림자인 것만** 출입.
- **이동 표면**: 종별 허용 표면(BIOME_GRAMMAR 바이옴 표): 땅·눈·모래·뻘·바위·통나무·얼음. 물 위는 오리·소금쟁이·연잎 위 개구리만. 물속은 그림자만.
- **지면 접촉**: 발밑 그림자 중심이 발 위치에서 (0~4, 0~6)px 이내(원근 배율 적용). 점프·비행 중에만 분리되고, 분리량이 높이를 말한다.
- **가림(occlusion)**: y-sort. 동물이 나무 줄기 y 뒤로 가면 수관에 가려진다. 물속 그림자는 연잎·오리·바위에 가려진다.
- **속도·원근**: 위치 적분에 `moveScale(y)` 곱. 지평선 쪽에서 근경 속도로 달리면 A-2.
- **퇴장**: 반드시 화면 밖으로 몸을 돌려 걸어/날아/헤엄쳐 나간다. 알파 페이드로 사라지지 않는다(ADR-0017 ⑪ 원칙).
- **애니 판정**: 걷는데 다리·몸 상하 운동이 없으면(미끄러짐) A-2 P1. 방향 전환은 회전 속도 ≤ 5rad/s. 정지 → 이동 사이에 예비 동작(anticipation)이 있으면 가점(P3 폴리싱).

## 5. 검사에서 쓰는 자동 지표(전수검사 후보, PLAN-005 P2)

| 지표 | 계산 | 임계 |
|---|---|---|
| `airWalk` | 걷는 종 개체 중 `y < groundY(0.12)` 비율(debug 위치 노출 필요) | > 0 → P0 |
| `overlapRatio` | `propField` 쌍 중 `dist < 0.7·(r1+r2)` 비율 | > 8% → P1 |
| `layerDeltaL` | 산/언덕: 층 경계 상하 12px 평균 L 차 | < 8 → D-1 |
| `bandDelta` | 인접 시간대 쌍의 (지면 ΔL, 그림자 길이비, 하늘색 ΔE) 중 눈에 띄는 채널 수 | < 2 → T-1 |
| `weatherDelta` | 같은 시드·시각의 맑음 대비 날씨 프레임에서 바뀐 열 수(7열 중) | < 3 → W-1 |
| `loopSeam` | 시간 시트 인접 프레임 diff에서 국소 블록/선 에너지 | 임계 초과 → M-2 |
| `phaseSync` | 같은 종류 움직이는 요소들의 위치 시계열 상관 | > .9 → M-1 |
| `forbiddenCombo` | `forceWorld` 값 ∉ `weatherOptionsForMonth(m)` | 있음 → W-2 |
