# 코덱스에 보낸 프롬프트 (스냅숏)

정본은 **매니페스트**(`components/shared/ambient/art/manifest.ts`)이고, 여기 파일은 **그때 실제로 보낸 것**의 사본이다.
왜 남기나 — 프롬프트는 `.scratch-pw/`(추적 안 함)에서 뽑아 쓰는데, 기기가 바뀌면 사라져서 "무엇을 부탁했는지"를
납품물과 대조할 수 없다. 반려 사유를 쓰려면 그때의 지시가 있어야 한다.

새로 뽑는 법은 [../HANDOFF-20260908-pine.md](../HANDOFF-20260908-pine.md) "프롬프트 다시 뽑기" 참조
(아트 보드의 자리 상세 → 「이 자리 프롬프트」가 가장 쉽다).
