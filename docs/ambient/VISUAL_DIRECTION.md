# 앰비언트 비주얼 방향 — 코지·감성·몰입(2026-09-05)

> 이 문서는 계절 배경(바이옴 세계)의 **최상위 판단 기준**이다. 규칙 문서(BIOME_GRAMMAR·SEASON_TIME_WEATHER_GRAMMAR·
> MOUNTAIN_DEPTH_RULES·IMMERSION_BREAK_RULES)가 서로 부딪히면 여기로 돌아온다. 소유자 지시(2026-09-05)를 장기 규칙으로 옮긴 것.
> 상위: CLAUDE.md "Philosophy · Owner-fit palette rule"(오행 팔레트 — 이 문서보다 위다).

## 1. 목표 한 줄

**"모여봐요 동물의 숲"처럼 부드럽고 포근한, 몰입이 깨지지 않는 작은 세계.** 더 화려한 배경이 아니라 **더 자연스럽고 덜 거슬리는** 배경.

## 2. 우선순위(위가 이긴다)

1. **몰입 파괴 요소 제거 > 새것 추가.** 이상한 점 하나가 예쁜 점 열을 지운다. 새 동물·식물은 배경 문법이 정리된 뒤에.
2. **불쾌한 골짜기 0.** 사실적이려다 어색한 것보다 단순한 게 낫다. 단, "이상한 단순화"(도형 이어붙임·스티커 뿌리기)도 골짜기다.
3. **일관된 시각 문법.** 스타일화된 세계는 규칙이 하나면 믿긴다 — 카메라(3/4), 축척(타일 64), 픽셀아트, 오행 팔레트, 안개·그림자 규칙.
4. **환경은 상태에 반응한다.** 계절·시간대·날씨는 "오버레이"가 아니라 땅·물·하늘·식생·생물이 함께 바뀌는 **상태**다.
5. **잘 되는 것은 건드리지 않는다.** 한 라운드에 상위 2~3건만. P3(취향)는 소유자 요청 없이 손대지 않는다.

## 3. 감성의 정의(에이전트 A가 판단하는 것)

- **부드러움**: 각진 형태·전폭 직선·하드 에지 그라데이션 금지. 값(L) 단계는 3~5단, 채도는 낮게, 대비는 생명체에만.
- **포근함**: 화면 어디에도 "위협적인 검은 덩어리"가 없다(어두운 얼룩 금지 규칙). 밤도 정보가 남는 밤.
- **살아 있음**: 정적인 판이 아니다. 작은 것이 계속 조금씩 움직인다(풀·물·빛·생물). 단, 같은 위상으로 흔들리면 기계다.
- **읽힘**: 1초 안에 "여기가 어디(바이옴)·언제(계절·시간대)·어떤 날(날씨)"이 읽혀야 한다. 읽히지 않는 정보는 없는 것이다.
- **리듬**: 빈 곳과 찬 곳이 있다. 균일 산포는 벽지, 한 곳 몰림은 스티커.

## 4. 공간의 정의(에이전트 B가 판단하는 것)

- **"왜 저게 저기 있는가"에 답이 있어야 한다.** 바위는 노두·물가·비탈에, 나무는 무리와 빈터에, 게 구멍은 둔치에.
- **충돌(collision)이 아니라 시각 간격(visual spacing).** 안 겹쳐도 실루엣이 맞닿으면 뭉개진다. 관계별 최소 거리 표([BIOME_GRAMMAR §공통 간격](BIOME_GRAMMAR.md#공통-간격-규칙)).
- **접촉 관계.** 물에 잠긴 돌은 잠긴 만큼 물의 영향을 받는다. 눈 위의 것은 눈이 얹힌다. 모래 위의 것은 그림자가 있다.
- **층(전경·중경·후경)이 같은 평면이 아니다.** 크기·명도·채도·안개·겹침 다섯 단서가 같은 방향을 가리킨다.
- **생물은 존재 가능한 표면 위에만.** 땅 위 동물은 지평선 띠·하늘·물 위를 걷지 않는다. 그림자는 발밑에.

## 5. 시간의 정의(에이전트 C가 판단하는 것)

- **시간대는 눈에 띄되 필터가 아니다.** 새벽·아침·점심·노을·저녁·밤 여섯이 각각 정서로 구분된다([SEASON_TIME_WEATHER_GRAMMAR §2](SEASON_TIME_WEATHER_GRAMMAR.md#2-시간대-문법)).
- **날씨는 환경 상태다.** 비면 하늘·지면·수면·원경이 같이 젖고, 바람이면 풀·작은 나무·큰 나무가 다르게 흔들리고, 안개는 깊이로 감쇠한다.
- **루프는 안 튄다.** 랩·리셋·순간이동 금지. 큰 것과 작은 것의 반응 시간이 다르다.
- **동물의 움직임은 표면·레이어와 싸우지 않는다.**

## 7. 이 방향이 금지하는 것(빠른 판독표)

| 금지 | 왜 |
|---|---|
| 화면 전체 단색 필터로 시간대를 말하기 | "존재"는 하나 "읽히지" 않는다 — 정서 차이가 없다 |
| 등간격·같은 크기·같은 y의 반복 | 방풍림 열·빗살·벽지 |
| 겹친 수관·맞닿은 바위 | 실루엣 붕괴 = 스티커 |
| 반투명 원경 레이어 겹치기 | 셀로판 두 장 — 산/능선 모호성의 원인 |
| 지평선 위·띠 안에서 걷는 동물 | 공중 보행 = 가장 강한 몰입 파괴 |
| 도형 이어붙인 물길·잘린 돌 | 접촉 관계 부재 |
| 오버레이 날씨(비인데 땅이 마른 색) | 환경이 반응하지 않는다 |
| 사실주의로의 도피 | 골짜기. 단순하되 이상하지 않게 |
