# 합격본 레퍼런스 시트

`node scripts/ambient-art-reference.mjs <family 또는 slot>` → `<id>.png`.
정확한 파일 이름은 manifest `slotFiles()`에서 읽는다. singleton도 지원한다.
명시된 소나무 family는 세 계절을 함께 싣고, 그때만 밑동·눈 확대를 추가한다.
참나무·물고기 등 다른 자리에 소나무의 "밑동 한 덩이" 규칙을 적용하지 않는다.

시트는 합격본을 알파 경계로 자른 뒤 **정수배만** 확대한다. 합격본이 없는 자리는 없는 것을 기준으로 삼지 않는다.
대신 [스타일 파일럿 절차](../ART_PIPELINE.md)로 첫 합격본을 만든다.

새 요청은 시트를 `inputs/reference/`에 복사하고 해시를 기록한다. 현재 시트가 나중에 바뀌어도 과거 요청의 입력은 변하지 않는다.
합격본이 바뀌었을 때 이 폴더의 시트를 다시 생성한다. 기존 요청에 들어간 사본은 다시 굽지 않는다.

3차 소나무는 당시 측정한 항목을 통과해도 눈 위치·밑동 모양이 틀렸다. 이것은 지표의 한계를 보여준다.
"생성기가 파일을 못 봤다" 또는 "그림이면 실패하지 않는다"는 결론은 입증되지 않았다.
파일을 확인한 에이전트는 실제 연 경로·관찰한 특징·이미지 생성기에 전달한 참고를 따로 기록한다.

새 납품 검토에는 `review.png`(화면 CSS px 크기)와 `review-detail.png`(정수배 확대)를 함께 쓴다.
반려 예시는 REJECTED 라벨·문제 crop·기대 형태를 붙인 실패 설명이며, 이 폴더의 화풍 기준선으로 섞지 않는다.
