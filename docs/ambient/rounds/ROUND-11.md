## 수정

### ① 안개 밀도장 — `world/fog.ts`

옛 `groundFog`는 세 부품이었다: 화면 좌표 4-stop 세로 그라데이션 + `hz + .3(h−hz)` 고정 띠 + 바닥 8%f. 이제 **F(x, y) = 깊이항 × 고도항 × 결**:
- 깊이항 `fogDepth(v)` = .05 + .5·(1 − v)^1.6 — 지평선 아래 땅 비율 v로 **단조 감소**(원경 .55 → 근경 .05). 돌출 금지.
- 고도항 = 1 − (floor(x) − y) / H_fog(땅 높이의 22%) — 장면의 **`fogFloor(x)`** 위로 뜬 만큼 옅다(저지대 체류, 능선·수관 노출). 지면선 아래(물 속·땅 속)는 1.
- 결 = 32×32 값 노이즈 두 옥타브(윗변 ±15%, 안쪽 저주파 얼룩) — 전폭 직선 행 금지.
- 발치(v ≥ .7)는 0으로 수렴(관찰자 발까지 안개를 깔면 "필터"). 지평선 위는 .06h 꼬리만.
- 1/8 해상에 굽고 확대(LOD). 캐시 키 = 크기·밀도·색·`fogFloorKey`(조명 전이 중 프레임마다 굽지 않게).

장면별 `fogFloor(x)`(B 부록 A): 언덕 = 가운데 띠 능선 `hillRidge(1, x)`(bake의 지역 함수를 `hillRidgeFn`으로 노출) · 산 = ③ 애추 띠 윗변
`screeBand.top(x)`(안개가 ② 발치에 쌓인다, MOUNTAIN §4) · 계곡 = 그 열의 최근접 유로 점 y · 민물 = `waterTopAt(x)` · 해안 = `shoreY() + shoreOffsetAt(x)` ·
초원·숲 = 평지(엔진 기본). 엔진(`scene-engine.ts drawOnce`)이 `drawLightPass(…, fogFloor, fogFloorKey)`로 넘긴다.

소비자 셋: `depthFade(y, h)`가 `currentLight().groundFog`를 읽어 발 y의 밀도장만큼 개체를 더 옅게(나무·생물·낙엽·소품 그림자 열 곳이 한 줄로 —
C 처방 ⑤) · 안개 뭉치 `newWisp`는 밀도가 짙은 원·중경(v .04~.5)에서만, 멀수록 작게 · `light.ts` fog `desat` .2 → **.06**(균일 탈채도가 "필터"의 주범,
근경이 원경보다 더 빠졌다 — 탈채도는 밀도장의 안개색 혼합이 깊이별로 낸다).

### ② 안개 하늘 — `world/sky.ts`

- `bakeClouds`가 **안개에선 낱개 원반을 그리지 않는다** — 저주파 밝기 얼룩 한 장(α ≤ .08, 2w 타일 주기 유지)만. `cover` .12는 그대로(규칙
  "하늘은 어느 날씨에도 완전히 비지 않는다"를 지키는 단위 테스트가 있다).
