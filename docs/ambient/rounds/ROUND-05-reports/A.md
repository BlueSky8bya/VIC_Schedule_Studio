### C. 픽셀 어법·움직임·천체

- **구름**: 1/4 캔버스(350×215) → nearest 4×. 형태 = 원 3~6개 합집합 픽셀 채움 + **바닥 평평**(적운) + 2단 셰이딩(윗면/밑면) + 1 논리px 윤곽(같은 색조 −12L). 6~10색/구름. 원근: y가 hz에 가까울수록 scale .5·겹침(구름 띠), 위쪽 1.0. 2층(뒤 .6 / 앞 1.0) 위상·속도 다르게(M-1), 이동 맑음 = 화면 폭/180s, 바람 ×4, 랩은 화면 밖(M-2). 덮개는 `f.load` 비례(LOD). 구름 그림자(산 ②·③ 사면, 60~90s)는 P3.
- **별**: `fillRect` 1px(70%) · 2px 십자(30%), 색 3단 222 232 246 / 172 186 210 / 120 136 170, 포아송 + 성단 2~3 + 빈 곳(R-1), hz 근처 밀도 ×.3(대기 소광), 깜박임 8~12%만 0.3~0.6Hz α ±.25. 저녁 10~16개부터, 새벽 3~6개 잔존. 유성 = `SpawnDirector` 전설급 1/세션(꼬리 12px, .6s) — 옵션.
- **달**: 위상 = KST `f.date` → 삭망월 29.53059d(기준 신월 2000-01-06 18:14 UTC); 지름 14~18px(TILE/4) 픽셀 원반 236 240 232(sat ≤ .05 — 노랑 금지), 그늘 부분 = 하늘색 +3L 1단(지구조 힌트), 헤일로 **2단 계단**(r×1.5 α .10, r×2.1 α .05 — 소프트 원반 금지); 상현 오른쪽 밝음·하현 왼쪽 밝음; 위치 x·y = 위상별(보름 밤 중앙 위 / 초승 노을·저녁 서쪽 낮게 / 하현 새벽 동쪽 낮게), **`light.ts reflect.x`가 달 x를 읽어** 수면 달빛 띠와 일치(현행 .58 고정 제거); 삭 ±.03 = 달 없음; 흐림·비·안개 = 위 표.
