## 발견(P0 0 · P1 3 · P2 2)

1. **P1 S-4(+S-2) — 암석해안 물보라가 물가선·조석·바위와 무관한 직선(`shoreY−4`)에서 솟는다 — 썰물 띠에선 x의 63%가 마른 뭍이다.**
   `coast.ts` step() `x = rand()*w, y = shoreY()−4`. 물가선은 굽이 ±31 + 조석 ±17.2 + 숨 ±3로 433~512를 오가는데 스폰 y는 465.3 고정 → 밤 x의 63%가 물가선보다 뭍 안쪽(최대 32.1px),
   그려진 물보라 점의 26%가 물가선 아래(마른 바위 위에서 튄다); 노을 48%·14.9px·7%; 점심은 반대로 중앙 −52px(빈 바다에서 솟음). 목표창 dy ∈ [−24,+4] 만족 노을 30%·밤 38%, 바위 ±20px 이내 25%(우연 수준).
   `vx = (rand−.5)·60 + wind·40` → 평균 +40·wind(늘 오른쪽)인데 `particles().wind` = −1.
   Fix: 스폰 앵커를 `shoreRocks`의 `rocksSea` 쪽 바위로 — x = rk.x ± 20, y = lineY(rk.x) − 2~8, 빈도 = 파도 위상 × 바람, vx는 **부호 있는** 바람. 모래·갯벌은 스워시로 대체.
   Acceptance: 6띠 × 3날씨 스폰 dy ∈ [−24,+4] ≥ 95% · 뭍 안쪽 스폰 0 · x의 ≥ 80%가 어떤 shoreRocks ±20px · sign(평균 vx) = sign(particles().wind) 6띠 전부.
2. **P1 S-4(+W-1) — 비가 수면에 닿는 자국이 민물 말고는 하나도 없다.** 60프레임 원시명령 집계(수면 영역): 비로 늘어난 고리·튐 **0** — 늘어난 건 전부 바람 부스러기와 물보라(`light.wind` .08 → .4의 부산물).
   민물만 `rings` 1 → 17. ΔL(비−맑음) 물 −8.88 / 뭍 −6.72(암석), −8.60 / −7.78(갯벌): 전역 곱이라 **물이 젖은 땅보다 더 어두워지는** 뒤집힌 관계. `coast.ts`·`sea.ts`·`land.ts`는 `f.weather`를 하늘에만 쓴다.
   Fix: `water.ts` 공용 `drawRainRings` — 해안은 `lineY(x)` 위, 먼바다는 지평선 아래 전부, 계곡은 수로, 민물은 기존 것 이관. 뭍은 `mul` 대신 젖음 채널.
   Acceptance: 비 장면 수면 고리 ≥ 40개/초 · 전부 물 폴리곤 안(뭍 위 0) · 고리 반지름 중앙값 y상위⅓ : 하위⅓ ≤ 0.6 · ΔL(비−맑음) 뭍 − 물 ≤ −2 · 맑음 프레임 해시 불변.
3. **P1 S-4(+D-2) — 라운드 13 조석 층이 마운트 때 한 번만 구워진다.** `bakeShoreRocks`가 `resize()`에서만 불리고, `step()`의 `bake()`는 `rocksTide = NaN`으로 되돌리되 캔버스는 그대로 둔다 → 창 크기가 안 변하면 층은 영영 다시 굽지 않는다.
   실측: 점심 마운트 → band=night 6초 → 바위 bbox 픽셀 **16.43%**가 신선 마운트와 다르고 **2/7**이 틀린 접촉 등급 — (84,471)·(1081,488)은 물가선이 30.5·12.8px 물러났는데 잠김 틴트·수면선 링 유지(몸통 L 59.8 vs 신선 47.8 = +12L 유령). 캡처 시트에도 `rocksTide: null`(16/16).
   Fix: `step()`에도 `if (rocksTide !== tide(f) || rocksArt !== art.version) bakeShoreRocks(tide(f), f.dpr)`. Acceptance: 런타임 6띠 순회 후 bbox 차 ≤ 1% · `rocksTide` = tide(f) 항상 · 부호 ↔ 잠김 7/7 · 호출 ≤ 1/5s.
4. **P2 S-2(+D-1) — 한 화면에 바람 방향이 둘이고(입자 −1 · 물보라 +1) 지면·수면엔 방향이 아예 없다; 부스러기는 원근도 모른다.**
   `particles.ts`는 시드 비트로 dir(±1)을 정하는데 `Light.wind`는 **부호 없는 세기**라 소비자가 방향을 못 받는다: 물보라 vx +40·wind(늘 오른쪽), 파도 진폭만, 물가 거품 `drift = t·4`(늘 왼쪽), 풀 진행파(늘 오른쪽), 나무 평균 0.
   부스러기 corr(y, 크기) **−0.054**(대조군 눈 0.982) · 12%(갯벌)~76%(먼바다)가 수면 위(가을 갈색 부스러기 = 바다 위 낙엽).
   Fix: `light.ts`에 `windDir(±1)`을 올려 particles의 dir을 공유, 소비자 넷이 곱한다. `newMote`는 `depthOf(y)`로 d를 뽑고 수면 위 밀도 ×0.2.
   Acceptance: sign(물보라 vx) = sign(거품 이동) = sign(풀 파) = sign(particles().wind) · 나무 평균 기울기 = windDir × 0.5~2px · corr(y, 부스러기 크기) ≥ 0.6 · 수면 위 부스러기 ≤ 15%.
5. **P2 S-4(+S-2) — 겨울 해안의 눈이 물가선 바로 안쪽부터 쌓인다.** 눈 그라데이션이 로컬 y=70에서 α 0인데 로컬 물가선은 조석에 따라 60(썰물)~94(밀물) → 썰물 띠엔 물가 10px 안쪽부터 눈.
   ΔL(겨울−가을, 암석·밤): +2px **+4.1** · +10 +6.4 · +20 +8.9 · +40 **+16.6**. Fix: 눈 α 0 지점을 고조선 + 40px(로컬 134)로, 조간대는 눈 0, 그 위 40px는 얼룩 패치로만. → 라운드 15.
