# ROUND-25 — 여러 구름과 서울 별 지도

Status: 로컬 구현·화면 검증·독립 검토 완료, 소유자 시각 확인 대기 · 2026-09-11 KST

소유자는 WMO 10종 구름과 같은 종류 안의 다양한 모양, 맑을 때 드문 통과, 별의 색·크기·계절별 은하수와 서울 북극성/별 지도를 요청했다. 북향/남향 선택 질문에는 해와 달이 더 자주 보이는 쪽을 물었고 남향을 추천했다. 기본 남향, fixture에서 동·서·남·북 비교를 준비한다. 기존 R24 변경 위에 이어 작업하며 아직 푸시하지 않는다.

## 표현과 근거

- [WMO 국제구름도감](https://cloudatlas.wmo.int/en/descriptions-of-clouds.html)의 10속 형태를 구분: 권운·권적운·권층운·고적운·고층운·층운·층적운·난층운·적운·적란운. 종류별 3개 그림, 총 30개를 built-in imagegen으로 생성하고 개별 크기·높이·속도·빈 간격·좌우 방향을 섞는다. 처음 코드로 그린 시험 형태는 둥근 도형 같은 질감이라 자체 시각 검토에서 반려했다(`r25/after` 초기 14장). 최종은 기존 구름 화풍을 참조한 새 아틀라스이며 승인된 자산으로 표시하지 않는다. 식물·소품 이미지는 바꾸지 않는다.
- 맑음은 드문 권운/적운, 가을 맑음은 상층운 쪽. 흐림은 중·하층운, 비는 난층운 중심, 여름 비에만 적란운을 섞고 눈은 층상운 위주. 안개는 형태 없는 장막을 유지한다. 이 혼합 비중/속도는 감상용 설계이며 실제 서울 관측 확률/예보라고 주장하지 않는다.
- [HYG v4.0](https://github.com/astronexus/HYG-Database/tree/main/hyg/CURRENT)에서 6등급까지 실제 5,070개를 추출. RA/Dec·등급·B–V·고유운동을 보존. David Nash/Astronexus, CC BY-SA 4.0. `star-catalog-source.json`에 원본·출력 SHA와 재생성 경로, `public/ambient/licenses/hyg.txt`에 귀속/변경/라이선스 링크. 적응 데이터 JSON의 라이선스이며 독립 렌더 코드의 라이선스를 바꿨다는 뜻이 아니다.
- [USNO 항성시](https://aa.usno.navy.mil/faq/GAST)와 [고도·방위 변환](https://aa.usno.navy.mil/faq/alt_az), 서울 37.5665°N/126.978°E. 기존 KST 세계 날짜/시각에서 계산. [ERFA IAU1976 세차](https://raw.githubusercontent.com/liberfa/erfa/master/src/prec76.c)의 J2000 다항식 반영, 해당 라이선스 배포. UTC≈UT1, 장동·대기 굴절/소광·관측소 표고는 생략한 감상용 별 지도다.
- [ESA 은하 좌표](https://gea.esac.esa.int/archive/documentation/GDR1/Data_processing/chap_cu3ast/sec_cu3ast_intro.html)로 은하면을 같은 서울 하늘에 투영한다. 계절별 임의 대각선이 아니라 실제 세계 날짜·시각·방향에 따라 움직인다. 은하수의 얼룩/밝기는 절차적 예술 표현이고 관측 사진이나 서울 도심 빛공해 시뮬레이션이 아니다.
- [IAU 교육 자료](https://astroedu.iau.org/activities/evening-sky-watching-for-students/)에 맞춰 별빛 색은 과포화 무지개 대신 은근하게. 밝은 별을 더 크게, 일부만 천천히 반짝인다. 낮은 등급/은하수부터 가볍게 모드에서 생략한다.
- 해의 초원 위치와 달 위치도 같은 방위 창으로 제한한다. 달은 SunCalc의 지심 근사 고도/방위이고 시차·굴절·원반 기울기까지 재현하지 않는다. 낮에 떠 있는 밝은 달도 흐리게 표시한다. 북쪽 화면에 남쪽 해/달을 억지로 넣지 않는다.

## 성능·경계

구름 한 판 반복 대신 개별 경로; 같은 seed/time은 같은 화면이며 화면 밖에서 다음 형태가 들어온다. 동시 경로 최대 44, 원본 1254² 한 번 해독/매트 제외 후 작은 구름 30개 캐시. 별 위치/은하수는 세계 시각 1분 단위 최대 4개 캐시, 은하수 한 장 약 2MiB 상한. 큰 원본 처리는 로드 때만, 은하수 노이즈는 캐시 만들 때만 처리한다. 가볍게에서는 은하수와 4.8등급보다 어두운 별을 생략. 감상 모드·자동조절·정지·모바일 선제 제외·심해 봉인 유지. 실제 기기/OBS 부하는 별도 미측정.

생성 원본/정확한 프롬프트/실제 본 고정 입력/해시: `art-src/하늘·천체/공통하늘/작업회차/20260911-구름다양성-01/`. RGB 자홍 매트를 런타임에서 제외하며 투명 PNG라고 주장하지 않는다. `public/ambient/art/cloud-atlas-v1.png`는 생성 원본과 같은 바이트. 원본 5열×6행과 얇은 깃 끝 경계는 실제 화면에서 추가 검토한다.

서버 권한/공개 DTO/DB/달력 날짜 선택은 그대로. fixture만 방향·날씨·날짜·시각 선택 추가. public 데이터의 추가 출처는 공개 천문 목록뿐이다.
