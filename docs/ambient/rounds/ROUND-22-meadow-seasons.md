# ROUND-22 — 초원 사계절

Status: 여름·가을·겨울 초원 생성·로컬 연결·검증 완료, 소유자 시각 확인 대기 · 2026-09-11 KST

소유자 요청: 봄 다음 여름·가을·겨울 초원을 먼저 만들고 다른 바이옴은 나중에 확장한다. 봄에서 수용한 넓은 하늘(.35), 열린 중앙, 작은 불규칙 풀과 원경 흐림을 유지한다. 여름은 깊은 녹색, 가을은 옅은 황금·마른 풀, 겨울은 눈과 작은 마른 풀을 기본으로 한다. 나무는 추가하지 않는다. 계절마다 F/M/N 세 원본을 새로 생성해 연결한다. KST의 조회 달로 계절 선택, 모바일 제외, 감상 모드 동작, 자동조절, 심해 봉인 및 현재 역할별 초원 노출 범위를 유지한다. 이번 요청은 생성·연결이며 추가 푸시는 별도 요청 전까지 하지 않는다.

범위: 기존 봄 아트를 보존하면서 계절 소스 선택과 초원 공통 .35 좌표를 확장한다. 다른 바이옴 .26 및 권한/공개 데이터/DB는 변경하지 않는다. 원본·프롬프트·고정 입력·검증을 각 회차에 기록한다. 이전 봄만의 .35 예외는 이번 요청으로 초원 사계절까지 확대한다. 생성·검증·소유자 수용은 구분한다.

## 구현 및 생성 기록

내장 image_gen으로 1536×1024 원본 9장을 생성했다. 봄의 각 대응 레이어를 실제 보고 고정 입력으로 첨부했다. 다음 회차마다 `far-request.md`, `ground-request.md`, `frame-request.md`에 실제 프롬프트, `delivery.json`에 입력·원본·공개 파일 경로와 SHA-256을 기록했다.

- [여름 시안13](../../../art-src/배경층/초원/작업회차/20260911-여름초원-시안13/delivery.json): 짙은 녹색 초원.
- [가을 시안14](../../../art-src/배경층/초원/작업회차/20260911-가을초원-시안14/delivery.json): 황금빛 마른 풀.
- [겨울 시안15](../../../art-src/배경층/초원/작업회차/20260911-겨울초원-시안15/delivery.json): 옅은 푸른 그림자의 눈밭.

공개 PNG는 생성 원본과 바이트가 같다. F/N은 투명 PNG가 아니라 마젠타 바탕 RGB 원본이다. 측정한 Path2D 영역으로 바탕을 제외한다. 혼합된 분홍 가장자리까지 제외하도록 색 기준과 원본 1픽셀 경계 축소를 적용했다. 원본을 편집하거나 매 프레임 흐림 처리를 추가하지 않았다. 겨울의 옅은 보라 그림자를 남기면서 합성 경계의 분홍색을 제거했다.

현재 계절의 3장만 로드하고 준비 완료 후 한 번 지면을 굽는다. 가을·겨울도 새 원경/지면/근경으로 연결했다. 로딩·실패 상태에서 매 프레임 지면을 다시 굽던 경로를 수정하고, 하늘 효과를 지평선 위에 제한했다. 기존 날씨·시간·생물 효과는 유지한다. 테스트 화면 위의 봄/여름/가을/겨울 링크로 비교할 수 있다.
