## 수정

### ① 지평선·하늘 — `HORIZON_V` 0.12 → **0.26**

세 검토가 각각 .30(A) / .20(B) / .26(C)을 권했고 **셋의 공통 구간이 .26**이다. 하늘 103 → 224px, 땅 757 → 636px(−16%).
B의 "땅 손실 10% 미만" 조건은 못 지켰지만, B가 깨진다고 지목한 상수를 **전부 옮겨** 그 근거를 해소했다:

- **좌표 서비스 신설**(`view.ts`): `groundYAt(v, h)`(땅 비율 → y) · `aboveHz(h, dh)`(지평선에서 **위로** 거리) · `groundK(h)`(옛 땅 높이 대비 비율).
  지평선에 붙어야 하는 것(먼 언덕·나무 줄·지평선 광·안개 시작)은 hz 비례가 아니라 **거리**로 붙인다 — hz 비례면 먼 숲이 하늘 한복판에 뜬다.
- **C의 상수표 채택**: 하늘 오버레이 끝 `hz·1.10` · 원경 띠 끝 `groundYAt(.30)` · 안개 start `hz·0.85` · 안개 끝 `HAZE_END_GV .28` · `HAZE_ALPHA` .11 → **.13** ·
  `bakeHorizon H = hz + max(48, .22(h−hz))` · 별 `hz·0.92` · 달 `hz·0.35` · 해 `hz·0.80`(옛 값은 전부 hz·0.3 이하 = 상단 31px).
- **산은 지평선 아래를 지킨다**(A·B 합의). 봉우리 천장을 `gy() + (h−gy())·0.029`로, `amp`·`foot`·발치 컷을 **땅 높이 비례**로 — 절대 높이를 고집하면
  ① 정점이 지평선 위로 올라가 안개 띠를 뚫고 대기 원근이 뒤집힌다(MOUNTAIN §3).
- **물 경계**: `coast.ts LAND_V_BY`(화면 분수) → `SEA_GV_BY`(땅 비율 .25/.295/.386, 옛 값 환산) — B의 "최우선" 항목. `traces-draw.SHORE_V` → `SHORE_GV`+`shoreBandY()`,
  `shoreEdgeOffset(x, w, k)`에 `groundK` 배율(진폭이 절대 px라 땅이 줄면 물가가 기슭을 뚫는다). 먼바다만 수평선을 `hz + .06h`로 내렸다(A: 바다는 하늘이 넓을수록 산다).
- **하늘의 내용**: 구름을 **세 고도층**으로(먼 층 작고 옅게 → 가까운 층 크고 진하게, 뭉치 높이 hz의 7~13%) · 개수는 폭이 아니라 **띠 넓이** 비례 ·
  저해상 판의 알파를 3단계로 양자화해 **가장자리를 픽셀 계단으로**(A#4) · 새털구름을 바코드에서 **끝이 가늘어지는 갈고리 획**으로 ·
  별은 밀도 0.35개/1000px²(40~140) + 밝기 3등급 + **은하수**(달빛 lit < .35에서만, 새 색 없이 별 밀도로) · 달·해 원반은 **저해상에 굽고 nearest 확대**(AA 정원 제거),
  크기는 하늘 높이의 4.5%/5%로 소폭만(C: "커진 달은 만화").
- **밀도**: `scatterProps`의 개수에 `groundK` — 땅이 16% 줄었는데 같은 수를 뿌리면 벽지가 된다(A ④-4). 작은 것(풀·꽃·낙엽)은 그대로 두었다.

### ③ 아트 윤곽선 — `scripts/ambient-art-outline.mjs`

아주 어두운 픽셀(HSL L < .28)만 바닥 .13까지 들어 올리고 **그림의 지배 색조**를 입힌다(채도 없는 순검정은 색조를 빌려온다).

### ④ 눈 편한 테마 — 루트 filter 폐지

`html[data-eye-comfort="1"]`의 `filter: saturate(.85) brightness(.96) sepia(.03)`를 **삭제**하고 "1"·"lite" 모두 토큰 팔레트를 쓴다.
배경 캔버스는 body 안 z −1의 자식이라 루트 filter에서 빠져나갈 방법이 없다(자식 역필터는 밝은 하늘이 클리핑되고, 자식별 filter는 그 안의
