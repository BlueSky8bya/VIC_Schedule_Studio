# ROUND-21 — 봄 초원의 시점과 공간 크기

Status: 소유자 로컬 시각 수용 및 푸시 명시 승인, 배포 검증 진행 · 2026-09-11 KST

최신 승인: 소유자가 직접 테스트 뒤 “좋은 것 같은데?”로 현재 방향을 수용했고, 이어 “푸시 해보자. 실제 느낌 봐보게”로 main 푸시를 명시 요청했다. 현재 F-v2 / M-v5 / N-v2 구성과 테스트 도구·원본·검증 기록을 배포한다. 아래의 “로컬/푸시 없음”은 이전 단계 기록이며 이 요청이 배포 권한을 갱신한다.

Current implementation: 시안08을 참고로 새 원경·지면·근경을 생성해 연결했다. 회차09 지면은 큰 반복 풀 때문에 반려하고 회차10 지면으로 교체했다. 봄 초원만 지평선을 .35h로 맞추고, 나무·큰 관목 없이 작은 풀과 열린 중앙을 남겼다. 감상 중 원경 < 지면 < 근경 이동, 모바일 제외·자동조절·심해 봉인은 유지한다. 로컬 변경이며 추가 커밋/푸시는 하지 않았다. 실제 사이트는 ROUND-20 배포 상태다. 상세 대체 결정: [ADR-0024](../../agent/decisions/ADR-0024-spring-meadow-three-layers.md).

## 실제 적용 검증

소유자 직접 테스트용: fixture에 `live=1`을 명시하면 준비 뒤 재생하고 낮/밤·별똥별/일시정지 버튼을 보여준다. 기본 fixture는 기존 정지·결정성 동작을 유지한다. `VISUAL_TEST_FIXTURE=1` 서버에서만 접근 가능하며 실제 공개 사이트에 테스트 UI를 추가하지 않는다. build·typecheck·lint/806 tests·harness 통과. 실제 Codex 브라우저에서 낮↔밤, 일시정지↔재생을 확인하고 낮 재생 상태로 전달했다. 시간대 변경은 기존 강제 날씨/시드도 유지한다. 추가 푸시는 없다.

최신 지면 build `wK4KAAvOZSasyKf865WAh`: typecheck·lint·build, 전체 73파일/806 tests, 원본 geometry·harness·diff 검사 통과. `.scratch-pw/qa/r21-grass-depth`의 화면비/날씨/모드/모바일 35개와 `layers`의 소스/이동/클릭/천체 8개 통과. B 실제 3비율 검토: 차단 문제 없음, 거리감·불규칙 덩어리 개선. 잔여 P2는 초광폭에서 가로로 눌린 풀 무늬, 세로 화면에서 상대적으로 큰 근거리 군락. C 코드 검토: blur/갱신 추가 없음, 디코드 크기는 동일하나 파일 2,056,575→2,360,821바이트; 이번 성능 실측은 수행하지 않음. 로컬 변경이며 푸시 없음.

후속 지면 수정(소유자: 먼 쪽 흐림·잔디 불규칙성): 회차11은 큰 V형 풀 때문에 반려, 회차12 ground-v5를 로컬 적용했다. 먼 쪽은 옅고 작은 무늬, 가까운 쪽은 또렷한 작은 풀, 불균일한 군락과 빈터를 갖는다. 1536×1024 크기는 그대로다. 화면비와 무관하게 세로 거리 변화 전체를 보여주도록 지면 crop을 변경했다(가로 화면은 세로 압축, 세로 화면은 좌우 crop). 하늘·F/N·시간/날씨/입력/모드 및 공개 데이터 경계는 변경하지 않았다. 원본과 실제 첨부 입력·프롬프트·해시는 각 회차 delivery.json에 보존했다. 별도 실시간 흐림 계산은 없다. 아래 이전 성능 수치를 이번 새 원본 실측으로 인용하지 않는다.

- 최종 `selftest.mjs`: 초원·산·심해 3시나리오 결정성·정지·시드·시간대·심해 날씨 봉인 모두 통과(30초).
- 독립 A/B/C 검토: 차단 문제 없음. 큰 풀 무늬·큰 관목·중앙 근경 덩어리 수정. B가 마지막 세로 화면 이음선 제거를 실제 PNG로 확인했다. 남은 시각 보완 후보: 밤 지평선 아래 색 띠, 앞뒤 풀 밀도 때문에 다소 평평한 깊이감, 초광폭의 상대적으로 큰 지면 문양. 정확한 4배 면적이나 소유자의 최종 시각 승인을 주장하지 않는다.
- 원본은 각 회차에 그대로 보존했다. F/N은 RGB 바탕을 렌더 시 측정 마스크로 제외하며 진짜 알파 PNG로 표기하지 않는다. 원본 디코드 추산은 기존 6MiB에서 18MiB로 증가; F/N 표시 캐시는 각각 약 1MiB 이내. GPU/실제 저사양 기기 성능은 별도 미측정이다.

## 성능과 한계

지면 v5 독립 A 전후 비교: 같은 땅 안의 거리감 개선과 규칙적인 V 반복 감소 확인. 하늘/나무 없는 구성 유지, 새 접합선·잘림 없음. 하단 중앙의 밀도·대비가 다소 높아 향후 더 비울 여지가 남는다. 소유자 최종 시각 승인을 대신하지 않는다.

최종 성능 기록: `.scratch-pw/qa/r21-layers/perf-final/summary.json`. 독립 C가 최종 build에서 1400×860 headless PC 포인터 이동을 모드별 30초, 다른 검사 없이 측정했다. max RAF 평균/p95 16.731/16.8ms, paint CPU .242/.400ms, 59.80fps; auto 16.806/16.8ms, paint .325/.500ms, 59.54fps; lite 16.666/16.8ms, paint .198/.300ms, 의도된 약 30.02fps. 세 모드 모두 34ms 초과 0%, 추가 canvas 생성 0, 브라우저 예외 0. max M 5.411MB + F/N 1.312MB, lite M 1.353MB + F/N .328MB(기존 fallback front .562MB, 디코드 원본 18MiB·기타 브라우저 메모리 별도). F/N bakes 2→2. ROUND-20 final max RAF 20.102/33.4ms, paint .472/.700ms보다 이번 전체 경로는 개선됐으나, 서로 다른 구도/그림이며 최초 디코드·실제 저사양 기기·OBS·GPU 측정은 아니다.

## 소유자 피드백과 대체 결정

배포된 봄 초원은 땅 가까이의 낮은 시점, 작은 텃밭 같은 범위로 느껴진다. 이후 여러 나무와 계곡·민물·산·언덕·숲·갯벌로 넓힐 공간감이 필요하다. 지평선도 높게 느껴진다는 피드백이 있다. PLAN-015의 “각도 유지”는 이번 시점 수정 요청으로 대체한다. 좋아한 픽셀 묘사·색감·열린 중앙은 유지한다.

## 수정 기준

- 소유자 명확화: 현재 화면 네 개를 가로 2 × 세로 2로 이은 넓이의 땅을 더 멀고 높은 곳에서 내려다본다. 목표는 가로·깊이 약 2배, 보이는 땅 면적 약 4배이며, 풀·꽃·나무의 화면 크기는 대략 절반이다. 숫자는 체감 구도의 기준이며 실제 면적 측정 완료나 물리 카메라 계산값이 아니다. 완전한 위쪽 지도나 눈높이 풍경으로 바꾸지 않는다.
- 가까운 풀 덩어리와 반복 가로무늬를 줄이고, 중간 거리의 땅이 넓게 이어지게 한다. 작은 풀을 그리는 것과 화면 해상도를 낮추는 것은 다르다.
- 성목 여러 그루와 그 사이의 빈터를 함께 놓은 크기 비교가 필요하다. 나무 한 그루를 화면의 주인공으로 키우지 않는다. 비교용 나무는 실제 식재 기능이나 새 바이옴 구현을 뜻하지 않는다.
- 지평선을 아래로 내리는 해석 대신 더 멀고 높은 카메라로 확정했다. 지평선 한 줄을 옮기거나 기존 그림 네 장을 실제로 타일링하지 않는다. 새 연속 지형 구도와 공통 객체 축척을 함께 판단한다. 전 세계 HORIZON_V 숫자는 아직 변경하지 않았다.
- 봄 초원에서 확인한 뒤 다른 바이옴으로 확대한다. 심해 봉인, 모바일 제외, 감상 중에만 움직임, 자동조절 기본, KST/권한/공개 데이터 경계는 유지한다.

기존 배포와 비교 기준: [ROUND-20](ROUND-20-spring-release.md), 원본 `20260911-봄초원적용-시안05`. 수정 원본은 새 회차에 보존한다. 아직 새 구도 생성·제품 반영·배포 검증 완료를 뜻하지 않는다.

## 비교 시안과 다음 적용 범위

내장 이미지 도구로 `20260911-넓은시점-시안06`, 명확화 이후 `20260911-네배공간-시안07`을 생성했다. 두 회차에 원본·실제 첨부한 고정 입력·정확한 요청·해시 기록을 보존한다. 최신 비교 그림은 [네 배 공간 시안](../../../art-src/배경층/초원/작업회차/20260911-네배공간-시안07/원본/봄초원-네배공간.png). 나무 다섯 그루는 축척 비교용이며 소유자의 실제 식재 결정이 아니다.

독립 A/B는 원본과 비교 시안을 실제 열어 색감·열린 중앙 유지, 큰 모서리 풀 감소, 넓은 땅과 나무 사이 여유 개선을 확인했다. A: 가로 풀 무늬와 나무 옆면 때문에 충분히 높은 시점이라고 확정하기 어렵다. B: 앞뒤 풀 밀도가 비슷해 깊이감이 평평하다. 둘 모두 정확한 4배 면적이나 각도 측정으로 판정하지 않았다. C: 고정된 나무·그림자·낮빛이 들어간 비교 그림을 현재 .26 지평선/생물 좌표에 그대로 넣으면 안 된다.

다음 실제 적용은 비교용 나무를 제거한 지형 원본, 더 작은 풀 문양, 객체 크기·발 위치·판정·먼 배경을 한 구도로 맞추는 작업이다. 네 배 공간은 화면 픽셀/캐시를 네 배 늘리는 요구가 아니다. 현재 요청의 피드백 기준과 비교 시안은 업데이트했으며, 제품 코드·공개 원본 교체·추가 푸시는 이번 기록 시점에 수행하지 않았다. 문서 harness와 diff 검사는 통과했다; 제품 변경 테스트를 새로 실행했다고 주장하지 않는다.
