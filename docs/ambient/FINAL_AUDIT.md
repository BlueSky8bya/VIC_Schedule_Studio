## 6. Open Decisions(소유자 판단 대기 — 이번에도 밀어붙이지 않았다)

1. **밤의 어둠을 어디까지 내릴까.** 규칙은 지면 −16L이고 지금은 −12.9 ~ −19.6(양끝은 가장 어두운 지면과 가장 밝은 지면). 더 균일하게 하려면 면(수면/풀/뻘)마다 다른 앵커가 필요하고, 그건 "장면이 자기 재질을 안다"는 새 개념을 들인다.
2. **암석해안 뭍을 다시 그릴까.** A는 "판"이라 하고 고치려면 바탕 굽기를 재설계해야 한다(큼). 아니면 **아트 자리 배달**(노두 png)로 대신할 수도 있다 — 후자는 코드 변경 0.
3. **`debug().spots` 미노출 장면(초원·모래해안)에 계측을 넣을까.** 자동 간격 검사가 두 바이옴에 닿지 않는다. 노출은 쉽지만 debug 표면이 커진다.
4. **갯벌 밀물 띠 9.1%**(규칙 3~5%). 코드가 의도적으로 옛 비율을 유지 중이고, 줄이면 조석·층 관계가 다시 바뀐다(B: "안 고쳐도 되는 것").
5. **라운드 16 이후에도 자율로 계속할지.** 남은 것의 크기가 "작다"에서 "큼"까지 흩어져 있어 예산 규칙(라운드당 ≤ 2)을 유지하면 3~4라운드가 더 필요하다.

## 8. 지금 Ambient Visual QA를 "합격"으로 볼 수 있는가

**아니오 — 조건부.** C가 전수 측정으로 낸 판정이고 A·B의 남은 문제 목록과도 일치한다.

- **시간대(T)는 합격선**이다: 맑음 인접 띠 5쌍 × 9 장면 전부 ≥ 2채널 · 밤 하한 15/15 · 지면 추종률 10/11 · 결정성·봉인 계약 ✔.
- **공간(S)·레이어(A)도 합격선**이다: overlapRatio 0.00% · 공중 보행 0 · 물가 바위 23/23 · 풀 관통 ≤ 0.41%.
- **안개(D)는 합격선에 근접**: 밀도장 단조 6/7, 지평선 절단선 ≤ 2.9L.
- **날씨(W)가 미달**이다: 바람이 **초원 4장면에서 ×1.01**(코드에 소비자 0개)이고 육지 6장면에서 정지 채널이 없다, 비의 지면 채도가 규칙과 **반대 부호**, 수평선 띠가 비에서 아직 맑음의 1.4배.

**합격 기준 3줄(C 제안, A·B 동의)** — 이 셋이 초록이면 합격으로 본다:

1. 바람 weatherDelta ≥ 3(육지·해안 6/6) — 첫 단계는 `spring/summer/winter.ts`에 진행파 이식(가장 싸고 가장 많이 보인다).
2. 비 지면 채도 +5%p 이상 + 웅덩이 ≥ 2(초원·언덕).
3. 해안 수평선 peak−sky ≤ 1.3×같은 띠 맑음(6띠 × 3해안 18칸).

라운드 16을 이 셋으로 잡으면 한 라운드로 닿을 수 있는 거리다(1은 작다, 2는 중간, 3은 남은 몫이 작다).
