## 4. 할 일 — 소유자에게 먼저 물어라

두 갈래가 있고 **어느 쪽을 먼저 할지는 소유자 결정**이다. 혼자 정하지 말고 한 줄로 물어라.

**갈래 ① 소나무 4차 생성 (소유자가 `선별 완료`라고 말한 뒤에만)**
1. `레퍼런스/`에 남은 png·사이드카를 확인한다. 소유자가 직접 넣은 그림이 있으면 출처를 **묻는다**(추정 금지).
2. `npm run ref:notice` → `ref:check` → `art:catalog -- --entity tree-pine`.
3. **새 run**을 만든다. 파이프라인의 `request` 명령이 엔티티 레퍼런스를 `고정입력/레퍼런스/`로 명시 복사하는지 **먼저 확인**한다(`docs/ambient/ART_PIPELINE.md`). 지원이 없으면 그것부터 추가하고 소유자에게 알린다.
4. 생성 범위는 이전 파일럿과 같이 **변형 2·3 × 세 계절 = 6장**부터. 계절 셋은 반드시 한 배치.
5. 납품은 run의 `원본/`에 정확한 이름으로 → `정리본/` → `npm run art:check tree-pine` → 검토 시트를 합격본 옆에 놓고 **소유자 눈 판정**. 수치 통과는 합격이 아니다(3차가 수치 8개 다 통과하고 반려됐다).

**갈래 ② 지시서 A 마무리 (규칙 보존 증명)**
- `docs/agent/archive/20260909-CLAUDE-before-memory-split.md` 589줄을 한 줄도 빠짐없이 `→ 규칙 ID` / `→ 코드(파일:심볼)` / `→ 의도적 삭제(이유)` 로 분류해 `docs/agent/RULE_MIGRATION.md`로. 의도적 삭제 목록은 소유자에게 보여준다.

## 5. 알아둘 함정 (이번 세션에서 실제로 밟은 것)

- **레퍼런스 스캐너는 PNG/GIF만 센다**(`scripts/lib/ambient-ref-library.mjs` `imageName`). JPEG를 넣으면 `ref:check`가 조용히 무시하고 통과한다 — 통과가 검증이 아니다. 사진 참고가 필요해지면 확장자 계약을 넓힐지 소유자에게 묻는다.
- **`ref:fetch`의 픽셀 게이트는 우리 격자 기준**이라 진짜 픽셀아트도 떨어뜨린다(ArlanTR `pine_1.png`, isaiah658). 게이트 결과를 믿지 말고 nearest 확대 대조 시트로 눈으로 본다.
- **`ref:fetch`가 홍보 썸네일을 다시 받아온다**(`iso_pine_prev.png` — 이름에 preview가 아니라 prev라 배너 정규식을 통과). 돌린 뒤 폴더를 확인해 지운다.
- iNaturalist·rawpixel·Fab·itch 태그 페이지는 봇에 403. iNat은 `api.inaturalist.org/v1/observations?photo_license=cc0`로 사진 id별 라이선스를 확인할 수 있다.
- OGA 작품 페이지의 `license-name`은 curl로 읽힌다. 여러 라이선스가 섞이면 전부 CC0일 때만 저장.
- 실사 사진은 이번 소나무 후보가 **아니다**(2026-09-09 소유자). 픽셀아트만.
