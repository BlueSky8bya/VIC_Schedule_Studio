# PLAN-036 — 최초공개 응원단과 소리

2026-10-14 KST · L2 · 사용자 구현/커밋/푸시/배포 승인 범위.

## 요청과 결정

- 기대 버튼과 빅타민이 겹치는 절대 배치 해소. 스크린 안에 관객 전용 행을 확보한다. 단일/다중 일정, PC/모바일/짧은 가로 화면에서 확인한다.
- 응원봉/음악 전용 버튼 제거. 빅타민 자체가 44px 이상 네이티브 버튼이며 클릭·Enter·Space로 응원 프레임을 재생한다. 기대 상태나 DB를 변경하지 않는다.
- 원본 REF-016/017의 무사지·두 귀·사각층을 유지한 실제 다중 프레임 아틀라스. 응원봉은 몸의 겉 사각층에 짧은 리본으로 부착. 원본/생성 native/파생 과정 보존. 생성자 관찰과 사용자 미술 승인은 구별한다.
- 기존 공유 시계로 점프·봉 흔들기·착지 프레임을 선택한다. 별도 캐릭터 타이머/DB 요청 없음. 12→10초에 착석을 마치고 10초 이후에는 낮은 대비의 정지 관객만 남는다. 호스트·버튼·문구는 기존대로 퇴장하며 숫자에 집중한다.
- 기존 자체 합성 음악을 기본 자동 재생. 마스터 ON·축하 카테고리·음량을 모두 따른다. 자동 재생 차단 시 대기하고 첫 사용자 입력에서 재시도. 숨김/종료/재편성/마지막 10.5초에는 기존 세션 즉시 정리. 새 목표는 새 세션으로 시작한다. 추가 음원/의존성/AudioContext/스케줄러 없음.
- PLAN-034의 매번 음악 수동 시작 및 10초 관객 전체 숨김 조항은 최신 요청으로 위 두 조항이 대체한다. 최종 숫자 집중·무음은 유지한다.
- 앞서 반려된 토리 얼굴/머리 이식과 눈·입 국소 시안은 계속 로컬 미적용. 이번 작업은 토리 런타임 파일을 교체하지 않는다.
- 진입 완료 때 morph 속성 제거로 기본 fade가 다시 시작되는 근접 결함을 발견했다. 완료 표시를 남겨 이미 펼쳐진 창이 다시 사라졌다 나타나지 않게 한다.

## 경계와 연결

공유 `PremiereStage`/`PremiereScene`/choreography/music hook과 `lib/ui/sfx.ts`만 연동한다. 공개 DTO/DB·권한·잠금·KST·1840px 포스터 표면 변경 없음. 음악/응원은 클라이언트 로컬 효과. 실제 달력 시험 데이터는 만들지 않는다.

1. 원본을 실제 열고 VIC 계약/preflight/claim 후 스프라이트 시트 1회 생성. native와 프레임 순서·앵커·알파를 보존/확인한다. 전체 미술 PASS를 주장하지 않는다.
2. 공간 분리/직접 상호작용/공유 시계 프레임/기본 음악 구현. reduced motion·gfx lite/off·숨김 탭·포커스·재편성 정리 검증.
3. 단위/타입/린트/프로덕션 빌드 및 fixture Playwright. 기본 음악·마스터 음소거/음량·autoplay 차단 후 입력·10초 무음·이탈 정리, 클릭에 서버 쓰기 없음, 버튼/관객 비가림과 PC/모바일/짧은 가로/여러 일정 확인. 기존 경계 테스트 보존.
