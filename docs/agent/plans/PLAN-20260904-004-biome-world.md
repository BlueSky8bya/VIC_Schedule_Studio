## 1. 원칙(아홉)

1. **장난감 축척(동물의 숲 비율).** 세계의 모든 것은 **가장 큰 것 : 가장 작은 것 ≤ 1 : 12**. 나무를 키우는 게 아니라 **작은 것을 줄인다**
   (낙엽·발자국·클로버) + 나무는 조금만 키운다. 꽃·풀은 일부러 크게 — 귀여움의 비율.
2. **타일 한 칸 = 64 CSS px**(1×). 화면 1500×900 ≈ 23×14칸. 모든 크기는 타일 분수(§2), 상수는 `world/scale.ts` 한 곳.
3. **3/4 시점(오블리크).** 카메라가 45~50°로 비스듬히 내려다본다(§2.5). 위 = 멀다(작고 옅고 서로 가림), 아래 = 가깝다. 서 있는 것은
   세운 스프라이트(이미 그렇다), 바닥에 납작한 것은 세로로 눌린다, 그림자는 발밑 타원. 화면 위 띠는 **지평선·먼 것들**의 자리 — 나무가 작게
   줄지어 서는 이유가 생긴다.
4. **기본 화면 = 초원.** 달력 뒤도, 감상하기 첫 화면도 사철 같은 구도의 초원. 계절은 옷만 갈아입는다.
5. **물은 바이옴이다.** 연못·시내·바다는 각자의 화면. 초원에 물 띠를 억지로 넣지 않는다.
6. **세계는 하나의 연속된 땅.** 화면들은 이어진 지도, 이동은 카메라가 미끄러지는 것. 방향은 오행 방위(북 = 물, 서 = 금/돌, 동 = 목/숲)를
   따르고, 바다는 남쪽에서 시작해 **남으로 갈수록 깊어진다**.
7. **애플 결.** 카메라 620ms `ease-out-quint`, 이동 중 두 화면이 한 장으로 흐름, 도착 알약 1.6초, 미니맵, 이동 직전 목적지 굽기(드랍 0).
8. **효율.** 엔진 하나·캔버스 하나·활성 화면만 step, 바이옴 모듈은 종류별 하나(계절·변주는 파라미터), 생물은 에이전트 + 서식지 표.
9. **픽셀아트 확정(ADR-0017 ⑮⑦)** — 3/4 시점과 딱 맞는다(동숲 카메라 = 세워 그린 픽셀). 바탕 타일도 픽셀(P3).

### 2.5 시점 — 3/4 오블리크 카메라(새 항목)

동물의 숲의 카메라: 약 45~50°로 내려다본다. 바닥은 세로로 눌리고(cos ≈ 0.7), 서 있는 것은 그대로 세워 보이고, 멀수록 위에 있고 조금 작다.
우리 엔진에 넣는 규칙(`world/view.ts`, 전 장면 공통):

| 규칙 | 값 | 적용 |
|---|---|---|
| 바닥 눌림 `GROUND_SQUASH` | **0.7** | 납작한 것(flat: 발자국·클로버·연잎·조약돌·낙엽 더미·물고기 그림자·파문 고리·발밑 그림자)은 `scale(1, 0.7)`로 그린다. 파문 고리 = 타원 |
| 거리 축소 `depthScale(y)` | 화면 위 **0.60** → 아래 1.00 (선형; 0.80은 실측에서 약했다) | 서 있는 것·생물·소품의 배율. 픽셀 격자가 깨지지 않게 0.05 단위로 양자화 |
| 대기 안개 `drawDepthHaze` | 지평선 α .34 → 화면 58%에서 0 | 엔진이 장면 위에 한 겹(계절 안개색) — 잔디·물·발자국·생물이 멀수록 옅어진다 |
| 땅의 것 | `gy()/groundY(r)` | 스폰·랩·경계·자국·클릭은 지평선 아래에서만. 지평선 띠에 사는 것은 먼 것(새 그림자·산)뿐 |
| 그리기 순서 | **y-sort**(발 위치) 매 프레임 | 뒤의 것이 앞의 것에 가려진다. 나무 그늘 아래로 토끼가 들어간다 |
| 지평선 띠 `HORIZON_V` | 위 **12%** | 먼 것의 자리: 초원 = 낮은 언덕 실루엣 + 나무 줄(작게), 바다 = 수평선 + 하늘 한 줄, 숲 = 먼 나무 벽. 대기 원근(채도 −25%, 명도 +8%, 옅은 안개) — PLAN-003 층 무대와 같다 |
| 세계 → 화면 | `screen = (u·w, HORIZON + v·(h−HORIZON))` | 연대기 흔적·스폰 좌표는 정규화 그대로, 변환 한 곳 |
| 포인터 | 화면 좌표 그대로 | 상호작용 판정은 발 위치 기준, 반지름은 `depthScale` 곱 |
| 그림자 | 발밑 타원(폭 = 몸 폭 × 0.9, 높이 × 0.35), 해 방향 오프셋은 세계 시간 | 이미 있는 규칙을 전 장면에 통일 |
| 낙하물(낙엽·눈·꽃잎) | 화면 y로 떨어지되 착지 = 시작 v 근처 | 위에서 떨어지는 게 아니라 "먼 곳에서 가까운 곳으로" 오지 않게, 착지점을 x·v로 뽑고 화면 y만 애니메이션 |
| 물 | 연못 = 눌린 타원 물가, 바다 = 수평선에서 내려오는 파도 띠(위는 촘촘·아래는 성기게) | caustic 층은 `scaleY(0.7)` + 위쪽 옅음 |
| 아트 카메라 | `stand` 그대로(이미 3/4). `flat` 자리의 브리프를 "위에서 비스듬히(3/4) 본 납작한 것 — 세로가 살짝 눌린 타원"으로 개정 | 매니페스트 `VIEW_KO.flat` 갱신 |

효과: 위 띠에 작게 늘어선 나무 = "먼 산기슭"으로 읽힘(지금은 "왜 나무가 작지?"). 오리·토끼가 바닥에 서 있는 느낌. 가까운 것은 크고 또렷,
먼 것은 작고 옅음 — 이것이 소유자의 "거리감".

## 3. 지도 — 초원을 가운데 둔 3×3 + 남쪽 바다 두 줄

```
   ┌────────────┬────────────┬────────────┐
   │ 北西 계곡    │ 北 민물     │ 北東 산     │   계곡의 시내가 연못으로 흘러든다 · 산은 침엽수·절벽·독수리
   │ valley     │ pond       │ mountain   │
   ├────────────┼────────────┼────────────┤
   │ 西 들판·언덕 │ ★ 초원      │ 東 숲       │   ★ = 달력 뒤 · 감상 첫 화면
   │ hill       │ meadow     │ forest     │
   ├────────────┼────────────┼────────────┤
   │ 南西 갯벌    │ 南 모래해안  │ 南東 암석해안 │   해안 띠 — 위 1/3 땅, 아래 2/3 바다(3/4 시점이라 수평선이 위에)
   │ tidal flat │ sandy      │ rocky      │
   ├────────────┴────────────┴────────────┤
   │ 南南 먼바다  open sea  (땅 없음)        │   바다만 · 파도 · 물고기 떼 · 갈매기 · 상어
   ├─────────────────────────────────────┤
   │ 南南南 깊은 바다  deep sea (땅 없음)     │   어둡고 느린 물 · 발광 해파리 · 고래 그림자(전설) · 밤이면 별
   └─────────────────────────────────────┘
```

- **총 11화면**(3×3 + 남쪽 2). 마을길·텃밭 없음(소유자). 초원에서 ↓ 두 번이면 먼바다, 세 번이면 깊은 바다. 먼바다·깊은 바다는 한 화면 폭이지만
  좌우로도 이어진 것처럼 가장자리를 처리(세 해안 어디서 내려가도 같은 먼바다에 닿는다 — 좌표상 (−1,+2)·(0,+2)·(+1,+2)가 한 화면을 공유).
- **오행 방위**: 북 = 물(민물·계곡), 서 = 금(돌·억새·갯벌의 뻘 바위), 동 = 목(숲·산의 침엽수), 남 = 바다(밝은 모래·찬 물, 뜨거운 강세 없음).
- **지리 논리**: 계곡(北西) → 시내 → 민물(北) → (땅 밑) → 갯벌(南西)로 물이 흐른다는 설정. 산(北東)에서 숲(東)으로 나무가 이어지고 암석해안(南東)의
  바위는 산의 돌과 같은 색. 화면끼리 **가장자리 소품이 이어진다**(숲 오른쪽 나무 줄 = 산 왼쪽 나무 줄).

### 3.2 北 민물 pond — 연못과 시내
- 지형: 위 1/3 기슭(풀·갈대·부들·돌), 아래 2/3 연못(눌린 타원 물가, 지금의 caustic 층). 북서에서 시내가 들어온다. 연잎 군락(6→8월).
- 계절: 봄 올챙이·청개구리 · 여름 연잎 12·연꽃·오리·물고기·잠자리·소금쟁이·비 고리 · 가을 잎이 떠 흐름·기러기 그림자 · 겨울 **얼음**(가장자리부터, 1월 전체;
  얼음 밑 물고기 느리게; 얼음 위 발자국).
- 생물: 잉어·붕어·송사리 그림자, 오리+새끼오리, 왜가리(희귀), 청개구리, 잠자리, 소금쟁이, 거북(통나무 일광욕).
- 상호작용: 물수제비·오리 옮기기·거북 퐁당.

### 3.3 東 숲 forest
- 지형: 참나무 + **소나무** 8~12그루가 위·좌우를 두르고 가운데 그늘진 빈터(솔잎·이끼), 그루터기·통나무·바위·고사리·버섯. 나무 그림자가 시간대로 돈다.
- 계절: 봄 새잎·고사리 · 여름 짙은 그늘·**반딧불(저녁·밤)** · 가을 도토리 낙하·다람쥐 저장·낙엽 더미 · 겨울 나목·눈·여우 발자국.
- 생물: 다람쥐·청설모·고슴도치·올빼미(밤, 희귀)·딱따구리·까마귀·여우(겨울 에픽)·반딧불 무리.
- 상호작용: 나무 클릭 = 흔들림 + 잎/도토리/눈 떨어짐, 버섯 클릭 = 포자.

### 3.4 西 들판·언덕 hill
- 지형: 완만한 언덕(밝은 띠로 원근), 억새, 바위 무리, 들꽃. 바람이 보이는 곳(풀 진행파 최대).
- 계절: 봄 들꽃·나비 떼·종달새 · 여름 초록 억새·구름 그림자 · 가을 **은빛 억새 물결**(金) · 겨울 마른 억새에 눈·꿩·매 그림자.
- 생물: 꿩·종달새·참새 떼·나비 떼·메뚜기·들쥐·독수리 그림자(겨울 에픽 — 토끼·꿩이 숨는다).

### 3.5 모서리 — 北西 계곡 · 北東 산
- **계곡 valley**: 바위 사이 시내와 작은 폭포(물 흐름 = 저해상 스크롤 텍스처 + 거품), 이끼 바위, 고사리. 봄 산개구리·여름 물총새(희귀)·가을 단풍 잎이 물에
  떠내려감(연못으로)·겨울 고드름·얼어붙은 폭포. 생물: 물총새·산개구리·다슬기·수달(에픽, 겨울).
- **산 mountain**: 침엽수 고지 + 바위 절벽(위 띠 = 먼 봉우리), 눈이 가장 먼저 오고 가장 늦게 녹는다(계절이 초원보다 2~3주 앞서 겨울, 늦게 봄).
  생물: 독수리(에픽, 절벽에 앉는다)·산토끼·다람쥐·꿩·곰 그림자(전설, 가을 — 실루엣만 멀리).

### 3.6 남쪽 — 해안 셋 + 먼바다 + 깊은 바다(소유자 ⓪)
- **공통**: 3/4 시점이라 **수평선이 화면 위 12%**에 있고 파도가 아래로 밀려온다(거품 선 3~4줄, 위 촘촘·아래 성김). 해안 화면은 위 1/3이 뭍, 아래 2/3이 바다.
  먼바다·깊은 바다는 뭍 0 — 위 띠 = 수평선 + 하늘 한 줄(노을 띠에 붉지 않은 연보라·회장미).
- **南西 갯벌 tidal flat**: 젖은 뻘, 물골, 게 구멍, 낙지 구멍, 조개, 뻘 바위(金). **밀물·썰물**을 세계 시간으로(새벽·저녁 썰물 → 뻘 넓음, 점심 밀물 → 물 많음).
  생물: 칠게 떼(옆걸음, 다가가면 구멍으로 쏙), 짱뚱어(튀어오름), 도요새 무리(희귀, 가을), 낙지(에픽, 밤). 상호작용: 클릭 = 게가 일제히 숨음·발자국.
- **南 모래해안 sandy**: 모래·조개·불가사리·유목·발자국, 여름 튜브·파라솔 없음(사람 없음), 파도가 발자국을 지운다. 생물: 갈매기(착지·걷기), 소라게, 게,
  바다거북 상륙(에픽, 여름 밤 — 알 낳고 돌아감), 해파리 표류. 상호작용: 모래 클릭 = 조개 파기, 물 클릭 = 물수제비.
- **南東 암석해안 rocky**: 검은 바위·물웅덩이(tide pool: 말미잘·불가사리·작은 물고기)·물보라(파도가 바위에 부딪혀 흰 물보라, 저해상 파티클), 갈매기·가마우지
  (날개 말리기). 생물: 가마우지, 따개비·홍합(소품), 문어(희귀, 물웅덩이), 물범(에픽, 겨울 바위 위). 상호작용: 물웅덩이 클릭 = 물고기 흩어짐.
- **南南 먼바다 open sea**: 바다만. 큰 너울(느린 진행파 2겹), 햇빛 반짝임, 물고기 떼 그림자(고등어·전갱이), 날치(튀어오름), 갈매기 그림자, 돌고래 무리
  (희귀, 등지느러미·점프), **상어(전설, 지느러미가 수면을 가른다)**. 여름 튜브가 여기까지 떠내려온다(초원엔 없음). 상호작용: 클릭 = 물수제비 고리·물고기 떼 갈라짐.
- **南南南 깊은 바다 deep sea**: 어둡고 느린 물(진남색, caustic 거의 없음), 위 띠 = 수평선 + 별(밤 띠), **발광 해파리** 무리, 오징어 떼(밤), 고래 그림자
  (전설, 아주 크고 느리게 지나가며 물을 밀어낸다 — 화면의 절반), 가오리(희귀). 여기는 "조용한 방" — 입자 적고 소리 없고 움직임이 느리다.
  상호작용: 클릭 = 발광 파문(해파리가 모여든다).

### 3.7 공통 규칙
- 세계 시간·날씨·연대기는 열한 화면이 공유(한 세계). 갯벌의 조석은 세계 시간 함수.
- 연대기 흔적에 `biome`: 데뷔 나무·눈사람 = 초원, 도토리 = 초원+숲, 연잎 = 연못, 갯벌 게 구멍 수 = 계절 함수.
- 핫 존(달력)은 초원에만. 다른 화면은 감상 모드에서만 보이므로 전체가 놀이 공간.

| # | 결정 |
|---|---|
| ⓪ | 마을길·텃밭 없음. 바다는 **바다만**(먼바다·깊은 바다는 뭍 0). 해안은 모래·암석·갯벌 셋 다. **시점 = 3/4 비스듬히(거리감)** |
| ① | 사철 기본 화면 = **초원** |
| ② | 모서리 확장 긍정 → 계곡(北西)·산(北東)·갯벌(南西)·암석해안(南東) |
| ③ | 입력 = 방향키 + WASD + 스와이프 + 가장자리 쉐브론 + 미니맵 |
| ④ | 시청자 화면도 바이옴 감상, **만난 동물 수집 → 도감** |

착수 순서: P0(축척 + 시점) → P1 → P2 → P3. P0가 끝나면 네 계절 스크린샷으로 시점·축척을 먼저 보인다.
