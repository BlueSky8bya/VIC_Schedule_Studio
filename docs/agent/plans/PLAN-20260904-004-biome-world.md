# PLAN-20260904-004 — 바이옴 세계(Biome World): 동물의 숲 축척 + 방향키로 오가는 다섯 화면

Status: **Proposed** (소유자 결정 대기 — §8) · Task Risk: **L2** (구조적 — 계절 장면 4개를 "세계 × 카메라 × 바이옴" 구조로 재편, 축척 규격 도입,
여름 기본 화면 교체) · Created: 2026-09-04 · 선행: PLAN-20260904-003(연대기·에이전트 — Phase B는 이 계획 안으로 흡수)

> 소유자(2026-09-04): "나무 크기가 주변 비율이랑 전혀 안 맞아 — 나뭇잎이 나무만하면 어떡해. 여름은 땅을 억지로 윗부분에 만들면 어떡해.
> 나무 비율에 맞게 맵을 축소하자. 도감에 물고기 같은 해양 생물도 있으니 봄·여름·가을·겨울 맵마다 바이옴을 만들자 — 진짜 동물의 숲처럼.
> 감상하기를 누르면 평범한 초원, 거기서 화살표 위/아래/좌/우로 움직이면 민물·바닷물·숲 같은 다른 바이옴. 이것부터 정리하고 그 다음 생물
> 이미지를 생성해서 배치. 가장 합리적·효율적·애플 감성·부드러운 애니메이션으로, 바이옴을 어디 놓을지까지."

## 0. 한 줄과 세 가지 문제

**한 줄:** 배경을 "계절마다 다른 벽지 한 장"에서 **"계절마다 옷을 갈아입는 하나의 작은 세계(초원 + 네 방향 바이옴)"**로 바꾼다.
축척은 동물의 숲의 장난감 비율로 통일하고, 물은 억지 띠가 아니라 제 바이옴(연못·바다)에 산다.

| 문제 | 지금 | 왜 어색한가 |
|---|---|---|
| **축척** | 낙엽 30~50px · 장화 자국 36px · 오리 56px · 나무 52~168px | 나무 : 낙엽 = 1 : 4(실제 1 : 100, 동물의 숲 ≈ 1 : 12). 작은 것들이 "확대 사진" 축척, 나무만 "장난감" 축척 |
| **여름 기슭** | 물 화면 위에 뭍 띠 11%를 강제로 깔고 나무·싹을 그 위에 | 물 장면에 땅을 억지로 넣은 것 — 구도가 계절마다 달라 세계가 하나로 안 읽힌다 |
| **바이옴 없음** | 계절 = 화면 한 장 | 도감의 물고기·바다·숲 종이 살 자리가 없다. 여름에만 물이 있고 봄 연못·겨울 얼음이 없다 |

## 1. 원칙(여덟)

1. **장난감 축척(동물의 숲 비율).** 세계의 모든 것은 **가장 큰 것 : 가장 작은 것 ≤ 1 : 12** 안에 들어온다. 나무를 키우는 게 아니라
   **작은 것을 줄인다**(낙엽·발자국·클로버) + 나무는 조금만 키운다. 꽃·풀은 일부러 크게(동숲이 꽃을 과장하듯) — 귀여움의 비율.
2. **타일 한 칸 = 64 CSS px**(1×). 화면 1500×900 ≈ 23×14칸 — 동숲의 한 화면(≈20×12칸)과 같은 밀도. 모든 소품·생물 크기는 타일 분수로
   적는다(§2). 픽셀아트 논리 해상도(64~96px)와도 맞아떨어진다.
3. **기본 화면 = 초원.** 달력 뒤 배경도, 감상하기 첫 화면도 사철 **같은 구도의 초원**. 계절은 옷(색·소품·날씨·생물)만 갈아입는다.
4. **물은 바이옴이다.** 연못·시내·바다는 각자의 화면. 초원에 물 띠를 억지로 넣지 않는다. 여름 물결(caustic)은 연못·바다 화면에서 산다.
5. **세계는 하나의 연속된 땅.** 다섯 화면은 이어진 지도이고, 이동은 **카메라가 미끄러지는 것**(장면 교체가 아니라). 방향은 오행의 방위
   규칙(북 = 물, 서 = 금/돌, 동 = 목/숲)을 따른다 — 이미 편집실 배치에 쓰는 규칙이라 세계와 화면이 같은 나침반을 갖는다.
6. **애플 결.** 카메라 620ms `ease-out-quint`(오버슈트 없음, 도착이 부드럽게 멎는다), 이동 중 두 화면이 한 장으로 흐른다, 도착하면
   바이옴 이름 알약이 1.6초 떴다 사라진다, 미니맵 점 다섯이 현재 위치를 채운다, 이동 직전에 목적지를 미리 구워 프레임 드랍 0.
7. **효율.** 엔진 하나·캔버스 하나·**활성 화면만 step**(이웃은 이동 순간에만 깨움), 바이옴 모듈은 5개(계절은 파라미터·팔레트 표), 생물은
   에이전트(PLAN-003 Phase B)로 옮겨 "서식지" 표 한 줄로 바이옴에 배치. 새 파일을 20개(바이옴×계절) 만들지 않는다.
8. **픽셀아트 확정(ADR-0017 ⑮⑦).** 바탕 타일도 결국 픽셀 타일(4단계). 그 전까지 지금의 부드러운 절차 바탕 위에 픽셀 소품 —
   실측상 120px 이하에서는 어긋남이 안 보인다.

## 3. 바이옴 배치 — 십자 다섯 화면

```
                     ┌──────────────┐
                     │  北 민물      │  연못 + 시내(水)
                     │  pond        │
     ┌───────────────┼──────────────┼───────────────┐
     │  西 들판·언덕   │  ★ 초원       │  東 숲         │
     │  hill (金·돌)  │  meadow      │  forest (木)  │
     └───────────────┼──────────────┼───────────────┘
                     │  南 바닷가     │  모래 + 바다(빛·소금 = 火·金의 남쪽, 뜨거운 강세 없이)
                     │  shore       │
                     └──────────────┘
```

- **방향의 근거** — 편집실 배치에 이미 쓰는 오행 방위(CLAUDE.md "Direction → screen"): 북 = 물 → 연못·시내, 서 = 금 → 돌·억새·마른
  들판, 중앙 = 따뜻한 초원, 동 = 목 → 숲. 남은 규칙상 "뜨거운 강세 금지" 자리 — 바닷가는 모래(밝음)와 물(차가움)이라 안전하고, 한국 지형
  직관(남해)과도 맞는다. 사용자가 어느 화면에 있든 **"위로 가면 물, 오른쪽은 숲"**이 몸에 남는다.
- **네 모서리(북동·북서·남동·남서)는 2단계 예약** — 텃밭(북서), 산·바위 절벽(북동), 갯벌(남동), 마을 길(남서). 지금은 이동 불가(모서리로
  가려 하면 카메라가 살짝 튕기고 돌아온다 — "여기는 아직").

### 3.1 ★ 초원 meadow — 달력 뒤·감상 첫 화면 (지금의 봄/가을/겨울 장면이 이것이 된다)

| | 봄 | 여름 | 가을 | 겨울 |
|---|---|---|---|---|
| 바탕 | 연둣빛 잔디, 클로버, 햇빛 얼룩 | **짙은 초록 잔디, 열기 아지랑이(저해상 왜곡 아주 약하게), 매미 소리 없음(무음)** — 물결 대신 | 마른 풀·흙 얼룩, 낙엽(작아짐) | 눈밭, 발자국 |
| 지형·소품 | 데뷔 나무(고정 자리 u .78 v .06 → 초원 북동 구석 그대로), 데이지·민들레·두더지 흙더미 | 같은 자리 나무 짙은 초록, 풀 얼룩, 그늘 | 도토리 저장소·버섯·잔가지·낙엽 더미 | 눈사람(12/20~2/25), 눈 무더기 |
| 생물 | 나비·벌·무당벌레·참새(신규) | 나비(여름 종)·잠자리(연못에서 온)·개미 행렬 | 다람쥐·까치·들쥐 | 눈 토끼·고양이 발자국 손님·꿩 |
| 상호작용 | 클릭 = 풀 밟힘·민들레 홀씨 | 클릭 = 풀 밟힘, 아지랑이는 포인터에 잠깐 걷힘 | 잎 집어 던지기·도토리·흙더미 파기 | 발자국·눈가루·토끼 놀람 |

여름 초원은 **새로 만든다**(봄 초원 코드 + 여름 팔레트·소품). 지금의 여름 물 장면 코드는 §3.2/§3.5로 이사한다.

### 3.2 北 민물 pond — 연못과 시내

- 지형: 화면 아래 2/3가 연못(위에서 본 물, 지금의 caustic 물결 층 재사용), 위 1/3은 풀밭 기슭 — **기슭이 자연스러운 자리**(연못 화면이니까).
  오른쪽 위에서 시내가 흘러들어온다(가는 물줄기, 돌 몇 개). 연잎 군락(6→8월), 부들·갈대, 물가 돌.
- 계절: 봄 = 개구리알·올챙이 점·청개구리, 여름 = 연잎 12·연꽃·오리·물고기 그림자·잠자리·소금쟁이·비 고리, 가을 = 잎이 물에 떠 흐른다·
  기러기 그림자, 겨울 = **얼음**(가장자리부터 얼어 1월엔 전체, 눈 덮인 얼음 위 발자국, 얼음 밑 물고기 그림자 느리게).
- 생물(도감): 잉어·붕어·송사리 그림자, 청둥오리+새끼오리 행렬, 왜가리(희귀, 그림자로 왔다가 물가에 서서 낚시), 청개구리, 잠자리,
  소금쟁이, 붉은귀거북(통나무 위 일광욕).
- 상호작용: 클릭 = 물수제비(고리 + 물고기 놀람 뒤 모임), 오리 집어 옮기기(지금 것), 거북 건드리면 물로 퐁당.

### 3.3 東 숲 forest — 나무가 빽빽한 곳

- 지형: 참나무 + **침엽수(소나무, 새 자리 4계절)** 8~12그루가 위·좌우 가장자리를 두르고 가운데는 그늘진 빈터(낙엽·솔잎·이끼). 그루터기·
  통나무·바위·고사리·버섯 군락. 나무 그림자가 시간대에 따라 돈다(세계 시간 공유).
- 계절: 봄 = 새잎·고사리·새 둥지 소리 없음(무음), 여름 = 짙은 그늘·반딧불(저녁·밤 띠에만 — 세계 시간이 여기서 빛난다), 가을 = 도토리
  낙하·다람쥐 저장·버섯·낙엽 더미(잎이 아니라 더미), 겨울 = 나목·눈·여우 발자국·딱따구리 자국.
- 생물: 다람쥐·청설모·고슴도치·올빼미(밤, 신규)·딱따구리(신규)·까마귀·여우(겨울 에픽)·반딧불(여름 밤 무리).
- 상호작용: 나무 클릭 = 흔들림 + 잎/도토리/눈 떨어짐(동숲의 나무 흔들기), 버섯 클릭 = 포자.

### 3.4 西 들판·언덕 hill — 억새와 돌

- 지형: 완만한 언덕 실루엣(밝은 띠 두 개로 원근), 억새(가을 은빛), 바위 무리, 들꽃(봄), 밭 고랑 살짝(텃밭 예약의 예고). 하늘이 넓어
  **바람이 보이는 곳**(풀 진행파를 여기서 제일 세게).
- 계절: 봄 = 들꽃 군락·나비 떼·종달새 그림자, 여름 = 초록 억새·소나기 구름 그림자가 지나감, 가을 = **은빛 억새 물결**(오행 금), 겨울 =
  마른 억새에 눈·꿩·매 그림자(에픽).
- 생물: 꿩·종달새·참새 떼·나비 떼·메뚜기(가을)·들쥐·독수리 그림자(겨울 에픽 — 눈밭 위로 지나가면 토끼·꿩이 숨는다).
- 상호작용: 클릭 = 풀 밟힘·메뚜기 튐, 드래그 = 바람 방향.

### 3.5 南 바닷가 shore — 모래와 바다

- 지형: 위 1/3 모래(발자국 남음), 아래 2/3 바다 — **밀려오는 파도 띠**(거품 선 3~4줄이 위아래로 숨쉬듯, transform/opacity만), 젖은 모래
  띠가 파도 따라 넓어졌다 좁아진다. 조개·불가사리·유목·소라게 구멍.
- 계절: 봄 = 잔잔, 여름 = 튜브가 떠다니고 햇빛 반짝임·물고기 떼, 가을 = 파도 높고 회청색·갈매기, 겨울 = 잿빛 바다·빈 모래·눈이 파도에
  녹는다(눈송이가 물에 닿으면 사라짐).
- 생물(도감 바다 8종 신규): 고등어·전갱이 떼 그림자, 상어(전설, 지느러미가 수면을 가른다), 가오리 그림자(희귀), 게(옆걸음, 클릭에 구멍으로),
  소라게, 갈매기(그림자 + 착지), 해파리(밤 발광), 바다거북(에픽).
- 상호작용: 클릭 모래 = 발자국·조개 파기, 클릭 물 = 물수제비, 파도가 발자국을 지운다.

### 3.6 바이옴 × 계절 공통 규칙
- 세계 시간(여섯 띠)·날씨·연대기는 **모든 바이옴이 공유**한다(한 세계). 비는 다섯 화면 모두에 내리고, 밤은 다섯 화면이 같이 어두워진다.
- 연대기 흔적에 `biome` 필드가 생긴다: 데뷔 나무·눈사람 = 초원, 도토리 순환 = 초원 + 숲, 연잎 = 연못, 두더지 = 초원·언덕.
- 핫 존(달력)은 초원에만 있다 — 다른 바이옴은 감상 모드에서만 보이므로 전체가 놀이 공간.

## 4. 생물 배치표 — 서식지 한 줄이 배치를 정한다

(★ = 지금 살아 있음, 나머지는 PLAN-003 우선 20종 + 바다 8종 신규. 등급은 PLAN-003 표.)

| 바이옴 | 흔함 | 드묾 | 희귀·에픽·전설 |
|---|---|---|---|
| 초원 | 나비★·벌★·무당벌레★·참새·개미 | 눈 토끼★·까치·고양이·들쥐 | 꿩(드묾↑) |
| 민물 | 잉어★·붕어★·송사리 그림자, 오리★, 소금쟁이, 잠자리 | 청개구리·달팽이·지렁이·새끼오리 행렬·거북 | 왜가리(희귀) |
| 숲 | 다람쥐★·까마귀 | 청설모·고슴도치·딱따구리 | 올빼미(희귀, 밤)·여우(에픽, 겨울) |
| 언덕 | 나비 떼·메뚜기·참새 떼 | 꿩·종달새·들쥐 | 기러기 편대(희귀, 가을)·독수리 그림자(에픽, 겨울) |
| 바닷가 | 고등어 떼 그림자·게·갈매기 | 소라게·해파리(밤)·가오리 | 바다거북(에픽)·**상어(전설)** |

신규 바다 8종은 `species.ts`에 추가하고 아트 2차 표에 자동으로 들어온다(매니페스트가 종 레지스트리에서 파생).

## 5. 내비게이션·모션 스펙(애플 결)

| 항목 | 스펙 |
|---|---|
| 입력 | 방향키 ←↑→↓ · WASD · 터치 스와이프(모바일·태블릿) · 마우스가 화면 가장자리 24px에 머물면 **쉐브론이 떠오르고** 클릭 · 미니맵 점 클릭 |
| 카메라 | 세계 좌표(화면 단위 (0,0) 초원). 이동 = **620ms `cubic-bezier(0.22, 1, 0.36, 1)`**(ease-out-quint, 오버슈트 없음), 이동 중 출발·도착 두 화면을 한 캔버스에 translate로 함께 그린다(포인터 상호작용은 이동 중 잠깐 쉼). 잔여 입력은 큐에 넣지 않고 무시(연타해도 한 칸) |
| 예고 | 키를 누른 즉시 목적지 바탕을 굽고(≤ 16ms 예산 초과 시 다음 프레임), 그 다음 프레임에 카메라 출발 — 첫 프레임 드랍 0 |
| 도착 | 바이옴 이름 알약(예: "민물 · 봄 · 노을") 상단 중앙에 1.6초, 유리 알약(감상 나가기 알약과 같은 문법), 한 줄 설명은 처음 방문에만 |
| 미니맵 | 하단 오른쪽 십자 점 5개(현재 = 채움, 방문한 곳 = 테두리, 아직 = 점), 감상 모드에서만, 호버에 이름 |
| 모서리 | 이동 불가 방향(예약 칸)은 카메라가 12px 튕기고 복귀(180ms) + 알약 "여긴 아직 없어요" |
| 감상 진입·복귀 | 진입 = 초원(달력 뒤에 있던 그 장면이 그대로 이어진다 — 재생성 없음), Esc = 어디에 있든 초원으로 스냅한 뒤 감상 종료(달력은 항상 초원) |
| 생동감 OFF(`data-reduce-motion`) | 이동 = 200ms 크로스페이드, 파도·아지랑이 정지 |
| 시청자 화면 | 감상 모드는 시청자 레일에도 있으니 동일 세계·동일 조작(게이트도 동일). 도감(로그인만)은 4단계 |
| 세계 시간 | 개발자 강제(띠·날씨·날)는 바이옴 전체에 적용. fixture `?biome=pond` 추가 |

## 6. 아키텍처(효율)

```
components/shared/ambient/
  scene-engine.ts        Frame·루프 그대로 + camera {x,y,tx,ty,t0}·activeBiome·pendingBiome
  world/biomes.ts        BiomeKey · BIOME_GRID {meadow:[0,0], pond:[0,-1], forest:[1,0], hill:[-1,0], shore:[0,1]} · 이름·설명·오행
  world/world-scene.ts   WorldScene: Scene 인터페이스 그대로 구현(엔진은 모른다) — 바이옴 씬을 lazy 생성·캐시, 활성만 step,
                         이동 중 둘을 translate로 draw, 포인터 좌표를 바이옴 좌표로 변환, 미니맵·알약 상태를 DOM에 이벤트로 알림
  scenes/meadow/{spring,summer,autumn,winter}.ts   ← 지금 spring/autumn/winter.ts 이름만 옮김 + summer 신규
  scenes/pond.ts · forest.ts · hill.ts · shore.ts  ← 바이옴 모듈(계절 = 파라미터, 팔레트·소품·생물 표는 파일 위 상수)
  agents/                PLAN-003 Phase B — 생물 = 에이전트, species.ts에 habitat: BiomeKey[] 한 줄
  world/chronicle.ts     Trace.biome 추가(기본 meadow)
  art/manifest.ts        ArtSlot.biome? 추가 + 바탕 타일 자리(ground-<biome>-<season>, 64 타일) + 침엽수·부들·조개·게·갈매기…
```

- **엔진 변경은 최소**: `mountScene`은 `WorldScene`을 여느 Scene처럼 돌린다. 카메라·키 입력은 WorldScene 안. 기존 `__vicAmbient` 디버그에
  `biome()`·`goTo(k)` 추가.
- **비용**: 평소 = 지금과 같음(초원 하나). 이동 620ms 동안만 두 장면 draw(그중 하나는 이미 구운 바탕 + 생물 몇). 안 가 본 바이옴은 굽지
  않는다. 탭 숨김·OFF·일시정지 규칙 그대로.
- **여름 물 코드의 행선지**: `summer.ts`의 caustic·항적·물고기·오리·연잎 = `pond.ts`(여름 파라미터), 파도·튜브·햇빛 반짝임 = `shore.ts`.
  기슭 띠(`bakeShore`)는 연못 화면의 자연스러운 위 1/3이 된다 — 억지가 아니라 제자리.
- **축척 상수 한 곳**: `world/scale.ts` — `TILE = 64`, 항목별 타일 분수 표(§2). 장면·대체물·아트 로더가 전부 여기서 읽는다(하드코딩 금지).
- **검증**: 단위(그리드·이동 규칙·모서리 튕김·biome 필드), 실측(`probe-biomes.mjs`: 다섯 화면 스크린샷 × 4계절 = 20장, 이동 프레임 드랍
  측정, 축척 비율 ≤ 12, Esc → 초원 복귀, 시청자 화면 동일), 비주얼 스위트(감상 OFF라 무영향).

## 8. 소유자 결정(다섯)

1. **여름 기본 화면(달력 뒤)** — (추천) **초원**: 사철 같은 구도, 물결은 연못·바다에서. 대안: 여름만 연못을 기본으로(물결 그대로, 대신 구도가
   계절마다 달라짐).
2. **화면 수** — (추천) **십자 5**(초원 + 북 연못 · 동 숲 · 서 언덕 · 남 바닷가), 모서리 4는 예약. 대안: 3×3 아홉 화면 한 번에(아트·생물
   부담 2배).
3. **방향 배치** — (추천) 오행안(북 물 · 동 숲 · 서 돌·억새 · 남 바다). 대안: 직관안(북 산/숲 · 남 바다 · 동 연못 · 서 들판).
4. **이동 조작** — (추천) 방향키 + WASD + 스와이프 + 가장자리 쉐브론 + 미니맵 전부(발견 가능성). 대안: 방향키·스와이프만(더 조용).
5. **시청자 화면도 바이옴 감상** — (추천) 예(같은 세계, 게이트 동일). 대안: 편집실만.

결정이 오면 P0 → P1 순서로 착수하고, P1이 끝나면 2차 생물 프롬프트를 바이옴 순서(연못 → 바닷가 → 숲 → 언덕 → 초원)로 뽑는다.
