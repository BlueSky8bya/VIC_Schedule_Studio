## 0. 한 줄과 여덟 원칙

**한 줄:** 배경은 장식이 아니라 **달력이 가리키는 그 달의 작은 생태계**다. 조용하고(儉), 누추하지 않고(不陋), 사건이 있되
(華), 과하지 않다(不侈).

1. **검이불누 화이불치(儉而不陋 華而不侈)** — 김부식 『삼국사기』 백제본기 온조왕 15년조, 새 궁궐을 평한 여덟 자("검소하나
   누추하지 않고, 화려하나 사치스럽지 않다"). 설계 규칙로 옮기면: ① 한 화면에 **이목을 끄는 사건은 동시에 하나**(희귀 생물·
   랜덤 이벤트는 서로 겹치지 않게 스케줄), ② 바탕은 채도·대비를 낮춰 물러나고 **생명만 대비를 가진다**, ③ 장식은 **기능이 있는
   것만**(그림자는 높이를, 파문은 접촉을, 발자국은 시간을 말한다), ④ 여백은 비어 있는 게 아니라 다음 사건의 자리다.
2. **시점의 법(위에서 본다).** 물속 = 그림자(실루엣), 물 위·땅 위 생물 = 세워 그린 에셋(좌우 뒤집기만, 진행 방향으로 눕히지
   않는다), 위에서 본 에셋(무당벌레·나비·거북 등)만 진행 방향으로 회전. 그림자는 발밑 바로 아래(옆으로 떨어진 그림자 = 공중부양).
3. **손그림 금지, 에셋만.** Google Noto Emoji(Apache-2.0) · 퍼블릭 도메인 top-view 도안 → 실루엣 굽기(`bake-silhouette.mjs`) ·
   CC0 소품. 새 생물은 **에셋 확인 열(§8)**이 ✅가 아니면 착수하지 않는다.
4. **움직임의 장인정신 — "절반 잘림 금지".** 움직이는 몸은 반드시 연속 변형이다: 조각 파형(물고기), 관절 ≥4의 골격, 또는
   스프라이트 시퀀스. 디즈니 12원칙 중 게임 배경에 맞는 여섯을 모든 생물의 걸음새(gait)에 적용한다: squash & stretch(착지·
   도약), anticipation(뛰기 전 웅크림·날기 전 굽힘), follow-through & overlapping(멈춘 뒤 귀·꼬리·깃이 늦게 멈춤), slow in/
   slow out(가감속), arcs(뜀·비행은 포물선), secondary action(걷는 동안 머리 까딱·꼬리질). 불투명 합성 뒤 한 번에 옅게 —
   겹침이 짙어지는 줄을 만들지 않는다.
5. **생물 = 자율 에이전트.** 지각(threat·이웃·자원·빛) → 욕구(배고픔·두려움·호기심·휴식·영역) → 행동 선택(utility) → 조향
   (steering: seek/flee/arrive/wander/pursue/evade/separation/alignment/cohesion/hot-zone 회피) → 걸음새 → 렌더. 상태기계는
   종별 카드(§8)에 문헌 근거와 함께 적는다.
6. **상호작용 4축 매트릭스 필수.** 새 종은 생물–생물 · 생물–환경 · 생물–사용자 · 환경–사용자 네 축에 **각 1개 이상**의
   상호작용을 가진 뒤에만 출고한다(§3 표의 마지막 열).
7. **희귀도 = 동물의 숲 방식.** 스폰 풀(계절·월·시각대·날씨·장소) × 가중치 × 동시 상한 × 자비 타이머(pity) × 그림자/크기
   힌트. 희귀할수록 조건이 구체적이고 한 번에 하나만.
8. **연대기 = 결정적 세계 + 개인 흔적.** 세계의 흔적(저장소·싹·나무·눈사람·두더지 흙더미)은 `seed(slug, 연도)`로 결정적으로
   계산되어 **누가 어디서 보든 같다**(DB 없음). 사용자가 남긴 흔적(파낸 저장소·밟은 풀·날린 민들레)은 기기 로컬. 공유 흔적은
   §7의 결정.

## 1. 조사 요약 — 무엇을 빌려오나

### 1.1 벤치마크: 동물의 숲(뉴 호라이즌)의 등장 시스템
- 물고기·곤충은 **장소별 스폰 풀**(강·연못·바다·부두·절벽 위 강·강어귀)로 나뉘고, **월·시각대·날씨(비)**에 따라 풀이 바뀐다.
  그림자 크기가 종을 암시하고, 최희귀 종은 누적 조건(잡은 수 ≥100)이 있다. 미끼로 스폰을 앞당길 수 있다.
  → 우리 것: 풀 = 계절 × 무대 영역(물·물가·풀밭·나무·눈밭) × KST 시각대(새벽/낮/저녁/밤) × (선택) 실제 날씨; 그림자 크기 = 종
  힌트(여름은 이미 그림자); '미끼' = 사용자 행동(물보라 → 물고기 모임 → 상어). 누적 조건은 도감(§7)과 함께 결정.
- 출처: gamefaqs 데이터마이닝 스레드 · Animal Crossing World fish list · Dexerto 가이드.

### 1.2 미술: 층 위계로 만드는 대기 원근
- 대기 원근의 네 요소 — 크기 축소 · 디테일 상실 · 명도 약화(밝아짐) · 채도 저하 — 가 멀어질수록 함께 진행된다. 무대를
  전경/중경/배경 무대 세트처럼 층으로 나눠 생각한다(Art Prof·Draw Paint Academy·Vaia).
- 위에서 내려다보는 장면엔 '멀리'가 없다. 대신 **높이 층**이 있다: 바닥(가장 낮은 대비·채도) → 낮은 풀 → 긴 잡초(흔들림) →
  관목(부드러운 그림자, 생물의 은신처) → 나무 캐노피(가장 또렷·짙은 그림자, 해 각도로 그림자 방향) → 생물 → 공중 입자(꽃잎·
  낙엽·눈) → 빛 얼룩. 아래층은 채도 −20%·명도 +8%, 캐노피 그림자는 바닥을 10% 어둡게. 물속은 깊을수록 푸르고 흐리다(이미
  depth로 구현).
- 색: 계절 팔레트는 소유자 오행 규칙(붉·주황·노랑 강조 금지) 안에서 **생물만 자연색을 채도 낮춰** 쓴다. 대비는 생명에만.

### 1.3 움직임: 디즈니 12원칙의 게임 적용
- 게임에서 가장 값싸고 효과가 큰 것은 **secondary action**(가만히 선 캐릭터의 앰비언트 idle — 눈 깜빡임·무게 이동·귀 까딱)
  이며, squash & stretch는 "무게와 유연함을 형태 변화로 보인다"는 원리만 취하고 과장은 톤에 맞춘다(Animworks·GameJuice).
  → 모든 생물에 idle 2종 이상(숨쉬기·두리번), 이동엔 arcs + slow in/out, 정지엔 follow-through.

### 1.4 인공지능: 조향 행동과 유틸리티
- Reynolds의 조향 행동(seek·flee·arrive·wander·pursue·evade·obstacle avoidance·path following)과 boids(분리·정렬·응집)의
  **선형 결합**만으로 복잡한 군집이 나온다(red3d GDC99 · Nature of Code). 유틸리티 AI = 욕구별 점수로 행동을 고른다.
  → `agents/steer.ts`(조향 8종) + `agents/utility.ts`(욕구 4~5개, 종별 가중치) + 이미 있는 `threat()`(loom 기반 FID).

## 2. 아키텍처

### 2.1 에이전트 프레임워크 (`components/shared/ambient/agents/`)
```
Species {
  id, season pools ({season, months, hours, weather?, zone}), rarity tier, maxConcurrent,
  asset { kind: "shadow" | "upright" | "topdown", url, sizeRange, tint? },
  gait: "hop" | "walk" | "swim" | "fly" | "glide" | "crawl" | "skate" | "perch",
  perception { fid, loomK, boldness, sight },
  needs { hunger, fear, curiosity, rest, territory } (0..1, decay/refill rates),
  behaviors: StateMachine[] (utility-scored), interactions: { onThreat, onNeighbor(species), onResource, onClick, onSplash, onWeather },
  debug counters
}
```
- **서비스**: 공간 해시(이웃 O(1)), 자원 레지스트리(꽃·도토리·부스러기·그늘·앉을 곳·물가·굴), `threat()`, `steer.ts`, 걸음새
  렌더러(bob/squash/stride/tail-wave/wing-flap/skate-dimple), LOD 3단(포인터 근처 = 전부, 중간 = 조향만, 먼 곳 = 위치만),
  **스폰 감독**(풀·가중치·동시 상한·자비 타이머·쿨다운·가장자리 출입), **이벤트 감독**(희귀 사건은 한 번에 하나, 최소 간격),
  **날씨/시각 서비스**(KST 시각대·(선택)실제 날씨).
- 기존 8종(물고기 2형·오리·토끼·다람쥐·나비·무당벌레·꿀벌)은 Phase A에서 이 틀로 옮기되 화면 결과는 동일해야 한다(회귀 0).

### 2.2 연대기 엔진 (`chronicle.ts`)
- **시간 입력**: 보고 있는 달(달력) · 그 달의 날(현재 달 = 오늘, 과거 달 = 말일, 미래 달 = 1일 — "아직 오지 않은 시간엔 예고만")
  · KST 시각(빛·시각대 풀) · (선택) 실제 날씨.
- **결정적 세계**: `seed = hash(calendarSlug, year)`. 보고 있는 달의 세계 상태 = 기원(2024-01)부터 그 달까지 **달 단위 조립
  시뮬레이션**(프레임 아님, ms 단위): 가을마다 저장소 N개(정규화 좌표, 달력 밖 띠 — 위쪽 헤지로우 띠·좌우 12% 여백), 봄에
  그중 일부가 싹, 여름에 묘목, 가을에 작은 나무(잎을 떨굼·도토리를 떨굼 → 다음 해 저장소가 그 나무 근처에 생김 = 숲이 자란다,
  상한 N그루, 오래된 자리 안정), 겨울엔 눈사람(12/20 이후 손님이 며칠에 걸쳐 굴려 세움 → 2월 녹음), 두더지 흙더미(봄 → 여름
  풀 얼룩), 버섯 자리(가을마다 같은 자리), 연잎 군락(6→8월 확장), 제비 둥지(나무가 있으면 4월 → 6월 새끼).
- **월 안의 진행**(day-of-month): 3월 새싹·마른 풀 → 4월 벚꽃·꽃잎 → 5월 신록; 6월 작은 연잎·새끼오리 → 7월 장마 비 이벤트
  잦음 → 8월 반딧불이·큰 물고기·연꽃; 9월 아직 초록·잎 적음 → 10월 낙엽 절정 → 11월 헐벗음·서리; 12월 얇은 눈 → 1월 깊은
  눈 → 2월 군데군데 녹아 땅(과 지난 가을 저장소 흙더미)이 드러남.
- **개인 흔적**(localStorage `vic.world.<slug>`, 작게·만료): 내가 파낸 저장소(그 자리엔 싹이 안 난다!), 날린 민들레, 밟은 풀,
  놀라 달아난 생물의 경계심(같은 날 재방문 시 더 예민). **공유 흔적**(서버) 은 §7 결정 사항.
- 위치는 정규화 좌표(0~1)로 두고 편집실·시청자 화면의 핫 존을 피하는 띠에서만 생성 → 두 화면에서 같은 자리.

  + 다른 이벤트와 겹치지 않게 감독이 잠근다. 자비 타이머는 "한참 아무 사건이 없으면 드묾 이상을 보장"(감상 모드에서 특히).
- 도감(사용자에게 "봤다"를 기록)은 선택(§7). 없어도 시스템은 완결.

### 2.4 미술 방향(공용 토큰)
- 층: 바닥 → 낮은 풀/물결 → 긴 잡초(진행파 흔들림, 봄 타일 재사용) → 관목(부드러운 그림자, 은신처 자원) → 나무 캐노피(위에서 본
  둥근 캐노피 + 해 각도 그림자: KST 시각으로 방향, 정오 최소) → 생물 → 공중 입자 → 빛 얼룩. 아래층 채도 −20%/명도 +8%.
- 빛: 새벽·저녁 = 회청/회자색 tint(주황 금지), 밤 = 차게 + 달빛 글린트 + (여름) 반딧불이. 생동감 OFF·soft 판정은 정지 한 장.
- 계절 팔레트(생물은 자연색 채도 −25%): 봄 이끼·연둣빛·흰 꽃·연보라(라일락) / 여름 물빛·청록·백사 / 가을 갈색·와인·올리브·버섯
  크림 / 겨울 서리 청회·흰·마른 갈색. 어디에도 쨍한 붉·주황·노랑 없음(고추잠자리·단풍도 채도 낮춘 벽돌색·와인).
- 걸음새 사전(각 종 카드가 참조): hop(웅크림 → 포물선 → 착지 squash), walk(stride 주기·머리 반대 위상), swim(꼬리 파형·
  가속 맥동), fly(날개 flap·고도 bob·그림자 거리), glide(고정 날개·그림자 크게), crawl(신축), skate(보조개 4개), perch(착지
  감속·꼬리 follow-through).

### 2.5 성능 예산과 LOD
- 장면 CPU ≤ 2.5ms/프레임(load 1, 중급 노트북), 메모리 ≤ 40MB(스프라이트 포함). 열화 순서: 공중 입자 → 먼 생물 조향 → 이벤트
  빈도 → 생물 수(가장자리 퇴장). 공간 해시로 이웃 탐색, 스프라이트·바탕·캐노피 그림자 한 번 굽기, 저해상 층은 부드러운 것만.
- 종당 최대 동시 수와 총 상한(load 1: 40 에이전트 + 입자). lite(load .3)도 계절이 알아보여야 한다(각 계절 대표 3종은 항상).

### 2.6 검증 방법
- 종별 probe(카운터: 도주·경계·먹기·저장·전염 …), 확대 스크린샷(3×)로 **관절 줄·톱니·겹침 짙어짐 0**, perf-frames(nogpu·gpu),
  `npm run test:visual`(정지 프레임 기준선), 에셋 레지스트리 lint(손그림 파일 금지), 4축 매트릭스 체크리스트(§3 표 마지막 열이
  비면 출고 금지), 연대기 결정성 테스트(같은 seed·달 → 같은 흔적 좌표, 두 화면 일치).

## 7. 소유자 결정 — **결정됨(2026-09-04 밤)**
1. **하루 여섯 띠**: 새벽 · 아침 · 점심 · 노을 · 저녁 · 밤(`world/time.ts`, 계절별 일출·일몰 KST). 빛 톤은 낮 없음, 새벽 회청, 노을 **회자색**
   (주황 금지), 저녁·밤 청회. 야행성 종·반딧불이는 띠로 스폰.
2. **전설은 순수 확률** — 사용자 행동으로 부르지 않는다(상어도 물보라 조건 없음). 세션당 1회, 자비 타이머는 드묾 이상까지만.
3. **도감은 로그인 사용자만**(개발자·관리자·시청자 계정) — 계정별 서버 저장(`ambient_sightings`: user_id·species·first_at·last_at·count,
   RLS 본인만, 쓰기 API는 분석 가드와 rate limit). 비로그인은 도감 없음. Phase B에 데이터 경로, UI는 시청자 레일 '도감' + 편집실 모달.
4. **공유 흔적 없음** — 개인 흔적만(localStorage). 서버 세계는 결정적 연대기뿐.
5. **실제 날씨 없음, 날씨는 랜덤** — 단 **날짜 시드 난수**(`world/weather.ts`): 같은 달력·같은 날·같은 마디(오전/오후)면 누구에게나 같고
   리로드해도 안 바뀐다. 계절 확률표(7월 비 42%, 겨울 눈 25%, 11월 안개 18% …), '직전 마디' 날씨로 비 뒤 창(달팽이·지렁이).
6. **우선 20종**(§3 표에서 고름, 계절 공용 종은 하나로 셈): 참새 · 고양이 · 까치 · 개미 행렬 · 청개구리 · 달팽이 · 지렁이 · 붉은귀거북 ·
   소금쟁이 · 잠자리 · 새끼오리 행렬 · 왜가리 · 까마귀 · 청설모 · 고슴도치 · 들쥐 · 기러기 편대(그림자) · 여우 · 꿩 · 독수리 그림자.
   (+ 전설 이벤트로 상어·눈사람 완성은 종 수에 넣지 않는다.) 코드 표현: `world/species.ts`.
7. **채도는 균형** — 생물 자연색을 −20%로 낮추고, 의미색 8종(업 도움 rose·기간 안내 cyan 등)과 겹쳐 보이면 한 단계 더 낮춘다.

Phase A 착수(2026-09-04 밤): `components/shared/ambient/world/{seed,time,weather,chronicle,rarity,species}.ts` + Vitest, 엔진 Frame에
`date·time·weather·traces`, 빛 톤 레이어, 연대기 흔적 렌더(`world/traces-draw.ts`), 장면별 날씨 훅.
