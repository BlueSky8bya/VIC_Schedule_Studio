Status: Awaiting visual feedback. UI/liveness release cf00f2b4 is deployed and verified; eye scope remains pending. See [verification](../verification/COMPANION_LIVENESS_CHROME-20261018.md).

최신 소유자는 방송 중 표정까지 약1분 정지한 사례를 제보했다. OBS 원인으로 단정하지 않고 active/visible blur/parked/hidden/geometry/decode/long-frame의 실제 소유권과 재개 경로를 조사한다. 정상 숨기·현재 행동 완료 후 수면·실제 숨김 탭 정지·reduced/OFF·모바일 제외를 보존한다. active 무기한 정지는 회복하고, 조용한 수면도 컴포지터의 작은 생동감으로 보이게 한다. 새 상시 layout watchdog·모델/서버 요청은 추가하지 않는다.

편집실·viewer·preview에서 패널 제목의 재질/색과 header 집 진입의 버튼/간격을 공유 토큰으로 통일한다. 실제 옆 패널에서는 제목 접힘/저장을 유지하되, 버튼으로 연 작은 집에는 접힘을 두지 않고 전체 실내와 X만 제공한다.098의 compact 제목 접힘 규칙만 이 후속으로 대체하며 달력 공간 예약은 되살리지 않는다.

초기098 열린 눈 약90% 목표는 실제 생성에서 과하게 줄어 미달로 보존했다. 이후 사용자가 비교의 오른쪽 위 기본099 눈 크기를 선택해 그 시각 기준으로 대체했다. 기본 SHA는 유지하고 다른6묶음만 각각1회 교정했다. 감정0은 기준과 약3% 차이지만 놀이20~29%·응원17% 잔여가 있어 전체 통일로 배포하지 않는다. 사용자에게 실제5키 비교를 보여주고 추가 한정 수정/현 초안 적용/눈 보류 중 응답을 기다린다. constitution/imagegen의 실제 사용자 원문·사전검사·한 번 생성·초안 등록과 전512슬롯/응원16키의 표정 의미·두 귀·무사지 종이 몸·등록·alpha·기존 footprint·lazy decode 예산을 유지한다. 원본/영수증 SHA와 줄바꿈 바이트를 보존하며 시각 승인이나 독립 전문 검수를 지어내지 않는다.

서버 DTO·권한·언락·KST·DB·의존성은 변경하지 않는다. 사용자 기존 아트·로컬 설정과098 배포 후 기록은 보존한다. 독립 소스 검토와 쓰기 차단 production-fixture의 실제 조작/장시간 정지·복귀·중첩창·접힌 패널·모바일 제외·테마/크기별 스냅샷을 사용한다. 로컬 단위/typecheck/lint/build/harness 뒤 승인된 commit/push와 운영 full SHA/UI를 확인한다. 실제 방송 PC의 GPU/인코딩 부하는 별도 증거로 구분한다.
