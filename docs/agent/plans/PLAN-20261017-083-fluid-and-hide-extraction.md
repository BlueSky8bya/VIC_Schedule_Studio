## 범위

- 공유 빅타민의 기존 guest drag/키보드·팝오버 경계에서 축소 비율을 점진 복원한다. 잡은 재질상의 지점은 포인터를 따르고, 안으로 되돌리기·취소·놓기·창 닫기에도 한 표시 몸체와 기존 수면/직접 입력 소유권을 유지한다.
- 숨은 카드 한 곳에만 짧은 회전/이동 힌트를 간헐적으로 준다. 기존 카드 FLIP과 합성하고 동작 줄이기/gfx off·soft에서는 정적인 힌트만 유지한다. 새 상시 JS 타이머/geometry scan·DB·추적 수집은 없다.
- 실제 공용 일정만 대상이다. 제목/본문/태그/비공개 데이터·권한·KST 경계·1840 포스터 기하는 변경하지 않는다. 모바일 빅타민 제외 유지.
