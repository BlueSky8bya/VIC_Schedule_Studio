# 작은 손 표시 제거와 클래식 라디오 확장

2026-10-21 KST. Status: in progress. 최신 사용자 요청이 우선한다.

## 범위

- 현재 빅타민에 남은 작은 손 시각 경로를 조사하고 실제 renderer/ref/표시 CSS를 제거한다. 사용자 쓰다듬기 조작과 몸·표정 반응은 유지한다. 손 모양 전용 커서 숨김도 제거해 기본 포인터가 사라지지 않게 한다. 포인터 좌표/잡기 계산의 단어가 hand라는 이유로 물리 코드를 지우지 않는다. 원본 이미지에 손을 새로 그리거나 원본을 덮지 않는다.
- 기존 라디오13곡과 ID·음량·제외 설정·음소거·브라우저 제스처·OFF/숨김·한 번에 한 미디어 스트림을 유지하며 다양한 역사적 클래식 녹음21곡을 추가한다. 후보22곡 중 Aquarium은 출판자가 자동 Content ID 신고 위험을 명시해 채택에서 제외하고 거절 근거를 보존한다. 제목만 다른 같은 음원은 제외한다.
- 작곡 저작물과 연주/녹음의 권리를 구분한다. 공식 출판자 Incompetech가 CC BY4.0으로 제공하는 녹음 및 실제 출처/라이선스를 확인한 곡만 채택한다. 원본 다운로드·출처 페이지·변환/실배포 해시·크기·실제 디코드/길이를 보존하고, 현재 원본13과 과거 provenance-v111은 변경하지 않는다. 새 결합 provenance-v155를 둔다. 출처·제작자·라이선스·음량보정/변환 표시를 계속 제공한다.
- 새 유료서비스/의존성/서버 권한/운영DB/로그인/분석 메타데이터를 추가하지 않는다. 개인별 곡 제외와 동물 행동은 인간 활동 정보로 새로 수집하지 않는다.

## 실행과 검증

손 제거 작성자와 음원 출처 조사자를 별도로 실제 호출했다. 루트가 음원 변환·등록과 통합을 맡는다. 작성자가 자기 변경 승인자를 겸하지 않게 독립 리뷰를 거친다. 기존 사용자 제작기록·로컬 보고서·모든 실패를 보존한다.

관련 unit와 전체 unit/typecheck/lint/build, 실제 생산 빌드의 쓰다듬기·라디오 전체 곡 재생/PCM·3표면 설정/제외/음소거·단일 스트림·무자동재생을 확인한다. 새 고정 사용자 조작은 없지만 G-22 기존 타임라인/사용빈도/라벨과 포인터·키보드 캡처를 감사한다. 실제 OS 스피커/방송 PC/장시간 전곡 청취는 별개로 보고한다. 허용 companion 범위만 반영하고 공개 전체 SHA/자산 확인 후 배포로 보고한다.
