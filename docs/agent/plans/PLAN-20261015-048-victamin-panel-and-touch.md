- 태그 필터 제목은 편집실/시청자 모두 가운데 정렬. 시청자의 태그 필터·계절 배경·빅타민 집은 같은 제목 버튼으로 개별 접기, 접근성 상태·키보드와 기존 spring/패널 흐름을 유지한다. 집은 제목을 복원하고 빈 오른쪽 공간도 같은 재질의 작은 생활 소품으로 정리한다.
- 놓은 먹이는 실제 지지 DOM 또는 문서 좌표에 고정한다. viewport에서 벗어났다고 다른 발판으로 재배치하지 않으며 스크롤 후 원래 자리에 돌아온다. 드래그/식사 재집기·숨김·월 변경·동적 reflow를 분리한다.
- 빅타민의 점유 발판이 스크롤로 사라질 때는 임의의 x로 teleport하지 않는다. 현재 x를 보존하는 가까운 높이의 안전한 span으로 짧게 착지한다. 그런 span이 없으면 안전하게 숨고 접지가 돌아올 때 회복한다. 집 주민의 쿠션 고정은 유지한다.
- 한 출처의 귀여운 음식 그림체를 웹 원자료/라이선스로 검토한다. 선명한 작은 크기로 통일하고, 선택 음식의 장식 링을 없애되 키보드 focus 표시는 보존한다.
- 머리 영역에서 누르지 않은 마우스를 왕복하면 쓰다듬는다. hover 판정은 pet 위에서만 계산하고 직접 집기와 충돌하지 않는다. 손·행복 반응은 유한 transform/opacity 애니메이션, 중복 친밀도 정산 방지·동작 줄이기·중단/절전을 지킨다. 새 캐릭터 raster 생성은 하지 않는다.
