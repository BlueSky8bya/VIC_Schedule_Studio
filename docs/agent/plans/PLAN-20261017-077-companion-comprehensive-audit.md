## 목표와 고정 조건

소유자 요청에 따라 시청자·비로그인·시청자 미리보기·편집실의 빅타민을 다시 조사하고, 실제 production-build fixture 조작과 단계별 PNG로 발견한 문제를 수정한다. 모든 가능한 순열을 검증했다는 주장은 하지 않으며 실제 실행 조합·실패·수정 전후·남은 장비/로그인 범위를 기록한다.

076의 기본ON(저장값 없는 PC)·유효한 ON/OFF 선택 보존·모바일 완전 제외,92px 전체 몸체/최대3 decoded 이미지,1840 포스터 기하, full60/lite30 이동/기존 포즈 cadence와 감소 동작 우선권을 유지한다. 일반 창은 강제 밀기/옛 자리 복귀 없이 같은 개체·발판을 창 뒤에 유지한다. parked 빅타민의 자율 프레임·기하 측정0(quiet-tail), 실제 하트/일정 내용/사용자 입력을 바꾸지 않는 장난, 공개·역할·unlock·KST 경계도 유지한다. 편집창 자체의 기존 위치 동기화는 빅타민 비용과 구별한다.

## 수행과 출하

1. 공유 구현·기존 검사를 역할별로 독립 조사하고 코드 후보와 실제 재현을 구분한다. 현재5ff385f2와 같은 제품 소스의 production fixture를 기준으로 원 실패/스냅샷을 보존한다.
2. 현재 승인과 맞는 기존 spec 전체를 우선 조사하고, 오래된 계약의 검사와 제품 결함을 구별한다. 수치/픽셀/조작 기준을 낮춰 실패를 숨기지 않는다. 실제 DB/현재·미래 달 시험 데이터 없이 과거 fixture와 쓰기 차단을 사용한다.
3. 재현한 결함은 원인 경로에서 고치고 같은 경우의 수정 전후 PNG·실제 상호작용을 재검증한다. 새 아트·의존성·서버 API/DB 변경은 필요한 근거 없이 확대하지 않는다.
4. 수정된 제품은 typecheck/lint/unit/build 및 관련 native 회귀·독립 리뷰, 문서/harness를 실행한다. 기존 전체 unit8/harness2와 새 실패를 구분한다. 기존 배포 승인을 이어 commit/push 후 운영 SHA/리소스·안전한 익명 smoke를 확인한다.

## 기록과 한계

실행 보고서·PNG·원 실패는 `.scratch-pw/companion-077-*`에, 확정 결과는 별도 검증 기록에 남긴다. 원본 아트와 사용자의 미커밋 변경은 보존한다. 실제 OBS/SOOP 송출/GPU 장비·실제 로그인/RLS는 fixture와 구별하며 검사하지 않은 것을 PASS로 쓰지 않는다.

## 조사 중 확정한 수정

- 보호된 하단 월 이동 바닥보다 아래에 빅타민을 놓으면 실제 발판 없이 다시 그려지거나 다른 날짜로 이동하던 경로. 일반 첫 하향 접촉 규칙을 보존하고, 같은 x의 실제 viewport 바닥만 복구한다. 유효한 발판이 없는 수동 배치는 숨김을 유지하며 다른 열로 재생성하지 않는다.
- 일반 창이 열린 동안 두 번 눌러 위치를 고르면 표시용 perch만 저장해 명령이 무시되던 경로. 직접 드래그와 같은 실제 위치 채택·중력·기존 스케줄러로 연결한다. 자동 창 밀기/닫기 후 원래 위치 복귀는 복원하지 않는다.
- 편집실에도 공유되는 설정 설명의 시청자 전용 문구를 바로잡는다.
- 편집실 zoom 집에서 compact 포털 집으로 바뀔 때 뜨던 바닥 음식은 현재 실측 바닥−6으로 정렬한다. 다크 설정의 비선택 글자는 기존 공통 `--ink-soft` 토큰으로 대비를 보정한다.
- 이미 잠든 상태의 명시 이동이 끝나면 sleep·zzZ를 확정하고 기존 스케줄러를 멈춘다. 편집실의 일반 빅타민 직접 입력은 편집창 바깥 닫기에서 보호하며, 구조적 날짜 칸과 진짜 버튼·입력칸의 배치 소유권을 구분한다.
- 초기·뒤로가기 패널 전환에서 발견한 소파 앞면 중복은 local/외부 그림의 단일 소유권으로 해결한다. 같은 앞면을 기본 몸체에도 중복 채우지 않으며, 내부 개체와 앞면은 현재 방의 위치·alpha를 기존 유한 추종에서 공유한다. 애니메이션 시작 직전의 alpha1 조상도 측정 때 캐시해 뒤늦은 CSS 시작을 놓치지 않는다.
- 패널 이동 중 집이 화면 안으로 돌아와도 남던 occlusion은 기존 유한 추적에서 정식120ms 안전 스캔으로 다시 검증한다. 실제 이벤트가 큐 우선권을 갖고 검증발 요청은 추적 시간을 연장하지 않는다. 새 영구 루프 없이 controls·텍스트·clip을 통과한 실제 발판만 표시를 복구하며, parked 꼬리는 종료 시 구독을 해제한다.

기존 검사 중 과거76px·20행 metadata, 짧은 클릭=쓰다듬기, 창 자동 밀기, 같은 입력 이벤트 안의 동기 DOM 갱신을 가정한 검사는 원본/SHA와 실패 trace를 남기고 현재 승인 계약으로 교정한다. 중력·capture·실제 입력 hit·친밀도·parked0·포즈 cadence·원본 하트 불변 검사는 유지한다. 새 입력12·집2·표시4·발견 guest 최하단 추출1 검사는 별도 추가해 수정 전/후 실행한다.
