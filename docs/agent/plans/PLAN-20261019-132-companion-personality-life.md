# 132 — 빅타민 성격·생활 파이프라인 조사와 장면 제안

작성일: 2026-10-19 KST. 상태: 조사·제안. 이번 범위는 파이프라인 조사, 보고서와 별도 이미지 시안이며 **런타임 구현은 하지 않는다.** 이 문서는 구현 완료 기록이나 미술 승인 기록이 아니다. [집·작업 응원 보충](PLAN-20261019-132-companion-home-scenes.md), [장난감24종·추가12장면](PLAN-20261019-132-companion-toy-variations.md)에서 후속 설계를 확인한다. 생성 시안·실제 요청은 로컬 `art-src/빅타민/동행/작업회차/20261019-집생활상태132/README.md`에 보관하며 제품 배포나 공개 소스 반영에 포함하지 않는다.

## 1. 결론과 읽는 법

현재 개성은 주로 확률·속도·선호에 담겨 있다. 겉으로 보이는 전용 재롱은 성격마다 3개이고, 8성격의 재롱 집합은 실제로 5종류다. 같은 동작을 더 자주 재생하는 것보다 **무엇을 고르고, 어떻게 다가가며, 무엇으로 마무리하는가**를 다르게 만드는 것이 우선이다.

아래의 ‘현재’는 소스에서 확인한 동작 계약이다. ‘제안’과 108개 장면은 앞으로 설계할 후보이며 현재 작동한다는 뜻이 아니다. 새 균형 성격의 권장 이름은 **둥글이**로 정한다. 코드 식별자 후보는 `balanced`이며 아직 현재 성격 목록에 존재하지 않는다.

장면의 자원 표시는 다음과 같다.

| 표시 | 의미 | 구현·그림 경계 |
|---|---|---|
| 기존 자원 조합 | 현재 포즈·음식·장난감·가구 이미지를 연결하는 후보 | 새 판단·순서·상호작용·물리 연결 코드가 필요할 수 있다. 기존 자원만으로 최종 그림이 자연스럽다는 보장은 없으며 실제 크기·동영상 검수가 필요하다. |
| 새 표정 후보 / 새 포즈 후보 | 현재 그림으로 의도가 분명하지 않을 수 있는 후보 | 그림 추가 필요성부터 확인한다. 생성 완료나 그림 확정이 아니며, 기존 비율·외곽선·눈·입·접촉점과 함께 별도 검수한다. |

동일한 소품을 다른 각도에 놓거나 흔드는 것과, 그림 속 부품을 분리해 움직이는 것은 다르다. 예를 들어 바람개비 날개만 돌리거나 요요 실을 늘리는 일은 현재 단일 소품 그림을 통째로 회전하는 것으로 대체하지 않는다. 본 장면 목록은 그런 그림 분해가 필요한 효과를 기존 구현으로 간주하지 않는다.

## 2. 현재 파이프라인 전수 조사

### 2.1 정의·설정·즉시 반영 경로

현재 성격은 `curious`, `affectionate`, `sleepy`, `tidy`, `mischievous`, `gourmet`, `performer`, `homebody`의 8개다. [정의·이름](../../../lib/ui/viewer-companion/preferences.ts#L2), [설정 정규화](../../../lib/ui/viewer-companion/preferences.ts#L78).

선택 변경은 `setCompanionPreferences`의 로컬 저장과 같은 탭 이벤트를 거쳐 구독자에 전달된다. 다른 탭도 storage 이벤트를 구독한다. [설정 저장](../../../lib/ui/viewer-companion/preferences.ts#L119), [구독](../../../lib/ui/viewer-companion/preferences.ts#L136).

성격은 `worldPreferencesKey`에 포함된다. 음향 설정만 이 키에서 제외된다. 성격 변경 시 현재 행동 효과가 정리·재구성되고 위치·돌봄 기억을 이어 받는 경로이지, 선택 직후 대표 장면 1회를 확실하게 재생하는 경로는 아니다. 따라서 **설정값 즉시 반영과 즉시 성격 인식은 서로 다른 문제**다. 이 조사만으로 진행 중인 모든 물리 전환이 선택 변경에도 매끄럽다고 주장하지 않는다. [월드 설정 키](../../../lib/ui/viewer-companion/preferences.ts#L67), [효과의 설정 의존성](../../../components/poster/viewer-companion/viewer-companion.tsx#L3685).

동물 습관·성격·속도는 독립 축이다. 성격을 바꿨다는 이유로 사용자가 고른 속도나 기능 OFF를 켜면 안 된다. 습관 학습은 기본 동기를 제한적으로 보정하며 선택한 성격을 몰래 다른 성격으로 바꾸는 모델이 아니다. [행동 프로필](../../../lib/ui/viewer-companion/behavior-profile.ts#L7).

둥글이를 추가할 때는 성격 목록·이름·정규화뿐 아니라 전용 재롱 표, 장난감 동기·선호 표, 커튼 등 성격별 exhaustive 표와 관련 표현을 함께 연결해야 한다. 현재 균형형이 구현돼 있다고 표기하지 않는다.

표의 이름은 읽기 위한 요약이며 원래 코드의 `play` 식별자가 기준이다. [현재 재롱 표](../../../lib/ui/viewer-companion/personality-activity.ts#L44).

그 외 차이는 이동·놀이·새로움·교감·정리·사고 가중치에 많이 담겨 있다. 깔끔이의 음식 정리 재시도는 1.5초, 작업 후 대기는 6초이며 사고뭉치는 각각 2초·4.5초다. 장난감 동기 대기는 깔끔이 1.2초, 사고뭉치 5초다. 그러나 가능한 대상과 실제 경로가 없으면 그 행동은 발행되지 않는다. 이 값만 낮춘다고 항상 눈에 띄는 개성이 보장되지는 않는다. [프로필](../../../lib/ui/viewer-companion/behavior-profile.ts#L39), [장난감 동기](../../../lib/ui/viewer-companion/toys.ts#L283).

### 2.4 8초 예산·쿨다운·실제 우선순위

현재 `due`는 **마지막 의미 있는 행동을 기록한 활성 시간 이후 8초**다. 벽시계 8초마다 장면을 강제로 끊는 타이머가 아니다. 공통 식사·수면·목적 있는 이동·장면·소품 활동도 이 기록을 갱신할 수 있다. 그래서 ‘성격을 보여 주지 못한 채 공통 행동만 한 시간’과 다르다. 일반 걷기만 길어질 때 줄이는 예산도 있지만, 실제 먹기·장면·물건 운반은 보호한다. [preflight](../../../lib/ui/viewer-companion/personality-activity.ts#L12), [활성 예산·기록·선택](../../../lib/ui/viewer-companion/personality-activity.ts#L50).

대표적인 현재 제약은 다음과 같다.

- 실제 접근 가능한 식사, 계속 소유 중인 돌봄 목표, 진행 중인 장면·장난감·정리·귀가가 성격 후보를 막을 수 있다.
- 현재 재롱 선택은 직전 재롱 하나를 피한다. 최근 장면의 목적·대상·결말 전체가 다른지는 검사하지 않는다.
- 장면은 기본 25초·18회 예산으로 제한되고 실제 효과 ACK를 확인한다. 음식 정리는 별도의 30–45초·24–32회 한도와 재시도·완료 대기를 둔다. [장면 수명](../../../lib/ui/viewer-companion/scenes.ts#L326), [완료·효과 ACK](../../../lib/ui/viewer-companion/scenes.ts#L443), [음식 작업 수명](../../../lib/ui/viewer-companion/household.ts#L56).
- 기본 행동에도 식사·잠·숨기·재롱 등의 쿨다운이 있고, 실제 이동 시간과 재생 시간은 별도로 계산된다. [기본 쿨다운](../../../lib/ui/viewer-companion/brain.ts#L287), [시퀀스 시간](../../../lib/ui/viewer-companion/timing.ts).

최종 후보 결합은 음식 정리 → 장난감 → 거절 표현 → 상황 장면 → 음악 → 성격 재롱 → 액세서리 또는 일반 판단이다. 다만 성격 preflight가 일부 새 정리 작업보다 먼저 후보를 확보하고, 실제 소유권·직접 입력·가시성 조건이 그 전에 적용된다. 이 한 줄만 전체 우선순위로 해석하지 않는다. [preflight와 작업 후보](../../../components/poster/viewer-companion/viewer-companion.tsx#L2012), [최종 결합](../../../components/poster/viewer-companion/viewer-companion.tsx#L2070).

### 2.5 욕구·학습·맛·방문 기억

배고픔은 현재 `.35`부터 식사 후보를 만든다. 음식 정리는 `.65` 이상에서 양보하며, 배부를 때의 비최애 음식 버리기는 `.35` 미만과 현재 실제 쓰레기통·경로를 다시 검사한다. 장난감도 실제 식사나 소유 중인 돌봄 목표에 양보한다. `.35–.65`에서 실제 먹기와 실내 보관 중 무엇이 실행됐는지는 관측으로 구분해야 한다. [식사](../../../lib/ui/viewer-companion/brain.ts#L321), [정리 자격](../../../lib/ui/viewer-companion/household.ts#L34), [현재 목적지 판정](../../../lib/ui/viewer-companion/home-pantry.ts), [장난감의 식사 양보](../../../lib/ui/viewer-companion/toys.ts#L279).

첫 음식은 실제 먹은 도감 기록으로 익숙한 부류를 판단한다. 배고픔이 높을수록 수용 확률이 오르고, 같은 부류의 섭취 경험이 있으면 경계 횟수가 줄어든다. 등장만 했거나 원래 최애라는 이유로 섭취 도감을 열지 않는다. [음식 부류 경험](../../../lib/ui/viewer-companion/food-family.ts), [경계 정책](../../../lib/ui/viewer-companion/novel-food.ts#L10), [발견 기록](../../../lib/ui/viewer-companion/collection.ts).

성향 학습은 보통 0.035의 작은 변화와 활성 시간 18초의 학습 기회를 사용한다. 배신·거친 놀이는 더 강하게 반영하고 안심시키기에는 별도 변화율이 있다. 자동 행동을 무한 반복해 사람과의 경험을 위조하지 않는다. 맛 이유도 제한된 종류·개수와 활성 시간으로 보관한다. [습관 학습](../../../lib/ui/viewer-companion/habits.ts), [맛·장난감 경험](../../../lib/ui/viewer-companion/toy-tastes.ts), [최애와 생활 성향](../../../lib/ui/viewer-companion/life.ts).

방문 시간대, 20분 이상 간격의 새 방문, 오랜 부재, 자주 쉬는 장소, 좋아하던 음악과 미완료 장면을 기억하는 틀은 있다. 현재 시간대 기억은 주로 인사·상황 장면에 쓰이며, 사용자의 생활 전체에 맞춘 완성된 수면 스케줄러는 아니다. 부재를 배고픔·피로 벌점으로 계산하지 않는다. [방문·시간대 기억](../../../lib/ui/viewer-companion/scene-memory.ts#L61), [활성 시간 욕구 변화](../../../lib/ui/viewer-companion/brain.ts#L249).

| 16–20 | 음악 중 정리, 꺼낸 음식을 지켜보는 상황, 사용자 정리와의 관계, 중단된 정리 재개, 튕긴 음식 재확인 |
| 21–24 | 익숙한 음악, 사용자의 실제 악구에 반응, 중단된 곡 회상, 연주 마무리 반응 |
| 25–30 | 탐정 모자와 음식 관찰, 옷장 선호, 희귀 소품과 첫 음식, 소품을 착용한 휴식, 발견한 추억 회상, 첫 교감 기억 |
| 31–36 | 계절·날씨, 월 이동, 빈 달력, 시청자 화면에서 복귀, 레이아웃 변화, 파티 모자·음악·새 음식의 조합 |

이는 36개 독립 신규 그림 목록이 아니라 기존 포즈·목적·기억을 엮는 코드다. 각 장면의 조건을 없애고 전부 상시 재생하면 희소성과 사건의 의미가 약해진다. [장면 명령](../../../lib/ui/viewer-companion/scenes.ts#L187), [실제 조건·선택](../../../lib/ui/viewer-companion/scenes.ts#L263).

## 3. 제안하는 공통 행동 계약

### 3.1 첫 0–3초와 8초 기준

성격 선택 뒤 **첫 안전한 결정 기회에서 0–3초 안에 대표 행동을 시작**하는 것을 목표로 한다. 선택 순간 이미 낙하·착지·잡힘·직접 입력·실제 식사·운반 중이라면, 0–3초를 맞추려고 끊지 않는다. 해당 행동을 안전하게 끝낸 뒤 첫 기회부터 계산한다. 먼 대상을 고르면 먼저 성격다운 짧은 시선·준비 반응을 보이고 이동을 이어 간다.

활성 화면에서는 **8초 안에 의미 있는 성격 반응을 제안**하되 ‘8초마다 강제 중단’으로 설계하지 않는다. 후보 제안만으로 성공 처리하지 않는다. 자유 결정이 가능한 구간에서는 **설명 없이도 성격을 알아볼 실제 행동이 10초를 넘기기 전에 화면에 표시되는지**를 관측 기준으로 둔다. 먼 대상으로 가기 전에는 접근 준비·애교·정리 의지 같은 짧은 실제 표현을 먼저 보여 주고, 디코드 실패·대상 불가에는 유한 시간 안에 같은 성격의 준비된 대체 표현으로 전환한다. 일반 walk/idle/look나 미채택 후보는 이 기준의 성공으로 세지 않는다. 긴 이동 완료, 안전한 착지, 실제 먹기·운반 완료, 사용자 입력 소유권은 예외다. hidden·모달·차단·quiet 및 설정상 실제 비활성 시간은 예산에 쌓지 않는다. `activeWhileVisible=true`에서 화면이 보이지만 창 포커스만 없는 경우에는 기존 활성 정책을 유지한다. 장소나 물건이 없으면 같은 성격의 짧은 대체 장면을 사용한다. 잠꾸러기가 쿠션이 없다는 이유로 일반 멍때리기만 하거나, 깔끔이가 치울 물건이 없다는 이유로 무한 대기하는 상태를 피한다. 이는 다음 구현의 수용 기준이며 이번에 달성·검증한 동작은 아니다.

### 3.2 85–95%의 정확한 분모

**85–95%는 자유롭게 새 자율 행동을 선택할 수 있는 기회(free decision opportunities) 중 성격다운 목적을 선택하는 비율**이다. 총 화면 시간, 매 프레임, 모든 클릭, 모든 식사에 적용하는 확률이 아니다.

1. 사용자 입력·잡기·놓기·쓰다듬기·명시 귀가·중요한 편집과 물리 안전이 우선한다.
2. 급한 식사·피로와 이미 진행 중인 유한 행동은 소유권을 유지한다. 성격은 접근·반응·식후 마무리에 담는다.
3. 자유 선택 기회에서는 성격별 장면 묶음을 대체로 9/10 선택한다. 반대 성격 행동을 1/10에 억지로 넣지 않는다.
4. 공통 행동을 했다는 이유만으로 ‘성격을 보여 주지 못한 시간’을 초기화하지 않는다.
5. 최근 3개 장면의 목적·대상·결말을 함께 비교한다. 같은 동작 두 개를 번갈아 재생하는 순환도 반복으로 본다.
6. 소품·동선·강도·결말을 바꾼다. 그림이나 파티클 수를 늘리는 것만으로 변주를 대신하지 않는다.

### 3.3 수면·식사·사용자 입력·권한 예외

- 수면 OFF면 잠꾸러기도 실제 잠이나 잠든 상태의 연속 연출을 실행하지 않는다. 깨어 있는 하품·스트레칭·짧은 반응으로 대체한다. 현재 `sleep`은 핵심 공통 스위치이며 별도 낮잠/밤잠 설정이 구현됐다고 표기하지 않는다. [존재 상태](../../../lib/ui/viewer-companion/presence.ts#L8).
- 식사 OFF면 음식을 만들거나 실제로 먹는 전용 장면을 억지로 실행하지 않는다. 배고픈데 장난·소품·집착 장면만 반복하는 상황도 허용하지 않는다.
- 이동·점프·쓰다듬기·학습·소리 OFF를 성격이 다시 켜지 않는다. 동물 습관·속도 선택도 유지한다.
- 들고 있는 물건, 잡는 중인 사용자와 실시간 일정 편집에는 양보한다. 장난으로 일정 데이터나 제목을 바꾸지 않는다.
- owner/developer/viewer는 같은 공개 빅타민 기능을 공유한다. 역할 미리보기는 읽기 전용이고 실제 권한이 바뀌지 않는다. 성격은 private 일정·인증·운영 데이터를 보거나 판단 근거로 사용하지 않는다.
- 계절은 보고 있는 달력의 월, 시간대·특별 날짜는 기존 KST 규칙을 따른다. 실제 부재는 인사 변주에만 사용하고 방치 벌점을 만들지 않는다.
- 학습·방문·음식·장난감 선호는 기존의 제한된 기기 로컬 범위다. G-22는 사람이 누른 새 기능의 고정된 의미 대상만 감사한다. 자율 장면·식품 ID·발견 목록·성향을 사용자 활동으로 수집하지 않는다.
- reduced motion·낮은 그래픽 모드에서도 성격의 목적은 읽혀야 한다. 흔들림을 빼더라도 다른 성격과 같은 무표정 한 장만 계속 보여 주는 대체는 피한다.

## 4. 성격별 108개 장면 제안

각 항목은 **계기 → 실제 행동 → 결말**이다. 숫자는 성격별 12개를 유지하기 위한 제안 ID다. 별도 표기가 없으면 기존 자원 조합이며, 새 판단 코드 필요성과 최종 그림 미확정 원칙은 1절과 같다.

### 4.1 재롱둥이 — “나 좀 봐!”

1. **사용자가 돌아와 첫 안전한 자리에 착지하면** → 짧은 두 번의 통통 뛰기와 정면 인사 → 옆으로 비켜 서며 환영을 마친다.
2. **마우스가 안전한 근처에서 잠시 멈추면** → 옆자리로 와 응원 연습 한 토막 → 인사 한 번 뒤 마우스를 계속 쫓지 않고 놀이로 돌아간다.
3. **공이 한 개 놓이면** → 공을 한 번 튕기고 몸도 따라 통통 뛴다 → 공이 실제로 멈춘 곳을 보고 인사하며 끝낸다.
4. **별 지팡이를 선택하면** → 현재 등록된 앞쪽 운반점에 들고 점프·짧은 회전을 잇는다 → 실제 상자까지 운반하고 공연을 마친다.
5. **마라카스나 탬버린을 고르면** → 소품을 짧게 흔들며 리듬 동작 → 반복을 멈추고 정면 인사 후 실제 상자에 넣는다.
6. **기차가 가까이 있으면** → 안전한 짧은 구간으로 밀고 옆에서 행진하듯 따른다 → 기차가 멈추면 함께 멈춰 인사한다.
7. **공연 중 실제로 굴러 버리면** → 일어나 주위를 한 번 보고 몸을 턴다 → 아무 일 없었다는 듯 인사하고 해당 공연을 끝낸다.
8. **공연 직후 쓰다듬기를 받으면** → 방금과 다른 짧은 앙코르 한 번 → 두 번째 인사 후 같은 공연을 즉시 재시작하지 않는다.
9. **소유한 액세서리를 사용자가 착용시키면** → 실제 앞·옆 구도를 잠깐 보여 주며 포즈 → 현재 착용을 유지한 채 다른 활동으로 넘어간다.
10. **장난감 공연이 끝나면** → 같은 실물 장난감을 상자까지 운반 → 넣기 성공을 확인하고 상자 앞에서 마지막 인사를 한다.
11. **짧은 공연을 무사히 마치면** → 한쪽 눈을 찡긋하는 반응 → 평상 표정으로 돌아온다. **새 표정 후보: 공연 윙크.**
12. **귀를 이용하는 공연 후보를 고르면** → 토끼귀를 좌우로 번갈아 움직여 짧게 지휘 → 귀를 기준 자세로 돌리고 인사한다. **새 포즈 후보: 귀 지휘.**

### 4.2 호기심 — “저건 뭐지?”

1. **처음 보는 장난감이 정착하면** → 가까운 양쪽에서 번갈아 관찰 → 한 번 건드려 본 뒤 실제 상자에 돌려놓거나 놀이 한 번으로 끝낸다.
2. **처음 나온 음식이 실제 식사 대상이면** → 냄새를 맡고 한 걸음 물러났다가 재접근 → 검사 한도를 넘기지 않고 실제 맛보기로 이어 간다.
3. **같은 부류를 먹어 본 새 음식이 나오면** → 짧게 냄새만 확인 → 완전히 처음인 음식보다 빨리 실제 먹기로 전환한다.
4. **공이 굴러가면** → 처음에는 움직임을 지켜보다 멈춘 공에 뒤늦게 접근 → 한 번 톡 건드리고 도착 지점을 확인한다.
5. **종이비행기를 고르면** → 실제 안전한 목적지로 한 번 날린다 → 그 도착 지점으로 가 다시 살펴보고 놀이를 마친다.
6. **팽이를 가까이서 보면** → 고개를 기울여 보고 몸을 아주 짧게 돌려 본다 → 어지럼 동작을 길게 반복하지 않고 몸을 털며 끝낸다.
7. **만화경을 선택하면** → 소품 앞에 얼굴을 가까이 대고 바라본다 → 물러나 주변을 다시 살핀 뒤 실제 상자에 돌려놓는다.
8. **익숙한 장난감과 덜 놀아 본 장난감이 함께 있으면** → 아직 덜 경험한 실물 하나를 고른다 → 검사와 짧은 놀이를 마친 뒤 다음 기회에는 다른 대상을 고려한다.
9. **월 이동으로 새 안전한 자리가 드러나면** → 한 곳만 정해 짧게 탐색 → 그 자리에서 주위를 보고 이동을 마친다. 빈 공간 전체를 계속 횡단하지 않는다.
10. **공개 일정 뒤에서 사용자가 찾아 주면** → 다른 쪽으로 한 번 얼굴을 내민다 → 완전히 나와 인사하고 발견 상황을 종료한다.
11. **최애 음식과 새 음식이 동시에 있고 급하게 배고프지 않으면** → 새 음식을 먼저 확인한다 → 실제 먹기 또는 최애 선택으로 결정을 끝내며 두 음식 사이를 무한 왕복하지 않는다.
12. **관심 있는 쪽의 소리·움직임을 발견하면** → 한쪽 귀를 세우고 반대 귀를 기울여 집중 → 대상을 한 번 살피고 평상 자세로 돌아온다. **새 포즈 후보: 귀 기울여 탐색.**

### 4.3 애교쟁이 — “같이 있어 줘.”

1. **마우스가 실제로 접근 가능한 근처에 멈추면** → 안전한 간격까지 다가와 고개를 든다 → 잠깐 기다린 뒤 반응이 없으면 옆으로 물러난다.
2. **기다리는 중 쓰다듬기를 받으면** → 비비기와 웃는 반응 → 짧게 만족한 뒤 놀이로 돌아가며 같은 보상을 계속 요구하지 않는다.
3. **멈췄던 마우스가 조금 움직이면** → 한 번만 따라간다 → 계속 빠르게 움직이거나 편집 컨트롤로 가면 추격을 멈춘다.
4. **음식은 없고 사용자가 가까이 있으면** → 밥통 대신 마우스 쪽을 보고 인사 → 쓰다듬기를 잠깐 기다린 뒤 자신의 활동으로 돌아간다.
5. **오리나 물고기 인형을 고르면** → 몸 앞에 들고 잠깐 사용자 쪽을 본다 → 같은 인형을 실제 상자에 돌려놓는다.
6. **혼자 장난감으로 놀다가 사용자가 가까이 오면** → 한 번 마우스를 보고 인사 → 물건을 버려 두거나 순간 이동시키지 않고 원래 놀이를 마친다.
7. **실제로 넘어진 직후 쓰다듬기를 받으면** → 몸을 털고 안심하며 비빈다 → 원래 하던 일의 같은 대상으로 돌아간다.
8. **쿠션에 있는데 사용자가 가까이 오면** → 안전한 쿠션 범위에서 몸을 앞으로 내밀어 반긴다 → 내려올 필요가 없으면 다시 편히 앉는다.
9. **오랜만의 실제 방문이면** → 평소보다 적극적인 인사와 접근 → 환영을 마치면 작업을 방해하지 않는 옆자리로 물러난다.
10. **쓰다듬기가 끝나면** → 웃는 모습을 잠깐 유지한다 → 만족한 뒤 조용히 옆 활동으로 이어 가며 즉시 새 재롱을 덮어씌우지 않는다.
11. **거친 경험 뒤 다시 마우스가 멈추면** → 조금 다가오다 멈춰 망설인다 → 실제 안심 경험이 쌓이면 접근을 회복하고, 아니면 안전한 거리로 물러난다.
12. **비비는 교감을 마치면** → 편하게 눈을 감고 볼을 살짝 기대는 반응 → 원래 몸·귀 비율의 기본 자세로 돌아온다. **새 표정 후보: 만족하며 기대기.**

### 4.4 잠꾸러기 — “졸리지만 구경은 하고 싶어.”

1. **깨어 있어야 하는 짧은 쉬는 틈이면** → 반쯤 감긴 눈을 잠깐 깜빡인다 → 완전히 눈을 뜨고 주변을 확인한다. **새 표정 후보: 잠과 싸우는 반눈.** 수면 OFF에서 잠든 연속 연출로 사용하지 않는다.
2. **한 활동을 마치고 새 활동을 고를 때** → 큰 하품과 스트레칭 → 가까운 대상 하나를 살피며 깨어 있는 마무리를 한다.
3. **빈 쿠션에 도착하면** → 한 번 꾹꾹 누르고 자리를 조금 바꾼다 → 잠들기 조건이 아니면 일어나 주변을 본다.
4. **깃털 장난감이 가까이 있으면** → 조금 건드리며 따라본다 → 얼굴 가까이 온 소품을 보고 흠칫 깨어난 뒤 실제 상자에 돌려놓는다.
5. **물고기 인형을 선택하면** → 몸 앞에 두고 잠깐 편하게 바라본다 → 길게 멈춰 잠들지 않고 인형을 실제 상자에 넣는다.
6. **졸린 상태에서 배고픔이 충분히 높고 음식이 있으면** → 짧은 냄새 확인 뒤 실제 음식으로 향한다 → 식사를 완료한 뒤에만 휴식을 다시 고려한다.
7. **잠을 자도 되는 상태에서 장난감 하나가 가까이 있으면** → 그 물건 한 개만 실제 상자에 넣는다 → 쿠션에 돌아와 잠 허용 조건을 재확인한다.
8. **사용자가 들어오면** → 천천히 고개를 들고 눈이 마주치면 작게 인사 → 주변 확인 후 다음 활동을 고른다.
9. **쓰다듬기를 받으면** → 비비고 짧게 하품한다 → 수면 OFF면 일어나 스트레칭, ON이고 실제 휴식 조건이면 쿠션에서 쉰다.
10. **잠이 허용되고 활성 화면에서 쉬고 있다면** → 짧게 자세를 바꾸거나 눈을 뜨는 반응 → 잠을 계속할지 깰지를 현재 조건으로 다시 고른다. 장시간 무반응을 강제하지 않는다.
11. **장난감이 실제 가까운 바닥에 떨어지면** → 흠칫 눈을 뜨고 물건을 본다 → 안전함을 확인하고 한 번 인사하거나 원래 휴식으로 돌아간다.
12. **깨어 있는 졸음 표현을 선택하면** → 귀가 천천히 내려갔다 퍼뜩 다시 올라온다 → 눈을 뜨고 작은 스트레칭으로 끝낸다. **새 포즈 후보: 귀로 잠과 싸우기.**

### 4.5 깔끔이 — “제자리에 있어야 마음이 편해.”

1. **실제 장난감이 흩어져 있고 급하게 배고프지 않으면** → 가까운 물건부터 실제 상자로 운반 → 넣기 ACK 뒤 다음 물건을 고른다.
2. **집 안 음식 둘이 겹쳐 있으면** → 접근 가능한 음식 하나를 든다 → 실제 다른 음식·장난감과 44px 공간을 확보한 집 바닥에 놓는다.
3. **배부른 상태에서 비최애 음식이 남으면** → 실제 쓰레기통까지 운반 → 현재 포만도·경로·실제 도착을 재확인하고 버린다.
4. **배부른 상태에서 좋아하는 음식이 남으면** → 음식 하나를 든다 → 쓰레기통 대신 실제 집 안 빈자리에 보관한다.
5. **음식과 장난감이 함께 어질러지면** → 배고픔·현재 소유 중인 일·실제 경로로 한 작업을 고른다 → 그 작업을 마친 뒤 다른 종류를 처리한다.
6. **물건 하나를 제자리에 넣으면** → 정리한 쪽을 한 번 확인한다 → 다음 가까운 실물 하나로 이동하며 확인 동작을 길게 반복하지 않는다.
7. **치울 물건이 하나도 없으면** → 짧게 몸단장을 하고 주변을 한 번 훑는다 → 인사 후 기다리거나 다른 작은 생활 행동으로 넘어간다.
8. **정리 대상으로 가던 중 사용자가 그 물건을 잡으면** → 즉시 대상 소유권을 양보한다 → 다른 실제 물건을 고르거나 정리를 종료한다.
9. **운반 중 사용자가 새 물건을 떨어뜨리면** → 지금 든 물건을 먼저 마친다 → 새로 정착한 물건의 위치를 확인하고 다음 작업으로 선택한다.
10. **좋아하는 장난감으로 놀이를 마치면** → 같은 장난감을 실제 상자까지 운반 → 넣고 몸을 짧게 털며 끝낸다.
11. **정리하러 가다 실제로 굴러 버리면** → 일어나 몸을 턴다 → 원래 집으려던 같은 물건을 다시 찾아 정리를 마친다.
12. **상자 앞에 장난감 여러 개가 모이면** → 가까운 것부터 연속 운반한다 → 마지막 실물까지 넣은 뒤 한 번만 인사한다.

### 4.6 사고뭉치 — “가만히 있으면 심심해!”

1. **공이 있으면** → 짧게 굴리고 뒤쫓는다 → 따라잡은 뒤 한 번만 다른 방향으로 보내고 해당 놀이를 끝낸다.
2. **이미 나온 블록이 몇 개 있으면** → 안전한 범위에서 블록 주변을 뛰며 조금 흩어 놓는다 → 더 생성하지 않고 흩어진 결과를 돌아본다.
3. **장난감이 없고 꺼내기 허용·개수 여유가 있으면** → 실제 상자에서 한 개를 꺼낸다 → 그 장난감으로 짧은 놀이를 마치며 계속 새로 뽑지 않는다.
4. **먹을 수 있는 음식에 도착했지만 급하게 배고프지 않으면** → 먹을 듯 냄새를 맡고 한 번 장난친다 → 검사 한도와 현재 배고픔에 따라 실제 먹기로 전환한다.
5. **자동차 장난감을 고르면** → 앞으로 조금 밀고 따라간다 → 실제 멈춘 차를 따라잡고 작은 놀람 반응으로 끝낸다.
6. **둥근 고리를 따라가다 실제로 구르면** → 회복한다 → 원래 고리의 현재 위치로 돌아가 한 번 확인하고 놀이를 마친다.
7. **종이비행기를 날리면** → 잠깐 엉뚱한 쪽을 보다 방향을 바꾼다 → 실제 도착한 비행기까지 가며 화면 밖에서 물건을 지우지 않는다.
8. **사용자가 장난감을 움직여 내려놓으면** → 손에서 놓인 뒤 그 위치로 따라간다 → 한 번 덤벼들고 사용자가 다시 잡으면 즉시 멈춘다.
9. **안전한 공개 일정 뒤에 숨었고 사용자가 접근하면** → 얼굴을 한 번 내밀었다 다시 숨는다 → 발견됐을 때 완전히 나와 해당 숨기를 마친다.
10. **장난감 상한이나 공간 한계에 도달하면** → 이미 있는 물건 하나를 골라 다른 방식으로 논다 → 추가 생성 없이 한 활동을 마친다.
11. **실제 장난이나 넘어짐이 끝나고 사용자가 가까이 오면** → 눈을 옆으로 피하며 모르는 척한다 → 짧은 인사나 다른 놀이로 넘어간다. **새 표정 후보: 들킨 뒤 딴청.**
12. **사용자가 방금 장난감을 정리하면** → 정리된 상자를 잠깐 본다 → 바로 같은 물건을 꺼내 방해하지 않고 다른 놀이·짧은 달리기를 선택한다.

### 4.7 먹보 — “먹는 일에는 진심.”

1. **음식이 실제 바닥에 정착하면** → 먼저 고개를 돌리고 접근 가능성을 확인한다 → 현재 배고픔에 따라 실제 식사 또는 집 보관을 선택한다.
2. **배가 고프고 음식이 여러 곳에 있으면** → 현재 갈 수 있는 가까운 음식부터 고른다 → 위험한 최애 음식에 집착하지 않고 실제 한 끼를 마친다.
3. **최애 음식이 접근 가능한 곳에 있으면** → 귀를 세우는 짧은 반응 뒤 다가간다 → 실제 먹은 뒤 만족 반응을 보여 준다.
4. **먹어 본 빵류와 비슷한 새 빵이 나오면** → 짧은 냄새 확인만 한다 → 완전히 새로운 부류보다 빨리 실제 한입을 먹는다.
5. **음식 두 개가 가까이 있고 급하지 않으면** → 두 대상을 번갈아 짧게 확인한다 → 하나를 확실히 골라 식사를 끝내며 무한 왕복하지 않는다.
6. **배부른데 좋아하는 음식이 남으면** → 같은 실물을 집 안으로 운반한다 → 빈자리에 보관하고 먹는 연출을 억지로 추가하지 않는다.
7. **이전에 보관한 음식이 남고 다시 배고파지면** → 같은 음식의 현재 위치로 돌아간다 → 실제 식사·소멸·발견 여부를 정상 처리한다.
8. **한 끼를 실제로 먹고 나면** → 웃기와 짧은 몸단장 → 주위를 확인하고 다음 활동으로 넘어간다.
9. **당근 장난감을 처음 고르면** → 음식처럼 한 번 살핀다 → 실제 음식으로 먹거나 음식 도감을 열지 않고 장난감을 상자에 돌려놓는다.
10. **실제로 먹은 음식에서 싫은 맛 경험이 생기면** → 해당 맛 반응을 보여 준다 → 이후 실제 경험에 근거한 취향으로 남기며 ‘처음 봄’만으로 싫어함을 확정하지 않는다.
11. **맛있는 한입을 실제로 먹으면** → 볼이 아주 살짝 부푼 오물거림 → 기준 비율과 표정으로 돌아온다. **새 표정 후보: 만족하며 오물거리기.**
12. **실제 경험으로 최애가 바뀌고 두 음식이 다시 나오면** → 새 최애 쪽을 먼저 보고 귀를 세운다 → 그 선택을 실제 식사나 집 보관으로 마친다.

### 4.8 집돌이 — “내 방이 제일 좋아.”

1. **집 안에서 한 활동을 끝내면** → 쿠션·바닥의 실제 안전한 두세 자리 중 다른 곳을 고른다 → 그 자리에서 짧은 생활 행동을 마친다.
2. **실제 상자에 장난감이 있고 놀이를 고르면** → 한 개를 꺼내 집 가까운 범위에서 논다 → 실제 상자에 돌려놓는다.
3. **기차를 선택하면** → 집 앞의 짧은 안전 구간으로 밀고 따라간다 → 기차를 회수해 상자에 넣는다.
4. **고리 쌓기 장난감을 고르면** → 가까이 두고 앞·옆에서 관찰한다 → 실제 상자 쪽으로 운반해 마무리한다. 현재 없는 분해·쌓기 조작을 구현됐다고 보지 않는다.
5. **집 밖에 좋아하는 장난감이 있고 왕복 경로가 있으면** → 짧게 나가 그 실물을 든다 → 실제 집 상자까지 운반한다.
6. **좋아하는 음식이 남고 배가 부르면** → 실제 집 안 빈자리로 옮긴다 → 가까이서 쉬다가 배고파졌을 때만 실제 식사를 고려한다.
7. **쿠션에서 몸단장을 마치면** → 실제 바닥으로 내려와 한 번 스트레칭한다 → 안전한 입구를 통해 쿠션으로 돌아오며 가장자리를 관통하지 않는다.
8. **사용자가 집을 펼치면** → 방 안을 한 번 둘러보고 인사한다 → 다음 생활 행동을 고른다.
9. **사용자가 집을 접으면** → 기존 표면 이동·대기 정책으로 안전을 확보한다 → 보이지 않는 방 안에서 일을 성공 처리하거나 순간 이동하지 않는다.
10. **집이 다시 열리면** → 현재 이동을 안전하게 끝낸다 → 실제 열린 집 경로를 재확인한 뒤 귀가한다.
11. **자주 쉬던 자리에 다시 도착하면** → 직전과 다른 몸단장·꾹꾹이·짧은 소품 놀이 중 하나를 고른다 → 한 장면을 마친 뒤 정지한다.
12. **실제 쿠션에 편하게 자리 잡으면** → 얼굴과 귀만 편하게 내민 키를 보여 준다 → 사용자가 다가오면 고개를 들고 반응한다. **새 포즈 후보: 쿠션에 편히 파묻히기.** 실제 가구 가림 관계 검수가 필요하다.

### 4.9 둥글이 — “그때그때 재미있는 걸 골고루.”

1. **자유 선택 기회에 음식·장난감·멈춘 마우스 중 뚜렷한 대상이 있으면** → 현재 욕구와 접근성을 먼저 비교한다 → 가장 맞는 한 활동을 끝낸다.
2. **같은 목적의 활동을 두 번 마쳤고 다른 적합한 대상이 있으면** → 다른 종류의 짧은 활동을 고른다 → 최근 활동이 한쪽으로만 쏠리지 않게 한 번 완결한다.
3. **공을 고르면** → 짧게 한 번 가지고 논다 → 실제 상자에 돌려놓는다.
4. **장난감이 많이 흩어져 있고 급한 욕구가 없으면** → 한두 개만 실제 상자로 옮긴다 → 정리 한 토막을 끝낸 뒤 다른 생활 행동을 고른다.
5. **새 음식이 실제 식사 대상이면** → 한 번 확인한다 → 끝없는 검사 대신 현재 배고픔과 경험에 맞춰 실제 맛보기로 끝낸다.
6. **최애와 익숙한 다른 음식이 함께 있으면** → 최애에 짧게 반응한다 → 배고픔·거리·최근 식사에 따라 실제 하나를 먹으며 최애만 고집하지 않는다.
7. **마우스가 안전한 곳에 멈추면** → 한 번 인사하고 짧게 기다린다 → 사용자가 움직이면 계속 추격하지 않고 다른 활동으로 돌아간다.
8. **쿠션에서 짧은 쉬기를 마쳤고 깨어 있을 조건이면** → 실제 바닥으로 내려온다 → 가까운 작은 놀이 한 번을 끝낸다.
9. **이동 중 실제로 넘어지면** → 회복한다 → 원래 하던 같은 일의 대상으로 돌아가 마무리한다.
10. **익숙한 장난감과 덜 경험한 장난감이 함께 있으면** → 최근 선택과 다른 쪽을 고른다 → 검사·놀이·실제 상자 넣기를 한 번 마친다.
11. **최근 사용자와 즐거웠던 활동을 다시 제안할 조건이면** → 같은 소품이나 교감을 짧게 한 번 제안한다 → 반응이 없으면 물러나며 성격 선택 자체를 바꾸지 않는다.
12. **자유 시간이 있고 실제 장난감 한 개가 있으면** → 살펴보기 → 한 번 놀기 → 실제 상자에 넣기를 잇는다 → 마지막 인사로 짧은 생활 한 편을 끝낸다.

## 5. 구현을 요청받았을 때의 순서 제안

이 절은 실행 지시가 아닌 후속 설계 순서다.

1. **공통 계약부터 정한다.** 9개 성격의 대표 목적·예외·자유 선택 비율·최근 장면 중복 규칙을 한곳에서 정의한다. 표마다 따로 가중치를 늘려 성격이 서로 다르게 해석되는 일을 피한다.
2. **성격 변경의 첫 장면을 연결한다.** 저장값 반영과 대표 장면의 시작을 구분하고, 진행 중인 물리 행동·직접 입력을 안전하게 완료한 뒤 0–3초 목표를 적용한다.
3. **기존 자원 조합부터 구현한다.** 대상 선택과 마무리로 차이를 만든다. 방·음식·장난감이 없는 상황의 짧은 대체 장면까지 준비한다.
4. **소수의 새 표정·포즈 후보를 평가한다.** 현재 그림으로 의도가 읽히는지 실제 표시 크기와 동영상으로 본 뒤에만 생성 필요성을 확정한다. 새 포즈마다 모든 액세서리를 다시 그리는 대신 기존 공용 등록·앵커 구조를 유지한다.
5. **실제 장면을 확인한다.** 성격 선택 직후, 활성 10초, 짧은 1분 사용, 수면 OFF, 식사 OFF, 사용자가 중간에 물건 잡기, 집 접힘·펼침, 월 이동·스크롤을 각 성격에서 확인한다. 물리 이동을 타이머로 끊어 목표 시간을 맞추지 않는다.
6. **선택 비율과 소비 시간을 구분한다.** 성격다운 자유 선택이 85–95%여도 이동·식사 시간이 길 수 있다. 관측 항목은 선택 기회·제안·실제 시작·완료·안전한 취소·최근 목적 중복으로 분리하며 외부 분석 이벤트로 보내지 않는다.
