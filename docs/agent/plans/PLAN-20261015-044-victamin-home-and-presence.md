# 빅타민 집과 화면 안에서의 생활

2026-10-15 KST. 현재 사용자 요청으로 승인된 구현. PLAN-043의 움직임·기본OFF·로컬 돌봄을 계승한다.

## 목표와 계약

- 켜면 기존 계절 카드와 같은 측면 패널 안에 작은 집을 둔다. 친밀도·욕구, 간식 자판기, 쿠션, 쓰다듬기·옮기기·쉬기를 한 공유 컴포넌트로 제공한다. 기존 useSidePanel/폭/FLIP 규칙을 재사용한다. 패널이 없거나 접히면 작은 집 진입점으로 동일 조작을 제공한다.
- 먹이는 OS별 이모지 대신 프로젝트 재질에 맞춘 공통 SVG. 직접 집어 어디든 놓는 자유·최대3개·배고플 때 도달 가능한 경로로 먹는 계약 유지. 쿠션으로 돌아와 쉬기와 바깥 낮잠 모두 허용한다.
- 그림 하단의 접촉 그림자와 도약 중 분리되는 그림자로 접지감을 준다. 화면 전체 filter·외부 모델·DB 요청 추가 없음. 기존 raster 에셋 재생성/원본 덮어쓰기 없음.
- 실제 렌더된 날짜/제목/부제의 줄별 경계를 재고 위를 발판으로 삼되, 이웃 글자를 가리는 착지·보행 구간은 제외한다. resize/font/zoom/스크롤/필터·패널 변경 관찰 재사용. 텍스트/계정정보는 뇌나 저장소에 전달하지 않는다. 비행 중 완전한 글리프 무충돌과 정지/착지 안전은 구별한다.
- 빅타민 보라 하트의 우상단 별표 제거. 빅타민은 자기 보라 하트를 다시 끌 수 있고 인간 빨간 하트는 변경하지 못한다. 실제 count/aria-pressed/서버 투표 불변.
- 클릭/탭은 즉시 알아볼 수 있는 쓰다듬기 피드백, 집기는 꾹 누른 뒤 이동으로 구별한다. 집의 쓰다듬기·옮길 곳 고르기와 키보드는 동일 기능의 단일 포인터/비드래그 대안이다. 수면 zzz는 느린 엇갈린 상승·소멸, reduced는 정지 표현.
