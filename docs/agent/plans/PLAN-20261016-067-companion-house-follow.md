# 소파 앞 레이어 추종·편집실 패널 순서

2026-10-16 KST. L2. 진행 중. 소유자는 시청자/편집실 패널 접기·펼치기로 집이 이동할 때 소파 앞면이 옛 위치에 남는 오류 수정과 편집실 패널 순서 변경을 요청했다. 현재 세션의 커밋·푸시·배포 승인은 유지한다.

## 범위와 경계

- 기존 공유 빅타민 엔진의 고정 소파 앞면/집 기하와 유한 layout 추종의 소유권을 조사하고 실제 production-build fixture에서 재현한다. 현재/목적 발판과 무관하게 필요한 집 이동만 같은 이벤트 예산 안에서 추적한다. 새 상시 rAF/타이머·매 프레임 전체 DOM/Range scan은 금지한다.
- 기존 전체 몸체 소파 깊이·집바닥·집기/낙하·모달 배경/parked·패널 좌우/접기·감소동작/gfx·최초공개·위치 연결을 유지한다. 변경은 한 구현을 쓰는 viewer/Studio/preview에 함께 적용한다.
- 편집실 PC는 검색/태그/인사이트/단축키/설정 묶음→태그 필터→계절 배경→빅타민 집 순서다. 실제 준비 전 fallback도 같은 순서를 따르며 기존 재질 selector를 보존한다. 모바일 빅타민 제외와 최신 왼쪽 설정/오른쪽 계정 위치는 유지한다.
- 서버/DTO/DB/역할·unlock·KST·1840 poster·이미지/해상도/동작 cadence 변경0. 공개/비공개 경계를 새로 넘지 않는다. fixture와 모든 mutation 차단으로 검증하며 현재/미래 달 시험 데이터를 생성하지 않는다. 사용자 미술26줄·보류 자산·과거 raw는 보존한다.

## 단계와 검증

1. 독립 원인 조사와 수정 전 렌더 재현. 현재 발판이 집 밖/소파/집바닥일 때, 잠든 상태와 실제 허용된 창/패널 이동을 구별한다.
2. 최소 공유 엔진 수정과 PC 패널 DOM 순서 정정. 새 추적 loop 없이 기존 finite follow와 그려진 front의 같은 프레임 좌표를 일치시킨다. 독립 소스 검토 후 통합한다.
3. 관련 unit·typecheck·lint·production build, viewer/Studio native disclosure 중 실측 소파/front 좌표·clip/깊이, 최종 정지와 재개, 감소동작/gfx, 기존 소파/스크롤/프레임/모바일 회귀를 검사한다. 실행하지 않은 범위를 PASS로 쓰지 않는다.
4. 승인된 커밋·배포와 실제 운영 읽기 전용 확인. 결과와 한계는 주제 기록에 남기고 완료 row는 현재 작업에서 제거한다.
