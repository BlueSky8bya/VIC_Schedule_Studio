# PLAN-20260907-006 — 실제 태양 궤도로 잇는 시간대 + 하루 세 마디 날씨

Plan ID: PLAN-20260907-006
Status: Accepted (2026-09-07, 소유자 지시)
Task Risk: L2 (구조적 — 시간대가 '여섯 칸'에서 '연속 위상'이 되고, 날씨 마디가 2 → 3으로 바뀐다. 조명·하늘·그림자·QA 시트가 모두 이 입구를 읽는다)
Created / Updated: 2026-09-07

## Objective (소유자 지시 2건)

1. **시간대는 계속 이어진다.** 여섯 띠(새벽·아침·점심·노을·저녁·밤)는 남기되 **거점**이 되고, 그 사이는 연속으로
   보간된다. 거점의 시각은 계절·날짜마다 **실제 태양**이 정한다 — 황도가 기울어 겨울은 밤이 길고 해가 낮게 뜬다.
2. **날씨는 하루 세 마디.** 마디 경계 시각은 날짜 시드로 **랜덤**, 단 마디가 너무 짧게 연달아 바뀌지 않게 최소 길이를 강제한다.

## Design

### ① `world/sun.ts` (신설) — NOAA 태양 위치
- 서울(37.5665°N, 126.9780°E), KST(UTC+9). 순수 함수 + 날짜별 캐시.
- 황도 경사에서 나오는 **적위(declination)** 와 **균시차(equation of time)** 로 그 날의 일출·일몰·남중·최대고도·시민박명을 낸다.
- 겨울 남중고도 ≈ 29°, 여름 ≈ 76°(서울) — "겨울 해가 낮다"가 표가 아니라 **계산**에서 나온다.

### ② `world/time.ts` — 여섯 거점 + 연속 위상
- 거점 시각(그 날의 태양에서): 밤 = 태양 자정 · 새벽 = 일출 −0.4h · 아침 = 일출과 남중 사이 45% · 점심 = 남중 ·
  노을 = 일몰 · 저녁 = 시민박명 끝 +0.4h.
- `bandPhase(hour, date)` → `{ band, next, mix }`. `band` = 지나온 거점, `next` = 다음 거점, `mix` = 0~1(부드럽게 이징).
- `WorldTime`에 `next`·`mix`·`sun{alt,az}`·`rise`·`set` 추가. `band`의 의미는 그대로라 도감·스폰 풀·QA 시트·개발자 강제는 안 깨진다.
- `bandOf(hour, season)`(옛 서명)은 계절 대표일로 대신 계산해 유지 — 기존 호출·테스트가 살아 있다.

### ③ 조명 — 거점 두 개를 섞는다
- `lightAt(time, weather, season)` = `lerpLight(lightOf(band), lightOf(next), ease(mix))`.
- 엔진의 3초 전이는 **불연속 변화**(날씨 바뀜·거점 쌍 바뀜)에만 건다. 위상 표류는 이미 연속이라 즉시 반영한다 —
  아니면 `lightStable`이 영원히 false가 되어 그림자 굽기가 멈춘다.

### ④ 하늘 — 해 높이를 고도에서
- `SkyFrame.time.sun`이 오면 해 원반의 y를 **실제 고도**로 놓는다(겨울 노을 해가 더 낮게 걸린다). 없으면 옛 상수.

### ⑤ `world/weather.ts` — 하루 세 마디
- 경계 b1 ∈ [6.5, 11.0], b2 ∈ [max(b1+4, 13.0), 20.0] — **마디 최소 4시간**(마지막 마디도 4시간 이상).
- 마디마다 월별 표에서 뽑되 **55%는 앞 마디를 잇는다**(하루가 색종이처럼 튀지 않게).
- `weatherAt`는 `{ now, prev, segment: 0|1|2, until }`. `prev`는 직전 마디(첫 마디는 전날 마지막 마디).

## Verification

- 단위: 일출·일몰이 서울 실측 ±12분(하지·동지·춘분) · 남중고도 겨울 < 여름 · 24시간 위상 연속(인접 샘플 조명 점프 없음) ·
  세 마디 길이 ≥ 4h · 같은 날 = 같은 결과(결정성) · 여름에 눈 0.
- 게이트: tsc · eslint · vitest · build · `ambient:qa:selftest`.
- 눈으로: 같은 날 06→20시를 훑어 조명이 계단이 아니라 곡선인지, 겨울 노을 해가 여름보다 낮은지.
