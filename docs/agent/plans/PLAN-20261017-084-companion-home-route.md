# 빅타민 귀가 경로·배운 습관 설명

Status: Completed — owner-approved release99ee2a76 deployed and verified.

후속 정정: 임시 보조 발판/BFS 우선 조항은 소유자의 최신 요청에 따른 [085](PLAN-20261017-085-companion-direct-home.md)로 대체한다. 이 문서의 배포 결과는99ee2a76 당시 동작에 한정한다.

소유자 요청: 소파 호출은 걷기와 짧은 점프로 연결하고, 일정이 적은 달의 바닥에서도 귀가하며, 설정에 현재 배운 습관을 짧게 설명한다.

- 공유 renderer·기존 ballistic/BFS 경로를 사용한다. 매 착지마다 최신 발판으로 다음 한 행동만 정한다. 긴 비행과 일정 데이터 변경은 없다.
- 실제 발판을 우선한다. 집 아래 빈 공간은 텍스트·전체 버튼 hit target·집 경계를 피한 작은 보조 발판으로 연결한다. 귀가 중에만 보이며 음식/일반 배회의 발판으로 사용하지 않는다. 수·경로 길이를 제한하고 새 상시 loop/서버 요청은 만들지 않는다.
- 바닥에서 올라갈 수 없는 상태는 활성 시간의 짧은 대기 후 같은 귀가 경로로 회복한다. 사용자 drag/창/최초공개·접힘·동작 줄이기·OFF와 경로 상실은 기존 소유권/안전한 착지로 처리한다.
- 배운 습관은 기존 기기 내 성향의 요약이다. 초기/초기화/학습 OFF/저장 변경을 반영하고 새로운 기록·계정 연결·DB 수집은 추가하지 않는다.
- 권한·공개 DTO·KST·1840 기하·모바일 빅타민 제외는 유지한다. 메인082 파일/빌드/탭/프로세스와 사용자 아트는 보존한다. 초기 로컬 준비 뒤2026-10-17 소유자가 이 별도 대화에서 “배포 하자”로 commit/push/운영 배포를 승인했다.

검증: 순수 경로의 도달성/빈 달/옵션/상한/이동·삭제, 습관 요약 단위 검사; 격리 production build와 실제 fixture 소파 호출/바닥 귀환/방해·초기화 상호작용; typecheck/lint/관련 unit/harness. 실제 방송 PC·운영 로그인·독립 통합 리뷰/배포는 별도다.
