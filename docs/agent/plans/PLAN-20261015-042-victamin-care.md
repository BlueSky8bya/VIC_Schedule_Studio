## 제품 계약

- 사람 하트는 기존 빨강·실제 카운트. 빅타민 하트는 별도 보라 표식·기기 로컬이며 실제 클릭/북마크/기대/카운트/서버 요청을 만들지 않는다. 사람이 이미 누른 하트와 이미 찍은 빅타민 하트에는 막힘 파문·아쉬운 반응. 시도 시점에 다시 확인한다.
- 메뉴에서 사과·레몬 밥을 꺼내 드래그하거나 클릭/키보드로 놓는다. 화면 내 발판/바닥에 안착, 최대3개. 먹이는 달력 내용을 가리지 않는 작은 오버레이이며 월 변경/끄기 때 정리한다. 배고프면 접근·냄새·먹기, 배부르면 관심 없이 기존 놀이/휴식. 도달 불가 먹이로 순간이동하지 않는다.
- 배고픔·기력·호기심·친밀도 네 수치만 기기 로컬에 저장. 화면에서 실제 활동한 시간만 배고픔에 반영, 부재 페널티/죽음/서버 저장/사용자 식별 없음. 정산은 먹기 완료에 한 번만 한다. 중단된 먹기는 식사를 소비하지 않는다.
- 설정→빅타민→성격에 빅타민/고양이/강아지 단일 선택, 교감에 밥주기ON/OFF. 성향은 행동 선택 차이이며 외형은 빅타민 그대로. 기존 성격 세부 설정과 v1 저장값 호환.
- 고양이: 높은 안전 자리, 짧은 냄새/관심, 독립 휴식. 강아지: 가까이 오기, 냄새 찾기, 짧은 놀이·교감. 마우스는 좌표만 감지, 개인정보/일정 내용 수집 없음. 직접 조작/모달/최초공개/숨김 탭 우선 중단.
