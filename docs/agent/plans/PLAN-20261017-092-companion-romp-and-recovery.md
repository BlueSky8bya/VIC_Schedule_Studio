# 빅타민 빠른 정신 차리기와 달리기·넘어짐 다양화

Status: Local verification complete; release pending.

소유자 후속: 회복할 때 고개를 힘차게 좌우로 빠르게 털고, 짧게만 달리는 패턴을 다양화하며 구르기/음식 걸림이 실제 행동으로 나오는지 확인한다.091의 낙하 나선눈·감도·실제 지지점은 유지하고 약한 회복만 대체한다. 그림 존재와 실제 행동 연결/발동률을 구분한다.

- 회복: 현재800ms 중 앞 약520ms에3왕복의 연속 좌우 털기와 부드러운 시작/종료, 이후 정상 눈/중립으로 연결한다. 현재 HD23·기존 pose plane/표시 시계만 사용하며 분리한 얼굴/귀나 새 이미지·상시 루프를 만들지 않는다. 실제 지지점·viewport 전체 몸체 경계·감소/OFF를 보존한다.
- 활동: scoot의 거리·지속시간을 실제 현재 안전 발판의 여유 안에서 짧은/긴 구간으로 다양화한다. 현재 속도 취향/고양이·강아지·피로·텍스트/컨트롤 보호를 유지한다. 실제 달리기 완료에서만 선택한 도약은 중간 idle 없이 같은 타임라인으로 연결하고, 기존 정확 도착점 reachability·중력·천장 한계로 증명한다. 일반 배회/먹이/직접 귀가를 혼동하지 않는다.
- 사고: 현재 연속 이동 누적과 공유 play 쿨다운에 갇힌 조건을 실제 이동/접촉의 유한 기회로 정리한다. 실제 같은 발판 진행 경로의 settled/visible 음식에만 걸릴 수 있고 실제 음식 소비/영구 좌표/일정 데이터는 바꾸지 않는다. 가상 돌 entity를 추가했다고 주장하지 않는다. 충분한 폭의 발판에서 구르고, 안전 여유가 적으면 짧은 bump만 쓰며 중복 발동/소파·직접 집기·먹이 추적·귀가·모달·편집·공연·비활성·감소/OFF는 제외한다. 기존 카드 기울임 토글과 수동 복구를 보존한다.
- 검증: 실제 상태 전이를 진행하는 여러 seed의 단위 분포와 조건 주입 없는 production fixture native 관찰을 구분한다. 달리기 길이/속도/도약·접촉→실제 HD21·회복의 프레임 순서·식사/좌표/설정 불변·POST0을 각각 확인한다. 무작위 미발동을 다른 pose로 대체 PASS 처리하지 않는다. 회복은 실제 full/lite에서 빠른 좌우 반전 수·범위·끝 중립을 본다. 관련 이전 입력/관성/모달/귀가 회귀, 전체 unit/typecheck/lint/build/harness, 독립 검토와 소스 일치 뒤 같은 수정의 후속 commit/push/원격 CI·Vercel·운영 SHA 확인을 진행한다.

시청자·편집실·미리보기·비로그인 공유 구현, 모바일 제외, 공개 DTO/역할/언락/KST/1840 기하·직렬 쓰기를 유지한다. 운영 DB 변경·새 의존성·모델/서버 요청·사용자 아트 변경은 없다. 실제 OBS 장비나 모든 장치/RLS 검증으로 확대하지 않는다.
