# 모바일 로그아웃 복원·빅타민 방송 프레임 경로 최적화

2026-10-16 KST. L2. 소유자 요청: 모바일 편집실 로그아웃을 이전 자리로 복원하고, 이미지 해상도를 바꾸지 않으며 OBS/SOOP 송출과 병행할 때 빅타민 실행 부담을 줄인다. 기존 커밋·푸시·배포 승인은 유지한다.

## 범위

- 이전 커밋과 실제 모바일 기하를 비교해 로그아웃만 원위치로 돌린다. 편집실 설정은 월 이동 줄 오른쪽, 시청자 설정은 기존 위치를 유지한다. 로그아웃의 인증 동작/권한/라우팅은 바꾸지 않는다.
- 하나의 공유 엔진에서 프레임의 기하 읽기·수치 계산·표시 쓰기, 이벤트 관측과 중복 스케줄링을 조사한다. 기준/수정 production build의 실제 입력과 CPU 부담 조건에서 측정해 확인된 병목을 줄인다. 단순 FPS 제한·행동 축소·해상도 변경을 최적화 근거로 삼지 않는다.
- 귀/몸통 집기 관성·소파 전체 몸체 충돌/깊이·스크롤 발판·숨기/팝오버·065 위치 연결·최초공개 소유권을 보존한다. 모바일 전체 제외·기본OFF·감소동작/gfx·숨김/parked 정지·1840 기하는 유지한다.
- 서버/DTO/DB/권한·KST·이미지 자산을 변경하지 않는다. 운영 쓰기·시험 일정 생성0, synthetic fixture와 mutation 차단을 사용한다. 실제 OBS/인코더/GPU/SOOP 송출 환경은 브라우저 부하 검증으로 보증하지 않고 증거 범위를 구별한다.

## 단계·검증

1. 모바일 이전 위치 및 공유 프레임 경로 독립 조사, 동일 production baseline의 Layout/Style/JS/프레임 간격 측정.
2. 측정된 병목의 최소 파이프라인 수정과 로그아웃 복원. 독립 소스 검토 후 통합.
3. 관련 단위·타입·린트·production build, 동일 입력의 전후 비교, 소파/스크롤/집기/parked/미리보기/모바일·최초공개 회귀 검증.
4. 승인된 커밋·배포와 실제 운영 확인. 주제 검증 기록에 수치·제약을 남기고 완료 시 현재 작업에서 제거한다.
