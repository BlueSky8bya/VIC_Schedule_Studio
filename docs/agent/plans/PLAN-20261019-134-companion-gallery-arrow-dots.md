- 133의 가로 바와 좌/우키의 일반 페이지/개별 항목·분류 이동 계약만 대체한다.133의 방향별 가까운 미확인 선택/ACK1, 일반 포인터 페이지 탐색 ACK0, 고정 비율/작은 화면, 기존 소장·취향·아트·물리 계약은 보존한다.
