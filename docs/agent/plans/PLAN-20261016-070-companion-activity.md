# PLAN-20261016-070 — 빅타민 이용기록 연결

Status: Complete — deployed `7d377dd3`
Date: 2026-10-16 (KST)

## 목적

빅타민 설정·집·먹이·직접 교감 기능을 기존 이용기록의 행동 타임라인과 적게 쓰인 기능에 사람이 읽을 수 있는 이름으로 연결한다. 편집실과 시청자 화면은 공유 구현에서 계측한다.

## 경계와 방식

- 기존 `ui.click`/배치 수집·개발자 전용 조회·KST 집계 경로 재사용. DB/API 권한·공개 DTO 변경 없음.
- 사용자가 완성한 조작만 기록. 자동 걷기·점프·낮잠·식사·장난 및 프레임/포인터 이동은 기록하지 않는다.
- 고정 기능 ID·고정 선택값만 허용. 일정 제목/내용/ID, 음식 위치·마우스 좌표·개인 입력 및 상태 전체는 수집하지 않는다.
- 시청자/비로그인은 기존 일별 역할 집계만 유지. 내부자 행동 타임라인과 구분. 90일 보존 정책 및 기본 OFF인 파괴적 정리 작업은 변경하지 않는다.
- 기존 클릭 위임과 제스처 직접 기록이 중복되지 않도록 조작별 소유자를 하나로 정한다. 새 요청·반복 루프·의존성 없음.

## 단계와 검증

1. 설정/집/교감 조작과 사전·허용목록·통계 경로 조사, 누락 목록 확정.
2. 고정 이름·선택값 등록, 공유 컴포넌트에서 버튼 및 완료 제스처 계측.
3. 단위 검사: 허용목록·민감 canary 제거·선택값 번역·자동 행동 제외·중복 방지. 운영 DB를 쓰지 않는 fixture 상호작용 및 두 기록 화면 렌더 확인.
4. 독립 리뷰, typecheck/lint/관련 unit/build/harness 실행. 승인된 commit/push 이후 실제 배포 SHA와 읽기 전용 결과 확인.

## 위험

마우스 이동/자율 동작을 사용으로 세는 과대 집계, 클릭과 제스처 중복, 동적 한글 ID가 서버에서 제거되는 누락, 신규 기능 도입 전의 빈 기간을 미사용으로 오해하는 위험. 과거 기록은 소급 생성하지 않는다.
