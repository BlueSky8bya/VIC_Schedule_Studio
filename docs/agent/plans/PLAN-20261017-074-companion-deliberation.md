# PLAN-20261017-074 — 빅타민의 읽을 수 있는 판단

Status: Complete
Date: 2026-10-17 (KST)
Scope: L2, 공유 로컬 행동·표현

## 목표와 진단

소유자는 빅타민이 실제로 생각해서 행동하는 것처럼 느껴지길 원한다. 기존 planner는 탐험/귀가/먹이 목표, 경로 재검증과 장소 실패 기억을 이미 가지고 있다. 그러나 정지한 look는 대상을 바라보지 않으며, 목표가 사라져도 다음 결정에서 곧장 다른 행동으로 넘어간다. 멀티 발판 목표에 비해 가까운 발판 선택은 실패 기억을 덜 사용한다.

## 구현 결정

1. 새 먹이/귀가/다른 발판 목표를 정했을 때만 실제 대상 방향을 짧게 확인한 뒤 같은 목표로 이동한다. 가까운 즉시 식사·평범한 보행·중간 발판마다 관찰을 반복하지 않는다. 성격/종/걸음에 따라 관찰 시간이 다르며 극심한 배고픔은 우선한다.
2. 관찰도 같은 normalized intention을 보존하고 다음 결정에서 현재 음식/발판으로 경로를 다시 검증한다. 다음 행동의 오래된 좌표/closure를 보관하지 않는다. 실제 유지하던 목표가 사라지거나 막혔을 때만 유한 재확인 뒤 대안을 고른다. 음식의 임시 가림/집힘을 삭제로 취급하지 않는다.
3. 기존 장소 실패 기억을 가까운 발판 선택에도 사용한다. 결과 기억12개·후보200개·상위6개/경로 증명2개·행동 예산과 실패 재시도 지연을 유지한다.
4. 실제 대상 방향을 바라보기, 작은 몸 기울임, 재확인 두리번 포즈를 기존32개 clip과 pose mixer에서 연결한다. 친화적인 성격의 정지 관찰은 실제 포인터를 향할 수 있다. 생각 문구/풍선/아이콘/링/새 버튼은 추가하지 않는다.
5. 같은 renderer/brain을 viewer·비로그인·preview·studio에서 사용한다. 직접 드래그/쓰다듬기/짧은 클릭, 열린 창·휴면·최초공개, 감소 동작/gfx 권한이 우선한다. 모바일 제외/기본OFF/92px/1840 포스터/소파·입·발판·스크롤 기하를 보존한다.

기존 결정 경계에서만 판단한다. 프레임별 경로 탐색·DOM scan·RNG, 별도 상시 시계, 외부 모델/서버/DB/계정/의존성은 추가하지 않는다. 관찰 방향은 기존 좌표 snapshot으로 계산하고 실제 world 위치는 움직이지 않는다. 기억에는 익명 발판/로컬 음식 참조만 쓰며 제목·태그·내용·인증 정보와 자율 행동 로그를 추가하지 않는다. 공개 DTO·권한·unlock·KST 변경 없음. 기존 승인 아트/사용자 파일 보존.

## 근거와 적용 범위

- [Blumberg, MIT, 1996](https://characters.media.mit.edu/Theses/blumberg_phd.pdf), pp.41–43/54–56/63–64: 관련성·목표 지속성·의도 표현 및 흥미 감소. 목표를 유지하되 불가능한 목표를 고집하지 않는 설계에 참고한다.
- [Mateas, CMU Oz, 1997](https://www.cs.cmu.edu/afs/cs/project/oz/web/papers/CMU-CS-97-156.html): 성격·자발적 동기·관계·변화를 통한 캐릭터 설득력. 실제 생물학적 두뇌나 의식을 구현한다는 뜻이 아니다.
- [Rao/Georgeff, BDI Agents, 1995](https://cdn.aaai.org/ICMAS/1995/ICMAS95-042.pdf), pp.314–316: 의도 유지와 환경 변화에 따른 재고의 균형. 기존 행동 경계 재계획에 적용한다.
- [Dragan 외, HRI, 2013](https://publications.ri.cmu.edu/legibility-and-predictability-of-robot-motion): 예측 가능한 움직임과 목표가 읽히는 움직임의 구별. 가상 펫의 관찰/준비 동작에 대한 효과는 프로젝트 적용 추론이며 해당 논문의 직접 검증 대상이 아니다.
- [Reynolds, 1999](https://www.red3d.com/cwr/papers/1999/gdc99steer.html): 행동 선택·조향·이동 계층 분리. 기존 물리 renderer를 재작성하지 않는 근거다.

관찰 밀리초·기울임·선택 임계값은 이 프로젝트의 디자인 선택이며 논문 권장 수치가 아니다.
