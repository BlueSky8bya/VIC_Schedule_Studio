# 135 — 빅타민 아홉 성격, 이름과 대표 행동 읽기 자료

2026-10-19 KST. 상태: **사용자가 읽고 방향을 고르는 제안**. 성격 이름·행동·TV 취향·편집 응원은 이 문서로 제품에 적용되지 않는다. 현재 구현은 8성격이며, 아홉 번째 균형형도 제안이다. 앞서 작성한 **성격별 12개, 총 108개 장면**의 상세 조건과 결말은 [132 전체 행동 목록](PLAN-20261019-132-companion-personality-life.md#4-성격별-108개-장면-제안)에 보존한다. 여기서는 대표 장면과 차이를 먼저 보여 주고 집·작업·음악·귀가 조합을 덧붙인다.

## 1. 이름은 이렇게 부르면 좋겠어요

이미 친숙한 이름은 살리고, 명사만 남아 있던 ‘호기심’을 **탐험둥이**로 부르는 안을 권장한다. ‘호기심쟁이’는 성격 의미가 더 직접적으로 읽히는 대안이다. 균형형은 **둥글이**: 평범하게 멈춰 있는 성격이 아니라, 현재 상황에 어울리는 재미를 골고루 고르는 친구다. 모두 사람을 부르듯 읽히는 한국어 별명으로 맞춘다.

| 권장 이름 | 현재 이름·상태 | 한마디 | 먼저 눈에 보여야 할 대표 장면 |
|---|---|---|---|
| 재롱둥이 | 재롱둥이 · 현재 8종 중 하나 | “나 좀 봐!” | 소품으로 짧은 공연 → 정면 인사 → 소품 반납 |
| 탐험둥이 | 호기심 · 이름 변경 제안 | “저건 뭐지?” | 새 물건의 양쪽을 살핌 → 한 번 건드림 → 확인하고 마침 |
| 애교쟁이 | 애교쟁이 · 현재 | “같이 있어 줘.” | 안전한 옆자리로 다가옴 → 쓰담 기다림 → 만족하고 물러남 |
| 잠꾸러기 | 잠꾸러기 · 현재 | “졸리지만 구경은 하고 싶어.” | 하품·스트레칭 → 쿠션 꾹꾹이 → 조건에 맞춰 깨어 있거나 쉼 |
| 깔끔이 | 깔끔이 · 현재 | “제자리에 있어야 마음이 편해.” | 흩어진 실물 하나를 골라 상자에 넣음 → 정리한 자리 확인 |
| 사고뭉치 | 사고뭉치 · 현재 | “가만히 있으면 심심해!” | 공·자동차를 밀고 쫓음 → 실제 결과를 보고 짧게 딴청 |
| 먹보 | 먹보 · 현재 | “먹는 일에는 진심.” | 최애에 귀가 쫑긋 → 실제 한입 → 배부르면 같은 음식을 보관 |
| 집돌이 | 집돌이 · 현재 | “내 방이 제일 좋아.” | 집 가까이에서 놀이 → 같은 소품 반납 → 편한 자리로 귀가 |
| 둥글이 | 균형 · **신규 성격 제안** | “이번엔 이거 해 볼까?” | 살펴보기·놀이·정리를 한 편으로 연결 → 다른 생활로 전환 |

‘장난꾸러기·냠냠이·집콕이’처럼 전부 더 말랑한 별명으로 바꾸는 선택지도 있지만, 우선은 기존 이름의 기억을 살리고 두 이름만 보완하는 안이다. 탐험둥이의 내부 ID는 기존 `curious`를 유지하는 방향이며, 둥글이의 `balanced`는 아직 없는 신규 ID 후보다. 이름 표의 대표 장면도 새 행동 설계이며 현재 작동 보장이 아니다.

## 2. 현재 되는 것과 앞으로 만들 것은 구분해요

현재 성격 차이는 이동·놀이·교감·정리의 확률과 선호에 많이 들어 있다. 전용 재롱은 각 3개지만, 8성격의 재롱 집합은 5종류여서 겉보기에는 닮아 보일 수 있다. 탐험둥이와 사고뭉치, 깔끔이와 먹보, 잠꾸러기와 집돌이가 각각 같은 재롱 집합을 쓴다. [현재 성격 정의](../../../lib/ui/viewer-companion/preferences.ts), [현재 재롱 선택](../../../lib/ui/viewer-companion/personality-activity.ts).

이번 제안은 **무엇을 고르는지 → 어떻게 대하는지 → 어떻게 끝내는지**를 다르게 만든다. 같은 인사 동작을 더 자주 보여 주는 것만으로 성격 차이를 채우지 않는다.

| 구분 | 현재 확인된 자원·기능 | 이 자료에서 새로 제안하는 것 |
|---|---|---|
| 몸·표현 | 기본 행동 13종, 재롱 시퀀스 16종, 사건 장면 36개 | 성격별 목적·진입·결말·최근 장면 중복 억제 |
| 음식·장난감 | 음식 180종, 장난감 24종, 실제 먹기·운반·반납·발견 | 아래 대표 행동을 하나의 유한한 생활 장면으로 잇기 |
| 집·음악 | 집·소파·공유 계절/날씨·커튼·라디오·실제 악기 반응 | TV 채널 취향·전등 생활·씻기·자동 셔터와 성격의 연결 |
| 기억 | 방문 시간대·재회·익숙한 자리·실제 경험을 쓰는 로컬 틀 | 성격별 귀가 연출과 제한된 시간대 변주. 완성된 생활시간표는 아님 |
| 편집 응원 | 편집/모달/드래그의 기존 busy 억제 | 공개 일반 작업의 고정 완료 신호에만 짧은 응원을 연결 |

집의 시각 개편은 [135 인테리어 작업](PLAN-20261019-135-companion-interior-field-guide.md)의 별도 범위다. 새 방 그림을 붙였다는 이유로 아래 자율 TV·씻기·귀가·편집 반응까지 구현된 것으로 세지 않는다. [132 집·작업 설계](PLAN-20261019-132-companion-home-scenes.md)는 당시 조사와 새 설계를 구분해 둔 근거다.

## 3. 선택하고 10초 안에 알아보는 장면

성격을 바꾸면 **첫 안전한 결정 기회부터 0–3초 안에 대표 행동을 시작**하는 방향이다. 자유롭게 행동을 고를 수 있는 활성 구간에서는 **10초가 지나기 전에 설명 없이도 성격이 읽히는 실제 반응**이 보이는지 확인한다. 먼 상자까지 도착하는 데 오래 걸린다면, 먼저 물건을 골라 몸을 정돈하는 모습처럼 목적을 드러내고 이동한다. 단순 걷기·멍때리기·후보만 선택한 상태는 성공으로 세지 않는다.

현재 8초 예산은 마지막 의미 행동 뒤의 활성 시간 기준이다. 공통 식사나 실제 운반도 갱신하므로 ‘8초마다 성격 전용 행동이 반드시 보인다’는 뜻은 아니다. 제안의 10초 기준은 아직 구현·실측되지 않았다.

| 성격 | 가까운 소품이 있을 때 먼저 보일 반응 | 소품·집이 없을 때의 대체 후보 |
|---|---|---|
| 재롱둥이 | 소품 앞에 자리 잡고 짧은 응원 연습 시작 | 그 자리에서 응원 한 토막과 정면 인사 |
| 탐험둥이 | 덜 본 소품을 골라 갸웃하고 가까이 관찰 | 한 안전한 자리만 정해 탐색 준비·짧은 관찰을 완결 |
| 애교쟁이 | 멈춘 마우스의 안전한 옆자리로 다가가 쓰담 요청 | 현재 안전한 자리에서 짧은 쓰담 요청 후 기다림 종료 |
| 잠꾸러기 | 쿠션을 꾹꾹 누르고 하품 | 깨어 있는 하품·스트레칭 뒤 눈을 뜨고 반응 |
| 깔끔이 | 가까운 실제 물건을 골라 정리 시작 | 짧은 몸단장 → 주변 확인 → 종료 |
| 사고뭉치 | 공이나 차를 밀 준비 후 한 번 덤벼듦 | 허용된 작은 덤벼들기 한 번 후 몸 털기 |
| 먹보 | 가까운 실제 음식에 짧은 냄새 확인 | 짧은 몸단장·만족 인사. 없는 음식·먹은 경험은 만들지 않음 |
| 집돌이 | 집 안/집 가까운 익숙한 자리에서 짧은 생활 동작 | 현재 안전한 자리에서 포근한 비비기·몸단장 |
| 둥글이 | 현재 욕구·실제 대상을 비교해 놀이 한 번 시작 | 최근과 다른 짧은 교감·몸단장 중 하나를 완결 |

이 대체 표현만으로 먹보·집돌이까지 잘 구별되는지는 작은 실제 화면에서 확인해야 한다. 의도가 흐리면 새 표정이 필요한지 검토하며, 제안만으로 읽힘이 입증됐다고 하지 않는다.

실제 식사·운반·낙하·착지·사람의 잡기/쓰다듬기·편집 입력은 끝까지 우선한다. 숨김·모달·quiet·기능 OFF 시간은 이 예산에 쌓지 않는다. `activeWhileVisible=true`인 보이는 비포커스 화면은 기존 활성 정책을 따른다. 수면 OFF의 잠꾸러기도 잠든 연속 연출로 우회하지 않고 깨어 있는 반응을 쓴다.

## 4. 108장면을 성격별로 읽기

각 성격의 **대표 3개 + 다른 9갈래**를 요약했다. 괄호 번호는 132 원문의 장면 번호다. 조건·실물 소유권·결말을 포함한 전체 12개씩은 각 원문 링크에서 읽을 수 있다. 아래 모두 **새 제안**이며, ‘기존 자원 조합’도 연결 코드와 실물 검증이 필요하다.

### 4.1 재롱둥이 — 구경해 주면 신나요

- **첫 재회(1):** 실제 안전한 착지 뒤 통통 두 번과 정면 인사. 마치면 옆으로 비켜 작업 공간을 비워 준다.
- **소품 공연(5):** 마라카스·탬버린 하나를 골라 짧게 흔들고 인사한다. 같은 실물을 상자에 넣으며 공연을 끝낸다.
- **앙코르(8):** 공연 직후 실제 쓰다듬기를 받으면 다른 재롱을 한 번 더. 두 번째 인사 뒤에는 같은 공연을 즉시 되풀이하지 않는다.

다른 9갈래: 마우스 옆 응원(2) · 공과 함께 통통(3) · 별 지팡이 공연(4) · 기차 옆 행진(6) · 굴러도 회복 후 인사(7) · 착용한 액세서리 앞·옆 보여 주기(9) · 반납 후 마지막 인사(10) · 공연 윙크(11, 새 표정 후보) · 귀로 지휘하기(12, 새 포즈 후보).

차이: 사람의 시선을 받아 **작은 공연을 완성하고 인사**한다. [재롱둥이 12장면](PLAN-20261019-132-companion-personality-life.md#41-재롱둥이--나-좀-봐).

### 4.2 탐험둥이 — 먼저 살펴보고 해 봐요

- **새 장난감(1):** 바닥에 정착한 새 물건의 양쪽을 번갈아 살피고 한 번 톡 건드린다. 놀이 한 번이나 실제 상자 반납으로 끝낸다.
- **종이비행기(5):** 안전한 실제 목적지로 한 번 날린다. 도착한 비행기까지 가 다시 살펴본 뒤 마친다.
- **새 자리(9):** 월 이동 뒤 드러난 안전한 자리 하나만 골라 탐색한다. 도착해 주위를 확인하며 종료한다.

다른 9갈래: 첫 음식 냄새·물러남·재접근(2) · 먹어 본 부류는 짧게 확인(3) · 구르는 공을 지켜보다 톡(4) · 팽이를 보고 짧게 몸 돌리기(6) · 만화경 가까이 보기(7) · 덜 경험한 실물 선택(8) · 발견되면 반대쪽 얼굴 빼꼼(10) · 최애와 새 음식 비교 후 결정(11) · 귀 기울여 집중(12, 새 포즈 후보).

차이: 사고뭉치가 **변화를 일으켜 즐긴다면**, 탐험둥이는 **이미 일어난 것을 알아보고 확인**한다. [현재 ‘호기심’ 이름으로 남은 12장면](PLAN-20261019-132-companion-personality-life.md#42-호기심--저건-뭐지).

### 4.3 애교쟁이 — 사람 곁이 좋아요

- **가까이 멈춘 마우스(1):** 안전한 거리까지 다가가 고개를 든다. 반응이 없으면 짧게 기다린 뒤 옆으로 물러난다.
- **실제 쓰다듬기(2):** 비비고 웃은 뒤 만족해서 자기 놀이로 돌아간다. 같은 보상을 계속 요구하지 않는다.
- **오랜만의 방문(9):** 평소보다 적극적으로 반기고 다가간다. 환영이 끝나면 작업을 가리지 않는 옆자리로 간다.

다른 9갈래: 마우스를 한 번만 따라가기(3) · 음식 대신 사람에게 인사(4) · 인형을 들고 사용자 보기(5) · 놀이 중 반겨도 소품 마무리(6) · 넘어진 뒤 쓰담 받고 안심(7) · 쿠션에서 몸 내밀어 반기기(8) · 쓰담 뒤 만족 표정 유지(10) · 거친 경험 뒤 조심스럽게 재접근(11) · 눈 감고 볼 기대기(12, 새 표정 후보).

차이: 재롱둥이는 보여 주고, 애교쟁이는 **같이 머물고 교감**한다. [애교쟁이 12장면](PLAN-20261019-132-companion-personality-life.md#43-애교쟁이--같이-있어-줘).

### 4.4 잠꾸러기 — 졸려도 반응은 해요

- **활동을 마친 틈(2):** 하품과 스트레칭 뒤 가까운 대상 하나를 확인한다. 계속 멈춰 있는 대신 깨어 있는 결말을 만든다.
- **빈 쿠션 도착(3):** 한 번 꾹꾹 누르고 자리를 조금 바꾼다. 잠들 조건이 아니면 일어나 주변을 본다.
- **졸린데 배고픔(6):** 짧게 냄새를 확인한 뒤 실제 음식을 먹는다. 식사를 마친 다음에만 휴식을 다시 고른다.

다른 9갈래: 잠과 싸우는 반눈(1, 새 표정 후보) · 깃털 보고 흠칫 깨기(4) · 물고기 인형 편히 보고 반납(5) · 장난감 하나만 정리 후 쿠션(7) · 방문에 천천히 고개 들기(8) · 쓰담 뒤 하품·조건에 따른 스트레칭/휴식(9) · 휴식 중 짧은 자세 바꿈(10) · 떨어진 장난감에 눈 뜨고 확인(11) · 귀가 내려갔다 퍼뜩 올라오기(12, 새 포즈 후보).

차이: 집돌이는 집에서 **깨어 놀기를 즐기고**, 잠꾸러기는 **낮은 에너지와 졸음을 표현**한다. [잠꾸러기 12장면](PLAN-20261019-132-companion-personality-life.md#44-잠꾸러기--졸리지만-구경은-하고-싶어).

### 4.5 깔끔이 — 끝나면 제자리에 둬요

- **흩어진 장난감(1):** 가까운 실물부터 상자로 운반한다. 실제 넣기 완료를 확인하고 다음 물건을 고른다.
- **배부른데 최애가 남음(4):** 먹을 것을 하나 들어 집 안 빈자리에 보관한다. 좋아하는 음식까지 쓰레기통으로 보내지 않는다.
- **정리 중 사람이 집음(8):** 그 물건의 소유권을 즉시 양보한다. 다른 실물을 고르거나 해당 정리를 끝낸다.

다른 9갈래: 겹친 음식 간격 정리(2) · 배부를 때 비최애 음식 실제 버리기(3) · 음식/장난감 중 한 작업부터(5) · 반납한 자리 한 번 확인(6) · 정리할 게 없으면 몸단장(7) · 운반 중 새 물건은 다음 차례(9) · 놀던 소품 반납 후 몸 털기(10) · 굴러도 원래 정리 재개(11) · 여러 물건 마지막 반납 후 인사(12).

차이: 물건을 움직이는 동작보다 **실제로 제자리를 만든 결과**가 성격이다. [깔끔이 12장면](PLAN-20261019-132-companion-personality-life.md#45-깔끔이--제자리에-있어야-마음이-편해).

### 4.6 사고뭉치 — 움직이면 더 재미있어요

- **공 놀이(1):** 공을 굴리고 쫓아간다. 따라잡으면 한 번만 다른 방향으로 보내고 그 놀이를 끝낸다.
- **자동차 놀이(5):** 앞으로 조금 밀고 따라간다. 실제 멈춘 차를 따라잡고 작은 놀람 반응으로 마친다.
- **사용자가 방금 정리함(12):** 정리된 상자를 잠깐 본다. 같은 물건을 곧바로 꺼내 방해하지 않고 다른 놀이·짧은 달리기를 고른다.

다른 9갈래: 나온 블록 조금 흩어 보기(2) · 허용될 때 상자에서 한 개만 꺼내기(3) · 급하지 않은 음식 한 번 장난 후 실제 먹기(4) · 고리 쫓다 굴러도 회수(6) · 비행기 반대쪽 봤다가 따라가기(7) · 사람이 놓은 장난감에 한 번 덤비기(8) · 빼꼼 숨었다 발견되면 나오기(9) · 상한이면 기존 소품으로 변주(10) · 들킨 뒤 딴청(11, 새 표정 후보).

차이: **밀고·굴리고·쫓는 원인과 결과**가 짧게 이어진다. 무한 생성·상시 방해·물건 삭제로 장난을 표현하지 않는다. [사고뭉치 12장면](PLAN-20261019-132-companion-personality-life.md#46-사고뭉치--가만히-있으면-심심해).

### 4.7 먹보 — 한입도 소중해요

- **최애가 실제 가까이 있음(3):** 귀가 쫑긋한 짧은 반응 뒤 접근해 실제 먹는다. 식사 뒤 만족 반응을 준다.
- **배부른데 좋아하는 음식이 남음(6):** 같은 음식을 집으로 운반해 빈자리에 둔다. 먹는 연출을 억지로 더하지 않는다.
- **보관한 음식과 재회(7):** 다시 배고파졌을 때 남아 있는 그 음식의 현재 위치로 간다. 실제 식사와 발견 처리를 정상적으로 마친다.

다른 9갈래: 떨어져 정착한 음식부터 보기(1) · 배고프면 갈 수 있는 가까운 음식(2) · 익숙한 빵 부류는 빨리 맛보기(4) · 둘 중 하나 골라 식사 완료(5) · 식후 웃기·몸단장(8) · 당근 장난감 살펴도 먹지 않기(9) · 실제 섭취 뒤 싫은 맛 반응(10) · 볼 살짝 오물거리기(11, 새 표정 후보) · 실제 바뀐 최애에 반응(12).

차이: 깔끔이도 음식을 보관하지만, 먹보는 **맛·최애·식후 만족**이 중심이다. [먹보 12장면](PLAN-20261019-132-companion-personality-life.md#47-먹보--먹는-일에는-진심).

### 4.8 집돌이 — 방 안에도 할 일이 많아요

- **집 가까운 놀이(2):** 상자에서 하나를 꺼내 집 근처에서 놀고 같은 실물을 반납한다.
- **밖에 좋아하는 소품(5):** 안전한 왕복 경로가 있으면 잠깐 나가 가져온다. 실제 집 상자까지 옮기며 귀가를 완성한다.
- **집 다시 열림(10):** 하던 이동을 안전하게 끝낸 뒤 열린 집의 실제 경로를 확인하고 돌아간다.

다른 9갈래: 집 안 안전한 두세 자리 바꾸기(1) · 집 앞 짧은 기차 놀이 후 회수(3) · 고리 쌓기 소품 앞·옆 관찰(4) · 배부른 최애 집 보관(6) · 쿠션에서 내려와 스트레칭 후 복귀(7) · 집 펼치면 둘러보고 인사(8) · 접히면 기존 안전 대기(9) · 익숙한 자리에서 직전과 다른 생활(11) · 쿠션에 편히 파묻히기(12, 새 포즈 후보).

차이: 잠만 자는 대신 **작은 방을 거점으로 놀이·보관·몸단장**한다. [집돌이 12장면](PLAN-20261019-132-companion-personality-life.md#48-집돌이--내-방이-제일-좋아).

### 4.9 둥글이 — 재미를 골고루 이어 가요

- **여러 대상이 있음(1):** 지금 욕구와 실제 접근 가능성을 비교해 한 활동을 고르고 끝낸다.
- **비슷한 활동 두 번 뒤(2):** 다른 적합한 대상이 있으면 활동 종류를 바꾼다. 반대 성격을 억지로 흉내 내지 않는다.
- **짧은 생활 한 편(12):** 장난감을 살펴보고 한 번 논 뒤 실제 상자에 넣는다. 마지막 인사로 끝낸다.

다른 9갈래: 공 놀이 한 번 후 반납(3) · 한두 개만 정리(4) · 새 음식 한 번 확인 뒤 맛보기(5) · 최애만 고집하지 않고 식사 결정(6) · 마우스에 인사 후 과한 추격 중지(7) · 짧게 쉰 뒤 작은 놀이(8) · 넘어져도 원래 일 완료(9) · 최근과 다른 장난감 선택(10) · 실제 즐거웠던 교감 한 번 제안(11).

차이: 개성이 없는 기본값 대신 **서로 다른 활동을 자연스럽게 완결하고 전환**한다. [둥글이 12장면](PLAN-20261019-132-companion-personality-life.md#49-둥글이--그때그때-재미있는-걸-골고루).

## 5. 새 집·작업·음악·귀가와 만났을 때

아래 36조합은 108장면에 덧붙인 **후속 제안**이다. 표의 화살표는 실제 계기 뒤의 짧은 첫 반응과 결말을 뜻한다. 자유 결정이 가능한 상황에서 첫 반응이 10초 안에 읽히게 만들되, TV 시청·귀가·씻기 전체를 10초 안에 끝내려고 이동을 잘라내지 않는다.

### 5.1 집 안에서 — 모두 제안

TV는 무음 기본의 로컬 5채널(자연·음악·요리·장난감·달별) 후보다. 사람이 끈 TV·불을 즉시 자율로 되켜지 않는다. 샤워·자동 셔터·줄 당기기는 실제 가구 접점과 완료 확인부터 필요하다.

| 성격 | 실제 진입 계기 → 먼저 보일 반응 → 마무리 |
|---|---|
| 재롱둥이 | 음악 화면의 실제 시청 구간 완료 → 소파 앞 안전한 자리에서 짧은 리듬 재롱 → 인사하고 시청/다른 놀이 선택 |
| 탐험둥이 | 처음 보는 자연·장난감 화면을 실제 봄 → 고개 갸웃 → 한 채널만 비교하고 관심 있는 화면에 머무름 |
| 애교쟁이 | 시청 중 사람이 안전한 근처에 멈춤 → 화면에서 사람 쪽으로 고개 전환 → 한 번 쓰담 기다린 뒤 원래 생활 |
| 잠꾸러기 | 실제 졸음 + 수면 허용 + 안전한 귀가 → 짧은 하품 → TV·불을 끄고 실제 쿠션 휴식; 수면 OFF면 스트레칭으로 끝냄 |
| 깔끔이 | 마지막 장난감 실제 반납 완료 → 정리한 자리 확인 → 씻기 완료가 연결되면 깨끗한 자리에서 짧은 시청 |
| 사고뭉치 | 장난감 채널 한 구간을 보고 흥미가 낮음 → 채널을 한 번 바꿔 봄 → 여전히 심심하면 TV 대신 실제 장난감 하나 |
| 먹보 | 실제 식사 완료·포만 → 만족 몸단장 → 요리 채널 보기; 화면 음식은 먹기·발견 경험으로 세지 않음 |
| 집돌이 | 깨어 있는 낮의 실제 집 착지 → 익숙한 자리로 정돈 → 허용된 커튼/불 상태로 TV 빛 아래 편히 시청 |
| 둥글이 | 짧은 시청 구간 완료 + 다른 적합한 활동 있음 → 화면에서 소품 쪽으로 관심 전환 → TV를 마치고 놀이·정리 한 토막 |

### 5.2 편집하는 사람 곁에서 — 모두 제안

공개 일반 일정의 작업 완료 같은 **고정 enum/boolean 신호**만 기기 안에서 쓴다. 제목·본문·태그·ID·날짜·draft·비공개/떡밥 맥락을 읽지 않는다. 입력/IME·드래그·모달·저장 중에는 기존 busy 소유권이 우선이며, 오래된 응원을 복귀 뒤 몰아서 재생하지 않는다. viewer·익명·역할 미리보기에 편집 권한을 추가하지 않는다.

| 성격 | 실제 진입 계기 → 먼저 보일 반응 → 마무리 |
|---|---|
| 재롱둥이 | 실제 저장 성공 전환 → 짧은 축하 한 번 → 꾸벅하고 물러남; 같은 저장의 drag/sync와 중복 축하 없음 |
| 탐험둥이 | 공개 일반 편집창의 안전한 열림 신호 → 집에서 갸웃 → 입력이 시작되면 조용히 자기 자리로 |
| 애교쟁이 | 공개 일반 입력 종료·작업 여유 → 사람 방향으로 짧은 쓰담 요청 → 무반응이면 바로 양보 |
| 잠꾸러기 | 실제 작업 완료와 다음 입력 사이 안전한 틈 → 짧은 하품·스트레칭 → 깨어 있는 꾸벅 |
| 깔끔이 | 실제 저장 성공 → 자기 주변 물건 하나를 정리할 준비 → 조작 소유권이 없을 때만 해당 정리; 일정 내용은 손대지 않음 |
| 사고뭉치 | 실제 undo/redo 완료 뒤 안전한 틈 → 짧게 갸웃하다 통통 한 번 → 사용자 키/기록을 건드리지 않고 종료 |
| 먹보 | 실제 저장 성공 + 먹을 수 있는 음식이 가까이 있음 → 만족 반응 → 배고플 때만 실제 식사, 아니면 짧은 인사 |
| 집돌이 | 패널 자리 이동의 실제 geometry 완료 → 집에서 새 방향 보기 → 현재 집 안전 앵커에 머물러 작업 공간 양보 |
| 둥글이 | 가장 최근의 유효한 공개 작업 완료 → 짧은 꾸벅 하나 → 직전과 다른 조용한 생활로 전환 |

저장 실패에는 전 성격이 차분한 곁 지키기만 검토한다. 실패를 장난이나 축하로 바꾸거나 자동 재시도하지 않는다. 실패 상태를 아는 경우도 오류 내용은 전달하지 않는다.

### 5.3 실제 음악이 들릴 때 — 모두 제안

기존 라디오·실제 들린 악기 onset·공용 오디오 정책을 쓴다. 실제 악구의 끝과 불확실한 타이밍을 구분하고, 모르는 곡에 정확한 박자 평가를 만들지 않는다. 음소거·공연 소유권·소리 OFF를 뒤집지 않는다.

| 성격 | 실제 진입 계기 → 먼저 보일 반응 → 마무리 |
|---|---|
| 재롱둥이 | 허용된 실제 악구/리듬 도착 → 응원 연습이나 소품 리듬 → 악구가 끝나면 정면 인사 |
| 탐험둥이 | 실제로 처음 들은 소리의 짧은 구간 → 소리 쪽을 집중해서 봄 → 한 구간 듣고 원래 탐색 |
| 애교쟁이 | 실제 사용자의 연주 후 안전한 틈 → 사용자 쪽 인사 → 짧은 교감 기다림 후 종료 |
| 잠꾸러기 | 잔잔한 실제 음악 + 낮은 에너지 → 느린 스트레칭 → 잠 허용 조건이면 휴식, OFF면 눈 뜨고 감상 마침 |
| 깔끔이 | 정리 중 실제 음악 시작 → 지금 든 물건 반납부터 완료 → 가벼운 인사 뒤 다음 물건/감상 선택 |
| 사고뭉치 | 실제 경쾌한 구간 + 안전한 공간 → 허용된 짧은 덤벼들기·통통 → 소품을 하나만 골라 마침 |
| 먹보 | 실제 식사 중 음악 시작 → 식사 소유권 유지 → 먹은 뒤 만족 인사로 짧게 반응 |
| 집돌이 | 집에서 좋아하던 실제 음악 재생 → 익숙한 자리에서 편한 몸단장 → 한 구간 감상 후 생활로 복귀 |
| 둥글이 | 실제 악구 마무리 + 자유 결정 → 짧은 축하 → 감상·정리·교감 중 최근과 다른 한 가지 |

### 5.4 귀가 시간·계절과 만났을 때 — 모두 제안

‘귀가’는 실제 집에 도착한 사건이고 ‘방문’은 실제 보이는 만남이다. 시간대는 공유 KST의 거친 band, 계절은 보고 있는 달력 월을 따른다. 시간대 기억은 기기 로컬의 제한된 실제 관측만 사용하며, 부재 동안 배고픔·피로 벌점·밀린 경험을 만들지 않는다. 학습 OFF에는 학습된 시간대 읽기·쓰기·감쇠를 멈춘다.

| 성격 | 실제 진입 계기 → 먼저 보일 반응 → 마무리 |
|---|---|
| 재롱둥이 | 익숙한 저녁의 실제 재회 → 짧은 환영 공연 → 집 앞 안전한 자리에서 인사하고 비켜 줌 |
| 탐험둥이 | 봄 새벽의 실제 귀가 → 창 쪽으로 갸웃·냄새 확인 → 자연 화면/창밖 한 번 관찰 |
| 애교쟁이 | 밤의 실제 귀가·안전한 사용자 접근 → 조용히 반기는 비비기 → 곁에서 짧게 머무름 |
| 잠꾸러기 | 겨울밤 + 실제 졸음 + 수면 허용 → 하품 → 집 착지·물건 마무리 뒤 TV/불·셔터 순서 검토 |
| 깔끔이 | 실제 귀가 때 흩어진 물건 존재 → 가까운 물건 하나 선택 → 반납 확인 후 편한 자리 |
