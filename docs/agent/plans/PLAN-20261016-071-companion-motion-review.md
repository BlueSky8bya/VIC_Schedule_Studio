# PLAN-20261016-071 — 빅타민 전체 동작 리듬과 일정 장난

Status: In Progress
Date: 2026-10-16 (KST)

## 목표와 조사

울먹임만이 아니라 전체 포즈/행동의 접촉 반응·재생 속도·표정 유지·회복 전환을 전수 조사하고 공유 runtime에서 수정한다. 달리기→구르기·충돌·착지 실수·일정 기울이기의 실제 연결을 확인하고, 구현과 미구현을 구분한다.

## 구현 원칙

- 단순 일괄 배속 대신 빠른 접촉→읽을 수 있는 표정→짧은 회복의 개별 리듬. 이동·프레임 위상은 기존 단일 display clock과 거리 기반 stride 재사용.
- 장난 탭의 일정 기울이기 독립 토글. OFF 시 장식 회전/잔류 효과 제거. 공유 설정/저장/이용기록 경로 재사용.
- 일정 변화는 로컬 표시 효과만. 실제 일정/하트 데이터·공개 전 떡밥·선택/편집/드래그는 건드리지 않는다. 공개 DTO/권한/언락/KST 경계 변경 없음.
- 모바일 빅타민 비활성, reduced motion/gfx 등급/숨김 탭/OBS 프레임 상한·정지 정책 유지. 추가 per-frame DOM 탐색·배경 네트워크·반복 타이머 금지.
- 기존 승인 아트와 사용자의 작업 파일 보존. 새 그림은 필요가 입증되는 경우에만 별도 아트 규칙을 따라 진행.

## 단계와 검증

1. 모든 논리 clip과 상황을 표로 기록하고 느린 구간/끊김·잘못 연결된 장난 근거 정리.
2. clip별 타이밍과 전환, 실제 착지/충돌 계기, 일정 장난 토글 연결.
3. 독립 리뷰, 단위 timing/trigger/preferences/활동기록 계약, 두 surface native 입력 및 행동 연결 실물 검사.
4. typecheck/lint/build/harness, 검증 기록 및 승인된 commit/push·실제 배포 확인.
