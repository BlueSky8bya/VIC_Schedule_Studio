## 3. 제품 모델과 행동강령

### 네 층의 성격

1. 종족 성질: 빅타민에게 공통인 발견 공유·리듬 반응·작은 생활 의식.
2. 타고난 기질: 기존 9성격. 안정적으로 유지하며 명시적 사용자 선택을 우선.
3. 함께 배운 버릇: 반복된 실제 교감으로 천천히 변화.
4. 현재 상태: 피로·포만감·들뜸·짧은 싫증. 장기 성격과 분리.


### 고정 행동강령

- 직접 입력, 사용자가 허용한 설정, 안전한 물리 경로가 학습보다 우선.
- 하던 일의 목적을 유지. 새 관심은 제한된 확인 후 원래 일로 이어짐.
- 관찰·휴식에도 이유가 있고, 매번 재롱으로 시간을 채우지 않음.
- 같은 자극에는 익숙해지고 충분히 즐긴 활동에는 잠시 싫증이 남.
- 친밀함은 발견 공유·근처에서 쉬기·익숙한 놀이의 변주로 표현.
- 실수 뒤에는 접근을 조정하되 같은 사고를 반복하는 개그 루프는 만들지 않음.
- 부재로 관계/허기 손실 누적 없음. 무반응을 거절이나 싫어함으로 단정하지 않음.
- 타고난 기질은 보존하고 경험은 그 위에 버릇을 더함.

빅타민 대표 문법은 발견 → 자기 방식으로 탐색 → 사용자 쪽 확인 → 실제 반응이 있으면 변주 → 만족하면 마무리다. 고양이/강아지 모드는 기존 별도 성질을 유지한다. 모든 성격에 같은 재롱을 강제하지 않는다.

### 학습할 내용

- 기존 3축에 짧게/길게 교감, 조용한 동행, 발견 공유, 익숙함/새로움 선호를 우선 연결.
- 놀이 강도와 자리·순서의 의식은 후속 단계. 처음부터 많은 성격 축을 만들지 않음.
- 제한된 연속 수치 + 근거량을 저장. 사용자 인격·심리·민감 특성을 판정하지 않음.
- 제공한 물건의 빈도, 빅타민의 실제 만족, 사용자의 놀이 참여를 구분.
- 기존 허용 후보 안에서 기질 + 상황 + 학습 보정 + 목표 유지 - 최근 반복으로 판단. 학습 보정은 상한을 두고 차이가 작은 후보에서만 탐색.
- LLM·외부 추론·네트워크 학습 없음. 장기 지연 보상 강화학습은 처음부터 넣지 않고 로컬 실험에서 필요성과 효과가 확인된 경우만 검토.

구현 확인 후 사용할 설명 초안:

> 빅타민은 함께 놀고 돌본 경험을 바탕으로 취향과 버릇을 기억해 행동에 반영합니다. 이 기록은 사용하는 브라우저에만 저장되며 서버로 보내지 않습니다. 설정에서 배우기를 끄거나 학습 기록을 초기화할 수 있습니다. 브라우저 데이터를 지우면 기록도 사라집니다.
