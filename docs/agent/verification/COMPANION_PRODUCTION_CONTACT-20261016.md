## 진단·수정

기존 소파 앞면은 현재 몸체 대신 원래 발판/목적지가 소파인지로 표시했다. 따라서 옆에서 집어 들어온 경우와 밖으로 들어 나가는 경우 깊이 전환이 달랐다. 놓기 충돌도 중립 발 위치 한 점과 폭만 검사해 귀를 잡고 늘어진 몸체를 놓쳤다. 포커스/위치 고르기에는 전역 버튼 규칙을 포함한 보라 원형 outline이 남아 있었다.

공유 엔진의 현재 등록/clip과 포즈·접촉·지지 반응·방향·관성·화면 transform을 수치 합성한 전체 몸체로 소파 안/밖을 판정한다. 디코딩 대기 시 실제 마지막으로 그린 이미지의 등록 정보를 유지한다. 앞쪽 몸체 위로 소파 턱이 그려지지 않도록 앞면 깊이를74/76으로 구분하고, 내부 정착은 좌석 앞/뒤 레이어를 유지한다. 기존 시계·프레임·캐시된 소파 실측을 사용하며 새 루프/매 프레임 DOM 측정은 없다. 잡은 손 위치를 강제로 움직이지 않는다. 소파를 출입하는 도약은 측정된 턱 위로 상승→통과→착지하는 유한 경로를 사용한다.

보라 pet outline/그림자를 명시 제거한다. 키보드는 중립색 짧은 선으로 표시하며, 소파 안에서는 턱에 가리지 않게 위로 배치한다. 일정의 보라 pet 하트 구분은 유지한다. 모바일 편집실 톱니만 월 이동 줄 오른쪽으로 옮기고 가운데 월 이동 그룹과 공통44px 버튼/설정 창/history를 유지한다. 시청자 톱니 위치는 유지한다.
