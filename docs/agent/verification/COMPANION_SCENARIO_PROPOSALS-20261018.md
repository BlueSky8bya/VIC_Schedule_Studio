# 빅타민과 함께 지내는 장면 36가지 — 제안 전용

2026-10-18 KST · PLAN-116 조사 제안 · 구현 승인 대기

**아래 36개 연결 장면은 모두 미구현 제안이다.** 이번 조사로 게임 동작·기억·설정을 추가하지 않았다. 음식 먹기, 쓰담과 안심 학습, 식사 중 반응, 정리와 음식 장난, 라디오 반응, 의상 묘기, 수첩, 숨바꼭질은 이미 있는 기능이다. 여기서는 그 기능을 **어떤 상황에서 시작하고, 무엇을 기억하며, 다음에 어떻게 다르게 행동할지** 제안한다. 같은 포즈를 쓴다고 새 장면까지 구현된 것은 아니다.

현재 음식은 **180종**, 실제 착용 목록은 **27종**이다. 몸동작은 **논리 행 41개(0–40)**로 구성되며, 그중 **7번은 사용하지 않는 이전 행**이다. 이 수치는 원본 그림·파일 수와 다르다. 집에는 창문, 선반, 수첩, 라디오, 쿠션, 음식통, 휴지통이 있다. 아래 장면은 이 자원과 현재의 바라보기·걷기·꾸벅·부비기·냄새 맡기·기지개·몸단장·폴짝·자리 만들기 포즈를 중심으로 골랐다.

## 다시 만나는 시간

### 1. 오랜만의 재회 ★ 추천

사흘 만에 실제로 화면을 열었다. **두리번거리던 빅타민이 멈춤 → 사용자를 향해 돌아봄 → 안전한 바닥에서 몇 걸음 다가옴 → 꾸벅하거나 쓰담을 청함.** 애교쟁이는 바로 가까이 오고, 고양이 모드는 무심한 듯 몸단장하다 뒤늦게 접근한다. 잠꾸러기는 쿠션에서 기지개부터, 사고뭉치는 달려오다 앞에서 급히 멈춘다.

기억할 것은 마지막 만남과 이번 간격뿐. 부재 중 굶거나 삐진 것으로 만들지 않는다. 현재의 창 복귀 기상 동작과 구별되는 새 제안이다.

### 2. 늘 만나는 시간 ★ 추천

실제 방문이 여러 날 저녁 9시 무렵에 모였다. 다음에도 그 시간에 들어오면 **짧게 돌아봄 → 익숙한 인사 → 평소 함께 하던 쓰담이나 조용한 놀이를 한 번 청함.** 애교쟁이는 곁으로, 깔끔이는 주변 음식부터 살피고, 잠꾸러기는 쿠션 가까이서 맞는다.

앱이 닫힌 동안 기다리는 동작을 실행하는 것은 아니다. 다음 실제 만남에만 익숙함을 표현한다. 늦거나 안 와도 불이익은 없다.

### 3. 오늘은 일찍 왔네

주로 밤에 만나다가 아침에 처음 들어왔다. **눈을 뜸 → 길게 기지개 → 한 번 고개를 돌려 확인 → 작은 인사.** 잠꾸러기는 하품이 먼저 나오고, 사고뭉치는 몸을 털더니 금방 폴짝한다. 고양이 모드는 한 박자 더 바라보다 온다.

새 시간대에도 만날 수 있다는 경험만 조금씩 쌓는다. 사용자가 실제로 언제 일어나고 자는지 단정하지 않는다.

### 4. 우리 집의 마무리 시간

여러 번 비슷한 저녁 시간에 사용자가 직접 집으로 불러 쉬게 했다. 다음 만남에는 **쿠션을 바라봄 → 사용자에게 한 번 돌아봄 → 꾹꾹이 → 자리를 잡음.** 잠꾸러기는 바로 웅크리고, 애교쟁이는 쉬기 전에 곁을 청한다. 깔끔이는 식사 대상이 아닌 남은 음식 하나를 정돈한 뒤 쉴 수도 있다.

방문 시각만으로 취침을 추정하지 않고, 실제로 집으로 불러 준 경험을 배운다. 다시 놀아 주면 바로 다른 활동을 받아들인다.

## 하던 일과 쌓인 믿음

### 5. 못 끝낸 작은 공연 ★ 추천

응원 재롱 도중 창을 닫았다. 다음에 안전하게 만났을 때 **아까 하던 자리를 흘끗 봄 → 살짝 엉킨 모습에서 빼꼼 → 정돈 → 뿌듯한 표정.** 깔끔이는 곧장 마무리하고, 사고뭉치는 한 번 더 버벅이다 성공한다. 애교쟁이는 끝내기 전에 사용자를 확인한다.

응원 포즈와 짧은 연속극은 이미 있다. 새 제안은 ‘못 끝낸 공연 하나’를 기억했다가 짧게 결말을 보여 주는 연결이다.

### 6. 아까 숨바꼭질, 여기까지

숨바꼭질 중 화면을 닫아 실제로 찾지는 못했다. 다시 만났을 때 **현재 보이는 일정 쪽을 흘끗 봄 → 빼꼼 나오는 동작 → 꾸벅.** 강아지 모드는 금방 모습을 보이고, 고양이 모드는 한 번 딴청을 피운다. 사고뭉치는 잠시 뒤 다른 적합한 카드에서 새 놀이를 청할 수 있다.

못 찾은 옛 일정의 내용을 기억하거나, 사용자가 찾았다고 도장을 주지는 않는다. 끝나지 못한 놀이를 가볍게 정리한다.

### 7. 이제 저 발판은 괜찮아

조금 전 이동을 망설이던 곳에 사용자가 안전하게 내려 주었고, 실제로 착지했다. **착지 확인 → 지나온 쪽을 돌아봄 → 몸을 턺 → 짧게 자신 있게 걸음.** 깔끔이는 발밑을 한 번 더 보고, 호기심쟁이는 먼저 나서며, 애교쟁이는 사용자에게 꾸벅한다.

현재도 최근 실패를 조심하는 기능은 있다. 새 제안은 실제 성공 뒤 ‘도움받아 괜찮아진 순간’을 눈에 보이게 잇는 것이다.

### 8. 다시 먼저 다가오는 날 ★ 추천

거친 조작 뒤 조심하던 빅타민에게 여러 번 천천히 쓰담해 주었다. **처음에는 한 걸음 떨어져 머묾 → 쓰담을 받아들임 → 다음 자발적 만남에서는 조금 가까이 옴 → 나중에는 먼저 부비기를 청함.** 강아지 모드는 먼저 다가오는 쪽, 고양이 모드는 접촉을 받아들이는 쪽부터 바뀐다.

안심과 자신감의 작은 학습은 이미 있다. 새 장면은 회복의 변화를 한눈에 알 수 있게 보여 준다. 일부러 놀라게 한 뒤 달래는 반복에 별도 보상을 주지는 않는다.

### 9. 너랑 고른 내 자리

사용자가 넓고 안전한 곳에 조심히 내려 주고, 그곳에서 여러 번 쉬거나 쓰담했다. 나중에는 **현재도 갈 수 있는 비슷한 자리를 선택 → 주변 확인 → 편하게 자리 잡음.** 고양이 모드는 안전한 높은 곳, 잠꾸러기는 쿠션, 애교쟁이는 사용자 가까운 쪽을 더 고른다.

특정 방송 제목이나 옛 화면 좌표 대신 ‘집·넓은 바닥·넓은 카드 같은 자리 종류’를 선호하게 한다.

### 10. 우리끼리 인사법 ★ 추천

여러 번 ‘꾸벅하면 쓰담’, 또는 ‘폴짝하면 함께 놀기’를 했다. 다음에는 **익숙한 첫 동작 → 잠깐 기다림 → 실제 응답을 받으면 기쁜 마무리.** 애교쟁이는 꾸벅 뒤 쓰담, 사고뭉치는 폴짝 뒤 놀이, 잠꾸러기는 기지개 뒤 쓰담을 먼저 청한다.

사용자가 다른 일을 하면 그냥 두리번거리며 넘어간다. 반복해 요구하지 않는, 둘 사이에서 배운 짧은 순서다.

## 음식에도 이어지는 사연

### 11. 두 간식 사이의 고민 ★ 추천

실제 바닥에 좋아하는 사과와 처음 보는 크루아상이 함께 놓였다. **양쪽을 번갈아 봄 → 새 음식 냄새를 맡음 → 하나를 골라 다가감 → 실제로 먹은 뒤 반응.** 호기심쟁이는 배가 아주 고프지 않으면 새 맛을, 잠꾸러기와 깔끔이는 익숙하고 가까운 것을 고를 수 있다.

현재의 취향·음식 계열 익숙함·허기는 선택의 재료다. 새 제안은 그 고민이 보이는 장면이며, 새 음식은 실제로 먹어야 발견으로 남는다.

### 12. 나, 빵 쪽은 좀 알아

식빵·크루아상·프레첼을 실제로 먹어 봤는데 다른 빵이 나왔다. **짧게 냄새 맡음 → 알아본 듯 꾸벅 → 먹음.** 처음 보는 카레 앞에서는 여전히 조금 더 살핀다. 강아지 모드는 반가움을 크게, 고양이 모드는 짧은 확인으로 표현한다.

먹은 음식의 계열에 익숙해지는 기능은 이미 있다. 여기서 새로 제안하는 것은 가끔 보이는 ‘알아본 순간’과 그 경험을 수첩에서 알아보기 쉽게 연결하는 짧은 표현이다.

### 13. 이건 놀고 나서 먹을래

배부른데 좋아하는 음식이 남았고 지금은 놀이가 당긴다. **음식을 확인 → 같은 안전한 면의 한쪽으로 한 번 옮김 → 놀이로 돌아감 → 나중에 실제로 배고프면 아직 남아 있는 음식을 찾아감.** 깔끔이는 가지런히, 사고뭉치는 살짝 밀었다가 결과를 확인한다. 잠꾸러기는 남겨 둔 뒤 그냥 쉴 수도 있다.

음식 운반과 정리는 이미 있다. 새 제안은 ‘나중에 먹고 싶던 것’을 잠깐 기억하는 연결이다. 사용자는 언제든 치울 수 있다.

### 14. 어, 이게 더 좋아졌어

실제로 먹으며 쌓인 취향이 바뀌어 새 최애가 생겼다. **먹었던 자리 확인 → 사용자에게 돌아봄 → 기쁜 표정 → 작은 인사.** 호기심쟁이는 폴짝하고, 잠꾸러기는 만족스럽게 기지개를 켠다. 고양이 모드는 몸단장하다 슬쩍 부빈다.

최애가 바뀌는 학습과 최근 경험 표시는 이미 있다. 새 제안은 바로 그 변화가 일어난 순간의 짧은 축하와 다음 재회의 연결이다.

### 15. 사과가 싫어진 건 아니야

실제로 사과 앞에서 넘어졌던 뒤, 같은 종류의 음식을 안전하게 먹고 쓰담도 받았다. **조금 천천히 접근 → 실제로 먹음 → 발밑 확인 → 긴장을 풂.** 깔끔이는 착지를 더 확인하고, 사고뭉치는 이번에는 달리지 않는다. 애교쟁이는 끝에 부비기를 청한다.

현재도 사고가 영구적인 음식 혐오가 되지는 않는다. 새 제안은 ‘놀람→다시 시도→괜찮아짐’을 실제 경험끼리 잇는 작은 결말이다.

## 정리와 장난의 앞뒤

### 16. 음악 듣기 전에 자리부터

라디오를 켰고, 배부른 깔끔이 앞에 식사 대상이 아닌 음식이 흩어져 있다. **재생 중인 라디오를 봄 → 음식 하나를 안전한 쪽에 정돈 → 듣던 자리로 돌아옴 → 짧게 흔들흔들.** 사고뭉치는 오는 길에 하나를 툭 건드리고, 애교쟁이는 정리보다 곁으로 오는 것을 고른다.

정리와 음악 반응은 각각 이미 있다. 새 제안은 둘을 하나의 ‘편하게 듣기 위한 준비’로 잇는 것이다.

### 17. 장난치다 들킨 순간 ★ 추천

사고뭉치가 실제 음식통에서 하나를 꺼내 장난치던 중 사용자가 곁에 머문다. **멈칫 → 옆눈으로 확인 → 음식을 정돈하는 쪽으로 한 번 옮김 → 아무 일 없던 듯 꾸벅.** 호기심쟁이는 꺼낸 것을 살피고, 깔끔이는 처음부터 정리를 계속한다.

현재의 음식통·음식 장난·운반·흘끗보기로 가능한 새 연결이다. 들켰다는 이유로 혼내거나 가짜 활동 기록을 만들지는 않는다.

### 18. 같이 끝낸 청소 ★ 추천

빅타민이 남은 음식 하나를 휴지통으로 옮기던 중 사용자가 다른 음식을 직접 치웠다. **자기 몫을 실제로 처리 → 깨끗해진 곳 확인 → 사용자에게 돌아봄 → 뿌듯한 인사.** 깔끔이는 방을 살피고, 사고뭉치는 한 번 장난칠까 하다 이번에는 정리를 마친다. 잠꾸러기는 곧 편하게 눕는다.

자율 정리 자체는 이미 있다. 새 제안은 양쪽이 실제로 행동했을 때만 생기는 ‘같이 끝냈다’는 짧은 경험이다.

### 19. 밥부터 먹고 마저 할게

정리하러 가던 중 사용자가 새 음식을 실제로 내려 주었고 빅타민도 배가 고프다. **안전한 곳에서 정리 중단 → 새 식사 확인 → 같은 음식을 끝까지 먹음 → 아직 필요하면 남겨 둔 정리 하나만 마침.** 잠꾸러기는 식후 정리를 잊고 쉬고, 깔끔이는 끝내려 한다.

현재 식사 우선권은 유지한다. 새 제안은 중단한 집안일을 한 번 기억해 마무리하는 것이며, 먹으려는 음식을 먼저 버리는 장면은 만들지 않는다.

### 20. 생각보다 멀리 굴렀네

호기심쟁이나 사고뭉치가 실제 음식을 한 번 툭 건드렸는데 예상보다 멀리 굴렀다. **굴러간 쪽을 봄 → 실제 멈춘 곳으로 접근 → 냄새를 맡음 → 더 건드리지 않고 물러남.** 고양이 모드는 먼저 지켜보고, 강아지 모드는 바로 따라간다. 깔끔이는 마지막에 한 번 정돈한다.

새 공 장난감 없이 현재 음식의 실제 움직임을 작은 탐색의 원인으로 쓴다. 끝없이 다시 굴리는 반복은 아니다.

## 음악과 옷에 붙는 취향

### 21. 우리 집 음악 취향 ★ 추천

사용자가 잔잔한 곡을 여러 번 직접 틀고 함께 머물렀다. 다음에도 그 분위기의 곡이 실제로 시작되면 **첫 박에 돌아봄 → 익숙하게 몸을 흔듦 → 듣기 편한 곳에서 안정됨.** 잠꾸러기는 차분한 곡, 장난기가 자란 빅타민은 신나는 곡, 고양이 모드는 작은 움직임을 더 선호할 수 있다.

현재도 성격에 따라 음악 반응은 다르다. 새 제안은 세 분위기에 대한 취향이 실제 공유 경험으로 조금씩 달라지는 것이다. 자동 재생은 하지 않는다.

### 22. 세 음 치면 네 차례

사용자가 달력 악보에서 실제로 짧은 구절을 연주했다. **구절 끝에 빅타민이 꾸벅 → 사용자가 다음 구절을 침 → 실제 리듬에 맞춰 격려하거나 장난스러운 표정.** 애교쟁이와 강아지 모드는 삐끗해도 응원하고, 사고뭉치는 잠깐 놀리다 기뻐한다. 잠꾸러기는 조용히 한 번 듣는다.

실제 악보의 리듬 반응은 이미 있다. 새 제안은 그것을 ‘나 한 번, 너 한 번’처럼 느껴지는 두 구절의 교환으로 잇는 것이다.

### 23. 아까 그 멜로디

연주 중간에 창을 닫았다가 나중에 직접 연주를 다시 열었다. **빅타민이 연주 쪽을 봄 → 알아본 듯 작은 인사 → 사용자가 다시 치면 짧게 응원.** 호기심쟁이는 연주 쪽을 더 오래 살피고, 애교쟁이는 바로 응원한다. 잠꾸러기는 곁에서 듣는다.

기억할 것은 중간에 멈춘 허용된 악보 구간 하나다. 빅타민이 대신 버튼을 누르거나 소리를 자동으로 이어 틀지는 않는다.

### 24. 한 곡만 더?

활기찬 짧은 연주를 끝냈고 빅타민도 아직 놀고 싶다. **한 번 폴짝 또는 꾸벅 → 연주 쪽을 잠깐 봄 → 응답이 없으면 기지개를 켜고 돌아감.** 사고뭉치는 크게 폴짝, 깔끔이는 차분한 인사, 고양이 모드는 눈길만 준다. 잠꾸러기는 요청하지 않을 수도 있다.

다시 연주하면 현재 음악 반응으로 이어진다. 지나쳐도 서운함이나 놓친 보상을 만들지 않는 짧은 앙코르 제안이다.

### 25. 오늘은 탐정 빅타민

사용자가 이미 가진 탐정 모자를 직접 씌웠고, 처음 보는 음식이 실제로 근처에 있다. **현재 모자 묘기 → 음식 쪽을 살핌 → 냄새 맡기 → 배고프면 실제로 먹기.** 잠꾸러기 탐정은 중간에 하품하고, 깔끔이 탐정은 발밑까지 확인한다. 사고뭉치 탐정은 안전한 곳에서 폴짝하며 다가간다.

돋보기나 새 소품 없이 모자와 현재 포즈로 역할놀이를 한다. 여러 장신구를 동시에 쓰거나 모자에서 음식을 만들어 내는 장면은 아니다.

### 26. 그 옷 입을 때 재밌었어

특정 소품을 착용하고 실제로 편안한 휴식이나 즐거운 놀이를 여러 번 했다. 다음에 옷장을 열면 **그 소품을 보여 주는 초상 → 기존의 작은 의상 묘기 → 짧은 취향 표현.** 애교쟁이는 부비던 때의 소품, 호기심쟁이는 새 음식을 만났던 소품, 잠꾸러기는 잘 쉬었던 소품에 익숙해진다.

실제 소유한 물건 중에서만 선호를 보여 준다. 사용자가 고른 옷을 빅타민이 마음대로 바꾸지는 않는다.

### 27. 요술 주머니는 텅 비었는데

이미 얻어 착용한 요술 주머니가 있고, 방금 새 음식을 실제로 다 먹었다. **주머니를 열어 봄 → 빈 입구 확인 → 먹었던 자리로 눈길 → 만족스럽게 꾸벅.** 호기심쟁이는 한 번 더 살피고, 사고뭉치는 두 번 번갈아 본다. 잠꾸러기는 잠깐 보고 닫는다.

주머니가 열리는 묘기는 이미 있다. 새 제안은 ‘아까 먹은 걸 여기서 찾는 듯한’ 짧은 농담이다. 음식이나 선물을 추가로 꺼내 주는 보상은 없다.

### 28. 프로펠러보다 졸음이 세다

이미 얻은 프로펠러 모자를 착용했고, 빅타민은 실제로 쉬는 중이다. **프로펠러가 짧게 돎 → 잠깐 고개를 듦 → 하품 → 다시 편하게 자리 잡음.** 사고뭉치는 작은 재롱으로 이어지고, 호기심쟁이는 위를 살핀다. 애교쟁이는 사용자를 한 번 본다.

기존 회전 묘기와 졸음 포즈를 잇는다. 새 비행 경로나 프로펠러를 손으로 잡는 그림이 필요한 장면은 아니다.

## 수첩과 달력도 함께 겪는 공간

### 29. 너도 봤지? ★ 추천

실제 새 행동이나 순간을 발견한 뒤 사용자가 수첩의 해당 항목을 직접 보고 닫았다. **다시 보이는 빅타민이 관련된 짧은 동작 → 사용자에게 눈길 → 평소 행동으로 복귀.** 쓰담 기억이면 애교쟁이는 부비고, 집에서 쉰 기억이면 잠꾸러기는 기지개를 켠다. 넘어졌던 기억은 사고를 되풀이하지 않고 흘끗보기만 한다.

현재 수첩과 읽음 표시는 그대로 쓴다. 새 제안은 기록을 확인한 다음 빅타민도 그 경험을 알아보는 짧은 회상이다. 재연으로 발견 도장을 다시 주지 않는다.

### 30. 우리 처음 그랬잖아

급한 일이 없는 다음 방문에, 실제로 얻었던 첫 경험 하나가 있다. **그 경험의 해롭지 않은 한 동작 → 짧은 기쁜 표정 → 일상으로 복귀.** 애교쟁이는 첫 쓰담 뒤 인사를, 잠꾸러기는 편히 쉬었던 때의 기지개를 떠올린다. 호기심쟁이는 해당 음식이 실제로 있을 때만 눈길을 줄 수 있다.

새 일기나 과거 일정 재현 없이 현재 수첩에 남은 경험을 가끔 돌아본다. 없어진 음식과 물건을 기억 속 장면이라며 다시 만들지는 않는다.

### 31. 겨울 달력을 보니 포근한 쪽으로

사용자가 겨울 달로 넘겨 실제 계절 배경이 바뀌었다. **창문이나 배경 쪽을 바라봄 → 기지개 → 쿠션으로 가서 자리 만들기.** 잠꾸러기는 웅크리고, 호기심쟁이는 조금 더 구경한다. 사고뭉치는 신난 듯 한 번 폴짝하고, 깔끔이는 차분하게 앉는다.

현재 창문과 계절 배경을 행동의 계기로 연결하는 새 제안이다. 계절은 보는 달력을 따른다. 새 눈송이 소품, 실시간 날씨나 창턱 발판이 이미 있다고 주장하지 않는다.

### 32. 새 달, 새 발판

실제로 달을 넘겨 달력 전환과 발판 배치가 안정됐다. **현재 자리에서 새로 보이는 곳 확인 → 갈 수 있는 곳으로 짧게 이동 → 착지 뒤 인사.** 호기심쟁이는 탐색하고, 고양이 모드는 허용된 높은 곳을 살핀다. 애교쟁이는 사용자 곁을, 잠꾸러기는 쿠션을 유지할 수 있다.

현재 위치 연속성과 이동 안전은 이미 있다. 새 제안은 달이 바뀐 것을 주민의 작은 탐색으로 표현하는 것이다. 스스로 달력을 넘기지는 않는다.

### 33. 일정이 없는 날도 같이

현재 공개 달력에 일반 일정 카드가 없다. **실제 바닥에서 기지개 → 넓어진 곳을 살핌 → 쓰담을 한 번 청하거나 집으로 돌아감.** 애교쟁이는 함께 있기를, 잠꾸러기는 쉬기를 고른다. 호기심쟁이는 빈 공간을 구경하고 사고뭉치는 안전한 짧은 달리기를 할 수 있다.

일정이 비었다는 현재 화면만 장면의 원인으로 쓴다. 방송 취소를 추측하거나 가짜 일정으로 빈칸을 채우지 않는다.

### 34. 우리 그 공개 기다렸어

실제 최초공개가 끝나 빅타민이 달력의 안전한 자리로 돌아왔다. **착지 → 방금 공개된 카드 쪽을 돌아봄 → 기쁜 표정이나 인사 → 하던 관심사로 복귀.** 호기심쟁이는 카드를 먼저, 애교쟁이는 사용자를 먼저 본다. 잠꾸러기는 기지개, 사고뭉치는 한 번 재롱을 고른다.

최초공개 입장·합류·복귀는 이미 있다. 새 제안은 실제 복귀 뒤의 짧은 여운이다. 숨겨진 내용을 미리 아는 반응은 아니다.

### 35. 자리는 바뀌어도 괜찮아

사용자가 패널을 옮기거나 창을 닫아 빅타민의 주변 배치가 달라졌다. 기존 복귀가 안전하게 끝난 다음 **새 자리 확인 → 사용자에게 눈길 → 기지개나 다시 자리 잡기.** 깔끔이는 한 번 더 살피고, 호기심쟁이는 한 걸음 탐색한다. 애교쟁이는 곁에, 잠꾸러기는 편한 자세로 남는다.

현재 기하 복구를 새 기능으로 내세우지 않는다. 새 제안은 복구 직후 ‘이제 괜찮다’고 보이는 두세 동작이다.

### 36. 우연히 열린 작은 축하

실제로 얻은 고깔 모자를 쓰고, 신나는 라디오가 재생 중이며, 방금 첫 음식 발견까지 마쳤다. **모자 묘기 → 꾸벅 → 현재의 기쁜 음악 반응.** 사고뭉치는 조금 크게 흔들리고, 깔끔이는 단정하게 인사한다. 잠꾸러기는 작은 고갯짓만 할 수도 있다.

음식·옷·음악이 우연히 맞아 생기는 새 조합이다. 특정 새벽이나 기념일에만 볼 수 있는 숙제, 추가 아이템 보상으로 만들지 않는다.

## 장면을 고를 때의 공통 기준

이 목록 전체를 한꺼번에 돌리자는 제안은 아니다. 우선 추천에서 관계가 이어지는 장면 몇 가지를 고르고, 현재 주민의 행동 사이에 드물게 넣는 편이 어울린다. 한 번에 한 장면만, 사용자가 먹이 주기·이동·집으로 부르기 등을 하면 즉시 그 행동이 우선한다. 못 봤거나 응답하지 않아도 손해가 없다.

시간 제안은 다음 실제 접속 때 기기 안의 UTC 간격과 KST 시간대를 확인하는 방식으로 가능하다. 앱을 닫은 동안 돌보기를 진행하지 않는다. 방문 시간은 거친 집계만, 미완성 일은 하나만 기억하는 정도로 제한할 수 있다. 새 서버·AI 호출·상시 백그라운드 시계는 제안하지 않는다. 현재는 이 시간·연결 기억도 구현되지 않았다.
