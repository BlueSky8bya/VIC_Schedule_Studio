# 빅타민 장신구 비율·시점·화풍 · 2026-11-13 KST

- 첨부 장신구는 빵 모자. 같은 정면 포즈 기준 폭이 몸통의 약 48%라 얼굴에 비해 좁았다. 빵 모자는 약 57%로 키웠고 베레모·야구·탐정·벙거지 모자도 14–16% 넓혔다. 귀 뿌리 부착과 몸체 원본은 유지한다.
- 둥글·금테·뿔테·하트·사각 안경은 정면의 눈 간격과 기존 기울기를 유지한다. 비스듬한 시점에서는 가까운 쪽 다리가 보이고 반대 끝은 몸체 뒤에 위치한다. 뒷면에 렌즈를 그리지 않는다. 기존 선글라스는 전용 가림 기준을 유지하고 픽셀 선글라스는 의도된 도트 무늬를 보존한다.
- 벡터 장신구는 몸체에 맞춘 갈색 선과 따뜻한 명암으로 새 판본을 만든다. 이전 원본 atlas, 몸체 픽셀, 토리 눈 프린트, 소유 데이터, 희귀도는 그대로다.
- 정지 스프라이트 520개 × 장신구 27종의 부착을 점검하고, 대표 포즈 10개를 양쪽으로 렌더링했다. 현재 몸체 원화에는 완전 측면 포즈가 없어 실제 시각 확인은 정면·비스듬·뒷면에 한한다. 로컬 비교: `runs/20261113-victamin-accessory-fit/report.html`.
- 공용 착용 렌더러의 그림 변경이다. 공개 DTO, 역할, KST, 키보드 제어, 타임라인·적게 쓰인 기능 분류에 변경 없음.

- 검증: Chromium 공유 착용 렌더러 14,040개 부착값과 특수 동작 8,320개 표본, 장신구 단위 테스트 31개 및 옷장 UI 확인. 기준 커밋의 오프라인 테스트는 v7 고정값이 v8 소스와 어긋나 6개가 실패했다. 테스트가 실제 캐시 이름을 읽도록 고쳤다.

- 후속 착용 조정: 야구모자 상단, 로고, 기존 귀 뿌리 부착을 유지하고 하단만 정면·비스듬·측면·뒷면별로 완만하게 넓혔다. 베레모는 직전 비교안보다 약 12% 키웠다. 이전 원본과 다른 장신구 유지. 전후 기준은 사용자가 본 직전 로컬 옷장 화면이다. 배포판 기준은 별도로 이전 보고서에 남아 있다.

- 배포 전 추가 각도 점검: 채택된 프레임의 눈 위치를 모자 기울기에 맞춰 투영하고, 챙이 닿는 컷에서만 눈 위로 올린다. 브라우저에서 구르기 16프레임의 좌우 방향과 낮은 이마, 투척, 낮잠을 대조했다.

- 사용자 지적 후 접힌 귀가 모자 앞에 오도록 가림을 교정했다. 낮은 이마의 두 귀를 원화 좌표로 따고, 모자와 겹치는 영역에서만 원래 귀가 드러나게 했다. 좌우 반전과 모자 재롱에도 원래 귀의 위치를 사용한다.
