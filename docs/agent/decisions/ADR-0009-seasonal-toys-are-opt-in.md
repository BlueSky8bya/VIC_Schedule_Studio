# ADR-0009: 시즌 장난감(미니게임·테마)은 포스터를 덮지 않는다 — opt-in

Status: Superseded
Superseded-by: 월드컵/축구 시뮬 전부 삭제(2026-08-27, 사용자 결정 — CHG-20260827-002). 코드는 git 이력.
Date: 2026-07-12
Related: `components/seasonal/worldcup-ball-goal.tsx`(기본값), `worldcup-ball-goal.css`(.wc-dim),
`components/poster/public-poster.tsx`(effectivePosterTheme, 중력공 언마운트)

## Context

월드컵 미니게임이 **데스크톱에서 자동 시작**이었고, 딤 레이어가 `pointer-events: auto` + blur라
첫 방문자는 "축구 시뮬 뒤에 흐릿하게 깔린 일정표"를 봤고 하트·필터·월 이동이 눌리지 않았다.
월드컵 달이면 포스터 테마도 오너가 고른 테마를 **덮어썼다**(내보낸 PNG까지 잔디밭).

## Decision

시즌 연출은 **포스터 위의 곁들임이지 뚜껑이 아니다.**

1. 미니게임 기본값 = **꺼짐**(모든 플랫폼). '⚽ 미니게임 켜기' 칩으로만 연다. 예전에 직접 켠
   사람(localStorage `vic.worldcupGame=on`)은 웹에서 자동 복원.
2. 켠 동안은 집중 모드가 맞다 — 딤(잔디 톤 + blur)과 클릭 차단은 **사용자가 켰을 때만** 적용.
3. 시즌 테마는 **오너가 테마를 고르지 않았을 때만**(`posterTheme === "none"`) 자동 적용. 오너 선택이 우선.
4. 두 장난감(미니게임 · 캐주얼 중력공)이 동시에 뜨지 않는다 — 미니게임이 켜지면 중력공은 언마운트.
5. 장난감 토글은 콘텐츠 위를 돌아다니는 요소(공)나 다른 크롬(아바타 컨트롤, 아젠다 헤더)과
   자리를 다투지 않는 크롬 층에 둔다.

## Consequences

- 새 시즌 연출(테마·게임·마스코트)을 추가할 때마다 이 규칙을 통과해야 한다: 기본 꺼짐, 클릭 통과,
  오너 선택 우선, 다른 토이와 동시 노출 금지.
- 자동 연출로 얻는 "우와" 효과는 포기한다. 대신 첫 화면은 언제나 일정표다.

## Revisit Conditions

토리님이 특정 기간만 자동 노출을 원하면(예: 한국 경기 당일), '그 날만 자동'처럼 좁은 조건으로
다시 열 수 있다 — 단 클릭 통과와 오너 테마 우선은 유지한다.
