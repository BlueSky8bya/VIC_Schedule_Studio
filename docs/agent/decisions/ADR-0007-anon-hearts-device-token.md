# ADR-0007: 하트(관심 표시)는 비로그인도 허용한다 — 기기 토큰

Status: Accepted
Date: 2026-06-08 (소급 기록 2026-07-12)
Related: `db/migrations/0040_*`, `lib/schedules/heart-actions.ts`

## Context

시청자 참여(하트)에 Google 로그인을 요구했더니 **로그인 장벽이 참여의 병목**이었다. 하트는 저위험 상호작용이고
공개 데이터에만 붙는다.

## Decision

비로그인 시청자도 하트를 누를 수 있다. 식별은 기기 토큰(로컬 저장 + 서버 기록)으로 하고, 로그인 사용자는 계정에
귀속한다. 집계(`get_event_heart_counts`)는 공개 일정만 세고 `user_id`를 노출하지 않는다.

## Consequences

- 완벽한 중복 방지는 아니다(브라우저/기기 바꾸면 새 토큰). 의도적으로 감수 — 참여율 > 정밀 집계.
- 하트 수는 인기 배지(tier)에 쓰이므로, 배지 계산은 항상 **단조화 + 직렬 큐**로 처리한다(과거 회귀 2건).

## Revisit Conditions

실제 어뷰징(봇/새로고침 조작)이 관측되면 레이트 리밋 또는 로그인 요구로 좁힌다.

## Open Follow-up

인기 배지를 절대 임계값 → **상대 순위**로 전환하기로 합의됨(미구현).
