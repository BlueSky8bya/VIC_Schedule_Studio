# ADR-0016 — 금생수(金生水) 디자인 언어: 일은 금, 품는 것은 수

Status: Accepted
- Date: 2026-09-03
- Supersedes(부분): CLAUDE.md "Owner-fit palette rule"의 첫 조항 "물·은이 틀, **따뜻한 콘텐츠 안쪽**". 콘텐츠 중
  '일(work) 요소'는 이제 금(金)의 형태 언어를 갖는다. 방위 규칙·주 행동 하나(저장, 물빛)·극(克) 금지·차분 모드는
  그대로.
- 관련: `docs/ux/saju-redesign-direction.md`, ADR-0011(UX 전면 개선), `app/metal-water.css`,
  `components/studio/studio-calm-layer.css` ④, `components/poster/poster-metal-water.css`

## 맥락

관리자(사용자)가 2026-09-03 지시: "일정이나 편집 팝오버, 업 도움/기간 안내 띠, 각종 버튼 등 토리님의 **일과 관련된
건 금(金)**의 기운으로 깔끔하게, 그것을 **감싸는 달력·박스는 수(水)**로 은은하게 모든 걸 품는 느낌으로 —
**금생수**를 디자인 철학으로. 시청자 화면·미리보기도 편집실과 같은 뉘앙스로." 근거는 소유자의 오행 결론(수 용신·
금 희신). 원국·생년은 어떤 파일·UI·API에도 싣지 않는다(ADR 본문도 결론만).

## 결정

1. **형태 언어 두 벌**(토큰 `--gs-metal-*`, `--gs-water-*`, `app/metal-water.css`):
   - **금 = 일**: 편집 팝오버·읽기 카드·띠·버튼·타일·칩·일정 카드 테두리·달 이동 링. 헤어라인(#c9d3dd/#aeb9c7),
     윗면 광택 한 줄(inset 0 1px #fff), 작은 라운드(10px), 슬레이트 글자(#263242), 띠 글자는 각인(text-shadow).
   - **수 = 품는 것**: 페이지 바탕·포스터 표면·달력 칸·요일 머리·패널/도구 카드·상단바·힌트 바·역할 팝오버.
     물빛 유리(rgb 241 246 252 / 84%), 큰 라운드(22px), 낮은 대비 헤어라인(rgb 30 90 168 / 12%), 안쪽 빛.
   - **금생수**: 물 컨테이너의 가장자리는 금 헤어라인, 금 요소 안엔 물빛이 담길 수 있다(저장 버튼 = 은선 틀 + 물빛 면).
2. **불변**: 의미색 8종·태그색·하트 링·오늘 골드·미정 주황 · 기하(표면 1840, 칸 높이, 띠 17px·레인, 팝오버 356) ·
   공개/비공개 경계. 띠는 inset 그림자만 써서 높이·레인 계산이 그대로다.
3. **적용 범위와 되돌리기**:
   - 편집실: `html[data-studio-calm]` 아래(④ 블록) — 차분 스위치 하나로 전부 이전 모습.
   - 시청자 화면(= 편집실 미리보기·export): 기본 모습에 적용(파일 하나 삭제로 복귀). `mist` 테마는 더 짙은 물로
     그 위에 얹힌다.
   - 모바일 아젠다·VOD 창·최초공개 연출·인사이트 모달은 이번 범위 밖(다음 라운드에서 같은 토큰으로).
4. **접근성 우선**: WCAG AA(눈 편한 필터 뒤)는 이 언어보다 위. 새 글자색은 슬레이트(#263242)뿐이라 대비가 오른다.
5. **눈 편한 필터와의 관계(2차, 같은 날)**: `sepia(.1)`은 옅은 물빛을 중성 회백으로 눌러 이 언어를 지웠다(실측
   칸 #e8f0f9 → 233,235,235). 필터를 `saturate(.85) brightness(.96) sepia(.03)`으로 바꾼다 — 채도·눈부심 저감은
   유지, 따뜻함만 살짝. 물 토큰은 필터 뒤에도 남는 깊이(b−r ≥ 25)로 정한다. lite 팔레트(약한 기기)는 옛 필터
   기준 색이라 그대로 두고, 재계산은 별도 작업.

## 결과

- 편집실·시청자 화면이 한 재질 체계를 공유해 "미리보기 = 실제"가 색까지 맞는다.
- 비주얼 기준선(시청자 포스터·편집실) 전부 갱신. 기하 스펙(geometry.spec)은 픽셀이 아니라 치수라 그대로.

## 다시 볼 때

- 소유자가 따뜻한 크림 톤을 다시 원할 때(편집실은 차분 OFF, 시청자는 poster-metal-water.css 제거).
- 인사이트 모달·VOD 창·모바일 아젠다까지 같은 언어로 넓힐 때(토큰만 쓰고 새 색을 만들지 않는다).
