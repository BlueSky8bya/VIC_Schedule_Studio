# ADR-0016 — 금생수(金生水) 디자인 언어: 일은 금, 품는 것은 수

Status: Accepted
- Date: 2026-09-03
- Supersedes(부분): CLAUDE.md "Owner-fit palette rule"의 첫 조항 "물·은이 틀, **따뜻한 콘텐츠 안쪽**". 콘텐츠 중
  '일(work) 요소'는 이제 금(金)의 형태 언어를 갖는다. 방위 규칙·주 행동 하나(저장, 물빛)·극(克) 금지·차분 모드는
  그대로.
- 관련: `docs/ux/saju-redesign-direction.md`, ADR-0011(UX 전면 개선), `app/metal-water.css`,
  `components/studio/studio-calm-layer.css` ④, `components/poster/poster-metal-water.css`

## 맥락

관리자(사용자)가 2026-09-03 지시: "일정이나 편집 팝오버, 업 도움/기간 안내 띠, 각종 버튼 등 토리님의 **일과 관련된
건 금(金)**의 기운으로 깔끔하게, 그것을 **감싸는 달력·박스는 수(水)**로 은은하게 모든 걸 품는 느낌으로 —
**금생수**를 디자인 철학으로. 시청자 화면·미리보기도 편집실과 같은 뉘앙스로." 근거는 소유자의 오행 결론(수 용신·
금 희신). 원국·생년은 어떤 파일·UI·API에도 싣지 않는다(ADR 본문도 결론만).

## 결정

1. **형태 언어 두 벌**(토큰 `--gs-metal-*`, `--gs-water-*`, `app/metal-water.css`):
   - **금 = 일**: 편집 팝오버·읽기 카드·띠·버튼·타일·칩·일정 카드 테두리·달 이동 링. 헤어라인(#c9d3dd/#aeb9c7),
     윗면 광택 한 줄(inset 0 1px #fff), 작은 라운드(10px), 슬레이트 글자(#263242), 띠 글자는 각인(text-shadow).
   - **수 = 품는 것**: 페이지 바탕·포스터 표면·달력 칸·요일 머리·패널/도구 카드·상단바·힌트 바·역할 팝오버.
     물빛 유리(rgb 241 246 252 / 84%), 큰 라운드(22px), 낮은 대비 헤어라인(rgb 30 90 168 / 12%), 안쪽 빛.
   - **금생수**: 물 컨테이너의 가장자리는 금 헤어라인, 금 요소 안엔 물빛이 담길 수 있다(저장 버튼 = 은선 틀 + 물빛 면).
2. **불변**: 의미색 8종·태그색·하트 링·오늘 골드·미정 주황 · 기하(표면 1840, 칸 높이, 띠 17px·레인, 팝오버 356) ·
   공개/비공개 경계. 띠는 inset 그림자만 써서 높이·레인 계산이 그대로다.
3. **적용 범위와 되돌리기**:
   - 편집실: `html[data-studio-calm]` 아래(④ 블록) — 차분 스위치 하나로 전부 이전 모습.
   - 시청자 화면(= 편집실 미리보기·export): 기본 모습에 적용(파일 하나 삭제로 복귀). `mist` 테마는 더 짙은 물로
     그 위에 얹힌다.
   - 모바일 아젠다·VOD 창·최초공개 연출·인사이트 모달은 이번 범위 밖(다음 라운드에서 같은 토큰으로).
4. **접근성 우선**: WCAG AA(눈 편한 필터 뒤)는 이 언어보다 위. 새 글자색은 슬레이트(#263242)뿐이라 대비가 오른다.
5. **눈 편한 필터와의 관계(2차, 같은 날)**: `sepia(.1)`은 옅은 물빛을 중성 회백으로 눌러 이 언어를 지웠다(실측
   칸 #e8f0f9 → 233,235,235). 필터를 `saturate(.85) brightness(.96) sepia(.03)`으로 바꾼다 — 채도·눈부심 저감은
   유지, 따뜻함만 살짝. 물 토큰은 필터 뒤에도 남는 깊이(b−r ≥ 25)로 정한다. lite 팔레트(약한 기기)는 옛 필터
   기준 색이라 그대로 두고, 재계산은 별도 작업.

## 4차 개정 (2026-09-03, 같은 날 — 근본 재설계)

사용자: "광택 효과가 너무 강하다, 색상이 단조롭다(3차 개정 후에는 오히려 파편화됐다는 뜻으로 재확인),
편집실이나 시청자 화면·미리보기나 배경색이 아직 아이보리인데 이것도 좀 바꾸거나 해봐 — 붕 뜬 느낌이다."
후속 메시지: "1번 사진 보면 카드들이랑 배경이 안 어울린다. 토리님이 원래 좋아하시던 아이보리가 맞는
색인데, 물결 느낌은 버리고 싶지 않다 — 모래사장 위로 얕은 물결이 일렁이는 느낌을 배경에 투영하고
싶다. 2번 사진 보면 스크롤 자리 배경색이 안 맞는다."

**근본 원인**: 3차까지 "물"을 컨테이너의 **베이스 색**(파랑·남빛·옥빛·연보라 네 갈래)으로 구현했다 —
아이보리를 완전히 밀어냈고, 넷이 서로 다른 색이라 파편화됐다. 또 물결 레이어(.studio-tide) 자신이
**불투명한** 트리플 라디얼 배경을 그리고 있어(전 개정 실수) 사실상 "물결 위에 물결"이었고, 이걸 보이게
하려고 셸/포스터 페이지를 조건부로 transparent 처리했는데, 조건이 안 맞는 상태(동작 줄이기·약한 기기)
에서는 셸이 **불투명한 냉색 폴백**으로 떨어져 — 그 폴백이 안 닿는 스크롤/거터 영역만 아이보리(body)로
남아 이음새가 생겼다.

**결정**: '물'과 '색 베이스'를 분리한다.
- 컨테이너 베이스 색은 ADR-0016 이전(즉 아이보리/크림) 그대로 — 여기서 다시는 덮지 않는다.
- '물'은 오직 물결 레이어 하나 — **자기 배경이 없는 완전 투명 컨테이너**, `components/shared/
  water-tide.tsx`(편집실·시청자 공용). 셸/포스터 페이지는 물결이 보이는 조건에서만 transparent(그
  아래 body 아이보리가 비침), 조건 밖에서는 셸/페이지 **자신의 원래 정적 배경**(아이보리 계열, 냉색
  폴백 없음)이 남는다 — 어떤 상태에서도 파란 폴백이 존재하지 않으므로 스크롤/거터 불일치가 구조적으로
  불가능해진다.
- 물결 색은 스웰 a·b(옅은 물빛) + c(따뜻한 금빛 윤슬=햇살)의 대비로 — "다채로움"을 네 컨테이너색이
  아니라 물 자체 안의 물+빛 두 결로 표현.
- 금(일 요소) 광택은 두 톤 꺾임·강한 흰 하이라이트를 없애고 단순 위→아래 그라데이션 + 얇은 헤어라인만.

### 4차-b — "위에서 내려다본 얕은 물"(같은 날)

4차 직후 물결이 사실상 안 보였다. 원인 ⓐ `html { background }` 추가가 body 배경의 캔버스 전파를 끊어 body가
자기 배경을 블록 배경(페인트 3단계)으로 직접 그리게 됐고, 음수 z-index 레이어(`.gs-tide`, 2단계)를 통째로
덮었다 — **html에 배경을 주지 않는다**(body 전파 캔버스가 오버스크롤까지 덮는다). ⓑ 값이 너무 옅었다.
재설계: 바닥 띠가 아니라 화면 전체의 얕은 물(필름 + 잔물결 그림자 띠 셋 + 윤슬 선 셋 + 스웰 + 빛살), 그리고
물결이 보이는 상태에선 달력 칸·패널·포스터 표면을 **반투명**(색은 원래 크림, 알파만)으로 해 물결이 모래 위로
비친다. 오늘 칸·일정 카드·팝오버·띠는 불투명(물 위의 물건). PNG 내보내기는 철수(ADR-0015), 비주얼 테스트는
동작 줄이기 ON(물결 숨김 → 불투명)이라 결정성은 그대로.

### 4차-c — 애플 결의 물, 편집실 팔레트를 시청자 화면에 맞춤(같은 날)

"무늬가 밋밋하고 구리다 — 애플식으로 세련되게" / "색 조화는 시청자 화면 쪽이 더 좋다". 규칙적인 사인파 줄은
클립아트로 읽힌다 → 기하 무늬를 전부 버리고, 크고 흐릿한 물그림자·빛 얼룩(blur 60~70px)과 유기적 caustic
(SVG 노이즈 필터의 중간 밝기 등고선 → 빛 그물, 두 겹 간섭)만 아주 느리게 떠다니게 한다. 필터·blur는 내용이
불변인 레이어에 한 번만 래스터되고 이후 transform만 — 무한 애니 규칙 유지. 편집실의 은백·파스텔 혼합
팔레트를 시청자 화면의 크림 팔레트로 통일하고, 금 토큰도 따뜻한 은(샴페인 실버)으로.

## 결과

- 편집실·시청자 화면이 한 재질 체계를 공유해 "미리보기 = 실제"가 색까지 맞는다.
- 비주얼 기준선(시청자 포스터·편집실) 전부 갱신. 기하 스펙(geometry.spec)은 픽셀이 아니라 치수라 그대로.

## 다시 볼 때

- 소유자가 따뜻한 크림 톤을 다시 원할 때(편집실은 차분 OFF, 시청자는 poster-metal-water.css 제거).
- 인사이트 모달·VOD 창·모바일 아젠다까지 같은 언어로 넓힐 때(토큰만 쓰고 새 색을 만들지 않는다).
