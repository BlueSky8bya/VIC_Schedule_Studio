# ADR-0031 — 시청자 로컬 빅타민 동행

Status: Accepted for implementation by owner request, 2026-10-15 KST. 미술 시각 승인과 기능 구현 승인은 구별한다.

감상 동행 경계 개정([2026-10-23 계획](../plans/PLAN-20261023-showcase-transients-toy-storage.md), 최신 소유자 요청): 이전 초원의 자동 주민 생성은 실제 배경에 완전히 노출된 같은 빅타민·음식·장난감만 빌리는 화면 수명의 소유권으로 대체한다. UI를 숨기기 전에 전체 그림 경계와 실제 박스의 교차를 판정한다. 감상 중 옮긴 좌표는 메모리에만 두며, 복귀 뒤 박스에 가려지면 숨기고 재진입 때 같은 실물을 보인다. 노출된 빅타민은 같은 발 위치에서 기존 생활로 돌려보내며, 가려진 주민 때문에 독립적인 집 조작을 막지 않는다. 새로고침·월/경로 변경·pagehide/BFCache 복귀는 임시 상태를 폐기한다. sessionStorage·서버 기억·새 수집/취향 쓰기·자동 활동 기록은 추가하지 않는다. 실제 직접 조작은 기존 고정 이름만 사용하고 개인 실물 ID·좌표를 전송하지 않는다.
