# ADR-0031 — 시청자 로컬 빅타민 동행

Status: Accepted for implementation by owner request, 2026-10-15 KST. 미술 시각 승인과 기능 구현 승인은 구별한다.

소유자는 달력 발판 탐험·집기·쓰다듬기·수면·하트 장난·배경 숨바꼭질, 수백 픽셀 프레임과 모든 행동의 전용 설정을 요청했다. 전체 기본값은OFF다.

채택: 순수 Utility AI+중단 가능한 실행 상태, visible DOM geometry 발판, opt-in 동적 UI 하나,256셀 새 atlas, 기기 설정v1. 모델/DB/외부 추론 요청0. 설정은 공유 리스트의 `빅타민`→`움직임/장난/교감/성격` 한 구현이다. 욕구·친밀도·짧은 기억·쿨다운으로 행동을 고르며 직접 입력이 우선한다.

이유: 초파리 connectome은 배선 연구 데이터이며 캐릭터 인격 파일이 아니다. LLM은 말하지 않는 시각 동행에 다운로드·메모리·추론 지연을 추가한다. 원논문과 대안은 [PLAN-041](../plans/PLAN-20261015-041-viewer-victamin-companion.md)에 연결했다. 초파리 뇌 탑재/신경학적 인격/학습을 주장하지 않는다.

경계: 두뇌는 일정 제목/본문/실제eventid를 받지 않는다. 실제 하트·기대·설정 버튼 자동클릭 금지. 장난은 로컬 효과, 배경은 최대20초 임시 lease로 저장 선호 불변. 모바일/낮은gfx 제한 유지. 사용자 배치 gesture의click도 소비해 실제 일정/하트 동작으로 보내지 않는다.

2026-10-15 후속 돌봄 요청([PLAN-042](../plans/PLAN-20261015-042-victamin-care.md)): 뇌의 기하 입력에 하트 눌림 여부·먹이/포인터 좌표를 추가한다. 별도 하트 어댑터만 명시 공개eventid를 최대128개 기기 로컬에 기억한다. 인간 빨강과 구분하는 보라 표식은 count/aria-pressed/click/서버 불변, 인간 하트 우선. 이 표식에 한정해 기존 떡밥 보라 토큰을 재사용한다. 이미 있는 하트는 막힘·아쉬운 동작. 공용 설정에 단일 동물모드(기본/고양이/강아지)·밥주기 토글, 메뉴에 사과/레몬 배치·남은 밥 치우기를 연결한다. 배고픔/애정/기력/호기심 네 수치만 v1 local 저장, 시도도5초 제한·먹기/정리 때 강제 저장. 부재시각/계정/제목 저장 없음, 부재 페널티 없음. 최대3개 먹이는 월 변경/기능OFF 때 정리하며 도달 가능한 발판 경로로만 접근한다. 기존256셀의 표정/자세와 작은 nibble/막힘 효과를 재사용, 새 미술 승인이나 신규64셀 제작으로 주장하지 않는다.

기존 seasonal-minigame 철수 규칙에서 이번 명시 요청의 비게임 동행만 새 기능으로 허용한다. 이전 스티커/꾸미기/미니게임 복원 승인이 아니다. export1840·KST·공개 경계·역할 권한 무변경.

설정OFF는 즉시 언마운트·루프/observer/lease 해제, 세부취향 유지. 최초공개/상세/설정/미디어/쇼케이스/숨김에는 방해하지 않는다. 동작 줄이기는 제자리 표정 중심, 메뉴·키보드 대안 제공.

재검토: 자연어 대화·서버 기억/학습·다중 캐릭터·실제 투표 동작 요청 때 범위/비용/권한을 별도 결정.
