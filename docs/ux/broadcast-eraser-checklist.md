# 일정 그림판 — 지우개·채우기·선택 검증 체크리스트

2026-08-05 사용자 지적 3건에서 출발한 전수 점검표.

> ① "내가 지운 부분 말고 주위 것들까지 같이 지워진다"
> ② "채우기로 채운 색이 선택 범위에 안 들어갔는데도 같이 선택된다"
> ③ "지우개 쓰고 깜빡인다든지 사소한 것까지"

각 항목은 **자동 검증**이 있고(단위 = `tests/unit/*`, 브라우저 = `tests/visual/*`),
고친 코드를 되돌리면 해당 검증이 실패하는 것까지 확인했다(뮤테이션 체크).

## 왜 이랬나(뿌리 원인 3개)

1. **획은 포인터가 움직인 만큼만 점을 남긴다.** 빠르게 그으면 점 간격이 20~60px다.
   지우개 판정이 그 점 단위라, 점 하나가 자국에 닿으면 **양옆 구간이 통째로** 사라졌다.
   → 지우개 근처만 1.5px 간격으로 다시 샘플링한 뒤 자른다(`refineNearEraser`).
2. **도형은 닿으면 통째 삭제였다.** 사각형 한 변만 지워도 사각형 전체가 없어졌다.
   → 윤곽을 폴리라인으로 펴서 닿은 만큼만 덜어내고, 남은 조각은 `tool:"poly"`로 남는다.
   렌더는 **곧은 선**이다(곡선 보간을 쓰면 직각 모서리가 30px씩 깎여 나간다 — 실측).
3. **그림(채우기 조각)은 상자로 판정했다.** 채우기 결과의 상자는 '바뀐 픽셀 전체'라 화면
   절반만 하고, 그 안 대부분이 투명하다. → 알파 마스크로 **칠해진 픽셀**을 본다(`image-mask.ts`).

덤: 지우개가 그림을 건드리면 픽셀에 구워 새 PNG로 다시 인코딩하는데, 그 data URL이 디코드될
때까지 재생에서 그림이 빠져 **한 프레임 사라졌다** = 깜빡임. 방금 만든 캔버스를 그대로 들고
있다가 즉시 그린다(`bmpCache`).

## 나중에 다시 밟기 쉬운 함정

- **반투명 획을 쪼개면 이음매가 진해진다.** 조각 둘이 경계점을 공유하면 둥근 캡(반지름 = 굵기/2)이
  완전히 겹쳐 그 자리만 두 번 칠해진다. 불투명 펜은 티가 안 나고 형광펜에서만 보인다.
  → 잘린 끝을 반굵기만큼 물린다(`trimSeamEnds`). 캡이 경계까지만 닿아 겹치지도 벌어지지도 않는다.
- **그림을 분할 선택하면 원본 객체를 고치면 안 된다.** 되돌리기용 before 스냅샷이 얕은 복사라
  같이 바뀐다 — 남는 쪽도 **새 객체**로 만든다.

## 손으로 볼 때(회귀 감각 점검)

- 굵은 형광펜을 그은 뒤 가장자리를 살짝 지워 본다 — 벡터 지우개는 **획 굵기 단위**로 끊긴다
  (가장자리만 얇게 깎이지 않는다). 이건 사양이다(GoodNotes류 벡터 지우개와 같은 문법).
- 도형을 여러 번 부분 삭제하면 조각이 늘어난다(각 조각은 따로 선택·이동된다).
