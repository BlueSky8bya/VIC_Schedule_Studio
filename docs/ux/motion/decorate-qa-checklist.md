# 달력 꾸미기 "화려함" P1–P4 — 수동 QA 체크리스트

자는 동안 구현·자동검증한 것 정리 + 토리님(또는 개발자)이 **직접 눌러보며** 확인할 것.
모든 작업은 `/studio/decorate/[year]/[month]`(PC 꾸미기 화면)에서 확인. 새 필드는 전부
**공개 스티커의 시각 속성**이라 비공개 데이터와 무관(꾸미기 권한 = 소유자·개발자·매니저·작업자).

## ✅ 자동으로 검증한 것 (코드)
- 매 단계 `tsc --noEmit` + `eslint --max-warnings=0` + `next build` 통과.
- 적용된 마이그레이션(DB 라이브 반영 완료): `0028_sticker_anim`, `0029_sticker_text_fx`,
  `0030_sticker_shape`, `0031_sticker_locked`.
- 경계: 새 속성(anim/text_fx/shape_key/locked)·배경 테마는 공개 포스터 시각 요소. `canDecorate`
  게이트 + `public-loader`로 시청자에게 정상 노출. 비공개/엠바고/방문데이터와 무관.

> 캡쳐(내보내기 PNG)는 거의 안 쓰기로 해서, 움직임은 **라이브 화면에서만** 보이고 PNG엔 정지
> 프레임으로 담깁니다(의도된 동작).

## 🔎 직접 눌러봐 줘 (내가 못 보는 시각·상호작용)

### P1a · 움직이는 스티커
- [ ] 이모지/도형/텍스트 스티커를 올리고 선택 → 툴바 **"움직임"** 줄에서 둥실·반짝·흔들·빙글·콩닥을 고르면 그 모션으로 움직인다.
- [ ] **정지**를 누르면 멈춘다.
- [ ] **선택 중엔 멈췄다가**(잡기 쉽게) 선택을 풀면 다시 움직인다.
- [ ] 새로고침해도 움직임이 유지된다(저장됨).
- [ ] 시청자 화면(미리보기/실제)에서도 실제로 움직인다.
- [ ] OS "동작 줄이기/Reduce Motion"을 켜면 멈춘다.

### P1b · 화려한 텍스트
- [ ] 텍스트 스티커 선택 → **"효과"** 줄에서 **그라데**(무지개빛 글자)·**네온**(글자색으로 번지는 빛)이 적용된다.
- [ ] **기본**으로 되돌리면 원래 글자색으로 돌아온다.
- [ ] 네온일 때 글자색 피커를 바꾸면 글로우 색도 같이 바뀐다.
- [ ] 새로고침 후 유지된다.
- [ ] (알아둘 점) **아치/곡선 텍스트는 이번에 미포함**(SVG 대공사라 보류).

### P2 · 데코 도형
- [ ] 팔레트 **"도형"**에서 하트·별·반짝·말풍선·리본·화살표·동그라미·테이프가 추가된다.
- [ ] 도형 선택 → 툴바 **"색"** 피커로 재채색된다.
- [ ] 회전·크기·투명도·좌우/상하 대칭·맨앞/뒤로·복제·**움직임**·**잠금**이 도형에도 다 먹는다.
- [ ] 새로고침 후 도형과 색이 유지된다.
- [ ] 시청자 화면에도 보인다.

### P3 · 배경
- [ ] 꾸미기 상단 테마 줄에 **노을·민트·도트·별밤·꽃가루**가 추가됐고, 누르면 포스터 배경이 바뀐다.
- [ ] 새 배경 위에서도 **달력 날짜·글자가 잘 읽힌다**(대비). 이상하면 그 테마 알려줘 → 톤 조정.
- [ ] 새로고침/시청자 화면에서 유지된다. (테마 변경은 소유자 권한일 때만 버튼이 보임.)

### P4 · 잠금
- [ ] 스티커 선택 → **자물쇠 버튼**을 누르면 잠긴다(버튼 강조).
- [ ] 잠긴 스티커는 **드래그해도 안 움직이고**, 크기/회전 핸들이 안 보인다.
- [ ] 잠긴 스티커도 **클릭하면 선택은 돼서** 자물쇠로 해제할 수 있다.
- [ ] 새로고침 후 잠금이 유지된다.

### 공통 / 모바일
- [ ] 위 모든 동작 후 **저장 실패 메시지**가 뜨지 않는다(낙관 반영 후 조용히 저장).
- [ ] 실행취소(Ctrl+Z)/다시실행(Ctrl+Y)이 새 속성 변경(움직임·효과·색·잠금)에도 동작한다.
- [ ] (모바일/좁은 화면) 툴바 "움직임/효과" 줄 버튼이 줄바꿈되어 안 잘린다. 좁아서 답답하면 알려줘.

## ⏸️ 이번에 보류한 것 (다음에 — 함께 보며 하는 게 안전)
핵심 렌더/모델을 건드려 **육안 검증이 꼭 필요**하거나 회귀 위험이 커서, 자는 동안 단독으로
밀어넣지 않았습니다. 원하면 다음 세션에서 같이 확인하며 구현:

1. **날짜 칸 강조 데코**(특정 날짜 칸에 글로우/뱃지로 "이 날 주목"): 달력 그리드 렌더 변경 +
   새 데이터 모델 필요 → 육안 확인 필수.
2. **영구 그룹**(여러 스티커를 한 덩어리로 묶어 함께 다루기): 드래그/선택 로직 깊이 관여.
   (참고: **다중 선택 이동·복제는 이미 됨** — Shift+클릭.)
3. **시즌/이벤트 원탭 팩**(배경 + 어울리는 스티커 자동 배치): 배경은 P3로 들어갔고, 스티커
   자동 배치만 남음(추가 작업).
4. **아치/곡선 텍스트**(SVG textPath 렌더).

## 문제가 있으면
항목 번호로 "P2 도형 색이 안 바뀜" 처럼 알려주면 바로 고칠게요. 특히 **새 배경 대비**와
**모바일 툴바 폭**은 실제 화면을 봐야 알 수 있어 확인 부탁해요.
