# 계절 배경 아트 브리프 — 자리 매니페스트 · 드롭인 · 아트 보드 · 코덱스 프롬프트

> 📖 **현행 규칙**(2026-09-04 출고, ADR-0017 ⑮). 정본은 `components/shared/ambient/art/manifest.ts` — 이 문서의 프롬프트 사본은 보드에서 복사한 것이다(표가 바뀌면 보드에서 다시 복사).

## 왜

소유자(2026-09-04 밤): "나무나 초목을 지금처럼 기본 도형 몇 개 붙이면 어떻게 하냐 — 겨울 나무는 말미잘 같고, 봄 초목은 껌딱지 같고, 가을엔 정체불명 흙더미가 널려 있고, 여름 연잎은 입체감 없이 다 겹쳐 있다. 모여봐요 동물의 숲(soopoolleaf 물고기·곤충 도감)처럼 식물·동물을 이어서 디자인하게 코덱스 프롬프트를 주고, 특정 라우트에서 디자인을 모아 한꺼번에 관리하게 해달라."

첫 참나무 4장 피드백(같은 날): "1024×1024는 오버스펙(어차피 축소해서 박는데, 생성 토큰도 더 든다), 모양도 복잡 — 살짝 단순해야 동물의 숲 느낌." → 가이드에 **단순함 최우선**을 못 박고 저장 크기는 스크립트로 줄인다.

## 파이프라인

1. **자리(slot)** — `manifest.ts`의 목록 하나가 배경의 모든 그림 자리를 정한다(1차 초목·지형 36 + 2차 생물 29 = 종 레지스트리 파생, 총 65). 자리마다 id(= 파일 이름)·계절·카메라(`stand`/`flat`/`shadow`)·화면 크기·변형 수·그릴 것·동숲 참고·지금 원천.
2. **파일** — `public/ambient/art/<id>.png`(변형 `<id>-1.png`…). 투명 배경 정사각, 한 장에 한 물체. 있으면 장면이 쓰고(`art/load.ts` ArtSet: 알파 경계로 잘라 자리 상자에 맞춤, 404는 세션 기억, 전부 도착하면 바탕 한 번 재굽기) 없으면 지금의 대체물(`art/props.ts` drawProp: 코드 도형·Noto 이모지·실루엣). `next dev`는 새로고침, 운영은 커밋·배포(프로덕션 서버는 시작 때의 `public/` 목록만 낸다).
3. **크기** — 생성기는 1024 아래를 못 주므로(gpt-image 계열) **품질을 낮음/중간**으로 낮춰 토큰을 아끼고, 저장은 `npm run art:normalize`(`scripts/ambient-art-normalize.mjs`: 알파 트리밍 → 화면 px의 4배(128~512; 나무 512·소품 128~256) → 팔레트 PNG)로 줄인다. 첫 참나무 4장: 1024·2.1MB → 512·313KB(장당 60~88KB). 128은 소품엔 충분하지만 나무는 확대 화면(DPR 2 × 줌)에서 340px까지 그려져 흐려진다. 보드가 무거운 원본을 표시한다.
4. **카메라** — 땅·물 위에 납작한 것(발자국·낙엽·연잎·물속 실루엣)만 위에서(`flat`/`shadow`). **서 있는 것(나무·관목·꽃·버섯·눈사람·동물)은 동물의 숲 카메라 `stand`**(높은 앵글 3/4 정면, 앵커 = 바닥 접점, 발밑 타원 그림자는 엔진). 나무를 위에서만 그리면 어떤 아트로도 말미잘/캐노피 얼룩을 벗어나지 못한다.
5. **보드** — `/studio/ambient-art`(개발자 전용; 설정 모달 개발자 줄 "배경 아트 보드 → 열기"; fixture `/visual-fixture/ambient-art`): 자리 카드(지금 대체물 ↔ 납품 PNG + 픽셀·KB, 규격, 납품됨/부분/대기, 무거운 원본 경고), 계절·분류·상태 필터, 프롬프트 복사(1차/2차/전체/자리별).
6. **새 소품이 필요하면** 자리를 추가하고 `props.ts`에 대체물을 그린다 — 장면 안에 새 절차적 식물을 그리지 않는다. ACNH는 스타일 참고만(닌텐도 원본 복제 금지), 오행 색 규칙(선명한 빨강·주황·노랑 금지) 유지.

## 검증

`.scratch-pw/probe-art-board.mjs`(프로젝트 루트에서, prod 서버 3100, `VISUAL_TEST_FIXTURE=1`): 기본 모드 = 보드·복사·필터·비로그인 가드·개발자 줄·네 계절 대체물·에러 0; `--make-art` → 서버 재시작 → `--delivered` = 보드 납품됨 + 여름 연잎·겨울 나무가 실제 그 그림을 그림; `--clean-art`. `probe-art-look.mjs` = 납품 아트가 네 계절 위 띠에 놓인 모습. 단위: `tests/unit/ambient-art.test.ts`.

## 1차 마스터 프롬프트(보드에서 복사한 사본, 2026-09-04 개정 — 단순함·크기 규칙 반영)

```markdown
# VIC 계절 배경 아트 — 생성 의뢰(1차: 나무·초목·지형·물)

빅토리 일정표(스트리머 방송 일정 편집실)의 배경은 달력의 달을 따라 봄·여름·가을·겨울로 바뀌는 살아 있는 장면이다.
지금은 코드로 그린 기본 도형(원·선)으로 나무와 풀을 흉내 내고 있어 겨울 나무는 말미잘처럼, 봄 풀은 껌딱지처럼 보인다.
아래 표의 자리마다 **모여봐요 동물의 숲 느낌의 그림 한 장씩**을 만들어 달라. 만든 파일은 public/ambient/art/ 에 표의 id 이름으로
넣기만 하면 장면이 자동으로 그 그림을 쓴다(편집실 /studio/ambient-art 보드에서 자리별 상태를 확인한다).

## 스타일 가이드(모든 그림 공통)
- 참고: 모여봐요 동물의 숲 도감 그림의 **느낌**을 따른다 — https://animalcrossing.soopoolleaf.com/ko/acnh/Fish/ · https://animalcrossing.soopoolleaf.com/ko/acnh/Bugs/ .
  닌텐도 원본을 복제·트레이스하지 말고, 같은 어법으로 **새로 그린 원작**을 만든다(둥글고 통통한 덩어리, 단순한 면, 또렷한 실루엣, 장난감 같은 귀여움).
- **단순하게(가장 중요).** 이 그림은 화면에서 12~170px 크기로 놓인다 — **128px로 줄여도 형태가 읽혀야 한다.** 잎·깃털·털·비늘 하나하나를
  그리지 않는다. 물체 = **매끈한 둥근 덩어리 2~3개**(예: 나무 = 공 모양 잎 덩이 2~3개 + 짧은 줄기). 색은 물체당 3~4개, 하이라이트 1, 그늘 1.
  붓 터치·질감·잔무늬·잔가지 잔뜩 금지. 사실적/회화적 렌더 금지 — 장난감·마스코트처럼.
- 형태: 실루엣이 먼저 읽히게. 좌우 균형 잡힌 둥근 덩어리, 모서리는 둥글게, 비율은 통통하게(2등신 감각).
- 선: 외곽선은 아주 얇고(크기의 1~1.5%) **그 부분 색보다 한 단계 어두운 같은 계열 색**(검정 선 금지). 안쪽 선은 최소.
- 명암: 셀 셰이딩 2단(밝은 면·그늘 면) + 위 왼쪽에서 오는 부드러운 빛, 작은 반사광 한 점. 그라데이션은 넓고 부드럽게, 질감 노이즈 금지.
- 색(오행 규칙): 채도 낮은 부드러운 색. **선명한 빨강·주황·노랑 금지** — 가을은 갈색·황토·와인(갈색이 주, 붉은 기는 아주 조금), 꽃의 노랑은
  크림 노랑, 무당벌레는 벽돌빨강. 초록은 연둣빛(봄)·짙은 초록(여름). 물빛은 #9cc4e0 계열. 흰색은 순백 대신 #f6f8fb.
- 배경: **완전 투명(알파 0)**. 바닥·그림자·풍경·글자·워터마크·테두리 없음. 한 장에 **한 물체만**, 캔버스 가운데, 긴 변이 캔버스의 85%를 채운다.
- 형식: PNG 투명 배경, **정사각**. 크기는 생성기의 최소(대개 1024×1024)로, **품질은 낮음/중간**(디테일이 필요 없고 우리가 128~512로 줄여
  저장한다 — scripts/ambient-art-normalize.mjs). 파일 이름은 표의 id 그대로(<id>.png, 변형은 <id>-1.png, <id>-2.png…).
- 카메라(자리마다 표기): stand = 동물의 숲 카메라(높은 앵글 3/4 정면) · flat = 정확히 위에서 · shadow = 위에서 본 단색 실루엣.
- 일관성: 같은 종의 계절 변형(예: 참나무 봄·여름·가을·겨울)은 **같은 실루엣·같은 줄기**에 잎만 바뀐다. 변형(-1, -2, -3)은 같은 크기·같은 스타일에 형태만 조금 다르다.

## 납품
- 자리마다 PNG 투명 배경 정사각 한 장(변형은 <id>-1.png…). 한 장에 한 물체. 표의 id를 파일 이름으로. 크기는 생성기 최소, 품질 낮음/중간 — 저장은 우리가 줄인다.
- **단순하게**: 128px로 줄여도 읽히는 덩어리 2~3개. 잎·털·비늘 낱개, 붓 터치, 잔가지 뭉치 금지.
- 같은 종의 계절 변형은 같은 실루엣을 유지한다. 먼저 참나무 4장(봄·여름·가을·겨울)을 만들어 스타일을 확정한 뒤 나머지를 같은 어법으로.
