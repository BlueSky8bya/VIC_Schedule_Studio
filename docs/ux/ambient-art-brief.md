# 계절 배경 아트 브리프 — 자리 매니페스트 · 드롭인 · 아트 보드 · 코덱스 프롬프트

> 📖 **현행 규칙**(2026-09-04 출고, ADR-0017 ⑮). 정본은 `components/shared/ambient/art/manifest.ts` — 이 문서의 프롬프트 사본은 보드에서 복사한 것이다(표가 바뀌면 보드에서 다시 복사).

## 왜

소유자(2026-09-04 밤): "나무나 초목을 지금처럼 기본 도형 몇 개 붙이면 어떻게 하냐 — 겨울 나무는 말미잘 같고, 봄 초목은 껌딱지 같고, 가을엔 정체불명 흙더미가 널려 있고, 여름 연잎은 입체감 없이 다 겹쳐 있다. 모여봐요 동물의 숲(soopoolleaf 물고기·곤충 도감)처럼 식물·동물을 이어서 디자인하게 코덱스 프롬프트를 주고, 특정 라우트에서 디자인을 모아 한꺼번에 관리하게 해달라."

두 번의 시안 뒤 확정:

1. 1차(회화풍 1024, 잎 낱개까지) → "1024는 오버스펙(축소해서 박는데 토큰도 더 든다), 모양도 복잡" → 가이드에 **단순함 최우선** + 저장은 스크립트로 축소.
2. 2차(**픽셀아트**) → "엄청 괜찮아졌다" → **확정 스타일 = 픽셀아트**. 겨울 줄기만 붉은 갈색(hue 8°·채도 .62)이 눈밭에서 튀어 탈색(hue 15°·채도 .44, `.scratch-pw/desat-trunk.mjs`).

## 파이프라인

1. **자리(slot)** — `manifest.ts`의 목록 하나가 배경의 모든 그림 자리를 정한다(1차 초목·지형 36 + 2차 생물 29 = 종 레지스트리 파생, 총 65). 자리마다 id(= 파일 이름)·계절·카메라(`stand`/`flat`/`shadow`)·화면 크기·변형 수·그릴 것·동숲 참고·지금 원천.
2. **파일** — `public/ambient/art/<id>.png`(변형 `<id>-1.png`…). 투명 배경 정사각, 한 장에 한 물체. 있으면 장면이 쓰고(`art/load.ts` ArtSet: 알파 경계로 잘라 자리 상자에 맞춤, 404는 세션 기억, 전부 도착하면 바탕 한 번 재굽기) 없으면 지금의 대체물(`art/props.ts` drawProp: 코드 도형·Noto 이모지·실루엣). `next dev`는 새로고침, 운영은 커밋·배포(프로덕션 서버는 시작 때의 `public/` 목록만 낸다).
3. **스타일은 픽셀아트로 고정** — 확정 기준물은 `public/ambient/art/tree-oak-*.png` 네 장. 새 그림은 이것들과 나란히 놓아 한 세트로 보여야 한다(도트와 물감이 섞이면 장면이 깨진다). 논리 해상도 64~96px급 도트를 정수배로 키운 느낌, 물체당 6~10색, 안티에일리어싱 금지, 외곽선은 같은 계열의 훨씬 어두운 색(순수 검정 금지).
4. **크기** — 생성기는 1024 아래를 못 주므로 **품질을 낮음/중간**으로 낮춰 토큰을 아끼고, 저장은 `npm run art:normalize`(`scripts/ambient-art-normalize.mjs`: 알파 트리밍 → 화면 px의 4배(128~512; 나무 512·소품 128~256) → 팔레트 PNG). 참나무 4장: 674KB → 238KB(장당 41~71KB). 보드가 무거운 원본을 표시한다.
5. **카메라** — 땅·물 위에 납작한 것(발자국·낙엽·연잎·물속 실루엣)만 위에서(`flat`/`shadow`). **서 있는 것(나무·관목·꽃·버섯·눈사람·동물)은 동물의 숲 카메라 `stand`**(높은 앵글 3/4 정면, 앵커 = 바닥 접점, 발밑 타원 그림자는 엔진).
6. **색** — 오행 규칙(선명한 빨강·주황·노랑 금지) + **밝은 바탕(눈·모래)에 서는 줄기는 회갈색**(붉은 줄기가 눈밭에서 제일 튄다 — 실측).
7. **새 소품이 필요하면** 자리를 추가하고 `props.ts`에 대체물을 그린다 — 장면 안에 새 절차적 식물을 그리지 않는다.

`.scratch-pw/probe-art-board.mjs`(프로젝트 루트에서, prod 서버 3100, `VISUAL_TEST_FIXTURE=1`): 기본 모드 = 보드·복사·필터·비로그인 가드·개발자 줄·네 계절 대체물·에러 0; `--make-art` → 서버 재시작 → `--delivered`; `--clean-art`. `probe-art-look.mjs` = 납품 아트가 네 계절 위 띠에 놓인 모습(+ 무거운 원본 개수). 단위: `tests/unit/ambient-art.test.ts`.

빅토리 일정표(스트리머 방송 일정 편집실)의 배경은 달력의 달을 따라 봄·여름·가을·겨울로 바뀌는 살아 있는 장면이다.

아래 표의 자리마다 **그림 한 장씩**을 만들어 달라 — 스타일은 **이미 확정된 참나무 4장**(public/ambient/art/tree-oak-*.png)과 같은 픽셀아트.

- 자리마다 PNG 투명 배경 정사각 한 장(변형은 <id>-1.png…). 한 장에 한 물체. 표의 id를 파일 이름으로. 크기는 생성기 최소, 품질 낮음/중간 — 저장은 우리가 줄인다.
- **픽셀아트 한 어법으로**: 이미 확정된 참나무 4장(public/ambient/art/tree-oak-*.png)과 나란히 놓아도 한 세트로 보여야 한다.
- **단순하게**: 128px로 줄여도 읽히는 덩어리 2~3개. 잎·털·비늘 낱개, 붓 터치, 안티에일리어싱 금지.
- 같은 종의 계절 변형은 같은 실루엣을 유지한다. 나무 4장은 확정 — 다음은 묘목·새싹·관목 4계절(같은 나무 계열)부터.
- 색은 오행 규칙(선명한 빨강·주황·노랑 금지)을 어기지 않는다. 밝은 바탕(눈·모래)에 서는 줄기는 회갈색.```
