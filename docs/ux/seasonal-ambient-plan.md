# 계절·특정일 앰비언트 배경 — 설계안 (2026-09-04)

> 상태: **1·2단계 출고(2026-09-04, ADR-0017)** — 레지스트리·스위치·봄/가을/겨울 레이어. **같은 날 개정 2**: 계절 = 달력 달,
> 물결 = 여름 전용, 스위치 OFF = 전부 없음, 봄/가을/겨울은 위에서 내려다보는 **상호작용 캔버스 장면**(낙엽 물리·나비·
> 눈밭 발자국 — `components/shared/ambient/scene-engine.ts`, `scenes/*`). 3단계(특정일)·4단계(포스터 테마 철거)는 미착수. 관리자 아이디어(2026-09-04) ① 계절별 배경(봄·여름·가을·겨울, 지금 물결 = 여름) + 별도 ON/OFF
> ② 특정일 배경(성탄·할로윈·24절기 등)을 따로 관리하는 루트. 사주(오행) 보정은 CLAUDE.md "Owner-fit palette rule"
> 아래의 상징 레이어 — 원국 자체는 로컬 문서에만(커밋·UI·API 금지).

## 1. 결론 먼저

- **된다. 단, 새 파일 몇 개가 아니라 "앰비언트 레이어 레지스트리"라는 작은 구조를 먼저 세운다.** 지금 물결(`.gs-tide`)은
  단일 컴포넌트가 CSS 게이트로 켜지는 구조라, 계절 4종 + 특정일 N종을 같은 방식으로 늘리면 게이트·토큰·검증이
  N배로 흩어진다. 레지스트리 하나로 모으면 "오늘(KST) → 어떤 레이어" 판정이 한 곳, 켜고 끄는 스위치가 한 곳, 성능
  게이트(생동감·gfx·모바일)가 한 곳이 된다.
- **기존 포스터 테마 7종(`data-poster-theme`: sakura/summer/autumn/winter/sunset/mint/dot/starry/confetti/mist)은 이
  레지스트리가 대체(supersede)한다.** 시청자 전용·정적 그라데이션·DB 저장(`calendars.poster_theme`)이고, 실제로 2026-09-03에
  라이브 값 'autumn'이 금생수 스킨을 통째로 덮어 "시청자 화면이 안 바뀐다"의 원인이 됐다(두 시스템이 같은 배경을 두고
  싸운다). 새 구조에선 `poster_theme = 'auto'` 하나만 남기고(값만 추가, 컬럼 재사용) 계절/특정일은 KST 날짜가 정한다.
  → **ADR 필요**(ADR-0016 보완 또는 ADR-0017: "배경은 레지스트리 하나가 그린다, 테마 셀렉트는 auto/none으로 축소").

## 2. 구조

```
components/shared/ambient/
  registry.ts      // { key, kind: "season"|"day", match(kst: {y,m,d}) → boolean|priority, Layer, intensity }
  ambient-layer.tsx// 오늘 판정 → 우선순위 최상 레이어 하나만 마운트(특정일 > 절기 > 계절)
  seasons/spring.tsx summer.tsx(=지금 water-tide) autumn.tsx winter.tsx
  days/christmas.tsx halloween.tsx solar-terms.ts(24절기 표, KST)
app/ambient.css    // 공용 게이트·토큰(지금 metal-water.css의 .gs-tide 규칙이 여기로)
```

- **판정은 KST 고정**(Non-negotiable 1). 절기는 연도별 표(천문 계산 대신 정적 표 — 서버·클라이언트 동일 결과, 결정성).
- **게이트는 지금과 동일**: `html:not([data-reduce-motion]):not([data-gfx="lite"])` ∧ ≥641px. 여기에 스위치 하나 추가 —
  **"계절 배경"**(`vic.ambient`, 기본 ON, 설정 톱니 목록 `StudioSettingsList`에만 추가). 시청자 화면은 설정 UI가 없으므로
  소유자의 서버 값(`poster_theme`: `auto`=계절·특정일 자동, `none`=배경 없음)을 따른다.
- **레이어 규칙(성능·품질 불변)**: transform/opacity만 애니, scale·blur·mix-blend 금지, 필터 래스터는 1회, 어두운 얼룩
  금지, WCAG AA(눈 편한 필터 뒤에서도), export 표면(`[data-export-surface]`) 밖, `html`에 background 금지. 헤드리스
  드래그 스펙(studio-drag-indicator)이 비용 게이트 — 레이어마다 통과해야 출고.
- **숨은 요소(산타·루돌프 등)**: 시청자 화면에 두되 `aria-hidden`, 포인터 무시, 캘린더 위가 아니라 **표면 바깥 여백**에만.
  관리자 UI·비공개 배지와 무관(공개 경계 불변).

## 3. 사주 보정(오행) — 계절별 방향

| 계절 | 계절의 기운 | 토리님에게 필요한 쪽 | 배경 방향 |
| --- | --- | --- | --- |
| 봄 | 木 왕(火 상승) | 水·金 | 쨍한 햇빛(火) 대신 **푸릇한 초목(木)·아침 이슬(水)** — 연둣빛 풀 그림자, 옅은 물기 |
| 여름 | 火 왕 | 水 | **지금 물결(caustic)** 그대로 = 해변의 얕은 물 — 火를 水로 식힌다 |
| 가을 | 金 왕(조토 건조) | 水·金 | 형형색색 낙엽은 붉·주황·노랑 = 火·조토 증폭이라 **채도 낮춘 갈색·와인 낙엽 + 은빛 서리·안개(金·水)** |
| 겨울 | 水 왕 | 水·金 | **소복한 눈(水의 결정 = 흰 金색)·축축한 습기** — 눈 내림은 느리게, 얼음 결 하이라이트는 은선 |

- 특정일: 화이트 크리스마스(눈 + 표면 밖 여백의 트리·산타·루돌프 숨김 요소), 할로윈(어둡게 만들지 않는다 — 밝은 바탕
  위 보랏빛 안개·박쥐 실루엣 정도; 붉/주황 증폭 금지), 24절기(각 절기의 기운을 위 표의 보정 규칙으로 — 예: 입하·소만은
  水로 식힘, 처서·백로는 이슬(水)·서리(金)).
- 전부 "검이불누 화이불치": 느리고 옅게, 의미색 8종·태그색·하트·기하 불변.

## 4. 순서(제안)

1. ADR + 레지스트리 뼈대 + 지금 물결을 `summer`로 이관(동작 0 변화) + 설정 스위치 "계절 배경".
2. 겨울(눈) → 봄(초목) → 가을(서리·낙엽) 순(당장 다가오는 계절부터, 각각 드래그 스펙·픽셀 실측·비주얼 기준선).
3. 특정일(성탄 → 할로윈 → 절기 표).
4. 포스터 테마 셀렉트를 `auto/none`으로 축소하고 옛 7종 CSS 제거(ADR로 supersede).
