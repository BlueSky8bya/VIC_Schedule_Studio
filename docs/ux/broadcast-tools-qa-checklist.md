# 방송 가독성 도구 QA 체크리스트 (A안 달력 확대 + B안 방송 판서)

> PLAN-20260725-001 M5. 단위 DOM 테스트를 생략한 대가로 게이트(G1-r·G3a-r·G3b)에서 합의한
> **필수 스모크**다. 배포 후 실기기(방송용 PC) 검증 전까지 '통과'라고 말하지 않는다.
> 상태: ☐ 미실행 / ☑ 통과 — 최초 작성 시점(2026-07-25)엔 전부 미실행.

## A안 — 달력 확대 (게이트 합의 필수 5)

- ☐ ①우클릭 잇기·끊기 드래그 중 팝오버가 닫히고 Ctrl+휠 확대가 차단된다
- ☐ ②확대 중 +N 칩에서 Enter — 팝오버 고정만 되고 편집창이 같이 열리지 않는다
- ☐ ③팝오버 내부 스크롤(긴 세부)이 팝오버를 닫지 않는다
- ☐ ④핀 팝오버가 스크롤·resize로 자동 닫힐 때 포커스가 앵커 카드로 복귀한다
- ☐ ⑤Ctrl+휠이 달력 패널 위에서만 먹는다(달력 밖=브라우저 기본) · 미리보기 진입/모바일
  전환 시 리스너 해제·배율 초기화(MOBILE_QUERY 전체 조건)

추가 확인:

- ☐ 125/150%에서 7열 유지, 카드 겹침·업도움 띠/날짜 헤더 겹침 없음
  (폭 매트릭스: 1180/1280/1920 × 아바타 on/off × 편집창 open/closed)
- ☐ 확대 중 카드 드래그 — 유령 크기 일치(--cal-zoom 복사), 삽입선 위치 정확, FLIP 튐 없음
- ☐ 하단 플로팅 −/%/＋가 스크롤 위치와 무관하게 보이고, 100% 복귀 시 사라진다

## B안 — 방송 판서 (게이트 합의 필수 ⑥~⑨)

- ☐ ⑥판서 열림 중 브라우저 뒤로가기 = 판서만 닫힘(미리보기 유지) — 포스터 내부 오버레이
  ('이 달 기록' 시트)가 열려 있을 때의 우선순위 포함
- ☐ ⑦미니 달력에서 키보드(Enter/Space) 토글 후 Shift+클릭 — 확장 기준이 마지막 토글 칸
- ☐ ⑧실물 export 경로(공식 포스터 PNG 생성 스크립트)에 판서·확대 UI 무흔적
  (fixture 단언 tests/visual/poster.spec.ts는 통과했지만 실제 파이프라인은 별도)
- ☐ ⑨판서판 가로/세로 스크롤 시 날짜 카드와 그린 선이 함께 움직인다(좌표 분리 없음)

추가 확인:

- ☐ 불투명: 판서 여는 순간부터 뒤 화면이 한 프레임도 안 비친다(등장 연출은 내부만)
- ☐ Esc 순서: 날짜 선택 있음 → 선택 해제만 / 없음 → 판서 닫힘 / 닫은 뒤 진입 버튼 포커스
- ☐ 판서 열림 동안 편집실 단축키(Ctrl+S/Z/C/V·Alt+N) 전면 무반응, 닫으면 즉시 복구
- ☐ 형광펜: 그리는 동안 반투명 이음매 진해짐 없음, 뗄 때 겹침 순서 그대로(튐 없음)
- ☐ 지우개: 잠긴 레이어는 안 지워진다(펜 잠금 → 형광펜만 지워짐)
- ☐ 그림 레이어 썸네일·이름을 마우스로 위/아래 drag — 5px 전에는 클릭 선택,
  이후 ghost·보라 삽입선 표시, 놓으면 합성 순서 변경, Ctrl+Z/Y 한 번에 왕복
- ☐ 레이어 drag 중 `Esc`·pointercancel/lost capture·목록 바깥 drop — 패널은 닫히지 않고
  순서·undo 이력 변화 없음. 취소 뒤 첫 마우스/키보드 레이어 선택도 정상 동작
- ☐ pen drag 중 두 번째 mouse pointer 입력 — 기존 ghost·body 선택 잠금이 덮어써지지 않음
- ☐ 긴 레이어 목록 위/아래 가장자리 drag — 패널만 자동 스크롤, `일정`은 항상 맨 아래 고정
- ☐ 눈·잠금·삭제 버튼은 drag를 시작하지 않음. 키보드 `Alt+↑/↓` 이동 뒤 포커스·live 알림 유지
- ☐ 7개 이상 레이어 추가 — 버튼에 분수/최대치 없음, 캔버스·썸네일 정상, 닫고 재진입 시 소멸
- ☐ 상단 command/tool/property-color 구역이 1180/1280/1920px에서 잘리거나 캔버스를 가리지 않음
- ☐ undo 전량 → 화면 맞춤 잠김 유지(redo 기록) → 전체 지우기(2단계)로만 해제
- ☐ 창 닫고 재진입 — 판서판·그림·undo 기록 전부 빈 상태(소멸 계약)
- ☐ 리사이즈(창 크기 변경) — 그리던 획은 자동 완성 커밋되고 기존 획은 재생으로 보존
- ☐ teaser(미공개) 일정 — 판서 카드가 🔮 가림 룩(제목·시간·태그 없음)

## 역할·경계 (DoD 상시 항목)

- ☐ viewer(비로그인) 공개 포스터: 확대 컨트롤·판서 버튼·관련 DOM 흔적 0
- ☐ manager/worker: 판서 진입 버튼 안 보임(owner/developer만)
- ☐ 비공개 일정 본문이 판서 창 DOM/네트워크 어디에도 없음(devtools 확인)
