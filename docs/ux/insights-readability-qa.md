# 인사이트 가독성 수정 — 확인 체크리스트

대상 커밋: `8a7fe8f`(시간대 차트 + 행동 타임라인) · `98e6bb3`(진행 중 구간 전반)
전제: **개발자 계정**으로 로그인(대부분 개발자 전용 화면). 오늘 날짜 기준으로 봐야 '진행 중'
표시가 나온다 — 과거 달/과거 날짜를 열면 안 보이는 게 정상이다.

---

## 1. 일별 방문 모달 — 시간대별 동접

경로: 편집실 → 달력에서 **오늘 날짜 칸** 클릭 → `이용 기록 열기`

- [ ] x축 라벨이 **0 / 3 / 6 / 9 / 12 / 15 / 18 / 21** (예전 0/6/12/18)
- [ ] 축 오른쪽 끝에 **`24`** 와 짧은 세로 끝선
- [ ] 현재 시각 위치에 보라 세로선 + **`지금`** 알약
- [ ] `지금` 선 **오른쪽 칸들이 흐림**(아직 안 온 시간). 왼쪽 빈 칸은 원래 밝기
- [ ] 지금 시간대 막대가 **실제 사람 수 높이**로 서 있다(정각 직후에도 바닥에 눌리지 않음)
- [ ] 라벨이 두 줄로 깨지거나 서로 겹치지 않음 (모바일 폭에서도)

**과거 날짜**로 다시 열기 (달력에서 지난 날짜 클릭)

- [ ] `지금` 마커 없음 · 흐린 칸 없음 (전 구간 동일 밝기)

---

## 2. 일별 방문 모달 — 관리자 접속 세션

같은 모달 아래쪽 `관리자 접속 세션` 트랙

- [ ] 막대가 **시작~끝 길이**로 그려짐 (예전엔 실측 체류라 짧게 잘렸다)
- [ ] 막대 안쪽에 **더 진한 채움** = 실제로 화면에 떠 있던 시간, 바깥 옅은 부분 = 자리비움 포함
- [ ] 지금 켜져 있는 세션은 **오른쪽 끝이 각지고 보라 선**이 붙음
- [ ] 그 세션 툴팁/목록이 `21:32–지금(계속 중)`
- [ ] 아래 시간 눈금이 **0/3/…/21/24**, `0`은 왼쪽 끝에 · `24`는 오른쪽 끝에 딱 붙음(잘리지 않음)

---

## 3. 행동 타임라인 (같은 모달 아래)

- [ ] `진단` 토글을 켰을 때 `탭 가시성` 줄이 **visible=true / false 별로 나뉘어** 보임
      (예전엔 전부 `visible=true ×5` 한 줄)
- [ ] 여러 번 접힌 줄(×N)의 시각이 **`17:55` 아래 작게 `↓21:32`** 로 끝 시각까지 보임
- [ ] 방문 한 줄 요약(접힌 상태)에 **횟수**가 남음 — 예: `일정 저장 ×3`
- [ ] `타임라인 복사` → 붙여넣기 → 접힌 줄이 **`17:55–21:32`** 형식
- [ ] 40px 시각 칸에서 끝 시각이 잘리거나 줄바꿈 안 남 (**모바일에서 특히**)

---

## 4. 월별 인사이트 — 방문 탭

경로: 편집실 → `관리 ▾` → `월별 인사이트` → 방문

- [ ] 시간대별 동접 축이 **0/3/…/21 + 끝 24** (여긴 `지금` 마커·흐림 **없는 게 정상** — 여러 날 평균이라)
- [ ] 지금 시간대 막대가 부자연스럽게 낮지 않음
- [ ] **요일×시간 히트맵** 축이 `0/3/…/21` + 오른쪽 끝 `24`, 라벨이 해당 칸 **바로 아래 중앙**
      (예전엔 반 칸 왼쪽으로 밀리고 끝이 `23`)
- [ ] **미니 달력**: 오늘 칸에 보라 테두리, 내일 이후 칸은 흐림
- [ ] **일별 세션 막대**: 오늘 막대 빗금, 내일 이후 흐림
- [ ] `관리자 접속 세션`(이번 달) 트랙도 2번 항목과 같은 규칙(폭=span, 2층, live 표시)

---

## 5. 월별 인사이트 — 추이 탭 (제일 눈에 띄는 변화)

- [ ] 안내문에 `(이번 달은 진행 중이라 지난달 같은 페이스와 비교)` 문구
- [ ] 방문 / 컨텐츠 / 하트 / 방송 시간 각 줄에 **`진행 중 7/31일`** 칩
- [ ] 변화 배지가 **`≈▲` / `≈▼`** (≈ 없으면 진행 중 계산이 안 걸린 것)
- [ ] 배지에 마우스 올리면 `지난달 전체 … · 이 시점까지의 페이스로 환산하면 …` 툴팁
- [ ] 마지막(이번 달) 막대에 **빗금 + 점선 윗면**, 옆 달 막대와 확실히 구분
- [ ] 태그 누적 차트(콘텐츠별/형식별/하트별)도 마지막 칸 빗금 + `8월` 라벨이 보라색
- [ ] 방송 시간 **일별 막대**: 오늘 이후 날짜가 흐림 (예전엔 '방송 안 함'과 같은 회색)

**지난달로 이동**(달 이동 후 다시 열기)

- [ ] `진행 중` 칩 사라짐 · 배지에서 `≈` 사라짐 · 빗금 사라짐 (예전과 동일한 계산)

---

## 6. 다른 역할·시청자 화면 (같은 배지를 공유함)

- [ ] **관리자(토리님)/매니저/작업자 인사이트**의 추이 탭에도 `진행 중` 칩 + `≈` 배지 + 빗금
- [ ] **공개 포스터 → 인사이트**(시청자 화면)의 최근 6개월 차트 마지막 칸도 빗금
      (하트 차트는 숫자 비공개 정책 그대로 — 숫자가 새로 노출되면 안 된다)
- [ ] 시청자 화면에 개발자 전용 정보(방문 수·계정·세션)가 **새로 새지 않았는지**

---

## 7. 회귀 — 건드리지 않은 것이 그대로인지

- [ ] 차트 호버 툴팁이 예전처럼 뜨고 잘리지 않음(막대·히트맵·트랙 전부)
- [ ] `동작 줄이기`(설정) 켠 상태에서 새 표시가 깜빡이거나 튀지 않음
- [ ] 모바일 폭(≤640px)에서 축 라벨·칩이 가로로 넘치지 않음
- [ ] 인사이트 새로고침 버튼 → 값이 갱신되고 표시도 따라 바뀜

## 알려진 한계 (버그 아님)

- 페이스 환산은 "한 달 안에서 활동이 고르다"는 가정이다 → 그래서 `≈`를 붙였다.
  주말에 몰리는 지표는 요일 구성에 따라 흔들린다.
- `지금` 마커 위치는 칸 사이 2px 간격을 무시한 근사(최대 ~2px 오차). 툴팁도 원래 같은 근사다.
- 월 경계(1일 0시)·말일은 실제로 그 시각이 되어야 확인 가능하다. 계산은
  `tests/unit/month-progress.test.ts`가 고정 시각으로 검증한다.
