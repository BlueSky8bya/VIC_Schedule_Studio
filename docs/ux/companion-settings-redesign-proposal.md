# 빅타민 설정 화면 개편 설계안

작성 2026-11-18 · **6판(같은 날, 5판의 2단계 이후에 대한 독립 검증 반영)** · 상태: 큰 결정은 확정, **0·1단계는 시작 가능(검증 판정)**, 2단계 이후는 4차 검증이 "문서를 고치고 시작"으로 판정했고 그 지적을 이 판에 반영함(반영본은 아직 재검증받지 않음), **결정 완료(2026-11-18 소유자, 확인 A·B·C 포함 전부 추천대로)** · 적용은 아직 시작 안 함
이 문서는 설계만 담는다. 코드·화면·문구는 하나도 바꾸지 않았다.

조사 방법: 실제 코드를 읽고, 로컬에서 고정 자료 화면을 창 없이 띄워 시청자 PC, 편집실 PC, 모바일을 직접 찍어 보았다. 다른 AI(코덱스)가 1판, 3판, 4판, 5판(2단계 이후)을 각각 코드로 검증했고, 그 지적을 내가 코드로 재확인했다.

## 0. 판마다 바뀐 것

| 판 | 방향 | 항목 수 |
|---|---|---|
| 1판 | 줄이기. "조용하던 기기가 시끄러워지는" 경우를 여러 개 놓침 | 28 → 24 |
| 2판 | 옛 설정의 뜻을 하나도 안 바꾸기. 거의 못 줄임 | 28 → 27 |
| 3판 | 소유자 결정: 뜻 지키기보다 줄이기(단순화)가 먼저 | 28 → 20 |
| **4판** | **3판의 선택은 그대로. 적용할 때 사고가 나는 곳과 빈칸을 메움** | 28 → 20 |
| **5판** | **4판의 선택은 그대로. 라디오와 "직접 표시"의 남은 빈칸을 메움. 0·1단계는 시작해도 된다는 검증 판정을 받음** | 28 → 21 |
| **6판** | **5판의 선택은 그대로. 2단계 이후에서 서로 어긋나던 설명과 단계 경계를 맞춤** | 28 → 21 |

**소유자가 확정한 것 (2026-11-18, 4판에서도 그대로)**

- 줄이기(단순화)가 먼저.
- 빅타민 소리 3단계(끔 / 만질 때만 / 전부), 움직임 3단계, 장난 2줄.
- '음악에 맞춰 춤추기' 스위치 없앰, '더 보기' 6줄은 접어 두기만.
- 내가 집을 때의 들어 올리기와 내가 흔든 뒤의 어지럼은 "내가 만질 때" 소리.
- 쿠션으로 부른 뒤의 착지는 "혼자 놀 때" 소리.
- 라디오를 빅타민 소리에서 떼기, 한 쪽에 카드로 놓기, 전원을 공통 머리줄로, 톱니로 들어오면 설정 먼저, 성격·배우기를 '함께 지내기'로.

## 1. 지금 상태 요약

**빅타민 설정 화면에서 손댈 수 있는 것은 28개이고, 6군데에 흩어져 있다.** (저장되는 선택 27개 + 초기화 단추 1개. 집 안 물건과 숨은 값은 따로 센다.)

| 어디 | 몇 개 | 무엇 |
|---|---|---|
| 설정 창 › 빅타민 › 환경설정 (전원 + 하위 탭 5개) | 27 | 전원 1, 기본 4, 움직임 5, 장난 5, 교감 3, 소리 5, 라디오 4 |
| 설정 창 › 빅타민 › 옷장 | 1 | 입힌 소품 |
| 설정 창 › 소리 | (남의 설정) | 사이트 효과음·음량이 빅타민 소리와 라디오를 통째로 막음 |
| 설정 창 › 움직임 | (남의 설정) | '생동감 있는 동작', '최초공개 무대'가 빅타민 행동을 막음 |
| 설정 창 › 배경 | (남의 설정) | '배경 효과'가 빅타민 춤·묘기·일부 소리를 막음 |
| 빅타민 집 안 물건 | 12 | 2-7 참고 |

**가장 큰 문제 5가지**

1. **너무 깊다.** 설정 창 안에 탭이 3겹이다(왼쪽 묶음 → 빅타민 4쪽 → 환경설정 5탭). 톱니에서 전원까지 3번, 소리 스위치·라디오까지 4번 눌러야 한다. 소리·기본 탭은 그 안에서 또 스크롤해야 한다.
2. **'돌아다니기'가 숨은 큰 스위치다.** 끄면 깡충 뛰기, 장난 5개, 음악에 맞춰 춤추기, 밥 찾아가기, 집안일까지 멈춘다. 화면에서는 그 스위치들이 모두 켜진 초록색 그대로다.
3. **다른 탭의 설정이 말없이 이긴다.** '생동감 있는 동작'을 끄면 돌아다니기·깡충 뛰기·숨바꼭질이 꺼진 것처럼 움직이고, '배경 효과'가 부드럽게로 잡히면 춤·소품 묘기·'움직임' 소리가 멈춘다. '배경 효과'는 기본이 자동이라, 아무것도 안 건드려도 기기 성능 판정만으로 이렇게 될 수 있다. 빅타민 설정 화면에는 아무 표시가 없다.
4. **소리가 여러 겹으로 잠겨 있고 이유를 알려 주지 않는다.** 안내는 "전체 효과음이 꺼져 있어요" 한 줄뿐이고 스크롤 아래에 있다. 집의 라디오 버튼은 막혀 있으면 눌러도 반응이 없다.
5. **이름과 실제가 다르다.** 착지 소리가 '돌보기'에 있고, '숨바꼭질'이 집 어지르기·장난감 꺼내기까지 맡고, '밥주기'를 끄면 쓰레기통도 사라지고, '집어 옮기기'를 끄면 키보드로 옮기기도 막힌다.

## 2. 현재 설정 전체 표

### 2-9. 겹침·충돌 목록

**같은 일을 하는 손잡이가 둘 이상**

- 빅타민 소리 끄기: '빅타민 효과음' 스위치 = '빅타민 음량' 0. (묶음 3개를 다 끄는 것은 소리는 같게 꺼지지만 라디오를 막지 않는다는 점이 다르다.)
- 라디오 못 틀게 하기: '집 라디오' 스위치 = '라디오 음량' 0 = '빅타민 효과음' 끄기 = '빅타민 음량' 0. (정지 버튼은 다르다. 지금 재생만 멈추고, 뒤에 빅타민이 스스로 다시 틀 수 있다.)
- 가만히 있게 하기: '돌아다니기' 끄기 ≈ '생동감 있는 동작' 끄기(이쪽이 더 넓게 막음).
- 뛰지 않게 하기: '깡충 뛰기' 끄기 = '돌아다니기' 끄기 = '생동감 있는 동작' 끄기.

**말없이 이기는 곳**

- '돌아다니기' → 깡충 뛰기, 장난 5개, 음악에 반응하기.
- '생동감 있는 동작' → 돌아다니기·깡충 뛰기·숨바꼭질, 패널 자리 장난, 일정 기울이기, 희귀 소품 장난, 음악에 반응하기, '움직임' 소리.
- '배경 효과' 끄기·부드럽게(자동 판정 포함) → 음악에 반응하기, 희귀 소품 장난, '움직임' 소리.
- '빅타민 효과음'·'빅타민 음량' → 라디오.
- 사이트 '축하' 소리 → 달력 악기 반응.

**이름과 실제가 다른 곳**

- 착지 "통"이 '돌보기' 묶음.
- '숨바꼭질'이 집 어지르기·장난감 꺼내기까지.
- '밥주기'가 쓰레기통까지, '집어 옮기기'가 키보드 이동까지, '걸음'이 쉬는 길이·뛰는 높이까지.
- '음악에 반응하기'가 라디오 칸에 있지만 달력 악기 반응까지.
- '움직임'이라는 이름이 세 곳(설정 창 왼쪽 묶음, 빅타민 하위 탭, 빅타민 소리 묶음)에 있고 뜻이 다 다르다.
- 성격이 '기본' 탭, '성격 바꾸기' 지름길, '함께 지내기' 세 곳에 나온다.

**켜도 변화가 없는 곳**

- 크기(숨은 값).
- '돌아다니기'가 꺼졌을 때의 깡충 뛰기·장난 5개.
- 막혀 있을 때의 미리 듣기 버튼(흐려지기만), 집의 라디오 버튼(무반응).

## 3. 개편안

### 3-1. 큰 방향

1. **탭 3겹을 2겹으로.** 환경설정 안의 하위 탭 5개를 없애고 한 쪽에 카드 4장을 놓는다.
2. **톱니로 들어오면 설정 쪽이 먼저, 집의 수첩으로 들어오면 '함께 지내기'가 먼저.** 톱니 → 빅타민, 두 번에 스위치가 보인다.
3. **전원 스위치는 네 쪽 공통 머리줄로.** 스크롤해도 붙어 있다.
4. **처음 보이는 것은 8줄.** 나머지는 '더 보기'에 접는다.
5. **성격·동물 모드·배우기는 '함께 지내기' 쪽으로.**
6. **막힌 줄은 그 자리에서 이유와 가는 길을 보여 준다**(3-4).

### 3-2. 새 묶음 구조

**빅타민 묶음 = 4쪽: 함께 지내기 · 도감 · 옷장 · 설정** (이름 '환경설정' → '설정')

**공통 머리줄**: 빅타민 전원 + 상태 한마디

**설정 쪽 — 카드 4장 + 더 보기**

| 카드(하려는 일) | 줄 |
|---|---|
| ① 소리 — "조용히 하고 싶다" | 지금 소리 상태 한 줄 · **빅타민 소리 [끔 / 만질 때만 / 전부]** · 음량 · (펼치면) 소리 들어 보기 |
| ② 라디오 | 한 줄: 라디오(켬/끔) + 지금 곡 + 재생·정지 · (펼치면) 음량 · 다음 곡 · **빅타민이 스스로 틀기** · 곡 고르기 · 출처 |
| ③ 움직임 — "가만히 있게 하고 싶다" | **움직임 [가만히 / 걷기만 / 뛰어다니기]** |
| ④ 장난 — "방해받고 싶지 않다" | **장난치기** · **패널 자리 옮기기** |
| ▸ 더 보기 (거의 안 바꾸는 것) | 걸음 · 자동 잠자기 · 다른 창 쓸 때도 놀기 · 집어 옮기기 · 쓰다듬기 · 밥주기 |

**'더 보기'와 접힌 곳의 펼침 상태는 기억하지 않는다.** 창을 다시 열면 접혀 있다. 기억하려면 새 저장값이 필요한데, 이 개편은 새 저장값을 만들지 않는다.

**함께 지내기 쪽에 더해지는 것**: 프로필 카드 안에 동물 모드와 성격(9가지 + '무작위로 되돌리기' 단추), '배운 습관' 카드 안에 배우기 스위치와 초기화.

**집의 성격 표시를 누르면**: '함께 지내기' 쪽이 열리고 성격 고르는 자리로 간다(성격이 그쪽으로 옮겨지므로).

| 빅타민 효과음 + 돌보기 + 움직임 + 발견·선물 (4개) | **빅타민 소리 3단계** (1개) | 사용자가 정하고 싶은 것은 "전혀 / 내가 건드릴 때만 / 혼자서도" 셋 중 하나. 4장 |
| 묶음별 미리 듣기 3개 | 소리 들어 보기 타일 | 지금은 묶음 대표 1개만 들림 |
| 돌아다니기 + 깡충 뛰기 (2개) | **움직임 3단계** (1개) | 깡충 뛰기는 돌아다니기 없이는 뜻이 없음 |
| 하트 콩 + 일정 기울이기 + 숨바꼭질 + 희귀 소품 장난 (4개) | **장난치기** (1개) | 하나하나 고를 까닭이 약함. "장난을 치게 둘지"가 실제 질문 |
| 패널 자리 장난 | 패널 자리 옮기기 (그대로 1개) | 화면 배치를 실제로 건드리는 유일한 장난이라 따로 남김 |
| 음악에 반응하기 | **'빅타민이 스스로 틀기'로 바꿈**(같은 저장값, 뜻을 좁힘) | 춤과 달력 악기 반응은 이 줄과 상관없이, 움직임이 허용되면 한다. 춤만 따로 끌 까닭이 약함. 못 움직이게 하려면 '가만히'. 이 줄은 "빅타민이 저절로 라디오를 트는 것"만 정한다 |
| 걸음 · 자동 잠자기 · 다른 창 · 교감 3개 | 유지하되 '더 보기'로 접음 | 서로 겹치지 않고, 꺼 둔 사람에게는 꼭 필요함(실수로 집히는 것 막기 등) |
| 크기(숨은 값) | 읽지 않음 | 아무것도 안 바꿈 |

**없애지 않은 것과 이유**

- 교감 3개(집어 옮기기·쓰다듬기·밥주기): 합치면 "쓰다듬기는 좋은데 실수로 집히는 건 싫다"를 못 한다. 없애면 꺼 둔 기기에서 쓰다듬기 소리가 되살아난다. 접어 두기만 한다.
- 자동 잠자기, 다른 창 쓸 때도 놀기: 방송하는 PC에서 실제로 갈리는 선택이라 남긴다.
- 곡 고르기: 곡별로 빼는 기능은 이전에 남기기로 정한 것이라 그대로 둔다(접힘).

### 3-4. 막힌 줄을 보여 주는 한 가지 규칙

- 줄을 흐리게 하되 **값은 그대로 두고 누를 수도 있게** 한다.
- 줄 바로 아래 작은 글로 이유 + 가는 길. 이유가 여러 겹이면 가장 바깥 것 하나만.

| 상황 | 보여 줄 말 | 가는 길 |
|---|---|---|
| 빅타민 전원 끔 | 빅타민이 쉬는 중이라 아래 설정은 켜면 적용돼요 | 머리줄 스위치 |
| '생동감 있는 동작' 끔 | 사이트의 '생동감 있는 동작'이 꺼져 있어 걷거나 뛰지 않고, 혼자 내는 소리도 쉬어요 | 움직임 설정으로 |
| '배경 효과'가 끄기·부드럽게 | 이 기기는 배경 효과가 부드럽게 맞춰져 춤과 묘기, 혼자 내는 소리를 쉬어요 | 배경 설정으로 |
| 움직임이 '가만히' | 움직임이 '가만히'라 장난을 치지 않아요 | 같은 쪽 위 카드 |
| 사이트 효과음 끔 / 음량 0 | 사이트 효과음이 꺼져 있어요 | 소리 설정으로 |
| 사이트 '축하' 끔(악기 반응만) | (따로 표시하지 않음. 소리가 없으니 반응도 없는 것이 자연스러움) | – |

'가는 길'은 그 설정이 있는 묶음으로 옮겨 가서 해당 줄을 잠깐 강조한다. 다른 곳의 스위치를 여기서 대신 켜지 않는다.

위 표의 말은 **소리 3단계를 올린 뒤**의 모습이다. 1단계에서는 그때의 실제 규칙대로 쓴다(8장의 '단계마다 안내 글' 표).

### 3-5. 미리 듣기·미리 보기

- 움직임 3단계·성격: 고르면 옆의 작은 빅타민 미리보기가 그 모습으로 한 번 움직인다(지금 성격 미리보기에 쓰는 것을 그대로).

## 4. 소리 — 따로 자세히

### 4-1. 지금: 소리 하나가 나려면 통과해야 하는 문 7개

1. 사이트 효과음이 켜져 있고 사이트 음량이 0이 아닐 것
2. 빅타민 전원이 켜져 있을 것
3. 빅타민 효과음이 켜져 있고 빅타민 음량이 0이 아닐 것
4. 그 소리가 든 묶음(돌보기 / 움직임 / 발견·선물)이 켜져 있을 것
5. ('움직임' 묶음만) '생동감 있는 동작'이 켜져 있고 '배경 효과'가 끄기·부드럽게가 아닐 것
6. 지금 이 탭을 보고 있고, 페이지를 한 번이라도 눌렀을 것
7. 너무 잦지 않을 것

### 4-2. 바꾼 뒤: 사용자가 정하는 것은 두 가지뿐

| 정하는 것 | 어디서 |
|---|---|
| 사이트 효과음(전체)과 음량 | 설정 › 소리 (지금 그대로) |
| **빅타민 소리: 끔 / 만질 때만 / 전부** + 음량 | 설정 › 빅타민 › 설정 › 소리 카드 |

- **끔**: 빅타민 소리가 전혀 안 난다.
- **만질 때만**: 내가 직접 한 일에 대한 소리만 난다. 가만히 두면 조용하다.
- **전부**: 빅타민이 혼자 놀면서 내는 소리도 난다.

**사용자가 바꾸지 않는 규칙**

- 동작을 줄였거나 배경 효과가 끄기·부드럽게인 기기에서는 **혼자 내는 소리만** 쉰다. 내가 만질 때 나는 소리는 난다.
- 다른 탭이면 쉰다. 같은 소리는 간격을 둔다(착지 소리의 0.65초 간격은 음식 떨어짐과 몸 착지가 지금처럼 하나를 같이 쓴다).

### 4-3. "내가 만질 때"와 "혼자 놀 때"를 가르는 방법

소리 이름으로는 못 가른다. 같은 소리가 양쪽에서 나기 때문이다. 그래서 **"직접 표시"** 를 쓴다.

**규칙**

1. 내가 빅타민이나 집 물건을 누르거나 집는 순간 "직접 표시"가 생긴다.
2. 그 표시는 **그 조작이 일으킨 반응**에 붙는다. 그 반응 안에서 나는 소리, 그 반응으로 생긴 낙하, 그 반응 중에 생긴 새 발견이 모두 "내가 만질 때" 소리가 된다.
3. 표시가 사는 범위는 **그 조작이 일으킨 반응 줄기 끝까지**다. 예: 흔듦 → 낙하 → 착지 → 어지럼, 쓰다듬기 → 답례, 던짐 → 낙하 → 착지, 음식 꺼냄 → 그 음식의 낙하 → 착지. 중간에 동작이 여러 번 바뀌어도 줄기가 끝날 때까지 이어진다.
4. 표시는 **조작이 만든 것마다 따로** 붙는다(그 동작, 그 물건, 이미 나가기로 정해진 그 소리). 음식 두 개를 잇따라 꺼내면 각 음식이 자기 표시를 갖는다.
5. 표시가 사라지는 때: 그 반응 줄기가 끝남, 그 줄기가 취소됨. 내가 다른 것을 눌러도 **그 누름이 실제로 취소한 줄기만** 끝난다. 이미 나가기로 정해진 소리는 뒤의 취소에 영향받지 않는다.
6. 빅타민이 스스로 고른 다음 행동에는 표시가 넘어가지 않는다.
7. 표시가 없으면 전부 "혼자 놀 때" 소리다. 표시를 붙이는 것을 빠뜨린 곳도 "혼자 놀 때"로 친다(조용한 쪽).

**소리별로 풀어 쓰면**

| 소리 | 내가 만질 때 | 혼자 놀 때 |
|---|---|---|
| 쓰다듬기 · 집으로 부르기(쿠션) · 입히기 · 벗기기 | 항상 | – |
| 들어 올리기 | 항상(내가 집을 때만 남) | – |
| 선물 | 내가 상자를 열 때 | 상자가 저절로 도착할 때 |
| 어지럼 | 내가 흔든 뒤 | 밥 먹은 뒤의 반응 |
| 놀이 | 내가 장난감을 꺼내거나 넣을 때, 내가 톡 치거나 쓰다듬은 바로 뒤의 답례 | 스스로 놀 때, **집의 씻기 버튼을 눌러 가서 씻을 때** |
| 잠들기 | 내가 재울 때 | 스스로 잘 때, **쿠션으로 불러온 뒤 쉬면서 잠들 때** |
| 밥통 | 내가 누를 때 | 빅타민이 스스로 꺼낼 때 |
| 착지 | 내가 꺼낸 음식이 떨어질 때, 내가 놓거나 던진 뒤 떨어질 때 | 스스로 뛰고 내려올 때, 모자 묘기, **쿠션으로 불러서 뛰어온 뒤**(소유자 확정) |
| 새 발견 | 내가 쓰다듬거나 같이 노는 반응 줄기 안에서 생겼을 때 | 그 밖. **처음 먹어 본 음식의 발견(첫맛)** 은 여기 |
| 밥 다 먹음 | – | 항상(내 누름과 시간이 떨어져 있음) |
| 넘어짐 | – | 항상 |

**덜 정해져 있던 상황을 이렇게 정한다** (조용한 쪽. 들어 보시고 바꿀 수 있다)

- **먹이기의 범위**: 내가 밥통을 눌러 음식이 나오고 그 음식이 바닥에 닿을 때까지가 "내가 만질 때"다. 그 뒤 빅타민이 스스로 가서 먹는 것, 밥 다 먹음, 첫맛 발견은 "혼자 놀 때"다.
- **쿠션으로 불러온 뒤**: 착지(소유자 확정)와 같은 원칙으로, 도착해서 쉬다 잠드는 소리도 "혼자 놀 때"다.
- **집의 씻기 버튼**: 누르면 빅타민이 패드까지 걸어가서 씻는다. 이때 나는 소리는 지금 '놀이' 소리다. 쿠션으로 부른 뒤와 같은 원칙으로 "혼자 놀 때"로 친다. 이렇게 하면 '움직임' 소리를 꺼 두었거나 배경 효과가 부드럽게인 기기에서 지금처럼 조용하고, **새로 나는 소리가 없다**(5-3 표에 더할 것이 없음). "내가 만질 때"로 바꾸고 싶으시면 그 기기들에서 씻는 소리가 새로 나게 되므로 따로 승인이 필요하다.
- **집어서 옮긴 뒤 놓아서 떨어질 때**: "내가 만질 때". **발판이 없어져 스스로 떨어질 때**: "혼자 놀 때".
- **한 길로 합쳐져 나가는 소리**(발견·선물·대기 중인 소리 가운데 하나가 골라져 나감): 골라진 그 소리가 가진 표시를 쓴다.

**알아 둘 것**

- 동작을 줄였거나 배경 효과가 '끄기'인 기기에서는 흔들어도 어지럼 반응 자체가 안 나오는 길이 있다. 그때는 소리도 없다. 소리 문을 풀었다고 반드시 소리가 생기는 것은 아니다.
- 일의 크기: 소리를 트는 곳은 15군데지만, 그 앞에서 "곧 낼 소리"를 정해 두는 곳이 12군데 더 있고, 행동과 발견이 한 길로 합쳐진 뒤 소리가 나는 곳도 있다. 15군데에 표시만 붙이면 끝나는 일이 아니다. 조작 → 동작 → 대기 중인 소리 → 낙하 → 발견까지 표시를 이어 넘겨야 한다.

### 4-4. 라디오

- 빅타민 소리에서 떼어 낸다. **내가 재생을 누르면**, 사이트 효과음과 라디오 스위치만 켜져 있으면 나온다. "효과음은 끄고 라디오만 듣기"가 된다.
- **빅타민이 스스로 라디오를 트는 것은 "혼자 놀 때" 소리로 친다.** 빅타민 소리가 '전부'일 때만 한다. 지금 있는 다른 조건(움직임이 허용됨, 동작 줄이기 아님, 배경 효과가 끄기·부드럽게 아님, 라디오 스위치 켬)도 그대로다.
- 지금은 '음악에 반응하기'가 꺼져 있으면 빅타민이 스스로 틀지도 않는다. 이 값을 그냥 안 읽으면 그런 기기에서 저절로 라디오가 나오게 된다. 그래서 **스스로 틀기에 한해서는 이 값을 계속 따른다**(춤과 달력 악기 반응은 확정대로 이 값과 무관하게 한다). 이 값은 라디오 칸의 접힌 곳에 '빅타민이 스스로 틀기' 한 줄로 둔다(확인 C, 소유자 확정).
- **"스스로 틀어도 되나"와 "나오는 음악에 춤춰도 되나"는 따로 판정한다.** 지금은 한 판정을 같이 쓴다. 나누지 않으면 '스스로 틀기'를 끈 기기는 내가 튼 라디오에도 춤을 안 추게 되어 확정된 것과 어긋난다. 춤 쪽 판정에는 이 값도, 소리 단계도 넣지 않는다.
- 줄 이름을 바꾸는 것, 춤·악기 반응을 이 값에서 떼는 것, 위의 판정 나누기는 **같은 단계(2-라)에서 한꺼번에** 한다. 따로 올리면 화면의 이름과 실제 뜻이 어긋나는 기간이 생긴다.
- 이렇게 하면 지금 빅타민 소리를 꺼 두어 라디오도 조용하던 기기에서, 개편 뒤에도 라디오가 저절로 나오지 않는다. 그래서 **옛 값을 옮길 필요도, 옮겼다는 표시도 없다.** (3판의 "라디오 끔으로 옮기기"는 사용자가 다시 켠 라디오를 꺼 버릴 수 있어 뺐다.)
- **반드시 멈추는 경우는 그대로**: 다른 탭, 빅타민 꺼짐, 최초공개, 모바일, 배경 감상, 준비 중 취소. 누가 틀었든 멈춘다. 돌아왔을 때 **끊긴 그 곡을 저절로 이어 틀지는 않는다**(지금과 같음). 다만 그 뒤에 빅타민이 허용된 조건 안에서 **새로 스스로 고르는 것**은 지금처럼 할 수 있다. 둘은 다른 일이다. 한 번에 한 재생도 그대로.
- **내가 켠 라디오는 빅타민이 스스로 끄지 않는다.** 지금은 내가 누른 뒤 15초가 지나면 빅타민이 끌 수 있다. 이것을 "내가 켠 재생이 이어지는 동안은 못 끈다"로 바꾼다.
- 재생 단추가 눌러지는 조건에서도 빅타민 효과음·음량 조건을 같이 뺀다(재생기만 고치면 단추가 흐린 채로 남는다).
- 소리 단계는 그때그때의 최신 값을 읽는다(소리를 바꿔도 빅타민이 멈칫하지 않는 지금 성질은 유지).

**라디오가 나오는 중에 소리 단계를 내리면**

| 누가 틀었나 | 준비 중 | 재생 중 | 곡이 끝난 뒤 |
|---|---|---|---|
| 내가 틀었다 | 그대로 진행 | 계속 나옴(단계와 무관) | 다음 곡으로 이어 들음 |
| 빅타민이 스스로 틀었다 | 취소 | **바로 멈춤** | 다음 곡 안 틈 |

- 빅타민이 튼 라디오 중에 내가 재생이나 다음 곡을 누르거나 곡을 고르면 그때부터 "내가 튼 것"이 된다. 그 뒤 곡이 끝나 넘어가도 계속 "내가 튼 것"이다.
- 반대로, 내가 튼 라디오가 나오는 중에 빅타민이 "켜기"를 시도해도 **"빅타민이 튼 것"으로 바뀌지 않는다.**
- 빅타민이 준비하던 재생을 내가 넘겨받은 뒤, 빅타민 쪽의 옛 취소가 뒤늦게 와도 내 재생을 끄지 않는다.
- **'스스로 틀기'를 재생 중에 끄면** 소리 단계를 내릴 때와 같다: 빅타민이 튼 것은 준비 중이면 취소, 재생 중이면 바로 멈춤. 내가 튼 것은 그대로.
- 빅타민이 생활 장면(잠자리 등)에서 라디오를 끄려다 "내가 튼 것"이라 거절되면, 그 장면은 끈 것으로 치지 않고 그대로 다음으로 넘어가거나 끝난다. 끌 때까지 기다리거나 되풀이해서 시도하지 않는다.
- 내렸다가 다시 '전부'로 올려도 저절로 다시 틀지 않는다. 빅타민이 다음에 스스로 고를 때까지 기다린다.
- 집의 라디오 버튼이 막혀 있을 때는 무반응 대신 설정 창의 라디오 줄을 열어 이유를 보여 준다.

### 4-5. "지금 왜 소리가 나는지 / 안 나는지" 알려 주는 방법

**소리 카드 맨 위 한 줄.** 가장 바깥 이유 하나만 보여 준다.

| 순서 | 조건 | 보여 줄 말 | 가는 길 |
|---|---|---|---|
| 1 | 사이트 효과음 끔 | 지금은 소리가 안 나요 — 사이트 효과음이 꺼져 있어요 | 소리 설정으로 |
| 2 | 사이트 음량 0 | … 사이트 음량이 0이에요 | 소리 설정으로 |
| 3 | 빅타민 전원 끔 | … 빅타민이 쉬는 중이에요 | 머리줄 |
| 4 | 빅타민 소리 '끔' | 빅타민 소리를 꺼 두셨어요 | 바로 아래 줄 |
| 5 | '만질 때만' | 내가 만질 때만 소리가 나요 | – |
| 6 | '전부'인데 동작 줄이기·배경 효과로 혼자 내는 소리가 쉼 | 지금은 내가 만질 때만 소리가 나요 — (이유) | 해당 설정으로 |
| 7 | 전부 통과 | 지금 소리가 나요 | – |

라디오 줄 아래에도 같은 방식의 한마디를 둔다. 효과음 상태와 라디오 상태는 따로 말한다. 라디오는 "내가 누르면 나오는지"와 "빅타민이 스스로 트는지"가 다른 조건이므로 두 가지를 따로 말한다(예: "누르면 나와요 · 빅타민이 스스로 틀지는 않아요 — 빅타민 소리가 '만질 때만'이에요").

**이 표는 소리 3단계를 올린 뒤의 모습이다.** 그 전(1단계)에는 그때의 규칙대로 안내한다(8장).

사이트 소리 탭 맨 아래에는 스위치 없이 길만 둔다: "빅타민 소리·라디오는 빅타민 설정에서 정해요 →".

## 5. 옛 설정 → 새 설정 대응표

**방법**: 새 저장값을 만들지 않는다. 옛 저장값을 새 뜻으로 읽고, 새 화면에서 바꾸면 옛 저장값 여러 개를 한꺼번에 맞춰 쓴다.

**섞여 있을 때의 규칙**: 조용한 쪽·얌전한 쪽.

### 5-1. 읽는 규칙과 쓰는 규칙

| 옛 설정 | 새 설정 | 읽는 규칙 | 새 화면에서 고르면 쓰는 값 |
|---|---|---|---|
| 빅타민 전원 | 같음 | 그대로 | 그대로 |
| 빅타민 효과음 + 돌보기 + 움직임 + 발견·선물 + 음량 | 빅타민 소리 3단계 + 음량 | 효과음 끔, 또는 음량 0, 또는 돌보기 끔 → **끔** / 효과음 켬·세 묶음 다 켬 → **전부** / 그 밖 → **만질 때만** | 끔 → 효과음만 끔 / 만질 때만 → 효과음 켬·돌보기 켬·움직임 끔·발견·선물 켬 / 전부 → 넷 다 켬. **켜는 쪽을 골랐는데 음량이 0이면 음량을 60으로** |
| 집 라디오 · 음량 · 곡 고르기 | 같음 | 그대로(옮김 없음) | 그대로 |
| 음악에 반응하기 | 빅타민이 스스로 틀기 | **스스로 라디오를 트는 데에만** 그대로 읽음. 춤과 달력 악기 반응에는 읽지 않음 | 그대로(같은 값을 켬/끔) |
| 돌아다니기 + 깡충 뛰기 | 움직임 3단계 | 돌아다니기 끔 → 가만히 / 돌아다니기 켬·깡충 끔 → 걷기만 / 둘 다 켬 → 뛰어다니기 | 가만히 → 돌아다니기만 끔 / 걷기만 → 돌아다니기 켬·깡충 끔 / 뛰어다니기 → 둘 다 켬 |
| 하트 콩 + 일정 기울이기 + 숨바꼭질 + 희귀 소품 장난 | 장난치기 | 넷 다 켬 → 켬. 하나라도 끔 → 끔 | 넷을 한꺼번에 켬/끔 |
| 패널 자리 장난 | 패널 자리 옮기기 | 그대로 | 그대로 |
| 걸음 · 잠 · 다른 창 · 교감 3개 · 동물 모드 · 성격 · 배우기 · 옷장 · 전등 · 집 접기 | 같음 | 그대로 | 그대로 |
| 크기(숨은 값) | (없앰) | 읽지 않음 | – |

고른 뒤 다시 읽으면 같은 단계로 읽힌다(소리 96가지, 움직임 12가지, 장난 32가지 경우 모두).

'장난치기'를 켜면 따라 켜지는 것: 하트 콩, 일정 기울이기, 일정 카드에 숨기, 집 어지르기, 장난감 스스로 꺼내기, 소품 묘기. 밥 먹기와 정리하기는 장난과 따로다.

### 5-2. 뜻이 달라지는 곳 — 조용해지거나 얌전해지는 쪽

- 돌보기 소리만 꺼 둔 기기 → 빅타민 소리 전체가 '끔'.
- 움직임이나 발견·선물 소리만 꺼 둔 기기 → '만질 때만'이 되어 혼자 내는 소리가 전부 조용해진다(스스로 꺼내는 밥통, 스스로 뛴 착지, 밥 다 먹음, 저절로 생긴 발견, 선물 도착 포함).
- 장난 넷 중 일부만 꺼 둔 기기 → 장난치기 '끔'으로 읽혀 켜 두었던 장난도 멈춘다.
- 돌아다니기를 끄고 깡충 뛰기만 켜 둔 기기 → '가만히'로 읽혀 깡충도 꺼진 것으로 움직인다. 실제로 달라지는 것은 하나: 사고뭉치를 쓰다듬었을 때의 답이 덮치기에서 킁킁으로 바뀐다. 쿠션으로 부를 때 뛰어오는 것, 던지기, 집어 옮기기는 그대로다(4단계를 만들며 확인해 적음).
- 동작을 줄였거나 배경 효과가 끄기·부드럽게인 기기 → 전에는 '돌보기'·'발견·선물' 묶음의 혼자 내는 소리(스스로 꺼낸 밥통, 스스로 뛴 착지, 밥 다 먹음, 저절로 생긴 발견, 선물 도착)가 났지만 이제 쉰다(4-2의 "혼자 내는 소리만 쉰다"를 그대로 적용한 결과. 2-나를 만들며 확인해 적음).

### 5-3. 뜻이 달라지는 곳 — 소리나 움직임이 느는 쪽 (전부)

| 옛 상태 | 개편 뒤 새로 나는 것 | 승인 여부 |
|---|---|---|
| '움직임' 소리만 꺼 둠 | 들어 올리기, 내가 흔든 뒤 어지럼 | 승인됨 |
| 〃 | 내가 재울 때의 잠들기, 내가 장난감을 꺼내거나 넣을 때의 놀이 소리, 톡 치기·쓰다듬기 뒤 답례 소리 | 승인됨(확인 A) |
| '발견·선물' 소리만 꺼 둠 | 내가 만지는 중에 생긴 새 발견, 선물 열기, 입히기, 벗기기 | 승인됨(확인 A) |
| 동작을 줄였거나 배경 효과가 끄기·부드럽게 | 들어 올리기, 내가 흔든 뒤 어지럼(반응이 나오는 경우에만) | 승인됨 |
| 〃 | 내가 재울 때의 잠들기, 내가 장난감을 꺼내거나 넣을 때의 놀이 소리, 답례 소리 | 승인됨(확인 A) |
| '음악에 반응하기' 꺼 둠 | 라디오에 맞춘 춤 | 승인됨 |
| 〃 | 달력 악기 소리에 들썩이기 | 승인됨(확인 A) |
| 빅타민 효과음을 꺼 둠 | 내가 라디오 재생을 누르면 라디오가 나옴(지금은 무반응) | 라디오 떼기로 승인됨 |

새로 나는 소리는 모두 **내가 직접 누르거나 집었을 때만** 난다. 가만히 두었는데 전에 없던 소리가 나는 경우는 없다(라디오가 저절로 나오는 경우도 없게 4-4에서 막았다). '확인 A'로 적은 줄은 3판에서 빠뜨렸다가 4판에서 따로 여쭤 승인받은 것이다(7장).

### 5-4. 옛 화면이 열려 있을 때

저장 형식은 깨지지 않는다. 하지만 **뜻은 서로 다르게 읽는다.** 일어날 수 있는 일을 그대로 적는다.

- 새 화면에서 '만질 때만' → 옛 화면에서 '움직임' 소리를 켬 → 새 화면은 '전부'로 읽는다. 혼자 내는 소리까지 켜진다. (옛 화면에서 사용자가 직접 켠 것이다.)
- 새 화면에서 '가만히' → 옛 화면에서 '돌아다니기'만 켬 → 숨어 있던 깡충 뛰기 값이 다시 살아난다.
- 옛 화면에서 장난 하나만 끔 → 새 화면은 장난치기 '끔'으로 읽는다.
- 옛 화면에서 관계없는 설정(걸음 등)을 바꾸는 것은 소리·장난 값을 망가뜨리지 않는다(실제 두 탭으로 확인됨).

### 5-5. 옛 버전으로 되돌렸을 때

| 새 화면에서 고른 것 | 옛 화면에 보이는 모습 | 실제로 달라지는 것 |
|---|---|---|
| 소리 '끔' | 빅타민 효과음 끔 | 같음(조용) |
| 소리 '전부' | 모두 켬 | 평소 기기는 같음. **동작을 줄였거나 배경 효과가 끄기·부드럽게인 기기는 양쪽으로 달라진다**: 내가 집을 때의 들어 올리기·재우기·장난감 소리가 다시 막히고, 반대로 빅타민이 스스로 내는 밥통·착지·밥 다 먹음·발견·선물 도착 소리는 다시 난다 |
| 소리 '만질 때만' | 돌보기·발견 켬, 움직임 끔 | **같지 않다.** 내가 집을 때의 들어 올리기·어지럼·재우기·장난감 소리가 꺼지고, 반대로 빅타민이 스스로 내는 밥통·착지·밥 다 먹음·발견·선물 도착 소리는 날 수 있다 |
| 장난치기 끔 | 장난 넷 다 끔 | 같음 |
| 움직임 '가만히' | 돌아다니기 끔 | 같음 |
| '스스로 틀기' 끔 | '음악에 반응하기' 끔 | 스스로 안 트는 것은 같음. **춤과 달력 악기 반응도 다시 멈춤**(옛 버전은 이 값으로 춤까지 막음) |
| '스스로 틀기' 켬 + 소리 '만질 때만' | '음악에 반응하기' 켬, 효과음 켬 | **같지 않다.** 새 버전에서는 스스로 안 틀던 기기인데, 옛 버전은 소리 단계를 모르므로 **빅타민이 다시 스스로 라디오를 틀 수 있다** |
| 라디오(내가 누른 재생) | 다시 빅타민 소리에 묶임 | 빅타민 소리가 '끔'인 기기는 눌러도 라디오가 다시 안 나옴 |
| 내가 켠 라디오 | 15초 보호만 남음 | 내가 켠 뒤 15초가 지나면 빅타민이 다시 끌 수 있음 |

'만질 때만'을 쓰는 기기는 되돌리면 소리가 눈에 띄게 달라진다(라디오가 저절로 나올 수 있는 것 포함). 되돌릴 일이 생기면 이 점을 알리고 진행한다.

### 5-6. 저장이 안 될 때

새 저장값도 옮김도 없으므로 지금 동작에서 더 나빠지는 것은 없다. 지금 동작은 이렇다.

- **쓰기만 실패**(저장 공간 부족): 바꾼 선택이 그 탭 안에서는 유지되고, 새로 열면 저장돼 있던 값으로 돌아간다.
- **읽기도 실패**: 그 탭이 기억하는 값, 없으면 기본값으로 움직인다.
- **다른 탭에서 바꿈**: 그쪽 값이 이긴다.
- 라디오 설정은 빅타민 설정과 다른 기록이다. 읽기가 되살아날 때 그 탭의 임시 선택이 사라지는 경우가 지금도 있다. 이번 개편은 라디오 기록에 아무것도 더하지 않으므로 이 동작을 바꾸지 않는다. 고치려면 별도 작업이다.

## 6. 대안이 갈리는 지점

### 갈림 1. 빅타민 소리를 몇 단계로

- B안 — 2단계: 끔 / 켬. 가장 단순하고 고칠 곳도 적다. "혼자 내는 소리만 끄기"를 못 한다. 방송 중에 이 요구가 있을 것으로 본다.
- C안 — 종류 3개 유지(2판). 줄지 않는다.

### 갈림 2. 장난을 몇 줄로

- **A안 (추천) — 2줄: 장난치기 / 패널 자리 옮기기.**
- B안 — 1줄. 패널이 움직이는 것만 싫은 사용자가 장난 전부를 꺼야 한다.
- C안 — 5줄 유지(2판). 줄지 않는다.

### 갈림 3. '음악에 맞춰 춤추기' 스위치

- **A안 (추천) — 없앰.** 못 움직이게 하려면 '가만히'로 충분하다. 대가: 꺼 둔 기기에서 춤이 되살아난다.
- B안 — '더 보기'에 남김. 뜻이 안 바뀐다. 21개가 된다.

### 갈림 4. '더 보기' 6줄을 더 줄일지

- **A안 (추천) — 6줄 그대로 접어 둠.** 처음 화면에는 안 보이므로 복잡함은 이미 없다.
- B안 — 집어 옮기기 + 쓰다듬기 → '손으로 만지기' 하나. 19개. 둘 중 하나만 꺼 둔 기기는 둘 다 꺼진 것으로 읽힌다.
- C안 — 걸음을 없애고 성격에 맡김. 18~19개. 걸음을 고른 사람의 선택이 사라진다.

### 갈림 5. 쿠션으로 불러서 뛰어올 때의 착지 소리

- **A안 (추천) — "혼자 놀 때"로.** 조용한 쪽.
- B안 — "내가 만질 때"로. 내가 부른 것이니 반응이 있어야 한다는 쪽.

## 9. 확인하지 못했거나 확신이 없는 부분

- **소리를 직접 듣지는 못했다.** 실제 스피커·방송 환경에서의 느낌도 확인하지 못했다.
- **찍은 화면은 운영 사이트가 아니다.** 로컬의 지난 빌드에 고정 자료를 넣은 화면이다.
- **새 화면은 아직 없다.** 높이는 지금 화면에서 잰 값(본문 약 626px, 그 안쪽 내용 약 584px, 전원 줄 약 68px, 탭 54px, 한 줄 64px, 접기 줄 44px)으로 어림했다.
- **"직접 표시"를 이어 넘기는 일(4-3)은 설계만 했다.** 행동이 여러 갈래로 합쳐지는 곳에서 표시를 깔끔하게 넘길 수 있는지는 2-가를 시작해 봐야 안다. 표시를 빠뜨린 길이 조용한 쪽으로 판정되는 것은 안전장치일 뿐이다. **4-3 표에 "내가 만질 때"로 정한 경우는 반드시 그렇게 나야 통과**이고, "넘기기 어려워서 혼자로 남겼다"는 완료로 치지 않는다. 정말 넘길 수 없는 경우가 나오면 멈추고 여쭌다.
- **어떤 설정을 얼마나 자주 바꾸는지는 보지 않았다.** 무엇을 '더 보기'로 접을지는 추정이다.
- **6판에서 고친 곳은 독립 검증을 받지 않았다.** 6판은 4차 검증이 요구한 수정만 반영했다. 내가 새로 정한 것은 씻기 소리의 분류("혼자") 하나이고, 조용한 쪽이라 새로 나는 소리는 없다.
- **4차 검증의 결과는 지금 코드와 설계 규칙을 맞대어 본 것이다.** 새로 만든 것 전체가 통과했다는 증거가 아니다. 옛 값 256조합에서 새 조건 때문에 더 허용되는 "저절로 트기"가 0건이라는 것은 검증 쪽이 따져 본 결과이고, 내가 다시 돌려 보지는 않았다.
- **'배경 효과' 끄기에서 걷기까지 다 멈추는지**, **역할 미리보기의 세부 차이**는 끝까지 확인하지 못했다.

**검증 기록**

- 1차(1판): 지금 상태에 대한 핵심 주장 11가지는 모두 맞음. 고치는 방법에서 여러 곳이 틀려 2판·3판으로 고침.
- 2차(3판): 판정 "고치고 진행". 소유자가 확정한 선택은 유지하고, 라디오 다시 끄는 사고, 음량 0 왕복, 직접·혼자 구분, 빠진 증가 목록, 되돌리기 설명, 착지 간격, 높이 어림, 단계별 안내를 고치라는 요구. 4판에 모두 반영.
- 3차(4판): 판정 "0·1단계는 시작 가능, 2단계 이후는 고치고 진행". 음악 반응만 꺼 둔 기기의 저절로 트기, 단계 내릴 때의 라디오, 직접 표시가 사는 범위, 내가 켠 라디오를 빅타민이 끄는 것 등을 5판에 반영.
- 4차(5판의 2단계 이후): 판정 "문서를 고치고 시작, 다시 설계할 필요 없음". 고칠 곳 일곱 가지와 표현 세 가지를 6판에 반영. 만들면서 확인할 것은 8장의 확인 표에 넣음.
- 4차 지적 가운데 내가 코드로 다시 본 것: 스스로 틀기 허락과 춤 허락이 한 판정을 같이 씀, 씻기 버튼을 누른 뒤의 소리가 '놀이' 소리로 나감, 씻기는 동작을 줄였거나 배경 효과가 '끄기'면 아예 시작하지 않음.
- 내가 코드로 다시 본 것: 동작을 줄여도 제자리 잠이 선택됨, 창 폭 1040 이하에서 빅타민이 사라짐, 발견·선물 소리가 한 길로 합쳐져 나감, 밥 먹은 뒤 반응이 어지럼 동작을 씀, 라디오 재생에 "사람이 튼 것/빅타민이 튼 것" 구분이 이미 있음.

## 부록 C. 적용할 때 조심할 기술 메모

- 저장 기록의 판 번호를 올리면 안 된다. 1이 아니면 "깨진 기록"으로 보고 **빅타민을 꺼 버린다.**
- 빅타민 설정 기록과 라디오 기록 모두, 옛 화면이 한 번 저장하면 모르는 필드가 사라진다(`normalizeCompanionPreferences`, `normalizeCompanionRadioPreferences`가 아는 필드만 골라 다시 쓴다). 그래서 **새 필드를 하나도 넣지 않는다.** 전부 기존 필드에서 계산한다.
  - 소리 단계 읽기: `!sound || soundVolume<=0 || !soundCare` → 끔 / `soundCare && soundMotion && soundKeepsakes` → 전부 / 그 밖 → 만질 때만.
  - 소리 단계 쓰기: 끔 → `sound:false` / 만질 때만 → `sound:true, soundCare:true, soundMotion:false, soundKeepsakes:true` / 전부 → 넷 다 true. 켜는 쪽인데 `soundVolume<=0`이면 `soundVolume:60`.
  - 움직임 단계: `roam`/`jump`에서 계산. '가만히'는 `roam:false`만 쓴다.
  - 장난치기: `heartPrank && cardPrank && ambientPrank && rarePrank`. 쓸 때는 넷을 같이.
  - 춤·악기 반응: `react`를 읽지 않는다. `react`는 스스로 틀기에만 읽는다(값과 필드 이름은 그대로, 화면 이름만 '빅타민이 스스로 틀기'). 지금 `react`는 `viewer-companion.tsx`의 `musicAllowed()` 한 곳에 들어 있고 `radioAllowed()`가 그것을 감싼다. 이 둘을 춤 고르기(`:2924`), 춤 이어 가기(`:2669`, `:4837` 부근), 악기 반응(`:4850`), 스스로 틀기(`:2938`의 `radioAllowed: …`)가 같이 쓴다.
- 소리 문은 묶음 이름이 아니라 "시작한 쪽"으로 판단한다. `playCompanionSound`에 시작한 쪽(직접/자율)을 넘긴다. 인자가 없으면 자율로 친다.
  - 트는 곳 15군데(`viewer-companion.tsx` 12, `companion-meadow-walk.tsx` 1, `companion-wardrobe.tsx` 2).
  - 그 앞에서 대기 소리를 정하는 곳 12군데(`pendingCue`류)와, 발견·선물이 한 길로 합쳐지는 곳(`viewer-companion.tsx`의 공통 재생 자리)에도 시작한 쪽을 같이 실어야 한다.
  - `launch(...)`로 시작하는 행동에 시작한 쪽을 싣는다. **한 행동이 끝났다고 지우지 않는다.** 그 행동이 같은 반응 줄기의 다음 행동(흔든 뒤 어지럼 `:3594` 부근, 뒤늦은 답례 `:2819` 부근)으로 이어지면 표시를 넘겨준다. 지우는 때는 4-3의 규칙 5뿐이다(줄기가 끝남, 줄기가 취소됨). 새 명령은 자기가 실제로 취소한 줄기의 표시만 지운다. 행동 정리 자리(`:3558` 부근)에서 표시를 통째로 비우면 안 된다. 음식 쪽 완료 알림(`companion-food.tsx`)에도 같은 값을 넘긴다.
  - 직접 씻기(`:2119`의 `wash` → `personality-director.ts`에서 놀이 동작으로 바뀜 → `:2478`에서 `play` 소리)는 **직접 표시를 붙이지 않는다**(4-3에서 "혼자"로 정함).
- 동작 줄이기·배경 효과(끄기·부드럽게) 문은 "자율 소리"에만 건다. 지금은 `category === "motion"`에 걸려 있다.
- 착지 소리는 이름을 나누지 않는다. `land` 하나에 시작한 쪽만 넘긴다. 쉬는 시간 0.65초도 하나를 같이 쓴다.
- 라디오(`radio-player.ts`): `allowed()`에서 `companion.sound && companion.soundVolume > 0` 조건을 뺀다. 설정 화면의 재생 단추(`studio-settings.tsx`의 `companionAudible`·`blocked`)에서도 같이 뺀다.
  - 스스로 틀기(`setCompanionRadioPlaying(true)` → `nextCompanionRadio("companion")`): 소리 단계 '전부' + 지금의 `radioAllowed()`(`viewer-companion.tsx`의 `musicAllowed()`에 `radioPreferences.react`·`effective.roam`·동작 줄이기·배경 효과 조건이 들어 있다). **판정을 둘로 나눈다.** ① 몸짓 허락(춤·악기 반응): 지금의 `musicAllowed()`에서 `react`만 뺀 것. 소리 단계도 넣지 않는다. ② 스스로 틀기 허락: ①의 조건 + `react` + 라디오 스위치·음량 + 소리 단계 '전부'. `:2938`의 `radioAllowed: …`와 자율 선택 쪽(`routine-arbiter.ts`의 `p.sound`·`:138` 부근)만 ②를 쓰고, 춤 쪽(`:2669`, `:2924`, `:4837`~`:4860`)은 ①을 쓴다. 지금의 `radioAllowed()`를 그대로 두고 `react`만 남기면 '스스로 틀기' 끔이 내가 튼 라디오의 춤까지 막는다.
  - 설정 화면의 미리 듣기(`companion-settings.tsx:109` 부근의 음량·묶음 듣기, `companion-sound.ts:61`의 `previewCompanionSound`)는 2-나에서 새 규칙으로 바꾸거나 없앤다.
  - 곡 끝(`media.onended`)은 지금 `"companion"`으로 불린다. 처음 튼 쪽을 기억해 두고, 사람이 튼 것이면 이어 듣기로 처리한다.
  - 스스로 끄기(`setCompanionRadioPlaying(false)`): 지금은 `humanPriorityUntil`(15초)만 본다. 사람이 튼 재생이 이어지는 동안은 거절하도록 바꾼다. 반드시 멈추는 경우(`allowed()`가 거짓이 되는 것)와는 따로다.
  - 소리 단계는 시작할 때 잡아 둔 값이 아니라 최신 값(`preferencesRef.current`)으로 판정한다. 소리 필드는 세계 다시 시작 대상이 아니므로(`companionWorldPreferencesKey`) 행동 선택 쪽이 옛 값을 들고 있지 않은지 확인한다.
  - 저장값·표시는 건드리지 않는다.
- 직접 표시: `launch(...)`로 시작하는 행동, 대기 소리(`pendingCue`), 음식 개체(`companion-food.tsx`의 낙하·완료 알림), 뒤늦은 답례·흔든 뒤 어지럼으로 이어지는 길에 각각 실어야 한다. 한 값을 전역으로 두지 않는다.
- 소리 설정 필드는 "세계 다시 시작" 대상에서 빠져 있다(소리를 바꿔도 빅타민이 멈칫하지 않음). 이 성질을 유지한다.
- 단추의 사용 기록 이름이 바뀌면 통계가 끊기고 빈 줄이 생긴다. 바꾸는 단계에서 바로 등록한다. 없어지는 이름: 소리 묶음 3개, 묶음 미리 듣기, 장난 4개, 깡충 뛰기, 하위 탭. **'음악 반응'은 없어지는 것이 아니라 쓰임이 바뀐다**('빅타민이 스스로 틀기'). 옛 이름으로 쌓인 기록과 뜻이 달라지므로 2-라에서 새 이름으로 등록하고 옛 이름은 옛 기록 표시용으로만 남긴다. 새로 생기는 이름: 소리 3단계, 움직임 3단계, 장난치기, 들어 보기 타일, 접기(더 보기·라디오·들어 보기), 무작위로 되돌리기.
