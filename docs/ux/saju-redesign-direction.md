- 근거: 사주 = 수 용신을 유일한 주 행동에(계획서 3a 조건부 채택, 신뢰도 중간). HCI = 지금 CTA는 비텍스트 대비

**② 방위대로 놓인 구조 — 서쪽 은백, 북쪽 물빛, 가운데는 따뜻하게**
- 무드: "물이 불을 감싼다". 콘텐츠(달력·카드)는 따뜻한 채로 두고, 테두리 구조만 식힌다.
- before→after: 좌측 태그 필터 패널 크림 → 은백 카드(`--studio-silver` #f3f5f7, 헤어라인 #d7dde5), 상단 달
  이동 셰브런 보라 → 물색(`--studio-action`), 달력 칸은 크림 유지하되 차분 모드에선 `--studio-cell` #eef2f6로 반
  단계 냉각. 팝오버·카드·태그·오늘·미정은 의미색 그대로.
- 눈 편한 테마 주의: sepia 0.1이 냉·온 차이를 눌러 은백(#f2f0eb)과 크림(#f4ead6)이 가까워진다 → **색만으로

- 근거: 사주 = 서=금(백호) 좌측, 북=수(현무) 상단, 중앙=토(계획서 2.3 북상 규칙). HCI = 시선이 콘텐츠로 모이고
  구조는 물러나는 대비(figure/ground); 좌·상 도구 배치는 현행 흐름 그대로라 학습 비용 0.

**③ 콜드 존 후퇴 — 액션바 행 자체가 사라진다** (→ 2026-09-03 출고, "배치 대개편")
- before→after: 크롬 두 행(헤더 + 액션바) → **한 행**. 태그 편집·멤버 관리·인사이트·단축키는 **서쪽 rail
  도구 카드**(아이콘+짧은 라벨 타일, 태그 필터 아래)로, 역할 배지·로그아웃은 헤더 **북동 모서리**로, 아바타
  좌/우 세그먼트는 **하단 중앙 고정 알약**(rail 안에 두면 rail과 함께 옮겨가 되돌릴 때 마우스 왕복이 화면
  폭만큼 — 중앙 고정은 어느 쪽에서든 같은 거리)으로. 달력이 액션바 높이(≈50px)를 얻는다. 접지 않는다(2026-08
  '드롭다운 접기 철회' 존중) — 위치만 방위대로(서=금=도구).
- 근거: 30일 0~2회 기능이 핫 존(달력)과 같은 채도·무게로 매일 시야에 있음. 핫 존은 세로가 곧 가치.
  사주 근거는 방위(서=도구)뿐, 나머지는 순수 HCI.

**④ 물결 레이어 — 물(수)이 흐르고 은선(금)이 날카롭게 빛난다** (→ 2026-09-03 출고)
- 편집실 배경(z:-1)에 물빛 스웰 둘 + 물결 채움 둘 + 1.25px 은선 하나가 38~62초 주기로 흐른다. 상단바
  헤어라인은 은선 + 18초에 한 번 글린트. 애플 결 = 느리고, 낮은 대비, 콘텐츠 카드는 그대로 따뜻.
- 보이는 조건: 차분한 편집실 ON ∧ 생동감 있는 동작 ON ∧ 약한 기기 아님(`data-gfx≠lite`). 소프트웨어 렌더
  실측 86→47fps라 기기 판정이 곧 안전장치.

**⑤ 설정 스위치 극성** (→ 2026-09-03 출고): "동작 줄이기(기본 OFF)" → "생동감 있는 동작(기본 ON)". 설정
넷이 전부 'ON=기본값'으로 읽힌다(토리는 설정을 거의 안 만진다 — 기본이 곧 경험).

**⑥ 금생수(金生水) 디자인 언어** (→ 2026-09-03 출고, ADR-0016 — 사용자 지시로 "따뜻한 콘텐츠 안쪽" 조항 대체)
- **일 = 금**: 편집 팝오버·읽기 카드·업 도움/기간 안내 띠·버튼·도구 타일·태그 칩·일정 카드 테두리·달 이동 링.
  헤어라인(#c9d3dd/#aeb9c7) + 윗면 광택 한 줄 + 작은 라운드(10px) + 슬레이트 글자(#263242) + 띠 글자 각인.
  "깔끔하게 처리한다"의 형태.
- **품는 것 = 수**: 페이지 바탕·포스터 표면·달력 칸·요일 머리·패널/도구 카드·상단바·힌트 바·역할 팝오버.
  물빛 유리(rgb 241 246 252 / 84%) + 큰 라운드(22px) + 낮은 대비 선(rgb 30 90 168 / 12%) + 안쪽 빛.
- **금생수**: 물 컨테이너의 가장자리는 늘 금 헤어라인, 금 요소 안엔 물빛이 담긴다(저장 = 은선 틀 + 물빛 면,
  팝오버 안 입력 칸·태그 묶음 = 옅은 물빛).
- 시청자 화면·편집실 미리보기·export도 같은 언어(기본 모습). 의미색 8종·태그색·하트·기하 불변.
- 눈 편한 필터(sepia .1·saturate .8)는 옅은 물빛을 중성으로 누른다 — 페이지 바탕은 쿨하게 남고(실측
  217,222,227) 표면·칸은 밝은 중성지가 된다. 필터 OFF면 전부 물빛. 더 짙게는 밝기를 깎아 여기서 멈춤.
- **종류 색은 금이 덮지 않는다**(토리 교정): 팝오버 윗변 액센트·손잡이 틴트(수정 보라·새 초록·업 도움 장미·
  기간 안내 하늘)와 띠 색은 그대로, 금은 은선 테두리·광택만. 헤더 순서 = 저장 상태·관리자·보여주기·로그아웃.
- 물결은 "검이불누 화이불치"(토리): 깊이 세 겹·은선 글로우·빛살 둘·가운데 스웰·상단 하늘물로 존재감을 올리되
  전부 느리고 옅게(3.5~9%, 26~84초).
- **2차(토리: "바다 말고는 차이를 못 느끼겠다")**: 원인은 눈 편한 필터의 sepia .1. 필터를 `sepia(.03)`로 내리고
  (눈 편함의 몫은 saturate·brightness가 담당) 물 토큰을 필터 뒤에도 남을 깊이로 올렸다(칸 #e3ecf7, 페이지
  #dfe9f5→#c8d8ec). 금은 브러시드 두 톤 광택 면·은화 달 이동 링·띠/카드 에나멜 오버레이로 재질이 보이게.
  시청자 화면(데스크톱·모바일 아젠다)도 같은 깊이. 규칙: **물빛은 b−r ≥ 25(필터 뒤 ≥ 12)**, 금은 두 톤 꺾임.

## 5. 한밤 물빛 포스터를 P2로 미룬 이유 (→ 2026-09-03 '물빛(mist)' 테마로 출고, 선택형)

출고 형태: `POSTER_THEMES`에 `mist` 추가(색만 — 기하·카드·태그·띠·하트 불변, 밝기 규칙 유지), 역할 배지
팝오버의 '포스터 테마' 셀렉트(소유자만, 서버 owner 검사)로 고른다. 특별한 날 빵빠레는 이 테마에서
쿨톤(🫧✨🌊). 기본값은 그대로 `none` — 토리가 골라야 바뀐다.

포스터는 시청자 화면이고 export 기하(1840 고정)·의미색 8종·하트 링·아젠다 카드가 모두 색에 얽혀 있다. 토리가

(카드·태그·띠·하트는 불변), 눈 편한 ON/OFF·1840 export·모바일 아젠다 스크린샷 회귀를 통과한 뒤 owner가
고르는 선택형.
