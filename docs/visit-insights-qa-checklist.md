# 방문 인사이트 개선 — 확인 체크리스트

작성: 2026-06-02 · 범위: **개발자 화면 전용**(개발자 인사이트 "방문" 패널 + 달력 날짜 클릭 → 일일 방문 상세)
member-insights(매니저/작업자/소유자 뷰)는 변경 없음 — 확인 불필요.

> 배포(Vercel) 후, 개발자 계정으로 들어가 아래만 눈으로 확인하면 됩니다.
> 데이터는 세션 모델 전환 이후부터 쌓이므로, 항목 일부는 방문이 좀 쌓인 뒤 확인하세요.

## A. 방문 정확도 (데이터)

- [ ] **유령 방문 0** — 주소 치고 엔터 후 로딩 중 바로 다른 앱으로 전환 → 그 방문이 안 잡힌다.
- [ ] **실제 방문 1** — 달력이 떠서 잠깐(3초+) 보면 방문 1 + 체류 초가 쌓인다.
- [ ] **스쳐감 제외(R1)** — 3초 미만으로 들어갔다 나가면 "방문 수"엔 안 잡히고 "스쳐감"에만 잡힌다.
- [ ] **재진입 여러 줄** — 봤다가 나갔다 다시 보면 일일 상세의 관리자/세션 목록에 줄이 늘어난다.
- [ ] **초 단위 체류** — 20초쯤 보고 나가면 "20초"로 표시(분 반올림 아님).

## B. 방문 패널 — 품질 요약 (상단)

- [ ] **분리 배지(R5)** — `시청자 N명 · 운영진 M명 · 세션 S회`가 보인다.
- [ ] **토글(R2)** — [시청자] / [운영진 포함] 누르면 아래 KPI 숫자가 바뀐다(본인 테스트 트래픽 포함/제외).
- [ ] **KPI(R4)** — 방문자 · 세션 · 스쳐감 · 바운스% · 평균체류 · 총체류 · 최고동접 타일이 보인다.
- [ ] **새/재방문(R12)** — 새 방문 · 재방문 타일이 보인다(이전에 본 적 있는 계정이면 재방문).
- [ ] **자동 문장(R6)** — 💡 "시청자는 주로 N시에 방문… 평균 체류 …" 류 1~3문장.
- [ ] **방문↔일정(R9)** — 💡 "방문 최다일(N일)엔 공개 일정이 있었어요/없었는데도 몰렸어요" 문장.

## C. 방문 패널 — 그래프

- [ ] **방문 막대** — 일별/주별 · 역할별/기기별 토글이 동작하고, 호버 시 분해 수치가 뜬다.
- [ ] **동접 막대** — 시간대별 막대 + 호버 시 평균/최고 + 역할 분해. 잠깐 머문 역할도 실오라기로 보인다.
- [ ] **요일×시간 히트맵(R7)** — 7행(일~토)×24열, 자주 본 칸이 진하다(시청자 기준).
- [ ] **날짜별 미니 달력(R8)** — 달력형, 방문 많은 날이 진한 초록. (표시 전용 — 클릭 동작 없음)
- [ ] **관리자 접속 세션** — 하루=한 줄 24h 타임라인, 호버 시 시작–끝·체류(초/분)·기기.

## D. 개발자 디버깅

- [ ] **데이터 건강(R11)** — `오늘 N세션 · end 미확정 X% · 평균 체류 Y` 한 줄.
      → end 미확정 %가 비정상적으로 높으면 종료 비콘(keepalive) 유실 의심.
- [ ] **최근 세션 로그(R10)** — "최근 세션 N건" 펼치면 시각·라벨·기기·체류(스쳐감 표시).
      → 관리자만 이메일로, 그 외는 역할 라벨(시청자/매니저…)로 — 일반 방문자 이메일은 안 보여야 정상.

## E. 일일 방문 상세 (달력 날짜 클릭)

- [ ] 상단에 **품질 요약 블록**(B와 동일: 배지·토글·KPI·새/재방문)이 그날 기준으로 보인다.
- [ ] **관리자 방문 기록** — 세션별 줄(시각·계정·체류 초·기기), 총 체류.
- [ ] 역할별/기기별 분해 + 시간대 동접 막대(그날).

## F. 경계/프라이버시 (중요)

- [ ] 위 모든 화면이 **개발자 계정에서만** 보인다(매니저/작업자/소유자/시청자엔 방문 데이터 노출 X).
- [ ] 최근 세션 로그·방문 기록에 **일반 시청자 이메일이 절대 안 보인다**(설정된 owner만 이메일 매칭).
- [ ] 방문↔일정 문장이 **공개 일정 유무만** 말한다(비공개/엠바고/작업자 일정 내용 노출 X).
