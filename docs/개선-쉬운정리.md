# 빅토리 일정표 개선 아이디어 — 쉬운 정리판

> 원본: `docs/hci-wide-benchmark-improvement-report.ko.md` (논문 80개 기반, 1099줄)
> 이 문서는 그걸 **코드 모르는 사람도 이해하게** 번호로 풀어 쓴 것.
>
> **쓰는 법:** 원하는 것만 `구현해줘 #10` 처럼 번호로 불러줘. 여러 개 `#10 #14 #18`도 OK.

**기호 읽는 법**
- 난이도: 🟢 쉬움(하루 안) · 🟡 보통(며칠) · 🔴 큼(새 기능급)
- 체감효과: ⭐ / ⭐⭐ / ⭐⭐⭐
- 🔒 = 보안(공개/비공개) 건드릴 수 있으니 주의
- ✅이미 됨 = 최근에 이미 구현한 것

## A. 모바일 조작감 📱

### 1. 버튼을 손가락에 맞게 키우기
- 📍 위치: 모바일 — 하트 ♥, 월이동 `‹ ›`, 비공개 토글, 편집 시트 버튼
- 지금: 일부 버튼이 작아 잘못 눌릴 수 있음
- 바꾸면: **보이는 아이콘은 작게 두되, 누르는 영역만 44~48px로 넓힘**(애플/구글 기준)
- 🟢 ⭐⭐ · 보안 무관

### 2. 자주 쓰는 버튼을 엄지 영역(하단)으로
- 📍 위치: 모바일 시청자 화면 하단
- 지금: 하단엔 월이동 `‹ ›`만
- 바꾸면:
```
┌─────────────────────────────┐
│        (일정 목록)           │
├─────────────────────────────┤
│  ♥ 관심  🔎 필터  ● 오늘  ▤  │ ← 엄지로 바로
│        ‹   5월   ›          │
└─────────────────────────────┘
```
- 🟡 ⭐⭐⭐ · 보안 무관

### 3. 편집 시트 3단계 + 키보드 가림 방지
- 📍 위치: 모바일 일정 편집창(아래에서 올라오는 시트)
- 지금: 키보드 켜면 입력창이 가려질 수 있음
- 바꾸면: 시트를 **살짝/반/전체** 3단계로 끌어올리고, 키보드 떠도 저장 버튼이 안 가려지게
- 🟡 ⭐⭐ · 보안 무관

### 4. 제스처 규칙 정리
- 📍 위치: 모바일 일정 카드
- 바꾸면: **탭=편집**, **길게누르기=정렬(오너만)**, 좌우 스와이프는 월이동과 겹치니 **카드 스와이프는 안 함**
- 🟢 ⭐ · 보안 무관

## B. 움직임 · 진동(햅틱) ✨

### 5. "장식용 움직임" 줄이고 "의미 있는 움직임"만
- 📍 위치: 전체 (제목 반짝이, 대시보드 숫자, 스티커 등)
- 지금: 계속 반짝이는 장식이 시선을 뺏을 수 있음
- 바꾸면: **꼭 필요한 곳만** 움직임 — 일정 옮긴 뒤 살짝 정착, 삭제 시 사라짐 효과, 비공개 풀릴 때 1회. 무한 반짝이는 줄임. (눈 피로↓)
- 🟡 ⭐⭐ · 보안 무관

### 6. 진동 정리 + 끄기 설정
- 📍 위치: 모바일(안드로이드)
- 지금: 안드로이드만 진동, iOS는 없음(정상) ✅이미 됨(부분)
- 바꾸면: "누를 때 / 저장 확정될 때" 2단계로 또렷하게 + **"동작·진동 줄이기" 설정** 추가
- 🟢 ⭐ · 보안 무관

## C. 편집실(웹) 작업감 💻

### 7. 버튼을 "영역별로" 묶기
- 📍 위치: 편집실 상단 버튼 줄
- 지금: 버튼이 다 평평해서 뭐가 중요한지 안 보임
- 바꾸면:
```
지금: [저장][미리보기][비공개][태그][멤버][인사이트][꾸미기][삭제]

제안: ┌─ 일정 ─┐ ┌─ 공개 ──┐ ┌─ 발행 ─┐ ┌─ 관리 ──┐    멀리→ ⚠[삭제]
      │ 저장   │ │ 비공개  │ │ 꾸미기 │ │ 태그·멤버│
      │ 미리보기│ │ 🔓잠금 │ │ 내보내기│ │ 비밀번호 │
      └───────┘ └────────┘ └───────┘ └─────────┘
```
- 🟡 ⭐⭐ · 보안 무관

### 8. 드래그로 순서 바꿀 때 더 매끄럽게
- 📍 위치: 편집실 달력(일정 끌어 옮기기)
- 바꾸면: 옮길 때 **부드러운 미끄러짐**, 떨어질 자리 **또렷한 안내선**, 저장 중인 일정에 작은 "동기화 중" 표시, 실패하면 그 일정만 원위치
- 🟡 ⭐⭐ · 보안 무관

### 9. 키보드 단축키
- 📍 위치: 편집실(PC)
- 바꾸면: `N`=새 일정, `Ctrl+S`=저장, `Del`=삭제, 방향키=날짜이동, `Esc`=닫기 (입력 중엔 비활성)
- 🟢 ⭐⭐ · 보안 무관

## D. 저장 신뢰 — "분명 바꿨는데 안 됨" 방지 💾  *(가성비 1등)*

### 10. 저장 상태를 항상 보여주기
- 📍 위치: 편집실 상단
- 지금: 저장 눌러도 됐는지 불확실
- 바꾸면:
```
지금: ✨ 빅토리 일정표              [ 저장 ]

제안: ✨ 빅토리 일정표   ● 저장됨 · 21:34 KST
     상태칩: ○저장 안 됨  ◐저장 중…  ●저장됨  ⚠저장 실패
```
- 🟡 ⭐⭐⭐ · 보안 무관

### 11. 경고는 위험할 때만 (남발 금지)
- 📍 위치: 화면 나가기 / 내보내기 직전
- 지금/문제: 경고가 너무 자주 뜨면 사람들이 무시함(논문 근거)
- 바꾸면: **안 저장된 채 나갈 때만** 경고 + 버튼 문구 또렷하게(`저장 후 나가기` / `저장 안 하고 나가기` / `계속 편집`). "확인/닫기" 같은 모호한 말 금지
- 🟡 ⭐⭐ · 보안 무관

### 12. 저장 실패는 조용히 사라지면 안 됨
- 📍 위치: 모든 편집
- 바꾸면: 실패는 **사라지는 토스트 X → 계속 떠 있는 빨강 배너** + `다시 시도` / `내용 복사`
- 🟡 ⭐⭐ · 보안 무관

### 13. 동시 수정 충돌 보호
- 📍 위치: 오너·워커가 같은 일정 동시 편집
- 바꾸면: 남이 먼저 바꿨으면 **덮어쓰기 막고 차이 보여주기**
- 🔴 ⭐ · 보안 무관 (서버 버전 검사 필요)

## E. 인사이트(통계) 📊

### 14. 첫 화면을 "한눈 요약"으로
- 📍 위치: 인사이트 대시보드 첫 패널
- 지금: 여러 그래프 패널을 넘겨봐야 함
- 바꾸면: 첫 화면에 **다음 방송 / 이번 달 공개 수 / 쉬는 날 / 인기 일정 / 방문 피크 / 보안경고**를 한 장에
- 🟡 ⭐⭐⭐ · 🔒(개발자/오너 전용 데이터 섞이지 않게)

### 15. 그래프마다 "결론 → 근거 → 다음행동"
- 📍 위치: 인사이트 각 패널
- 바꾸면:
```
지금: 금 23% ▇▇▇ (그래프만)

제안: 📈 금요일 방문이 제일 높아요        ← 결론
      최근 6개월 +23%, 20~22시 집중      ← 근거
      [ 이 시간을 다음 공지로 표시 ]      ← 행동(버튼)
```
- 🟡 ⭐⭐ · 보안 무관

### 16. 그래프 제목을 "메시지"로
- 📍 위치: 인사이트 차트 제목
- 바꾸면: "6개월 추이" → **"금요일 방문 집중"** 처럼 결론형 제목
- 🟢 ⭐ · 보안 무관

### 17. 색맹/색약 대응
- 📍 위치: 인사이트 차트
- 바꾸면: **색만으로 구분 금지** — 패턴/라벨/툴팁 같이. 데이터 표로도 볼 수 있게
- 🟡 ⭐ · 보안 무관

## F. 시청자 몰입감 — "일정 보는 중"이 아니라 "다음 방송 같이 기다리는 중" 🔥

### 18. 살아있는 일정표 (다음 방송 카드)
- 📍 위치: 시청자 화면 상단
- 바꾸면: **다음 방송까지 KST 카운트다운** + 라이브/휴방/변경됨 상태 + 카드 은은한 숨쉬기 (움직임 끄기 설정 존중)
- 🟡 ⭐⭐⭐ · 🔒(공개 일정만)

### 19. 스트리머 한마디
- 📍 위치: 일정 카드
- 바꾸면: 오너가 "이 날은 오래 기다린 합방!" 같은 **짧은 멘트**를 붙임 (공개로 지정한 것만 노출)
- 🟢 ⭐⭐ · 🔒(공개 지정한 텍스트만)

### 20. 함께 기다리는 신호 (익명 집계만)
- 📍 위치: 시청자 화면
- 바꾸면: "곧 시작 / 최근 변경됨 / 이번 주 하이라이트 / 팬들이 기다리는 일정" — **개인 이름 없이 숫자·분위기만**
- 🟡 ⭐⭐ · 🔒(반드시 익명 집계, 비공개 일정엔 표시 금지)

### 21. 편집 권한 없이 시청자 개인화
- 📍 위치: 시청자 화면
- 바꾸면: 즐겨찾기 ♥(이미 있음) + **로컬 알림 / 내 하이라이트 색 / 글자 크기(밀도) / 캘린더 구독(.ics)**
- 🟡 ⭐⭐ · 🔒(.ics에 비공개 절대 포함 금지)

### 22. 레이어 목록

- 바꾸면: 스티커/글자를 **목록으로 (이름·숨김·잠금·순서)** 관리. "한 칸 위/아래로" 이동

### 25. 스티커 조작감

## H. 눈 피로 · 접근성 👀

### 29. 비공개 모드 불안 줄이기
