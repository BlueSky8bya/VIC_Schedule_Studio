## ① 저장 상태 칩 (편집실 헤더)

- [ ] 편집실 들어가면 헤더 오른쪽(관리자 옆)에 **`● 저장됨`** 칩이 보인다.
- [ ] 일정 하나 만들거나 수정 → 잠깐 **`◐ 저장 중…`**(호박색, 점 깜빡) 떴다가
- [ ] 곧 **`● 저장됨 · HH:MM`** 으로 바뀐다(초록 점).
- [ ] 그 시각이 **지금 한국시간(KST)** 과 맞다.
- [ ] 태그만 바꿔도(저장 누름 없이) 칩이 저장 중→저장됨으로 반응한다.
- [ ] **모바일**에서도 헤더에 칩이 안 깨지고 들어간다(시각은 생략되고 점+글자만).
- [ ] (선택·어려우면 skip) 인터넷 잠깐 끊고 저장 → **`⚠ 저장 실패`** 빨갛게 뜨고, 편집창에도 경고가 사라지지 않고 남는다.

> 기대: "지금 저장됐나?" 를 항상 헤더 점 색으로 알 수 있음.

## ② 미정(아직 확정 아님)

### 켜고 끄기
- [ ] 일정 편집창 열면 **`🕗 미정 — 아직 확정 아님`** 토글이 보인다(공개 범위 아래쪽).
- [ ] 토글 **켜고 저장** → 그 일정 카드가 **점선 테두리** + 제목 앞 **「미정」 칩** 으로 바뀐다.
- [ ] 토글 **끄고 저장** → 다시 **실선** + 칩이 사라진다.
- [ ] **PC·모바일** 둘 다 편집창에 토글이 있고 동작한다.

### 어디에 보이나
- [ ] **편집실 달력**에서 미정 카드가 점선+칩으로 보인다.
- [ ] **시청자 화면 미리보기**에서도 미정 일정에 「미정」이 보인다(시청자도 봄 — 이게 목적).
- [ ] **모바일 목록(아젠다)** 에서도 제목 앞에 「미정」이 보인다.
- [ ] 다음 달/이전 달로 넘겼다 와도 미정 표시가 유지된다.
- [ ] 새로고침해도 미정이 유지된다(DB에 저장됨).

### 🔒 경계 확인 (중요)
- [ ] **비공개(엠바고/작업자) 일정**은 미정이든 아니든 **시청자 화면엔 아예 안 보인다**(미정이라고 비공개가 새면 안 됨).
- [ ] 미정 칩이 보여도 **비공개 일정의 제목/내용은 시청자에게 노출되지 않는다**.

> 기대: "이 방송 아직 확정 아님"을 팬들에게 솔직하게 알리되, 비공개 정보는 안 샘.
