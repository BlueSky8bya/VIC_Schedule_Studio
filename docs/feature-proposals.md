- 꾸미기 단축키 안내 박스(`#8`) 상시 표시.
- 업 도움 기간: 빠른 칩(당일/2일/3일/5일/1주/2주) + 직접 날짜 + 기간 요약.
- 태그/멤버 관리 팝업 디자인 리프레시(헤더 그라데이션·카드형 행·역할 배지).
- DB: `0010`(텍스트·효과) `0011`(하트) `0012`(테마) `0013`(글꼴) 적용.

> 우리 제품 맥락: 스트리머(빅토리) 일정 보드. 모두 로그인 → 시청자는 공개 포스터, 소유자/스태프는 편집실. 귀엽고 포스터다운 + 공유(캡쳐) 중심. 비공개 레이어·경계 규칙은 절대 불변.

## A. 기존 기능·디자인 개선안

### A-1. "다음 방송까지" 카운트다운 / D-day (★ 강력 추천)
- **왜**: 카운트다운은 캘린더 참여의 핵심 동기. 시청자가 "다음 방송이 언제지?"를 0초 만에 알게 됨.
- **어떻게**: 포스터 상단/메모 옆에 "다음 방송: 픽크타 D-2 · 토 20:00" 카드. 가장 가까운 미래 공개 일정 자동 계산. 실시간 갱신.
- **난이도**: 낮음 · **영향**: 높음

### A-2. 범례·태그 인터랙션 (필터/하이라이트)
- **왜**: 색만 보고 못 찾을 때, 범례 클릭으로 해당 태그 일정만 강조하면 스캔성↑.
- **어떻게**: "색상 안내"의 항목 클릭 → 그 태그 일정만 진하게/나머지 흐리게(토글). 시청자/편집실 공통.
- **난이도**: 낮음 · **영향**: 중

### A-3. 보기 전환 (월 / 주 / 리스트)
- **왜**: 캘린더 UX 기본. 모바일·"이번 주만" 보고 싶은 시청자에게 유용.
- **어떻게**: 상단 토글. 리스트뷰는 공유·모바일에 특히 강함("이번 주 방송" 요약).
- **난이도**: 중 · **영향**: 중~높음

### A-4. 오늘로 점프 + 월 전환 모션
- **어떻게**: "오늘" 버튼(현재 월로 이동·오늘 칸 펄스), 월 넘길 때 좌우 슬라이드 트랜지션(절제된 모션). 
- **난이도**: 낮음 · **영향**: 중

### A-5. 다크 모드 / 테마
- **왜**: 접근성·취향. 방송 중 화면 공유 시 눈부심↓.
- **어떻게**: 디자인 토큰이 이미 정리돼 있어 `prefers-color-scheme` + 토글로 비교적 수월.
- **난이도**: 중 · **영향**: 중

### A-6. 일정 상세 툴팁/팝오버
- **어떻게**: 칸의 일정에 hover/탭 → 시간·태그·메모(공개분) 팝오버. 칸 안 글자 잘림 보완.
- **난이도**: 낮음 · **영향**: 중

## B. 신규 기능 제안 — 시청자 몰입·재미

### B-1. 데뷔 D+ · 기념일 축하 연출 (★)
- **왜**: 이미 "데뷔 N주년 / D+100" 표기 로직이 있음. 여기에 **연출**을 더하면 "성취의 순간" = 재미·공유 유발.
- **어떻게**: 기념일 당일 포스터에 컨페티/반짝 애니메이션(1회, 절제), "축하 카드" 공유 버튼.
- **난이도**: 낮음 · **영향**: 중(감성·공유)

### B-2. 시청자 반응(이모지) — 공개 일정에 하트
- **왜**: 가벼운 참여로 몰입↑. (편집은 여전히 불가 — 반응은 별도 가벼운 상호작용)
- **어떻게**: 공개 일정 카드에 ❤️ 카운트(로그인 시 1인 1회). 집계만 공개, 개인정보 X.
- **주의**: 데이터 경계 — 반응은 공개 일정에만, 비공개엔 불가.
- **난이도**: 중 · **영향**: 높음(참여)

### B-3. 방송 알림 (웹 푸시 / 캘린더 내보내기)
- **왜**: "시작 전 알림"은 캘린더 핵심 가치.
- **어떻게**: ① 일정별 "내 캘린더에 추가"(.ics 다운로드 — 가장 쉬움·안전). ② 추후 웹푸시 구독.
- **난이도**: .ics 낮음 / 푸시 높음 · **영향**: 높음

### B-4. "이번 주 방송" 공유 카드 (OG 이미지)
- **왜**: 스트리머 스케줄의 본질 = SNS 공유. 캡쳐 외에 **자동 생성 공유 카드**.
- **어떻게**: 주간 요약을 세로 카드 PNG로 자동 렌더(이미 Playwright 포스터 캡쳐 인프라 있음). 트위터/디스코드 미리보기용 OG 메타.
- **난이도**: 중 · **영향**: 높음(유입)

### B-5. 출석/응원 스트릭 (가벼운 게임화)
- **왜**: 스트릭은 일일 재방문을 크게 올림(7일+ 시 2.3배). 단, **시청자용 가벼운 형태**로.
- **어떻게**: "오늘 일정 확인" 도장/연속 방문 스트릭(시청자 개인). 과하지 않게, 끄기 가능.
- **난이도**: 중 · **영향**: 중(리텐션)
- **주의**: 과한 게임화는 포스터의 차분함을 해칠 수 있음 → 옵션/은은하게.

### B-6. 응원 캠페인(업도움) 강화
- **어떻게**: 진행 게이지·목표·"도우러 가기" 클릭 수(공개 집계). 이미 있는 업도움 카드를 더 명확한 콜투액션으로.
- **난이도**: 중 · **영향**: 중

## C. 꾸미기(데코) 모드 고도화 — Canva/Figma식

> 현재: 이모지/업로드 스티커 배치·크기·회전·대칭·투명도, 드래그앤드롭 업로드, 버튼 충돌 방지, Delete 삭제. 여기에 "에디터다움"을 더한다.

### C-1. 스마트 정렬 가이드 + 스냅 (★ 강력 추천)
- **왜**: Canva/Figma의 시그니처. 드래그 시 핑크 라인으로 중앙·가장자리·다른 스티커와 정렬을 즉시 안내 → "깔끔하게" 놓임.
- **어떻게**: 드래그 중 다른 스티커/캔버스 중앙선과 좌표가 가까우면 가이드 라인 표시 + 스냅. Ctrl로 일시 해제.
- **난이도**: 중 · **영향**: 높음(완성도 체감 큼)

### C-2. 실행취소 / 다시실행 (Undo/Redo, Ctrl+Z/Y) (★)
- **왜**: 에디터의 기본 기대치. 실수해도 안심하고 꾸미게 함.
- **어떻게**: 스티커 상태 스택(추가/이동/삭제/크기 등) 히스토리. 상단에 ↺↻ 버튼 + 단축키.
- **난이도**: 중 · **영향**: 높음(안심·완성도)

### C-3. 다중 선택 + 그룹 이동/정렬
- **왜**: 여러 스티커를 한 번에 옮기고 정렬. (Figma 다중편집)
- **어떻게**: Shift+클릭/드래그 박스 선택 → 함께 이동·크기·삭제, 정렬(왼쪽/가운데/분배).
- **난이도**: 중~높음 · **영향**: 중

### C-4. 레이어 순서 조절 (앞으로/뒤로)
- **왜**: 스티커가 겹칠 때 앞뒤 정리. (z-index는 이미 있음 → UI만)
- **어떻게**: 선택 패널에 "맨 앞 / 앞으로 / 뒤로 / 맨 뒤" 버튼.
- **난이도**: 낮음 · **영향**: 중

### C-5. 키보드 조작 + 복제
- **어떻게**: 선택 후 화살표=미세 이동, Shift+화살표=크게, **Ctrl+D=복제**, Delete=삭제(이미 됨).
- **난이도**: 낮음 · **영향**: 중

### C-6. 텍스트 스티커 (귀여운 글자)
- **왜**: 스트리머 포스터엔 "이번주 빡세게!" 같은 손글씨/말풍선 텍스트가 자주 쓰임.
- **어떻게**: 텍스트 추가 → 귀여운 폰트·색·외곽선 프리셋. 스티커처럼 배치/회전.
- **난이도**: 중 · **영향**: 높음(표현력)

### C-7. 스티커 스타일 효과
- **어떻게**: 선택 스티커에 그림자/흰 테두리(다이컷 느낌)/색조·채도 슬라이더. 작은 토글로.
- **난이도**: 중 · **영향**: 중

### C-8. 움직이는 스티커(절제된 애니메이션)
- **왜**: 살짝 흔들/반짝이는 스티커는 "재미"를 주지만, 포스터 캡쳐(PNG)에는 정지 상태로 들어가야 함.
- **어떻게**: 화면 미리보기에서만 미세 애니메이션(둥실/반짝), 캡쳐 시 정지. GIF 스티커 지원도 옵션.
- **난이도**: 중 · **영향**: 중(재미)

### C-9. 테마 꾸미기 프리셋 / 시즌 팩
- **왜**: "한 번에 예쁘게". 크리스마스·핼러윈·벚꽃 등 스티커+배경 세트.
- **어떻게**: 큐레이션된 스티커 묶음 + 배경 패턴/그라데이션 적용 버튼.
- **난이도**: 중 · **영향**: 높음(첫인상)

### C-10. 배경 꾸미기
- **어떻게**: 포스터 배경에 은은한 패턴/그라데이션/스티커 타일 선택(현재 흰 종이 → 테마 배경).
- **난이도**: 낮음~중 · **영향**: 중

### C-11. 조작감(촉감) 디테일
- **어떻게**: 잡으면 살짝 커지는 스프링 + 그림자 진해짐, 놓을 때 가벼운 바운스(절제). 모션 최소화 선호 시 끔.
- **난이도**: 낮음 · **영향**: 중(품질 체감)
