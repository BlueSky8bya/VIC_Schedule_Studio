# 소나무 2차 반려본

이 폴더에 2차 반려본 21장과 덮어쓰기 사고로 보존한 `-1` 교체본 3장, 총 24개 PNG를 보관한다. 원래 이름과 바이트를 유지했다. `-1` 세 장은 최초 합격 원본이 아니다.

[상세 반려 사유·당시 수치](review.json)를 그림과 함께 읽는다. [이관 기록](../../../../이관기록/20260909-entity-layout.json)에 옛 위치와 원본 해시가 남아 있다.

폴더 한글화로 이관 기록 링크를 갱신했다. [이관 전 원문](원문-README.md)은 당시 경로와 바이트를 보존한다.
