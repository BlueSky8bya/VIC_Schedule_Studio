# 엔티티별 아트 작업실

엔티티 하나의 프롬프트·참고·반려·생성 원본·검토를 같은 곳에서 찾는다. [한글 폴더 ↔ 내부 ID 목록](목록.md)에서 한글 이름으로 찾고 실제 폴더 경로와 파일 계획을 확인한다. `npm run art:catalog -- --all`로 표를 갱신한다. 파일 규격은 manifest, 저장 규칙은 [AGENTS](AGENTS.md), 명령은 [ART_PIPELINE](../docs/ambient/ART_PIPELINE.md), 현재 작업은 [CURRENT_STATE](../docs/agent/CURRENT_STATE.md)가 맡는다.

목록의 범주는 프로젝트 아트 분류다. 표시 이름은 manifest·도감, 실제 폴더 이름은 [폴더명.json](폴더명.json)에서 관리한다. 이름이 같은 대상도 범주와 내부 ID로 구별한다. 폴더명 설정을 바꿀 때는 실제 이관과 새 기록이 함께 필요하다.

## 폴더 역할

```text
<한글 범주>/<한글 엔티티>/
  프롬프트.md                       # 생성된 진입점: 전체 파일 계획 + 현재 run
  레퍼런스/                         # 분류한 외부 영감 후보 + 원래 sidecar
  반려본/<과거-batch>/               # 반려 이미지·이유·출처
  생성본/<variant>/<계절-or-공통>/   # 정본 파일명으로 보존한 legacy 이미지
  검토/README.md                    # run의 평평한 납품 폴더·검사·시트 링크
  작업회차/<회차>/                  # 고정 의뢰·입력·원본·정리본·판정
공통화풍참고/                        # 전체 분위기·색감·구도·카메라 참고
```

탐색기로 전체 대상을 훑고 참고를 미리 넣을 수 있도록, 전체 엔티티의 `프롬프트.md`와 레퍼런스·반려본·생성본·검토 기본 폴더를 먼저 준비한다. 현재 207개 자리를 193개 작업 엔티티로 묶는다. 해변 장식용 `starfish`와 도감용 `animal-starfish`는 `동물/불가사리` 한 작업실에서 관리한다. 전체 엔티티·자리·파일 수는 생성된 목록에서 계산한다. 준비 명령은 `npm run art:catalog -- --all`, 전체 진입점 검사는 `npm run art:catalog -- --all --check`다.

변형·계절 하위 폴더와 run은 실제 자료·요청이 필요할 때 만든다. 계절은 파일 수에 곱하지 않는다. 여러 계절에 쓰는 한 PNG는 공통에 한 번 보관하고, 계절별로 따로 정의된 자리는 해당 계절에 놓는다. 정확한 대응은 엔티티 프롬프트의 파일 표를 따른다.

새 납품은 run의 `원본/`에 정확한 이름으로 들어간다. 별도 정규화·검사와 실제 소유자 검토 뒤 `promote`를 사용한다. public에 먼저 넣고 옛 `art:normalize`를 실행하는 절차는 철회됐다. [public/ambient/art](../public/ambient/art/)는 화면에 제공하는 정리본이며, 엔티티 원본 보관처와 역할이 다르다.

## 참고와 이력

엔티티의 레퍼런스 직하에 놓인 외부 그림은 **대상의 생김새·구조·생태를 확인해 연결한 영감 후보**다. [공통 화풍 참고](공통화풍참고/README.md)는 전체 분위기·색감·구도·카메라만 맡는다. 둘 다 [합격본 시트](../docs/ambient/reference/README.md)가 정한 우리 화풍보다 우선하지 않으며, 작업회차의 고정 입력에 기록되지 않은 자료는 자동 전달된 것으로 보지 않는다.

저품질 공용 후보 93장과 엔티티 후보 10장은 사용자 지시에 따라 해시 백업 후 제거했다. 기록은 [참고 자료 정리](이관기록/20260909-reference-cleanup.json)에 있다. 과거 루트 PNG와 incoming 폴더는 사용자가 승인한 이관으로 엔티티에 모았다. 당시 대응은 [기존 이관 기록](이관기록/20260909-entity-layout.json)에 보존한다. 이후 영어 폴더 223개를 한글화했으며, 기존 요청·입력·반려·출처 기록은 바이트를 유지하고 경로만 바꿨다. 현재 전후 경로는 [한글 폴더 이관 기록](이관기록/20260909-korean-folders.json), 백업·검증은 [한글화 결과](../docs/agent/handoffs/20260909-korean-art-folders.md)에 있다. 기존 요청서에 남은 영어 경로는 엔티티 프롬프트의 현재 납품·고정입력 링크로 찾아간다.

한글 이관 검사: `node scripts/ambient-art-folder-migrate.mjs check`. 내부 ID와 PNG 파일명은 유지하며, 새 작업 회차 이름은 한글·숫자를 사용한다.

카탈로그가 만드는 프롬프트와 하위 README는 직접 편집하지 않는다. 수기 메모·판정은 별도 파일에 쓴다. `.scratch-pw/`는 추적되지 않으므로 전달·재현의 유일한 보관처로 쓰지 않는다.

## 원본 계보의 한계

보존된 legacy 파일은 최초 생성 원본이나 합격본과의 계보가 입증되지 않았을 수 있다. public에 같은 이름이 있다는 이유로 승인된 원본이라 부르지 않는다.

2026-09-09 확인: 보존된 `sun-disc-2.png`는 448×448이다. 합격 소나무 `tree-pine-1`, `tree-pine-autumn-1`, `tree-pine-winter-1`의 최초 생성 원본은 없다. public과 run baseline은 정규화된 합격 참고이며, 반려 이력의 같은 이름 세 장은 240×432이고 합격본과 해시도 다르다. 이를 복구 원본으로 대체 표시하지 않는다.
