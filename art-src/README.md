# `art-src/` — 코덱스가 보낸 **원본 그대로**

여기 있는 것은 생성기가 내놓은 1024px 원본이다. 화면이 쓰는 것은 `public/ambient/art/`의
축소본이고, 이 폴더는 **그 축소본을 다시 만들 수 있게 하는 유일한 근거**다.

## 왜 저장소 안에 두나

1. **정규화는 되돌릴 수 없다.** `npm run art:normalize`가 자리 상자에 맞춰 정수배로 줄이면 정보가
   사라진다. 자리의 격자·상자·비율이 바뀌면 축소본에서 도트를 되살릴 방법이 없다 — 원본이 있어야
   다시 줄인다. (참나무 4장이 실제로 그 상태였다: lanczos3 시절 산물이라 재정규화로도 도트가 안
   돌아왔고, 코덱스에 재생성을 부탁해야 했다.)
2. **`.scratch-pw/`는 다른 PC로 건너가지 않는다.** 추적하지 않는 폴더라 세션·기기가 바뀌면 사라진다.
   2026-09-08 이전까지 원본이 거기 있었다.
3. 30장 252KB. 화면에 서빙되지 않는다(`public/` 밖).

## 규칙

- `art:normalize`가 `public/ambient/art/`의 파일을 덮어쓰기 **전에** 들어온 원본을 여기 복사한다
  (`keepSource`, `scripts/ambient-art-normalize.mjs`). 손으로 넣을 일은 없다.
- **여기 있는 파일은 지우지 않는다.** 자리를 접을 때에만 함께 지운다.
- 이 폴더의 그림을 코드가 읽지 않는다. 읽으면 안 된다 — 화면이 쓰는 것은 축소본뿐이다.

## 지금 없는 것(2026-09-08)

`tree-pine-1` · `tree-pine-autumn-1` · `tree-pine-winter-1` **세 장의 원본이 없다.** `keepSource`가
생기기 전에 배달돼 정규화됐다. 소나무 자리의 상자·격자를 바꾸면 코덱스에 재생성을 부탁해야 한다
(저장본에서는 도트가 안 돌아온다). 그 뒤 배달분부터는 자동으로 여기 쌓인다.
