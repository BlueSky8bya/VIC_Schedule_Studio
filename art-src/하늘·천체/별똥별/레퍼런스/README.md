공통 화풍 참고: [공통화풍참고](<../../../공통화풍참고>)는 소유자의 게임 캡처를 색인한 별도 자료다. 대상 형태의 근거나 합격 화풍이 아니며, 색인에서 고른 사본만 request가 고정입력/화풍참고/에 넣는다(ART-14). 현재 request.inputs 목록 밖 참고는 고정 입력으로 간주하지 않는다. 고정 입력이나 요청 해시를 수작업으로 바꾸지 않는다.
