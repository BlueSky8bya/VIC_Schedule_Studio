# 엔티티 폴더 이관 기록

[20260909-entity-layout.json](20260909-entity-layout.json)은 이동 전에 만든 source → target · SHA-256 · 크기 목록과 실행 결과다. 105개 파일(보존 원본 40 PNG, 소나무 반려 45 PNG, 외부 영감 후보 10장과 출처 sidecar 10개)을 이동했다. 별도 244개 파일은 경로와 바이트를 보호했다. public, 기존 run, manifest 계약, 남겨 둔 참고 이미지·sidecar가 여기에 포함된다.

기존 이미지와 출처 JSON은 다시 인코딩하거나 고치지 않았다. `생성본/`에 이관한 40장은 과거 보관 원본이며, 위치나 public 대응 파일만으로 해당 바이트의 소유자 승인 계보를 입증하지 않는다. `sun-disc-2.png`는 448×448이다. 소나무 2차 묶음의 `-1` 세 장은 240×432 반려 교체본이며, 유실된 최초 합격 원본이 아니다.

외부 참고는 대상 형태를 확인한 10장만 엔티티로 옮겼다. 화풍·종 일치·소유자 선별 완료를 뜻하지 않는다. 각 항목의 reason/confidence를 읽는다. 모호한 얼굴 아이콘·다람쥐 종, 버섯 캐릭터 등 나머지 93장은 기존 범주 공용 후보로 보존했다. 중복 파일도 자동 삭제하지 않았다.

```sh
npm run art:migrate -- check
```

이 명령은 기록된 모든 이동 결과와 보호 파일을 읽기만 하며 검사한다. 완료된 receipt를 고쳐서 검사 실패를 숨기지 않는다. 향후 의도적인 public 변경도 당시 보호 해시와 다르므로 이 역사 검사는 실패할 수 있다. 그때는 새 작업의 기록으로 변경을 설명한다.

실패 중단 시 receipt의 status/recovery를 먼저 읽는다. 자동 복구는 이번 호출이 생성했고 해시가 일치하는 파일만 되돌린다. 부분 파일이나 바뀐 바이트는 보존하며 `recovery-required`로 표시한다. 수동 복구도 source/target/sha256의 정확한 파일만 다룬다.
