# 데이브 더 다이버 — 공통화풍 원칙

186장을 대조 시트로 전부 열어 보고(2026-09-10) 반복 요소를 적었다. 외부 작품의 자산을 복제하라는 지시가 아니다. [합격 화풍](../../../docs/ambient/reference/README.md), [ART_RULES](../../../docs/ambient/ART_RULES.md)가 항상 우선한다.

## 목표 인상

바다 생물이 **옆모습 한 덩어리**로 읽힌다. 배경 없이 투명한 판 위에 놓여도 어떤 물고기인지 1초 안에 알 수 있고, 색은 실제 종의 온도를 따르되 어두운 물속에서 튀지 않는다.

## 적용 원칙

| 항목 | 관찰한 것 | 우리 픽셀아트로 옮기는 방법 |
|---|---|---|
| 실루엣 | 몸통·꼬리·큰 지느러미 세 덩어리가 먼저 읽히고, 잔지느러미는 실루엣을 깨지 않는 두께로 붙는다 | 도감 `side`·`shadow` 자리는 이 세 덩어리부터 잡는다. 128px에서 종이 구분되게 꼬리 갈래·머리 비율을 과장한다 |
| 카메라 | 어류는 정확한 옆모습, 거북·가오리·게는 위에서, 해파리·오징어는 정면 | manifest의 `view`가 우선한다. 위에서 본 판은 `flat`/`shadow` 자리의 발상에만 쓴다 |
| 색 | 종당 주색 1 + 배 밝은색 1 + 그늘 1~2 + 강조(지느러미·눈) 1. 심해 생물은 채도를 낮추고 발광점 하나만 밝다 | 물체당 6–10색, 같은 계열의 어두운 외곽선. 빨강·주황은 산호초 어종의 작은 강조로만 |
| 명암 | 등은 어둡고 배는 밝은 두 단 + 지느러미 반투명 한 단. 매끈한 그라데이션 없음 | 3–5단 명도 덩어리. 안티앨리어싱 금지 |
| 도트 밀도 | 원본은 128~256칸의 잔도트로 비늘·줄무늬까지 그린다 | **따라 하지 않는다.** 우리 자리는 16·32·64칸이다. 덩어리와 색 온도만 가져오고 비늘·줄무늬는 두세 덩이로 줄인다 |
| 심해 | 배경이 없어도 채도·명도만으로 "깊다"가 읽힌다: 청회색·검보라·연분홍 반투명 | `deep-sea` 태그 항목은 심해 자리의 색 온도 참고로만 붙인다 |

## 가져오지 않는 요소

- 게임 UI·캐릭터·배·장비 등 고유 디자인(장면 2장의 `has-character` 표시)
- 원본의 잔도트 밀도와 비늘 묘사
- 굵은 도트 아이콘 9장의 어법(다른 해상도 체계다 — `icon-chunky`로 표시해 뒤로 보낸다)
- 특정 종의 정확한 무늬를 옮겨 그리는 것. 형태 발상은 엔티티 `레퍼런스/`의 CC0 자료가 맡는다
