# 공통 화풍 참고

소유자가 모은 **상업 게임 캡처**를 게임별 폴더에 두고, 색인을 달아 엔티티 요청에 자동으로 붙이는 곳이다. 여기 그림은 **분위기·색감·구도·카메라·단순화 어법**만 보여 준다. 우리 그림의 정본은 여전히 [합격본 시트](../../docs/ambient/reference/README.md)이고, 어떤 자산도 복제·트레이스·`public/` 반출하지 않는다(ART-11, ADR-0021).

```text
art-src/공통화풍참고/
  분류어휘.json            닫힌 태그 목록 — 역할·종류·환경·부류(엔티티 ID 묶음)
  목록.md                  색인 요약. style:catalog가 굽는다(손으로 고치지 않는다)
  NOTICE.md                엔티티 레퍼런스(자유 라이선스) 출처 목록 — 이 폴더의 게임 캡처와 무관
  <출처 게임>/
    README.md              그 게임에서 무엇을 보는지
    공통화풍원칙.md          그 게임에서 읽어 낸 규칙(사람이 쓴다)
    색인.json              그림 한 장당 한 항목: sha256·크기·kind·style·view·subjects·env·time·season·role·flags·note
    분류대기.json           style:scan이 만드는 미분류 작업지(분류 뒤 apply하면 사라진다)
    **/*.png|jpg|webp      그림. 이름과 바이트는 그대로 둔다
```

| 위치 | 살펴볼 것 | 살펴보지 않을 것 |
|---|---|---|
| `공통화풍참고/<게임>/` | 전체 분위기, 색 온도, 화면 밀도, 카메라, 같은 부류를 단순화한 어법 | 특정 대상의 해부·구조, 게임 고유 디자인·캐릭터·UI |
| `<범주>/<엔티티>/레퍼런스/` | 해당 대상의 생김새·구조·생태(자유 라이선스 + sidecar: 픽셀아트·실물 사진) | 화풍 승인 |
| `docs/ambient/reference/` | 우리 합격 화풍·도트 어법 | 외부 작품 |

## 역할(색인의 `role`)

| role | 뜻 | 요청에 |
|---|---|---|
| `mood` | 장면 전체의 분위기·색·구도·카메라 | 엔티티의 환경·계절과 맞는 것 최대 2장 |
| `depiction` | 같은 부류 대상을 그 게임이 어떻게 덩어리·외곽선·색 단수로 단순화했는지 | 정확 일치 → 부류 → 범주 순으로 최대 3장 |
| `form` | 3D 렌더 등 비픽셀 자료의 비율·부위 배치 | 같은 부류의 그림체 참고가 없을 때만 1장 |
| `none` | 다른 게임·스톡·워터마크·UI·사진·출처 불명 | 첨부하지 않는다. 색인에는 남는다 |

기본 상한은 6장이며 `request --style-limit N` 또는 `--no-style`로 바꾼다. 스톡·워터마크·다른 게임 그림은 이 폴더에 있어도 `none`이다. 그 그림을 형태 참고로 쓰고 싶으면 라이선스를 확인하고 해당 엔티티 `레퍼런스/`에 sidecar와 함께 옮긴다.

## 새 그림을 넣었을 때

1. 게임 폴더 아무 곳에나 그림을 넣는다(새 게임이면 새 폴더). 이름을 바꿀 필요 없다.
2. `npm run style:scan -- --sheets` → `<게임>/분류대기.json` 작업지와 대조 시트가 생긴다.
3. 분류 에이전트(`.claude/agents/style-ref-classifier.md`)가 시트를 보고 작업지를 채운다. 새 폴더면 `slug`·`origin`·`usage`도 적는다.
4. `npm run style:apply -- "<게임 폴더>"` → 색인에 합치고 `목록.md`를 굽는다.
5. `npm run style:check` → 전부 색인됐는지, 바이트가 바뀌지 않았는지 확인한다.

그림을 지웠으면 `style:apply -- "<게임 폴더>" --prune`. 바이트가 바뀐 그림은 다시 분류 대상이 된다.

## 요청에 붙는 방식

```powershell
npm run style:pick -- tree-pine            # 어떤 장면이 붙을지 미리 본다
npm run art:pipeline -- request tree-pine --run <회차명> --variants 2,3
```

`request`는 고른 그림을 `작업회차/<회차>/고정입력/화풍참고/<slug>-<sha8>.<ext>`로 복사하고 request.json에 원본 경로·해시·역할·사유를 기록한다. 같은 폴더의 `화풍시트.png`는 그 사본들을 한 장에 라벨과 함께 모은 첨부용 보조 그림이다. 생성기는 저장소 경로를 열 수 없으므로 **고정입력 사본(또는 화풍시트)을 실제로 그림으로 첨부해야** 전달된다.
