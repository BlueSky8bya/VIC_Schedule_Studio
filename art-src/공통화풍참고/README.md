# 공통 화풍 참고

프로젝트 전체에서 원하는 **분위기·색감·구도·카메라·배치 감각**을 모으는 곳이다. 특정 나무·동물·물건의 생김새를 정하는 자료실이 아니다.

| 위치 | 살펴볼 것 | 살펴보지 않을 것 |
|---|---|---|
| `공통화풍참고/` | 전체 분위기, 색 조화, 화면 밀도, 카메라, 오브젝트 배치 | 특정 엔티티의 해부·구조·종 특징 |
| `<범주>/<엔티티>/레퍼런스/` | 해당 대상의 생김새, 구조, 생태, 실루엣 | 프로젝트 공통 화풍 승인 |
| `docs/ambient/reference/` | 우리 프로젝트의 합격 화풍·도트 어법 | 외부 작품의 자산이나 고유 디자인 |

합격 화풍과 충돌하면 `docs/ambient/reference/`가 우선한다. 이 폴더의 자료는 생성 요청에 자동 첨부되지 않는다. 실제로 전달한 그림은 작업회차 `고정입력/`과 `request.json`에 기록한다.

## 모여봐요 동물의 숲 자료

[모여봐요 동물의 숲](<모여봐요 동물의 숲/README.md>)에 화면 캡처나 참고 이미지를 넣을 수 있다. 현재 선별 결과와 적용 기준은 [공통화풍원칙](<모여봐요 동물의 숲/공통화풍원칙.md>)에 정리했다. 게임 자산·캐릭터·고유 오브젝트를 복제하거나 트레이스하지 않는다. 전체 느낌을 설명하는 자료로만 사용하며 `public/`에 복사하지 않는다.

새 자료에는 출처와 관찰 목적을 같은 폴더의 메모에 남긴다. 특정 대상 형태를 보려는 사진은 해당 엔티티의 `레퍼런스/`에 이미지와 `<파일>.json` 출처 기록을 함께 둔다.

```powershell
npm run ref:fetch -- tree --entity tree-pine --query "pine tree" --limit 20
npm run ref:notice
npm run ref:check
```

`ref:notice`와 `ref:check`는 엔티티 레퍼런스만 집계한다. 이 폴더의 외부 작품은 자동 CC0 목록에 섞지 않는다.
