# 공통화풍 원칙

69장을 실제로 열어 보고, 공통 환경 분위기를 분명히 보여 주는 플레이 화면 8장에서 반복 요소를 추출했다. 이 문서는 외부 작품의 자산을 복제하는 지시가 아니다. 프로젝트의 [합격 화풍](../../../docs/ambient/reference/README.md), [ART_RULES](../../../docs/ambient/ART_RULES.md), [VISUAL_DIRECTION](../../../docs/ambient/VISUAL_DIRECTION.md)이 항상 우선한다.

## 목표 인상

작고 포근한 세계가 한눈에 읽힌다. 화면은 밝고 친근하지만 장난감처럼 과밀하지 않다. 계절·시간·날씨가 전체 환경에 함께 스며들고, 오브젝트는 바닥과 물에 자연스럽게 붙어 있다.

## 적용 원칙

| 항목 | 공통 원칙 | 픽셀아트로 옮기는 방법 |
|---|---|---|
| 큰 형태 | 나무 수관, 강둑, 바위, 구름은 둥글고 큰 덩어리로 먼저 읽힌다. 작은 묘사는 큰 실루엣을 깨지 않는다. | 실제 표시 크기에서 1초 안에 읽히는 덩어리를 우선한다. 외곽은 계단이 자연스럽고 지나친 잔도트가 없다. |
| 카메라 | 생활 공간은 높은 3/4 시점, 바다·하늘 장면은 넓은 수평 공간을 쓴다. | 슬롯의 지정 카메라를 우선한다. 서 있는 물체는 윗면과 옆면이 함께 보이고, 납작한 물체는 지면 방향을 따른다. |
| 색 | 낮에는 맑은 청록·하늘색·초록이 넓은 바탕을 만들고, 계절색은 화면 전체에서 같은 온도로 변한다. | 물체당 6–10색과 낮은 단계 대비를 지킨다. 강한 빨강·주황은 작은 초점으로 제한하고 프로젝트 오행 팔레트에 맞춰 낮춘다. |
| 명암 | 낮은 부드러운 확산광, 밤은 청남색·보라 바탕 속에서도 형태가 남는다. 따뜻한 등불은 작은 국소 초점이다. | 순검정 덩어리와 매끈한 그라데이션을 쓰지 않는다. 같은 색 계열의 어두운 외곽선과 3–5단 명도 덩어리를 쓴다. |
| 공간 밀도 | 강·해변·수면처럼 쉬는 면과 나무·풀처럼 모이는 면이 번갈아 나온다. 균일 산포 대신 군집과 빈터가 있다. | 작은 소품을 전 화면에 같은 간격으로 뿌리지 않는다. 큰 덩어리, 보조 군집, 빈 공간 순으로 배치한다. |
| 접촉 | 해안선은 완만하게 굽고 얕은 물·포말·젖은 경계가 이어진다. 물체는 발밑 그림자·잔물결·가림으로 표면과 연결된다. | 지면판을 물체에 그려 넣지 않는다. 엔진 접촉 그림자와 충돌하지 않게 발점·수면선을 분명히 둔다. |
| 계절·시간 | 봄의 밝은 분홍·초록, 가을의 누른 바탕·탁한 주황, 밤의 청보라처럼 환경 전체가 같은 상태를 공유한다. | 단순 색 필터로 끝내지 않는다. 같은 변형의 실루엣은 유지하며 잎·지면·하늘·물의 상태를 함께 맞춘다. |
| 생명감 | 넓은 고요한 면 안에 물결, 꽃잎, 반짝임 같은 작은 움직임이 드물게 있다. | 애니메이션은 낮은 빈도와 서로 다른 위상을 쓴다. 반복 무늬나 동시에 흔들리는 장식은 피한다. |

## 우선순위

1. 우리 합격 시트의 도트 굵기·색 단수·외곽선
2. manifest의 슬롯별 크기·카메라·파일명·계절 계약
3. 이 문서의 공통 분위기·구도
4. 엔티티 `레퍼런스/`의 대상 형태·구조·생태

공통 참고 장수가 많아도 합격 시트보다 우선하지 않는다. 이미지 경로만 적었다고 생성기에 전달된 것이 아니다. 사용할 장면은 새 작업회차의 `고정입력/`과 `request.json`에 명시한다.

## 가져오지 않는 요소

- 게임 캐릭터 비율, 얼굴, 의상, 가구, 다리·등불·UI 같은 고유 디자인
- 스크린샷의 3D 표면 질감과 부드러운 렌더링을 그대로 흉내 낸 비픽셀 표현
- 도감 이름·문구·아이콘 배열과 화면 구성의 복제
- 워터마크 이미지, 출처 미기록 이미지, 서로 다른 픽셀 팩을 공통 화풍 기준으로 사용
- 개별 물고기·곤충·나무 사진을 공통 분위기 근거로 사용
