# 모여봐요 동물의 숲 화풍 참고

소유자가 넣은 캡처와 함께 모은 자료 263장. 파일 이름과 바이트는 그대로 두고 [색인.json](색인.json)이 역할을 정한다. 집계는 [목록](../목록.md), 읽어 낸 규칙은 [공통화풍원칙](공통화풍원칙.md).

| 위치 | 장수 | 역할 | 용도 |
|---|---:|---|---|
| `1-핵심-환경분위기/` | 8 | `mood` | 실제 플레이 화면 — 봄 강가, 낮·밤 해변, 가을 초원, 수면. 분위기·색감·구도·카메라 |
| 루트의 `<생물 이름>.webp` | 194 | `depiction` | 도감 아이콘. 같은 생물을 둥근 덩어리·진한 같은 계열 외곽선·적은 색으로 단순화한 어법. 바다 생물 아이콘은 작아서 `low-res` |
| `3-분류대기-대상자료/` 렌더 | 13 | `form` | 박물관 렌더(물고기·곤충). 비율·부위 배치만, 같은 부류 아이콘이 없을 때 1장 |
| `3-분류대기-대상자료/` 나머지 | 44 | `none` | 스톡 픽셀 팩·워터마크·사진·다른 게임·출처 불명. 첨부하지 않는다 |
| `2-보조-도감화면/`, 안내판 | 5 | `none` | 도감·안내판 UI. 정리 방식만 관찰, 복제 금지 |

`3-분류대기-대상자료/`의 스톡 그림(픽셀 소나무·참나무·바위·구름 등)은 라이선스가 확인되지 않아 첨부 후보가 아니다. 특정 엔티티에 형태 참고로 쓰려면 출처를 확인하고 sidecar를 만들어 해당 엔티티 `레퍼런스/`로 옮긴다. 옛 분류 receipt는 [이관기록](../../이관기록/20260909-common-style-reference-classification.json), 당시 선별 근거는 [선별기록](선별기록.md)에 남아 있다. 게임 자산·캐릭터·고유 오브젝트를 복제하거나 트레이스하지 않고 `public/`에 복사하지 않는다.
