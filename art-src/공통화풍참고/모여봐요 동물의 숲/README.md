# 모여봐요 동물의 숲 분위기 참고

화면 캡처·참고 이미지를 놓고, 같은 폴더의 별도 메모에 아래 내용을 기록한다. 현재 69장은 전부 보존하면서 역할별로 분류했다.

- 출처 또는 촬영 경로
- 참고할 분위기·색감·구도·카메라
- 따라 하지 않을 고유 캐릭터·오브젝트·UI

특정 엔티티의 생김새를 확인하는 자료는 해당 엔티티의 `레퍼런스/`에 둔다. 이 폴더의 이미지는 생성 요청에 자동 첨부되거나 `public/`으로 배포되지 않는다.

| 폴더 | 수량 | 용도 |
|---|---:|---|
| `1-핵심-환경분위기/` | 8 | 실제 플레이 화면에서 공통 분위기·색감·구도·카메라 관찰 |
| `2-보조-도감화면/` | 5 | 도감의 친근한 정리 방식만 보조 관찰. 게임 UI 복제 금지 |
| `3-분류대기-대상자료/` | 56 | 개별 생물·식물·바위 사진, 혼합 픽셀 스타일, 워터마크 자료. 공통 화풍 근거로 사용 금지 |

적용 기준은 [공통화풍원칙](공통화풍원칙.md), 선별 근거와 출처 상태는 [선별기록](선별기록.md), 전 파일 경로·해시는 [분류 receipt](../../이관기록/20260909-common-style-reference-classification.json)에서 확인한다.
