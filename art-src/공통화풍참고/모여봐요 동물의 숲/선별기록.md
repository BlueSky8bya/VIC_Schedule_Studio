# 참고 이미지 선별 기록

검토일: 2026-09-09 KST. 직접 자식 이미지 69장을 전체 확인했다. 원본 바이트와 파일명은 유지하고 세 하위 폴더로 이동했다.

## 판정

- **핵심 환경 분위기 8장:** 실제 플레이 환경, 낮·밤·봄·가을·해변·강·수면을 보여 주므로 공통 원칙 추출에 사용했다.
- **도감 화면 보조 5장:** 친근한 분류와 단순한 아이콘 표현을 보는 보조 자료다. UI·문구·아이콘 배열은 복제하지 않는다.
- **분류 대기 56장:** 개별 물고기·곤충·식물 사진, 독립 픽셀 에셋, 워터마크 이미지, 다른 게임/일러스트가 섞여 있다. 공통 화풍 입력으로 쓰지 않는다. 특정 엔티티에 필요하면 출처를 확인하고 sidecar를 만든 뒤 해당 엔티티 `레퍼런스/`로 별도 이관한다.

## 출처 상태

현재 이미지에는 원본 URL·촬영 경로 메모가 없다. 따라서 핵심 8장도 **관찰 자료**일 뿐, 작업회차 고정 입력으로 바로 사용할 수 없다. 실제 생성에 첨부하려면 출처 또는 소유자 제공 경로, 선택 이유, 이미지 해시를 새 run에 기록한다.

전체 파일의 이전·현재 경로, 바이트 수, SHA-256은 [분류 receipt](../../이관기록/20260909-common-style-reference-classification.json)에 있다.
