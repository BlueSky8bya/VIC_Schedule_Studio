# 숲 사계절 분리 레이어 검토

2026-09-15 KST. 사용자가 숲 구도를 승인하고, 나중에 나무 사이로 동물이 나올 수 있도록 뿌리 기준 분리 작업을 요청했다. 로컬 구현·검증 완료. 최종 화면의 사용자 감상 확인은 다음 단계이며 아직 푸시하지 않았다.

- [요청 원문·실제 입력](request.md), [8개 원본/런타임 해시·규격](delivery.json). 원본과 public 복사본 8개 모두 SHA256 일치 확인. 생성 원본은 수정하지 않고 런타임에서 알파 처리한다.
- 지면/먼 숲 4장, 계절별 분리 나무 atlas 4장. 나무 18개를 독립 뿌리에 배치. 중앙 공터와 하늘 유지. 나무·그림자는 동일 뿌리 변환, 낙엽과 앞뒤 순서 공유. 미래 동물도 같은 순서에 참여할 연결 경로 정리.
- 수관 내부 빈틈은 실제 투명 영역. 여름·겨울 실제 이미지에 임시 물체를 그려 줄기 뒤 가림, 앞 노출, 가지 사이 노출, 마우스 시차 이동 시 가림 유지까지 확인. 실물 동물은 추가하지 않음.
- A: 최종 사계절 낮/밤 8장 검토, 수관 사각 잘림·막힌 빈틈·뜬 뿌리·넓은 매트 얼룩 차단 문제 없음. 비차단 관찰: 봄/여름 일부 잎 끝의 따뜻한 하이라이트와 전경/중경 입자감 차이. 잔여 매트 여부는 화면만으로 확정 불가.
- B: 뿌리 기반 순서·가려진 낙엽 클릭 처리 확인. 발견한 미래 동물 순서 문제 수정 후 재검토 통과.
- C: 계절·KST·공용 하늘·로딩 정리·모바일/정지 게이트 차단 문제 없음.
- 타입·린트·빌드·908 단위 테스트 통과. 실제 사계절 잡기/놓기, 이동, 900/2560/3840 너비, 저성능/정지/모바일/이미지 실패 복구 확인. 세부 수치와 한계는 [R59](../../../../../docs/ambient/rounds/ROUND-59-forest-layers.md).

캡처는 로컬 `.scratch-pw/qa/r59/`. 실제 기기별 FPS·OBS·운영 배포는 미검증. 이 숲 배경 레이어 승인은 별도 소나무 엔티티 카탈로그 작업을 변경하지 않는다.

후속 사용자 피드백: 전경 두 그루만 보여 숲답지 않음. 중경 줄기가 드러나도록 8개 추가·엇갈린 배치, 전경 두 그루 축소. 생성 원본은 동일하며 자세한 재검증은 R59 기록 참조.

추가 사용자 피드백(과수원 같은 정형 배치·밑동 연결): 좌우 짝 배치를 비대칭 군집과 크기 차이로 변경. 해당 위치의 계절 지면을 나무 밑동 실루엣 안에만 부드럽게 겹쳐 접지 보완. 원본 이미지 변경 없음. B 가림 판정 보완 후 재검토 통과, C 수명/계절 처리 차단 문제 없음. 최종 빌드·사계절 상호작용·실물 이미지 가림 probe 통과.

최신 사용자 결정: 중앙을 비우던 이전 기준 폐기. 중앙 원·중·근경에 7그루 추가하여 총25그루, 숲속을 관통하던 빈 통로 제거. 하늘은 수관 위로 유지. 원본은 재사용하며 R59 후속 기록 참조.
