# 숲 근경 축척 보정

요청: 배경 앞부분을 훨씬 더 세밀하게. 기존 원경은 유지하고 가까운 흙·잘게 쌓인 낙엽·낮은 식생만 개선한다. 봄·여름·가을·겨울 네 장. 원본 크기를 두 배로 늘렸다는 의미가 아니다.

정확한 생성 요청은 여름요청.txt 및 spring/autumn/winter요청.txt. 여름 편집 입력은 고정입력/큰낙엽반려.png. 그 결과를 실제로 확인한 후 세 계절 편집에 같은 여름 이미지를 사용했다(고정입력/여름근경보정.png, public 여름 v2와 동일 바이트). 내장 imagegen 사용. 외부 사진/게임 캡처 입력 없음.

원본의 forest-ground-detail-{season}-v2.png 네 장을 같은 이름 public/ambient/art에 바이트 변경 없이 복사. 런타임에서 기존 숲 바닥 하단과 부드럽게 합성. 요청한 미세 잎 크기는 생성 지침이며 실제 모든 잎이 8픽셀 이하라는 측정 주장은 하지 않는다. 실제 크기·용량·해시는 delivery.json.
