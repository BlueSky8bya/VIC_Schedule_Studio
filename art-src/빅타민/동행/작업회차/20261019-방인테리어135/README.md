## 배치와 검사 경계

기존 소파 SVG 경로·좌석·전면 가림, 음식 출구·상자 입구, 125 계절/시간 풍경과126 커튼5단계는 유지한다. 낮/밤/전등은 배경·빛층 및 소파 공통 색 토큰을 바꾼다. foreground portal과 다른 필터를 쓰지 않는다. TV는 고정 본체에 화면만 올리고 실제 그림을 왼쪽 소파 쪽으로30도 돌린다. 패드는 상자·쓰레기통의 alpha>32 실제 그림 bounds 사이 최단선의 중점에 둔다.

수동 TV는 OFF→자연→음악→요리→장난감→달별→OFF의 유한 순환이다. 음원·외부 stream·새 시계·자동 AI·성격 학습을 추가하지 않는다. 전등도 수동 ON/OFF다. 새 그림과 버튼은 기존 측정 발판을 대체하지 않는다.
