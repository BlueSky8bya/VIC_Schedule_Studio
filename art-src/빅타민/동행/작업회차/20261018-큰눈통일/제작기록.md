# 빅타민 큰 눈 통일

각 폴더에 실제 원문에 연결된 회차·사전검사·편집 범위·생성자 관찰·원본 output 복사 SHA를 기록했다. 원래 PNG와 과거 패킹/등록은 보존했다. 원문 전체는 `원문피드백.json`, 실제 UI 입력 snapshot과 원본 기준은 각 `제작계약.json`에 있다. 원본 기준의 작은 점눈은 최신 사용자 요청의 눈 크기만큼 대체하며 다른 인물 그림의 규칙으로 확대하지 않는다.

후처리는 새 전체 키 crop·동일 비율 등록·기존 offline 귀/종이 rig·WebP 패킹뿐이다. 눈/입을 수작업으로 그리거나 얼굴을 붙이지 않는다. PLAY 일부 원화의 귀 가림은 기존 런타임의4개 EARS 키 치환으로 대응한다. `패킹입력.json`이7새원본/등록과 교체 전 metadata를 SHA로 고정하며 `패킹파생기록.json`이 최종512슬롯/33행/32packet·응원단의 새 원본 계보를 기록한다. 호환 전용 row7 slot127을 제외하면 실제 사용되는 슬롯450개, 전체 row의 고유 참조는451개다.
