# 빅타민 눈 간격·크기 정합 143 — 생성·기계등록 초안

현재 서기 그림을 기준으로 포즈마다 달라 보이는 눈을 맞춰 달라는 요청에 따른 새 버전이다. 기존 131·133 그림, 099 원본과 기존 런타임 패킷은 덮어쓰지 않았다. 자동 전문 검수·재생성은 하지 않았다. **생성 1회, 소유자 미술 승인 NONE, 실제 런타임 적용·표시 검사는 미실행**이다.

실제 builtin 생성 결과는 `../../원본/단일생성_눈정렬143.png` 하나다. 원본 SHA256은 `1b1dc2d4abf68a9a5e8125f222ffbe296b7f213f2fb034d970fadbe9972b3acf`이다. 원본 REF-016과 현재 서기 셀은 외형·기준 크기 참조로 사용했다. 전체 사용자 원문, 외부 원본 경로, 계약·claim·캡처는 로컬 근거이며 공개 자료에 포함하지 않는다.

생성본을 단순 축소한 눈 간격은 목표와 맞지 않았다. 같은 생성본의 실제 눈 성분을 측정해 눈마다 등비 크기와 위치를 등록했다. 손으로 눈을 그리거나 다른 셀의 눈을 복제하지 않았다. 생성 RGB는 미리 선언한 각 셀의 눈 영역 중 실제 볼·입 보호 영역을 제외한 부분에만 채택했다. 부모 알파와 나머지 RGBA는 그대로다. 입과 그 주변 1px은 실제 원본과 완전히 같다.

수정 범위는 physical144~159(쓰다듬기 논리 행9)와 physical376~383(전역 source atlas23, play atlas4, 논리 행24의 정면 절반)이다. **논리 행23은 source22/play03이며 이번 교정 대상이 아니다.** 368~375의 비스듬한 회복 그림, 뒷모습과 다른496프레임은 보존했다. 520개의 프레임·clip·몸/얼굴 중심/귀/머리/운반 anchor 좌표도 바꾸지 않는다. 모든 다른 포즈의 눈 크기 문제를 해결했다는 의미가 아니다.

동일한 RGBA 어두운 성분 판정(r<120, g<100, b<90, alpha>160, 8연결)으로 서기 양눈 중심 간격은192셀 기준33.936px이다. 후보는 쓰다듬기33.320~34.347px, 정면 회복33.012~33.225px이다. 각각의 눈 폭은11~13px이다. 감은 눈 높이는7~8px, 찡그린 눈은11~13px로 서로 다른 표정을 유지한다. 닫힌 눈을 열린 동공의 높이에 억지로 맞추지 않았다. 프레임 내 눈쌍 중심 최대 이동은0.266/0.656px, 인접 눈쌍 각도 최대 차이는1.351/0.675°이다. 이는 수치 관찰이며 실제 애니메이션의 미술 승인이나 완전한 연속성 보증이 아니다.

새 패킷은 기존과 같은1536×384, 8×2셀의 lossless exact WebP이다. 두 파일 합486,678B다. 정리 PNG와 WebP의 전체 decoded RGBA도 같다. 새 TypeScript source registry만 정확한 이전 src·SHA에 대해 새 이미지를 선택하고24개의 실제 눈 박스를 덧댄다. 기존 hd/play/mouth/accessory JSON 네 파일은 보존한다. 알 수 없거나 달라진 이전 소스는 새 그림의 정보를 빌려 쓰지 않는다.
