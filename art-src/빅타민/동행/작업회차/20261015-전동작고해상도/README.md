# 전 동작 고해상도 · 기계적 파생

PLAN052. 기존 원본과 이전 공개 파일은 보존한다. 새로운 감정 원화는 원본 REF016/017만 입력으로 builtin imagegen 한 번 생성한16키포즈이며 사용자 시각 승인은 아직 없다.

- 기존 고해상도16키포즈의 실제 몸 폭243–265px와 새 감정 원화를 텍스처로 쓴다. 작은256셀 원본은 움직임 폭·높이·귀 중심의 측정값만 제공하며 RGB를 확대하지 않는다.
-304런타임 슬롯/20논리 행을 오프라인 유한2D rig로 생성했다. 이는304새 손그림이나 원본256그림의 정확한 복원이 아니다. 얼굴·볼은 함께 rigid 변환하고 귀와 주변 종이층만 제한된 연속 변형한다. 서로 다른 키 그림의 표현은 이산 전환한다.
-192물리/80논리 셀,1536×384 액션 strip19개. strip별2.25MiB RGBA, 완료된 Image 강참조 LRU3개6.75MiB와 동시 decode2개4.5MiB를 구분한다. CSS 현재/이전 그림·브라우저 캐시/GPU 중복은 별도이므로 총 메모리 상한으로 주장하지 않는다.19개 모두 디코드하면42.75MiB다. 네트워크 합3170328B.
-원본 alpha1 RGB 점의 검은/흰 프리뷰는 불투명 찌꺼기라고 단정하지 않는다. alpha>160 주연결 몸 등록, 논리 clip여백2, 인코딩 alpha변경0. 원본에 이미 닿은 경계와 새 감정 키의 작은 부가 표시를 새 해부학으로 복원/삭제하지 않는다.

재현: `node scripts/prepare-viewer-companion-hd.mjs --check`. 원본 SHA·샘플링·프레임별 텍스처/rig/등록/밀도·한계는 [파생기록](파생기록.json). 최종92CSS·DPR2 시각/브라우저 메모리/실제 기기 검증은 별도이며 이 스크립트가 승인하지 않는다.
