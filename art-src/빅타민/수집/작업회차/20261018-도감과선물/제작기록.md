# 106 도감과 선물 제작 기록

2026-10-18 KST. 생성 원본과 기계적 파생물의 출처 기록이다. 사용자 시각 승인 상태는 `NONE`, 전체 전문 검수는 `NOT_REQUESTED`다. 생성자 전체 관찰, 패킹 수치, 오프라인 착용 합성은 이 두 상태를 바꾸지 않는다.

## 범위와 원본

[106 계획](../../../../../docs/agent/plans/PLAN-20261018-106-companion-discovery-and-gifts.md)의 현행 사용자 요청으로 빅타민 발견 도감, 먹거리와 도장 쌍, 행동 도장, 선물과 장신구를 추가했다. 이전의 도감·꾸미기 제안 전용 범위는 이 요청으로 대체된다. 장신구는 브라우저 안 빅타민 소지품에 한정하며, 철수한 일반 달력 꾸미기·스티커 기능을 복원하지 않는다.

기존 101 기본 렌더, 선택된 099 상대 눈 크기와 원래 빅타민 설계를 읽기 전용 기준으로 삼았다. 기존 눈·몸·두 귀 원본은 교체하지 않았다. 선글라스의 눈 가림은 요청된 착용 효과이며 눈 자체를 다시 그린 것이 아니다. 작은 모자·화관은 두 귀 끝과 눈·입을 드러내는 등록 위치를 쓰며, 모자 본체가 보이도록 귀뿌리의 낮은 부분에 한 겹으로 착용한다. 두 겹/일부 clip 방식은 native92px에서 장식이 띠처럼만 보여 대체했다. 정확한 입력 권한과 공개 가능한 SHA는 [제작범위](제작범위.json)에 있다. 그 파일의 준비 상태는 생성 이전 스냅샷이며, 현재 산출물은 아래 원본과 패킹 영수증이 증명한다.

실제 생성 도구는 루트 담당자의 기본 imagegen이었다. 시트마다 한 번, 총 여섯 번 생성했다. 음식·장신구·책/선물에는 캐릭터가 없고 행동 도장에만 빅타민이 있다. 모든 원본은 flat `원본/`에 보존했다. 원문 대화·비공개 인물 자료·내부 증빙 경로는 이 기록과 Git 산출물에 포함하지 않는다.

행동 도장의 공개 요청은 [행동도장공개요청.json](행동도장공개요청.json)에 프롬프트·참조 식별자/SHA·실제 로컬 요청 SHA를 보존한다. 비공개 절대 참조 경로가 있는 실제 인자 원본은 로컬에만 보관하고 Git에서 제외한다.

## 패킹과 런타임 등록

[패킹기록.json](정리본/패킹기록.json)은 6원본 SHA, 실제 알파, 원본 crop, 알파 trim, 등방 리사이즈 크기, 셀 여백, RGBA SHA와 5최종 WebP SHA를 묶는다. 원본의 RGB 배경색이 있어도 alpha0이면 투명 픽셀이다. 색상 키잉, 불투명도 보정, 재그림, 원본 덮어쓰기를 하지 않았다.

## 포즈 등록과 오프라인 착용 근거

`lib/ui/viewer-companion/accessory-anchors.json`은 현재 33개 캐릭터 패킷/41논리 행의520 실제 physical frame을 모두 등록한다. 입력 메타데이터3개와 패킷33개 SHA에 묶인 logical80 좌표이며, 얼굴/귀 뿌리/몸 알파 단면과 필요한 명시적 원본 키 관찰에서 앵커를 얻었다. 현재 파일 SHA는 `d51aa7bb482e18615cbde0cc3735a1d23814b508ae2d04fec37eccc6422bdf37`다. 재현 명령은 `node scripts/prepare-companion-accessory-anchors.mjs --check`다.

몸의 평면 회전과 정면/사선/뒤 시점을 구분한다. 실제 눈 없는 뒤돌기 셀에는 보이지 않는 눈을 발명하지 않았다. 기존 캐릭터에 순수 해부학적 side 전용 포즈가 없으므로520 프레임에 side를 억지 배정하지 않는다. 생성된 네 시점 cutout은 보존하며 실제 채택된 그림의 시점만 고른다. 요청된 다음 그림이 아직 디코드되지 않았을 때도 장신구는 실제 화면에 남은 채택 프레임의 앵커를 사용한다.

오프라인 착용 witness는 대표 physical21포즈 `0,32,128,224,272,288,323,326,328,331,440,500,508,512,513,514,515,516,517,518,519` ×장신구6 =126합성이다. 실제 `companionAccessoryPlacement()` 결과와 원래 cutout을 사용해 뒤/몸/앞 순서로 합성했다. `.scratch-pw/companion-106/wear-*.png` 여섯 장과 `wearable-qa.json`에 원본 불변·코드/앵커 SHA·샘플이 있다. 생성 담당자의 실제 시트 열람은 전문 검수나 전체520포즈의 브라우저 실물 검사와 다르다.

같은 포즈 painter120회 반복에서 추가 CSS쓰기0, 21포즈×3크기×2좌우의 선물 hit 역투영 오차0을 측정했다. 이는 순수 수치/오프라인 검증이다. 실제 DOM, 키보드, 디코드 지연, 최초공개, 쿠션 가림과 모션 조건은 별도 native 검사 대상으로 남는다. witness JSON SHA는 `8b48ebebbb6236159950afd3b9911bfcf10991394522659721955cba1d8de2c3`다.

생성자 관찰상 행동 도장12개와 두 귀/무사지 구조가 분리되어 보였다. 꾹꾹이·자리 만들기의 압력 차이는 작아 보통 기쁨/차분함으로 읽힐 수 있다는 관찰을 보존한다. 도장은 수집 상징이며 기존 runtime pose를 교체하지 않는다. 행동 원본은 `DRAFT_DELIVERED_FOR_USER_REVIEW`, 승인 `NONE`, 전체 전문 검수 `NOT_REQUESTED`로 등록했다.
