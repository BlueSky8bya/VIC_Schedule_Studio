생성 원본8장과 고정 수집목록 v2를 읽어96개 소품을 분리했다. 이 문서는 제작자의 기술 측정과 실제 표시 관찰이며, 독립 미술검수나 인간의 시각 승인을 대신하지 않는다. 이 패킹 작업의 이미지 생성 횟수는0이다.

- 원본7장은1448×1086, 간식4는1447×1087이다. 명목4열3행을 그대로 잘랐다면 접시 끝·토끼 귀 등이 잘리므로 실제 연결성으로 대상을 귀속했다.
- alpha≥32 연결성은 위치 판정에만 사용했다. 약한 가장자리와 고립된 작은 점을 포함한 모든 alpha>0 픽셀을 정확히 한 대상으로 귀속했고, 원래 RGBA를 그대로 원본분리 PNG에 복사했다. 분할맵0은 완전투명 바탕,1..12는 고정된 행 우선 항목 번호다. 누락·중복·보이는 원RGBA 불일치0은 원본 전체를 다시 대조한 실제 검사 결과다.
- 간식2의 돈가스·함박 접시가 원본에서 서로 닿는다. 해당 연결 부위만 x397을 경계로 귀속했다. 원래 픽셀을 새로 그리거나 복구하지 않았다. 이것은 원본의 인접 경계 모호함이며, 원래 없는 접시 외곽을 복원했다는 주장이 아니다.104px 확대와32/28px 표시에서 눈에 띄는 잘린 단면·이웃 음식 색 혼입은 관찰하지 못했다.

- WebP lossless는 완전투명 픽셀의 보이지 않는 RGB를 재예측한다. 모든 alpha 값과 alpha>0의 RGB가 크기 정리 입력과 정확히 같은지 먼저 검사했다. 최종 정리 PNG는 실제 WebP decode에서 보존했으므로 PNG↔런타임 전체 RGBA도 정확히 같다. 원본과 크기 정리 결과의 픽셀이 동일하다는 뜻은 아니다.

## 실제 작은 표시 관찰

검토 PNG4장을 실제 열람했다. 음식60종은 고정 순서와 일치하며 마지막 가리비·굴, 장난감의 하트컴팩트 등도 확인했다.32px와28px 음식 표시는 서로 다른 실루엣을 유지한다. 사진처럼 원본을 크게 보았을 때의 세부 질감이 작은 표시에서 모두 남는다는 주장은 하지 않는다.

장난감은 고정 목록에서 예상한 그림 비율과 실제 그림 비율이 다르다. 비눗방울 막대·부메랑·원반·하모니카·컵받기·패들볼은 현재 표시 상자에서 몸체 긴 변이 약20.9..25.0px다. 원본 픽셀과 희미한 가장자리를 버리지 않고 보존한 결과이기도 하다. 원본을 다시 그리거나 자르지 않고,6개 표시 상자의 가로·세로를 실제 그림에 맞추는 보완을 별도 제안했다. 현재 패킹은 그 표시 치수를 임의로 변경하지 않았다. 큐브의 약25.5px 몸체는 작은 물체로 유지하는 선택도 가능하다.

초기 PNG/WebP 전체RGBA 비교 실패는 완전투명 RGB의 codec 처리 차이였다. 초기 정리 PNG12개와v2 PNG12개는 보존하고 최종 스테이지 목록에서 제외했다. 이 기술 실패를 미술 반려나 추가 이미지 생성으로 바꾸지 않았다. 최종 자료는 명세가 참조하는v3 PNG와 실제 WebP뿐이다.
