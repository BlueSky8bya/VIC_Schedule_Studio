# 107 — 음식·추억·장신구

2026-10-18 KST. 생성·기술 검수 결과이며 사용자 그림체 승인이나 전문 전체 검수 PASS를 뜻하지 않는다.

## 제작과 보존

- 음식24종의 실물/도장48칸, 새 장신구5종×4시점20칸, 상황 도장12칸을 각각 별도 요청으로 총4회 생성했다. 재시도·원본 덧그리기 없이 제공된 native RGBA를 `원본`에 그대로 보존했다.
- 첨부 픽셀 선글라스는 새 코드 기반 벡터4시점으로 만들었다. 사진의 배경·서명·워터마크는 복제하지 않았다. 기존 음식36종·장신구6종·106원본/패킹 바이트는 보존했다.
- 따라서 새 원본8개, 파생84칸, lossless WebP4개다. 장신구 원본 이름의 ‘여섯종’은 픽셀 선글라스까지 포함한 전달 범위이며, 생성된 PNG 자체는5열×4행이다.
- 상황 도장은 현재101 렌더, 선택099 눈 크기, 읽기 전용 원형 REF-016/017을 실제 확인하고 참조했다. 신체·눈·귀 원본과 기존520포즈 좌표를 교체하지 않는다. 인물 관련 실제 요청·개인 경로·정확한 도구 인자는 제한된 로컬 증거에만 보관한다.
- 상황 회차 `12159A2D40AB1B7062CB`는 생성 후 원본 SHA에 대해 초안으로 등록했다. 승인 NONE, 전문 전체 검수 NOT_REQUESTED. `제작범위.json`의 preparation 상태는 생성 전 동결 시점 기록이다.

## 실제 관찰과 처리

- 음식04는 요청한9번째 와플이12번째 쌍으로 나왔다. 요청 순서와 실제 칸 순서를 별도 기록해 와플·도넛·머핀·컵케이크를 올바른 ID에 매핑했다. 원본 순서를 고쳐 그리지 않았다. 음식05는 요청 순서와 일치했다.
- 상황 도장은4열×3행으로 실제12개가 있다. 음식에 걸림 도장은 사과 옆 급한 움직임을 표현해, 별도 달리다 구름 도장보다 구르는 상징이 약하다. 집에서 잠들기에는 요청과 달리 작은 Z가 포함됐다. 해당 제공 결과를 보존하고 한계를 기록한다.
- 새 장신구와 기존 목 장식의 실제 합성을 검토하다 목도리·방울·리본이 일부 포즈의 눈/입을 덮는 문제를 찾았다. 원본 그림 대신 런타임 비율/얼굴 안전영역을 교정했다. 눈·입 검출 후보는0으로 줄었으며, 귀 후보20은 의도된 모자 겹침/검출 한계가 포함돼 전문 그림체 PASS로 해석하지 않는다.
- 패킹은 전체 alpha 연결 요소를 보존하고 투명 여백만 정리한 뒤 동일 비율로 축소한다. 픽셀 선글라스는 nearest-neighbor를 사용한다. `정리본/패킹기록.json`이 원본/파생 SHA와 실제 픽셀 수를 기록한다.

## 재현 검사

`node scripts/prepare-companion-collection.mjs --edition=107 --check` 및 기존106 기본 `--check`로 파생 파일을 재현한다. `node scripts/verify-companion-accessory-render.mjs`는 제품의 실제 배치/페인터/동작 함수를 사용한다. 520포즈×12장식=6,240매핑, 대표21포즈×12=252합성,132동작 샘플을 확인한다. 이는 실제 브라우저의 모든520포즈를 자동으로 봤다는 뜻이 아니다. 실제 상호작용과 음향은107 제품 검증 기록에 별도 남긴다.
