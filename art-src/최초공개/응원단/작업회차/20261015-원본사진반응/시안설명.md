# 원본 사진 반응 · 2026-10-15

최신 사용자 요청: 생성 표정 대신 기존 레퍼런스 사진을 쓰고, 기대 입력 때 짧게 깜빡여 웃음/경멸 사진으로 바꾼다. 실제 REF-004(기본)/REF-284(환한 웃음)/REF-120(경멸) 전체를 열고 읽었다. 원본을 고정입력에 그대로 보존하고 SHA를 검사한다.

`node scripts/prepare-premiere-reference-photos.mjs`는 사진 한 장 전체의 사각 crop→균일 축소→WebP만 수행한다. 얼굴 부품·머리를 다른 몸에 붙이지 않으며 눈매/입/기울기를 재그리거나 워핑하지 않는다. 각 원본의 의상/빛/배경/기울기를 유지하며 같은 4:5 사진창 안에서 국소 암전 중 전환한다. 원본 카메라 차이는 존재한다. 이는 새 얼굴 생성이나 "정면 표정 인증"이 아니다.

파생 3장 합계78,960bytes(각320×400), 메타데이터 제외. 실제 crop 좌표·원본/출력 SHA는 [파생기록](파생기록.json). 공개 파일은 `public/premiere/tori-photo-{neutral,delighted,unimpressed}.webp`다. 생성0회. 생성 표정 public2장은 제거하고 이전 원본/반려 시안은 이력으로 보존한다. 기본 V 포즈 배지와 빅타민 atlas는 별도 기존 자산 그대로다.

입력/사진 전환·관객 안무의 기능 및 운영 검증은 [PLAN-038](../../../../../docs/agent/plans/PLAN-20261015-038-premiere-reference-reactions.md)에서 이어진다. 사용자 시각 승인/독립 미술 PASS는 주장하지 않는다.
