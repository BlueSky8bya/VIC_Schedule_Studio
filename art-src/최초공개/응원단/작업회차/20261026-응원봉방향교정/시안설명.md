# 최초공개 응원봉 방향 교정 · 2026-10-26

기존 16프레임의 보라색 발광부가 몸 부착점 아래로 향하던 사용자 지적에 대한 국소 교정. REF-016/017 원본과 현재 전체 atlas를 실제 열람했다. builtin imagegen 1회로 기존 발광부에 가려진 종이층을 복원했다. 실제 생성문은 `생성문.txt`, 반환 원본은 `원본/가려진종이층복원.png`다. 두 원본 설계는 읽기 전용 입력이며 이 파일은 원본 설계를 새로 승인한 기록이 아니다.

`scripts/prepare-premiere-lightsticks.mjs`가 기존 발광부 영역 안에서만 복원 그림을 소비하고, **기존 보라색 발광부 픽셀**을 실제 부착점 주위로 반 바퀴 돌려 위로 배치한다. 다른 얼굴/귀/몸/자세/배치와 원본 atlas 파일은 보존한다. 합성 PNG는 발광부 이동·복원 영역 밖 decoded RGBA 변경0이며 원본 반려 셀9/10의 실행 제외를 유지한다. 생성 raw와 합성 final은 별개이며 숫자 보존 검사는 미술 승인이나 독립 미술 PASS가 아니다.

초기 CSS 클립 방식은 원래 발광부 뒤 몸이 투명하게 뚫려 폐기했다. 최종은 새 runtime PNG 하나를 기존 renderer가 읽으며 타이머/레이어/응원 버튼/활동 수집을 추가하지 않는다. 16셀 전체와 실제 크기를 생성자가 확인하고 제품 QA는 해당 계획에 별도 기록한다. 현재 사용자 요청은 제품 결함 교정/배포 범위이며 별도 새 전체 미술 승인은 주장하지 않는다.
